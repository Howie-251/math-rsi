# README navigation badges

Eight local, editable SVGs provide four two-part links in English and Chinese. Each badge is 24px tall with 4px corners and 12px text. The shared left segment is `#0F172A`; right segments use `#0D9488` (quick start), `#2563EB` (results), `#4F46E5` (visual tour) and `#334155` (agent guide).

Edit the SVG text, width and segment coordinates directly; there is no build step or external image service. Link destinations live in the two root README files. Language switching is separate. These are navigation labels, without release, paper or popularity claims.
