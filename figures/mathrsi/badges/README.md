# README navigation badges

Ten local, editable SVGs provide five two-part links in English and Chinese. Each badge is 24px tall with 4px corners and 12px text. The shared left segment is `#0F172A`; right segments use `#0D9488` (quick start), `#2563EB` (results), `#4F46E5` (website), `#334155` (agent guide) and `#7C3AED` (contributors).

Edit the SVG text, width and segment coordinates directly; there is no build step or external image service. Link destinations live in the two root README files. The compact `lang-cn.svg` and `lang-en.svg` badges switch between the two README languages; both use the same 24px height and 4px corners. These are navigation labels, without release, paper or popularity claims.

The website badge appears first and links to the public homepage. Its existing `visual-tour.svg` / `visual-tour.zh-CN.svg` filenames are retained.

The `contributors.svg` / `contributors.zh-CN.svg` badges link to the explicit `#contributors` anchor in each README.
