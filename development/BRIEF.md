# 首版开发事实与边界

用户要求：本地 MathRSI 仓库，base／领域插件／单题工作区，详细 Markdown 为主、薄 Python。充分发挥 agent 自主推理与选路，ARIS 能复用就复用；需要深入解释而非简单 SOP。开发中与 Gemini 4、Grok 讨论；不推远端、不恢复原数学 Goal。

## 已确定的设计

base 固定目标量词和验收、组织证明义务与替代路线、按需检索文献与 wiki、委派、诊断停滞、调用验证和交接。插件提供对象、定理与条件、归约、表示、策略、计算与验证适配。工作区保存具体题目的原始规格和研究过程。插件不能在解题过程中更改 base 与验收，但可提出单独评估的核心改进。

接口用五类人可读信息表达：任务、义务与连接、行动提案、结果与证据、验证能力。优先 Markdown；不强制统一 JSON 状态机、数值 score 或自动完成 gate。义务有共同依赖，也有可替代路线；不是所有节点必须完成。简单证明可以不拆图、不叫模型、不启 Lean。

## 经原项目核对的事实

- Property B：多个局部布局共同约束同一实际超图与坏对，不能分别取最坏后忘记共同对象；某个单项改善可能完全不改变实际总界。先连接实际选点、真实类型和原染色，再扩算。局部表合法与分类完整是不同义务。
- ECC：一个实际满秩矩阵且全部非零消息达距，足以证明存在；搜索无需完备。全域不存在性则须原对象无损归约、目录覆盖、保留集合无遗漏、全部拒绝和实际输入绑定。相同领域内部具有多种不同验证能力。
- ECC 历史172类目录可由实际172代表、两两不等价和外部“至多172类”定理闭合；发现过程可启发式。母码数量减少不必然降低联合扩张成本。
- 两个单独无损的规范化组合可能冲突，必须证明它们在同一对象上可同时成立。固定三个零锚点与后续边际规范化曾占用同一自由度。
- ECC 一批证据824370文件／125.836GiB；内核秒数不能代表准备、证据输出、独核和交接成本。
- 验证器挂具体义务。它验证的命题、实际输入、范围和剩余数学连接要明确。模型认可、自然语言证明、精确计算、Lean与原题对齐不能排成自动升级等级。
- 停止原因分清：固定域完成则复用；无信息增量需重新思考；仅预算不足可在资源和授权允许时沿原法继续。两轮无进展触发重新判断，不机械放弃困难数学。

## 第一版的实际交付

一个详细主技能 `base/skills/mathrsi-research/SKILL.md`，有真实分支决策、委派提示、验收和恢复示例；按需读取 references/ 的效率／证据说明。两个领域技能位于 `plugins/<domain>/skills/mathrsi-<domain>/SKILL.md`。`docs/ARIS_REUSE.md` 解释具体复用与数学差异；`docs/WORKSPACE.md` 用 Markdown 给工作区起步和恢复方式。原有检查器以命令和阅读地图接入，不造统一求解引擎。Python至多一个可选的只读文档连接小工具；能用现有工具就不用新写。

复用来源：本机 ARIS 提交 c485faa59a68e51c6575dea67ca57abc7a6a2b9c；用户指名 `skills/auto-review-loop/SKILL.md`（当前1211行，含大量宿主与reviewer细节），借鉴其解释粒度、持续状态、原回应、修正后再审，不照搬实验评分作为数学真伪。准确宿主版依实际安装选择。

可读背景在 development/context/：既有设计、ECC比较、仓库方案，以及ARIS自动审阅完整原文。它们是本地开发上下文，不随默认代码提交复制整个研究项目。

所有审阅请遵循 HERO：指出实际错误和影响结果的缺口，给适量修法；不提哈希、评分表、通用迁移平台或假想攻击。首版要能指导真实 agent 工作，但不承诺自我改进或提速已实证。
