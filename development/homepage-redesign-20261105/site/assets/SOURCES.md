# Homepage assets: sources and scope

## Mathematical typography

Results-card formulas are pre-rendered with **KaTeX 0.16.11** from the pinned official npm package. Local `math/katex.min.css`, its20 WOFF2 fonts and `math/LICENSE-KaTeX.txt` provide the finished page's mathematical typography. Original package, provenance and the thin authoring renderer are retained in `../../reviews/result-cards/math-render/README.md`. No browser runtime math script or CDN is used. Data-table numerals retain the proportional Geist family below.

## Typeface files

Downloaded 2026-11-05 from the official Fontsource npm packages, pinned to 5.3.0. These are real Latin upright variable WOFF2 files with weight range 100–900, including 400/500/600/700.

- **geist**: [`fonts/geist-latin-wght-normal.woff2`](fonts/geist-latin-wght-normal.woff2); 29,400 bytes. Package `@fontsource-variable/geist@5.3.0`; [original package tarball](https://registry.npmjs.org/@fontsource-variable/geist/-/geist-5.3.0.tgz). Original OFL text is preserved in [`fonts/geist-OFL.txt`](fonts/geist-OFL.txt).
- **geist-mono**: [`fonts/geist-mono-latin-wght-normal.woff2`](fonts/geist-mono-latin-wght-normal.woff2); 23,128 bytes. Package `@fontsource-variable/geist-mono@5.3.0`; [original package tarball](https://registry.npmjs.org/@fontsource-variable/geist-mono/-/geist-mono-5.3.0.tgz). Original OFL text is preserved in [`fonts/geist-mono-OFL.txt`](fonts/geist-mono-OFL.txt).

Official family pages: [Geist](https://fontsource.org/fonts/geist), [Geist Mono](https://fontsource.org/fonts/geist-mono). The fonts remain licensed under SIL OFL 1.1. No font source modification or renaming was performed.

Example CSS (the page owner chooses actual family names and styling):

```css
@font-face { font-family: 'Geist'; src: url('./fonts/geist-latin-wght-normal.woff2') format('woff2'); font-weight: 100 900; font-style: normal; font-display: swap; }
@font-face { font-family: 'Geist Mono'; src: url('./fonts/geist-mono-latin-wght-normal.woff2') format('woff2'); font-weight: 100 900; font-style: normal; font-display: swap; }
```

## Q6 illustration data

`q6.json` is a deterministic illustration, generated by `generate_q6.py`. It contains vertices 0–63, all 192 short edges of Q6, the binary-reflected Gray-code Hamilton cycle (including its closing edge), and eight explicitly selected disjoint cycle edges as the highlighted matching. The matching includes all six coordinate directions. Edge pairs are undirected; `cycleEdges` alone preserves traversal order. `vertexBits[id]` uses the conventional most-significant-bit-first display; edge direction 0 means the least significant bit.

`q6-check.json` records actual adjacency, Hamiltonicity and matching-containment assertions. This is one valid illustration, **not a new proof of matching extension for every matching**.

## Rendered Q6 illustration

The final page generates a reflected Gray cycle directly in `app.js`. It draws 16 disjoint cycle edges as the red matching (rather than the separate eight-edge sample in `q6.json`). Root/Sol checked all 64 vertices, the 32-to-0 closing edge, all 16 matching edges, and all 192 cube edges. This is an illustration of one matching, not the universal proof certificate.
