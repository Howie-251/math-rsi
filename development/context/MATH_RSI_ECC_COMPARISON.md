## 2. 目标语义决定完整性要求落在哪里

新 ECC 规格要求一个实际 `11×45` 二元矩阵，GF(2) 秩为11，全部2047个非零消息的重量至少17。一份满足该条件并独立复算的矩阵就足以完成存在性分支；不需要先证明搜索算法遍历了所有矩阵。

若要宣布不存在，则需要任意原目标到归约域的连接、完整母码／结构覆盖、规范化保真、实际全域检查和拒绝判定。检查所有保存下来的候选合法，只解决成员正确性，未解决是否误删了应保留的候选。

因此，一次插件输出应说明它究竟是：一个满足原目标的见证、一个条件定理、某范围内的完整排除、一个反例、还是探索结果。base 组织相应的数学审阅与检查器调用；不能只看执行退出码或名为 `PASS` 的字段。

来源：[新题规格](context/mathrsi-ecc-20261101/sources/ecc/FORMAL_SPEC_45_11_17.md)；[完整证明链阅读记录](context/mathrsi-ecc-20261101/proof-contract/EVIDENCE.md)。

## 3. 启发式发现与严格验收可以分开

旧题把任意假定目标归到满支撑偶 `[40,7,18]` 母码。项目实际取得172个合格且两两坐标不等价的代表，结合文献“至多172类”，得到完整目录。目录发现过程可以是启发式；完整性由实际代表、互异性和外部分类上限共同支撑。

随后每个母码上的全部合法陪集集合由两套完整遍历分别产生，并在对应坐标下比较。全部配对的低权拒绝见证再经完整重放，最终与归约连接，得出旧题不存在。这几个环节解决不同义务，不能互相替代。

可提炼的 base 原则是：**把完备性要求放在结论真正依赖的环节。** 探索程序不必一律穷尽，也不能因为一个探索程序不穷尽就否定其发现的可检查证书。插件必须交代证书为什么足够，以及哪些外部定理被导入。

分离的是职责与证据，实际执行仍保留“生成候选 → 验证 → 用低权见证或反例修正下一候选”的反馈。搜索器可以利用验证器的信息，最终结论仍按明确的检查范围验收。

来源：[旧题结论与证明摘要](context/mathrsi-ecc-20261101/sources/ecc/results/NONEXISTENCE_43_10_17.md)、[ECC 经验](context/mathrsi-ecc-20261101/sources/ecc/research-wiki/ECC_LESSONS.md)。旧题保留文献分类与软件信任，未作全链 Lean；本轮没有重新扫描。

## 4. 两领域共同的方法：保留同一个实际对象

Property B 的独立最坏布局可能丢掉“这些坏对来自同一个超图”的约束。ECC 也存在相同类型的建模问题：新增行各自满足距离条件，不代表它们的所有线性组合同时满足条件。

ECC 旧题把扩张先转成同一合法陪集集合上的相容图；所需三行扩张必有兼容边，而全部对应图均无边。因此一项较便宜的必要检查已经足够结束证明，无须继续三行组合。

新题九尾路线则将首头吸收到共同母码，按差标签分桶，并用同一个真实坐标交换群取商。先规范第一行，再用保持它不变的子群规范第二行；不能让两行各自独立取全群代表。未来的行还须同时运输。

base 可以提出通用诊断：“当前局部视图是否来自同一个原对象？是否丢了相容关系？使用的变换是否保持所需性质？”具体的加法、稳定子、选锁或共享坏对由领域插件解释和证明。这比把两个领域的公式写入同一核心更有迁移价值。

来源：[九尾完整报告](context/mathrsi-ecc-20261101/sources/ecc/work/goal-45-11-17-20261007/wave6/n37_pair_swap_compression/REPORT.md)。

## 5. 效率按实际联合成本判断

九尾的固定实例有明确的压缩与执行记录：

|阶段|实际域或结果|
|---|---:|
|原合法集合的无序配对|7,854,553,165,656|
|差标签分桶后|3,413,228,288|
|共同交换群取商后|26,665,846|
|实际执行|307块全部完成，输出17,403份中间矩阵|

完整307块进程为0.473743 CPU秒，另花2.088232 CPU秒恢复并验明中间矩阵。它们不包括先前合法集合生成、推导、实现、审阅及后续扩张。该实例说明数学压缩可以把联合计算变得便宜；不能据此计算整个新题的加速比，也不能把中间矩阵数当成最终目标数。

相反，十一尾只剩3个核心与3种关系型，七个新增头仍有很大的共同空间。九份完整局部试验全部非空，随后停止继续加深同类试验。这验证了“代表少”不是合适的难度指标。

从两领域可抽出三个实际决策：

1. 已有完整表示、成本实测可承接时，直接完成有限计算。不要仅因表达式呈指数形式就反复等待更强归约。
2. 局部产物增长而共同域与后续成本没有改善时，回到原对象、必要条件和整体路线重新判断。
3. 停止门槛依赖当时的模型和实测。新数学条件或实现改变成本后，可以安排新的有界试验；旧门槛不是永久数学禁令。

已有结果及时接回证明，保存可复用对象与运输，避免重扫已完成域。原始输入准备、计算、输出、独核、证明装配以及模型沟通都属于端到端成本。
