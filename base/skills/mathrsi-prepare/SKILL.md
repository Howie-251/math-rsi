# MathRSI 问题准备工作流

把用户问题变成可开始求解、也可最终验收的研究任务。本工作流实际调用 `mathrsi-specify` 和 `mathrsi-survey`：初步问题交调查，调查的真实结论再交规格定稿。它可以单独准备研究，也可以由 [mathrsi-research](../mathrsi-research/SKILL.md) 调用后同一轮继续求解。

输入是用户原题、工作区与授权范围，可能包括题面PDF、旧证明、文献和领域插件。输出沿用已有规格、文献与恢复文件；新任务默认 `FORMAL_SPEC.md`、`LITERATURE.md`、`NEXT_SESSION.md`。这些是阶段间传递的真实内容，不是调用前必须填好的模板。短题可在一份文件内保留相应部分。

被主流程或其它caller调用时，prepare是本准备范围的唯一内部调度者：specify初步返回调查委托，由prepare执行survey一次，survey返回后再由prepare执行specify定稿。完成后返回直接caller，不自行启动route-loop/prove/verify。独立调用只交付用户要求范围；明确授权持续研究且无上层调度者时，本执行者才读取主入口接任后继调度一次。

## 1. 读实际状态，选择起点

先读任务约定、原规格、恢复入口和wiki导航，再按当前义务读实体与原证据。后台计算或代理若已交回完整产物，主执行者及时消费；旧日志中的“运行中”不等于当前状态。准备材料不恢复暂停的Goal。

全新题目或原题含糊，进入下述澄清、广搜、定稿。规格与调查已固定且有可继续路线，返回原目标、可信结果、未闭义务和后继调用位置，交主流程直接进入prove。原对象/参数/方法刚变化，只调查差异，保留仍适用的证据。已有完整证明或见证且只请求验证，返回verify入口，不先发明多条路线。

用户只要求准备新Goal或读资料，完成准备即可交回；已授权持续研究，准备后同一轮接着执行。Goal是否启动、暂停和完成由宿主与用户指令决定。工作区边界见 [WORKSPACE](../../../docs/WORKSPACE.md)。

## 2. 实际执行 specify 初步模式

完整读 [mathrsi-specify](../mathrsi-specify/SKILL.md)，交用户原题、原始来源、参数和已有状态。要求提取对象、量词、目标及实质歧义，形成足以调查的表述；候选方法所需条件不进入原题假设。

```text
读取本仓 mathrsi-specify/SKILL.md，执行 preliminary 模式。
工作区 <W>；原题 <用户原话/题面文件及位置>。
先恢复已有规格和wiki；需要新写时使用 FORMAL_SPEC.md。
区分原对象、量词、允许终点和题面中的候选推导。
返回可供调查的问题、异名候选、已有来源及实质歧义。
本次规格由你单独写，文献报告由下一阶段写。
```

读回实际规格，确认仍是用户的问题。复杂量词转换未证明就交调查核查，不能为推进流程先当等价。必须由用户决定的目标歧义及时询问，同时继续不依赖答案的来源定位；命名等非阻塞选择自行处理。

## 3. 初步问题交给 survey，实际消费原文结果

完整读 [mathrsi-survey](../mathrsi-survey/SKILL.md)，传刚得到的规格、来源、wiki及领域文献入口。它内部实际执行ARIS research-lit、关键原文核读、按需wiki-enrich和wiki更新；一行“已查文献”不是调查产物。

```text
读取本仓 mathrsi-survey/SKILL.md 并执行。
调查 <W>/FORMAL_SPEC.md 的初步问题，复用原wiki和ref。
已启用插件 <实际入口与阶段> 一并交给你；Property B按survey中的
propertyb-literature调用执行领域种子、查询和误读核对，与通用发现共享一轮调查。
本轮未知是 <异名/基线/反例/指定进口>；新题首轮广搜，已有调查补差异。
结果写 LITERATURE.md，保留实际查询和原文位置。
返回可用结论及条件、基线、候选反例、关键未读来源，
说明哪些发现影响正式目标的解释。不要替用户换目标。
```

领域插件提供当前任务的具体查询与原文定位。例如Property B要对齐参数、同一基线及公式范围。让survey与领域literature分工消费同一报告，避免两个agent重复广搜；并行查不同来源时指定一个报告和wiki writer。

收到调查，读回基线与拟用进口的精确结论、版本、编号、前提和原题映射。找到现成证明就核对、复述或按用户要求寻找独立证明；找到反例先验原对象和性质。未搜到解答只表示当前搜索范围，不能作为原创或为真的证据。

关键原文缺失时返回survey补那一项，未变来源不重查。缺失不阻止另一路线时保留条件状态并继续独立工作，不让单一检索服务阻塞整个研究。

## 4. 调查交回 specify 定稿

第二次调用消费文献带来的知识变化，不是再让用户审批同一原题。

```text
读取 mathrsi-specify/SKILL.md，执行 final 模式。
消费 FORMAL_SPEC.md 初稿和 LITERATURE.md 的已核结论。
保持用户原目标，明确完整对象、量词、允许终点与验收。
把已证结果、文献进口和候选待证分开；核参数、严格性、计数单位。
更新原规格，不另造平行正式版本；返回可调用进口与仍需的原题连接。
```

主执行者读回原题及终点。若定稿删了难分支或降低参数，按原题修正；若发现只是方法不适用，保留原题，困难交路线迭代。真正目标歧义才向用户澄清，不能把等待时间当授权。

准备完成意味着后继agent知道应当解决什么、哪些工具适用、哪里缺事实、下一动作是什么；不表示任何候选定理已证。

## 5. 返回调用方继续，或完成独立准备请求

交回准确规格、进口及wiki位置、未闭义务、已有路线/证明与下一动作。建议新题接 [mathrsi-route-loop](../mathrsi-route-loop/SKILL.md)，在途研究回 [mathrsi-prove](../mathrsi-prove/SKILL.md)，完整稿接 [mathrsi-verify](../mathrsi-verify/SKILL.md)。组合调用由直接caller消费此建议并执行下一阶段，prepare不抢先启动；只授权准备则交付这些实际文件。

所有产物写任务工作区。默认specify单写规格、survey单写文献，父调用者更新恢复页；显式组合输出按各技能协议返回正文给唯一writer。子代理宣告完成却未交内容，取回真实产物再推进。

恢复页写下一动作怎样改变当前缺口。例如“分类上限已核；下一步验证手头代表属于该域且两两不等价”，比“继续证明”更可执行。ECC旧题正是文献类别上限与实际代表合法性/互异性合起来闭合目录，必须对齐对象域和等价关系；不将旧参数的类别数搬进新题。

route-loop或prove补文献时可直接调用survey，再回原义务，无需重新走整个prepare。只有原题解释受影响才回specify相应部分。这样首轮有广度，后续补搜有明确问题，已取得的证明与失败经验持续复用。
