# 原对偶／上下界协同探索协议

本参考供 [mathrsi-route-loop](../SKILL.md) 与 [mathrsi-prove](../../mathrsi-prove/SKILL.md) 在研究开放极值区间 `[L, U]` 或“存在性构造 vs 全称障碍”对偶问题时按需读取。它用共享的精确局部指标把见证搜索（下界／反例侧）与候选不等式发现（上界／障碍侧）耦合为有记忆的反馈回路，不增加第六个研究阶段，也不在 Base 中绑定任何特定问题评分器或模型通道。

## 1. 分离证明目标与对抗搜索目标

开轮显式分开记录两个不同字段：

- **主证明目标（Proof Goal）：** 要对全部合法对象证明的全称命题（例如 `f(X) ≤ U_goal`）。
- **对抗搜索目标（Search Target）：** 构造侧试图达到以反驳主目标的阈值（例如 `f(X) ≥ U_goal + 1`）。

搜索多轮未找到达标对象只能记作 `open`，绝不构成全称上界的证据。反过来，一旦构造出经独立验证合法的越界对象，**即使它不满足本轮附加的辅助探索条件**，也立即构成原无条件目标的候选反例，交独立复核并据实更新路线。

## 2. 近极值工作带不是隐含数学假设

远离极值边界的合法样本往往对紧约束缺乏区分度。允许设置可调的**近极值工作带**（Quality Band），让亲本选择、变异预算与不等式发现优先聚焦高分样本区域，同时允许单次构造内部先退步再重构回带内。

工作带仅改变探索优先级，**绝不静默变成候选不等式或最终定理的前提条件**。带外历史合法样本保留在共同档案中，继续参与所有适用不等式的反驳检验。

## 3. 共享精确局部指标与独立重算

两端共用同一组精确定义的局部可观测量 `φ(X)`（如规模、度数分布、局部子结构计数、子面聚合量），每项指标与每条候选不等式各自附带显式适用条件：

1. **宿主独立核验与重算：** 构造侧提交具体对象表示（如边表、矩阵、点集）而非分数声明。宿主或可信领域检查器先独立验证对象合法性与禁结构条件，再精确计算 `φ(X)`；生成程序自报的分数或性质不作为证据。
2. **条件不隐式传染：** 搜索任务的辅助筛选条件不自动并入候选不等式的适用域，候选不等式的局部条件也不改变原题规格。若新增声明式指标，须对既有归档对象补算一致值后再进入下一轮比较。

## 4. 用未违背不等式的有符号残差导引构造

对适用域内的候选不等式 `a·φ(X) ≤ b`，保留未违背时的负向距离信息，而不只给“是否成为反例”的二值信号：

```text
r(X) = a·φ(X) − b
z(X) = r(X) / max(‖a‖₁, IQR_archive(r))
```

残差从 `-5` 推进到 `-1` 说明构造正在逼近该约束边界；`r(X) > 0` 则给出该候选在适用域内的真实反例。为防止单一恒紧的总规模界掩盖其它结构关系，构造导引在四类通道间轮换或分层保留精英：

- **目标通道（Objective）：** 推进主目标值逼近对抗阈值；
- **挑战通道（Challenge）：** 轮换逼近或击穿单条具体结构不等式；
- **新颖性通道（Novelty）：** 在选定指标投影上保留尚未覆盖的结构区域；
- **条件通道（Condition）：** 探索指定局部条件域的可实现性。

`z(X)` 与通道奖励只是构造侧的搜索信号，不代表任何候选不等式成立。

## 5. 全档案反驳与待证义务导出

上界／障碍侧提出的每条候选不等式，必须在其声明的适用条件内对**全部已归档合法对象**（不限于本轮提示展示的少量样本或工作带内样本）执行检验；可穷尽的极小维基准另做完整枚举：

- **已反驳（`refuted`）：** 存在满足适用条件且 `a·φ(X) > b` 的真实对象。立即从后续奖励池移除，保留具体反例供上界侧修正条件或系数。
- **小域穷尽通过（`exhaustive_verified`）：** 仅用于确实完成了完整合法域枚举的极小参数，记录精确域大小与适用计数（适用计数为零标 `vacuous`）。
- **样本未反驳（`empirical`）：** 仅表示当前档案未推翻。**`empirical` 不是定理。**

准备用于原题证明的幸存候选，作为显式**待证义务（Proof Obligations）**移交 `mathrsi-prove`：在同一假想反例或任意合法对象上通过共同统计恒等式、结构引理或完整局部域精确对偶证书严格证明，并补齐所有条件分支覆盖。
