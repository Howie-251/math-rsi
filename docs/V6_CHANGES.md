## Three concrete base improvements

| Research situation | Action in the existing workflow |
| --- | --- |
| A proposed case split closes easy sub-families while leaving the hardest open core untouched | **Probe the hardest remainder first.** Run a bounded probe on the hardest open branch before adopting a split; measure progress by net-new union coverage on the same actual input and coordinate frame. Easy sibling passes do not reset the stall counter on the shared hardest core. ([actual-input-coverage](../base/skills/mathrsi-prove/references/actual-input-coverage.md), [global-reassessment](../base/skills/mathrsi-research/references/global-reassessment.md)) |
| Constructive lower-bound search and upper-bound inequality discovery stall in isolation | **Primal–dual coevolution.** Separate the open primary proof goal from the adversarial counterexample target; focus parent selection on a near-extremal working band (heuristic only), rotate four channels (`objective`, `challenge`, `novelty`, `condition`) with normalized signed residuals $z = (a\cdot x - b)/\max(\lVert a\rVert_1, \mathrm{IQR})$, and refute candidate cuts against the **entire** verified archive before exporting surviving `empirical` obligations to `prove`. ([primal-dual-coevolution](../base/skills/mathrsi-route-loop/references/primal-dual-coevolution.md)) |
| Outer float SDP/LP/CP iterations keep running after single-round gains fall below exact-repair noise | **Stop at the repair-residual floor.** Halt float iterations when apparent gains fall at or below $\varepsilon_{\text{repair}}$, and record nonzero feasibility residuals beside any uncertified approximate fit rather than presenting it as a proved lower barrier. ([route-loop](../base/skills/mathrsi-route-loop/SKILL.md), [verify](../base/skills/mathrsi-verify/SKILL.md)) |

## Happy Ending N(m,r,s) follow-up · 2026-11-17

This is later **`v6` maintenance on `main`**, keeping the fixed `v6` tag unchanged. It integrates the November 5–17 Happy Ending / ordered rank-3 signotope capacity package (`m = 7, 8, 9` and general $m$), which was developed in a hybrid **Trellis + ARIS + MathRSI `v3` (`mathrsi-prove`, `mathrsi-happy-ending`, `proof-writer`)** workflow on top of the earlier pre-MathRSI `b = N(7,5,6) = 25` and `ES(7) ≤ 77` working chain.

- **Base refinements (`mathrsi-route-loop`, `mathrsi-verify`, `proof-evidence.md`):**
  1. **Relaxation-ceiling exhaustion stop.** When an explicit $\{0,1\}$ occupancy/hole relaxation admits both an integer/DRAT dual lower bound and an exact relaxation-feasible primal witness meeting at the same integer threshold (e.g., the 9-hole hitting vector for the 115-row $N(8,6,6)$ matrix, or the `47,635`-row rational grid `123539833 / 10^6 <= 124` for depth-$\le 3$ $D_9$), halt further row-tightening inside that matrix and pivot to shared-label or geometric compatibility constraints — without mistaking the relaxation witness for an actual signotope or planar point set.
  2. **Generative sparse integer dual certificates.** Instead of bundling giant LP matrices, store only nonzero-weight row parameters `(q, p, inc, exc, weight)` so a standard-library checker independently reconstructs every used row and integer $\{0,1\}$ overload penalty $P = \sum_W \max(0, \ell_W - \Lambda)$ with zero floating-point arithmetic.
- **[`happy-ending`](../plugins/happy-ending/README.md) plugin, archive (`48.18 MiB`, max file `9.56 MiB`, zero Git LFS) & portable checkers:**
  - **$m = 7$ (heptagons):** Analytic working bounds $N(7,5,7) \le 39$ (owner intervals, no CNF) and $N(7,6,6) \le 49$ (general balanced strict capacity $2b - 1$ for $p \ge 4$), working chain $N(7,6,7) \le 75, N(7,7,7) \le 76 \implies \mathrm{ES}(7) \le 77$ (vs. Schroeder 2026 v1 planar $\le 81$), plus DRAT-verified exclusion of 5 common lock blocks ($\le 4$ blocks) and clean-root port flows.
  - **$m = 8$ (octagons):** `check_n866_milestone9.py` replays all 115 shared-label rows and `drat-trim` UNSAT for **$N(8,6,6) \le 61$** (with exact matrix minimum 9); `check_octagon_omission.py` replays Schroeder's 15-file omission trees (`193` / `124`), which combined with the project's abstract cyclic-sign packet bridge gives working signotope bounds $C_8 \le 193, D_8 \le 124 \implies N(8,7,8) \le 317, N(8,8,8) \le 318$ (**planar $\mathrm{ES}(8) \le 319$ is Schroeder's published preprint bound, not claimed as a new planar reduction**; autonomous fallback without public trees gives $N(8,8,8) \le 322, \mathrm{ES}(8) \le 323$).

## Full seven-dimensional matching extension · 2026-11-20

The November 19 working proof covers every matching in the seven-dimensional cube. The dense layers cover all matchings with at least 46 edges. A separate argument shows that every inclusion-maximal matching has at least 46 edges. Extending any input by adding disjoint cube edges therefore puts it in the dense range with all its original edges intact. The fixed v6 tag records the earlier 56-edge threshold.

On `main`, the route, proof and verification skills now compare the possible sizes of terminal extensions with the exact domain of an available theorem. The Hamilton plugin shows how to exclude the one remaining maximal size and how to check that a cut preserves the same matching on both faces. The new finite exclusion can be replayed locally. The full proof imports earlier results, with some older certificates omitted from the source distribution. External refereeing and Lean formalization remain open.
