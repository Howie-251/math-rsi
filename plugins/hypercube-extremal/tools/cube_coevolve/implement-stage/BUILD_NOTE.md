## 语义选择（完整披露）

- **A02（图的合法性）**：顶点为 n 位整数；简单无向超立方体子图；边界/重复边/四圈严格核验，奖励由宿主重算，不信任生成程序上报分数。来源：default。

- **A03（上界候选形式与状态）**：首版为整数系数线性不等式及指标比较组成的显式合取条件；所有适用归档图均参与反驳；样本成立仅 empirical；仅小维完整枚举可在其精确域标 exhaustive_verified。来源：default。

- **A04（reward 与多样性）**：边数、归一化有符号不等式残差、指标新颖性分开保留；轮换目标与不同档案槽，禁止用单一加权总分淘汰所有挑战者；归一化每轮固定，并在更新不等式后重算选择分数。来源：default。

- **A05（条件目标）**：任务条件与每条不等式条件分别校验；不适用的图不得作反例或目标达成；合法但不满足任务条件的图可作探索材料，明确标记。来源：default。

- **A08（上下界共同学习的证据含义）**：档案属于自适应发现样本，无独立统计泛化保证；留出图用于挑战，不据此宣称证明。Q8 本轮只验收工程调用，不宣称得到 683 或提高上界。来源：default。

- **A10（默认构造起点）**：Q8 读取现有已核验 682 边种子；演示使用小立方体；保留空图/不同密度及非奇方形探索，不能把已排除局部邻域搜索当新数学结果。来源：default。

- **A11（多条不等式奖励互相遮蔽）**：每轮指定一条挑战不等式；有相关性候选时优先于仅边数候选，按已经执行的 challenge 轮数轮换（不能按总轮数模候选数导致轮换混叠）。不能取所有残差的最大值作为唯一挑战奖励，否则恒紧的边数界会遮蔽其余梯度。来源：default。

- **A12（新颖性的具体含义）**：候选相对轮初全部归档图取标准化指标 L1 最近距离；重复图距离为零。档案父本排序才排除自己，表示对其它档案图的差异。投影为 edges/even_squares/degree_3..6/holes_max_side，缺失项略过，按当前范围且下限 1 标准化；不宣称图同构去重。来源：sweep。

- **A13（图簇及留出集合）**：图簇按奇方形性、edges//4、min_degree 分组；按图 ID 后缀模 4 留出约四分之一（非独立统计测试）。上界模型看训练分组范围及至多 48 张稠密图，宿主检验仍覆盖全档案。来源：sweep。

- **A14（各搜索方向的标量代理）**：objective=有向目标−(abs(target)+1)×条件距离+0.01×新颖性；challenge=指定归一化残差+0.01×归一化目标+0.01×新颖性；novelty=新颖性+0.05×归一化目标；condition=−条件距离+0.001×归一化目标。各分量仍完整保存，系数是启发式选择而非数学保证。来源：sweep。

- **A16（小维 oracle 验收边界）**：仅 n≤3 完整枚举全部边子集；空适用域标明 vacuous，不升级为有意义的已验证候选；n≥4 不运行此 oracle，输出明确未证义务。来源：default。

- **A17（反例如何反馈上界）**：留出只用于首次挑战，反驳后可公开给上界模型；每次最多带四张实际反例的完整边表、指标和所反驳候选 ID。保留所有反例于档案，不宣称该留出集合后续仍独立。来源：sweep。

- **A18（程序亲本与选择）**：先按图的各目标选择亲本，再取这些图的来源程序中最近四份源码给模型；这是图引导的程序选择。程序亲本 ID 只记实际进入提示的源码，另存图亲本 ID，不宣称采用独立程序适应度排行榜。来源：sweep。

- **A19（奖励归一化）**：不等式尺度为 max(系数绝对值之和, 当前适用图残差 IQR)，整轮固定；目标代理除以 abs(target)+1；所选挑战不适用时该通道取 −1e6，条件通道针对任务条件，不能混称它会优化每条候选自身的条件距离。来源：sweep。

## 接口选择

ASK=never，按已有授权自主执行；未索取新授权，具体默认值均记台账。

- **A01**：程序/模型接口；Python `generate(context)` 返回边表批次；Codex CLI 结构化输出为默认实际模型通道，另有显式离线演示通道；默认模型 gpt-6.1-sol，可配置。
- **A06**：恢复与失败；每轮记录输入/输出；完成轮次原子保存，恢复沿已有模型响应和评估结果续接；模型失败/超时单独记录，不能伪装成功或自动改用离线提供者。
- **A07**：指标扩展；基础注册表加声明式子立方体统计；新增指标定义写入运行状态并重新计算旧图，每轮保存实际注册表；原启动配置不改写。首版不自动执行模型生成的验证器/指标代码。
- **A09**：生成程序运行边界；受限 Python 导入/内置函数、独立进程、CPU/内存/墙钟及输出限制；合作式研究代码，不宣称对恶意 Python 的完备安全隔离。
- **A15**：失败程序如何被后继消费；后继下界提示包含最近至多四个失败程序的 ID、源码、评价和有限长度 stderr；模型错误单独保存且不自动重试。
- **A20**：运行环境；Python 3.10+ 标准库与 POSIX 资源/进程组接口，适用于 Linux/WSL/macOS；实际验收在当前 WSL 环境，未声称 Windows 原生或 macOS 已实测。
