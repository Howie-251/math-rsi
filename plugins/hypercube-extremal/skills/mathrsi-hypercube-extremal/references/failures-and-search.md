# Search mechanics and reusable failures

原始轨迹：[guide04](../../../archive/source/guide/04_TRAJECTORY.md)、[状态与复用](../../../archive/source/guide/05_RSI_REUSE_AND_STATE.md)、[最后column_lift源码](../../../archive/source/research/q5_empty_moment_20261028/column_lift.py)。这些是历史算法实例，不是新题默认预算。

**工作集过拟合。** `deep_history.json`的池值约0.59175而全域0.8347202840891347，补800行且iteration limit。它否定该候选的全域可行性，不否定共同Q4模型。遇此情况保存违反图、保留best、补约束并再次分离。不能只核原活动行或旧最坏图。

**末行不等于最佳。** full_flags末全域0.599895劣于保存iteration178。文稿取最终保存证书；新候选只有完整域且整数化后更好，才替换已接受best。原history均在[research](../../../archive/source/research/)，不能把每轮写成单调进步。

**相对朝向丢失。** 空根45单旗态将两连接臂同角/邻角/对角混掉。修法是240标号态及同步根作用；这是证书空间变化。进一步LP列生成、平滑、pool管理是同模型求解变化，两类收益分开。

**PSD与对偶定价混淆。** 末轮moment_min_eig≈−0.00056927是LP对偶的定价矩阵，寻找新秩一列；正式证书由整数LLᵀ给PSD。负定价既不否定已接受上界，也不证明能继续改进。反过来`dual_target_history.json`目标约0.59仍有负谱，不能声称模型极限已到0.59。

**目录名误读。** 最终控制证书在Q5命名研究目录，格式也带Q5，但q5_cuts=[]。接受范围由有效块和项决定。旧六块8/7/4/64/56/49不等于最终五面+顶点六块。

**错误单调剪枝。** score含正负矩阵修正，最坏mask3602350111只有17边。不能只遍历最密/极大图，也不能按某个真实图局部矩阵负谱删它。新剪枝须有对完整score有效的证明。

**一次无收益不等于全类无用。** column28八十轮未胜joint28；fine28后来胜。80粗投影项权重为0只说明该次求解没用；Horn修复未入最终证书不排除整个共正方向。重启条件应是有新模型/违反行/定价方向或资源证据，避免机械加轮。

新的候选循环可以复用几何域、索引和已证覆盖；改变Q后重计全域分数，舍入后再计一次。存restricted/full/best与stop原因、真实输入和代码，不要求重跑全部优化才能接受一份新精确证书。域变了则重新证明覆盖及高维抽样。
