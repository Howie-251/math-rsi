## 二、$n \to \infty$ 渐近密度 0.5912405941884453 完整证书与复现

渐近成果已全量归档于 `asymptotic_05912_flag_algebra/`，完全脱离早期 0.625 粗粒度界，实现了学术界最高精度的纯有理化 128 位无损整数证书验证：

### 1. 一键复验命令
在成果汇编包根目录下直接执行：
```bash
python recheck_asymptotic.py
```
或在 `asymptotic_05912_flag_algebra/` 目录下执行：
```bash
python verify_05912.py
```

### 2. 核心证据文件
* `verification_receipt.json`：由全空间 C++ 穷举校验器生成的机器证书收据；
* `q_int64.bin`（SHA-256: `00eae18e098514e70cc4e31081a6a452a3550cb0a4b5f0f6182b6d5b4e3fcdd9`）：6 块正交半正定核矩阵；
* `factors_int64.bin`：半正定性的整 Cholesky 认证因子；
* `cop_terms.json`：35 项 triangle-free 余正锥极端线项；
* `cubic_terms.json`：29 项切片半正定（Slice-PSD）张量系数；
* `track1_v1_qm_exact_potentials.json`：$m \in \{5..1024\}$ 阶广义超几何顶点度数势精确有理数；
* `independent_verify_track1.cpp` 与 `verify_qm_degree_potential.cpp`：支持 GCC `__int128_t` 的底层 C++20 验证器源码。

### 3. 复验指标与严格覆盖
* **$Q_4$ 非同构子图轨道覆盖**：共校验 3,212,821 个无四圈子图（覆盖全体 $2^{32} \approx 4.29 \times 10^9$ 边子集）；
* **方格相交性检查**：77,107,704 次无漏检；
* **矩阵分母指数**：$2^{62}$，全空间无上界违背；
* **最优上界**：$m=1024$ 阶时精确达到 $\beta = \frac{9701859764505653085708308080340303}{16409326186106551516455239680000000} \approx \mathbf{0.5912405941884453}$。
