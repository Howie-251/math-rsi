**T4 的五行无条件塔式补桥（消除 `0.5912_渐近密度_严格数学分析.md` §4.7.4 对 `n > 1024` 单调性的顾虑）：**
1. 对任意 `n ≥ m = 1024` 与任意无 `C₄` 子图 `G ⊆ Qₙ`，“均匀取四维面 `F ≅ Q₄` 再均匀取 `v ∈ V(F)`”与“均匀取 `v ∈ V(Qₙ)`，再均匀取 `S ∈ C([n], m)`，再均匀取 `T ∈ C(S, 4)` 并令 `F` 为过 `v` 由 `T` 张成的 `Q₄`”具有完全相同的联合分布（每个 4-子集恰含于 `C(n-4, m-4)` 个 `m`-子集中）。
2. 诱导局部度 `deg_{G[F]}(v)` 仅统计 `v` 在 `T` 中保留的关联边数，只依赖 `(v, T)`。
3. 对 `(v, S)` 条件化（设 `v` 在 `S` 中保留 `d_S(v) ∈ {0,…,1024}` 条边），超几何条件期望给出 `E[∑_{k=0}^4 b_k 1_{deg=k} | v, S] = Φ_1024(d_S(v)) / C(1024, 4) ≥ μ_1024 / C(1024, 4)`。
4. 对 `F` 的 16 个顶点应用期望线性性（无需独立性假设），对一切 `n ≥ 1024` 恒有 `E_F[a + ∑_{k=0}^4 b_k h_k(G[F])] ≥ a + 16 μ_1024 / C(1024, 4)`。
5. 全局 `Qₙ` 上的旗代数抽样碰撞误差（引理 4.1、4.2、4.8）仍为 `O(1/n) → 0`，直接给出 T4。
