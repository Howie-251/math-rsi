# Q4 精确半正定上界证书

认证上界：18933741304467/32000000000000 < 0.59167942。这是渐近边密度上界；本轮尚未达到 0.59。

## 最小核验

需要 Python 3 标准库，以及支持 C++17 的 g++ 或 clang++。不需要 NumPy、SciPy、SDP 求解器或互联网。

在本目录运行：

```bash
python verify.py
```

程序重建整数 Gram 矩阵、根对称群、Q3 图型轨道和全部合法 Q4 补全，然后直接计算局部不等式。最后输出精确最大分数、向上舍入小数，并检查它与 JSON 一致。

请勿使用 -DNDEBUG 编译，因为完整性检查使用 assert。默认编译命令不含该参数。

`certificate.json` 是精确整数因子；`keys.bin` 的规范代表表会被核验器从头检查覆盖性，不能跳过覆盖检查；`研究报告.md` 给出从局部整数不等式到高维渐近结论的证明。

`verification.log` 保存本轮最终打包后实际运行的输出。其自称独立是指不读取求解系数表，不表示已被第三方复现。

最终模型包括五种根面与一个顶点根，矩阵阶数为 240、212、190、187、170、9。整体根对称性通过对矩阵作共同群平均保留，而不是将两个旗各自旋转后取商。
