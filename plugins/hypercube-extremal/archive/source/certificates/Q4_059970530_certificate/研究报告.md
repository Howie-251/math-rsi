# 完整补全一致性与真实空面根矩阵：Q4 上界证书

日期：2026-10-27。本文区分文献结果、本轮推导与本轮计算。本文不是 Erdős 猜想的证明，不声称 SDP 已达到全局最优，也不声称已经完成第三方复现或同行审阅。

## 1. 认证结论

记 pi_Q(C4) = lim_{n→∞} ex(Q_n,C4)/(n 2^{n-1})。

本轮构造并验证的计算机辅助证书给出

**pi_Q(C4) ≤ 119941059204403 / 200000000000000 = 0.599705296022015 < 0.59970530。**

这个常数低于 Baber, *Turán densities of hypercubes*, arXiv:1201.3587v2, Theorem 4.1 中的 0.60318。这里作的是与这篇已核对文献的比较，不以一次网络检索声称已排查所有文献优先权。该结果也强于上一轮重建模型的认证值 0.60410234。

所有矩阵以整数 Gram 因子给出。独立验证器不读取求解器结果或预生成旗系数表，直接重新构造局部对象并核验整数不等式。

## 2. 新增信息是什么

原模型分别记录隐藏一个方向后的部分 Q4 类型，并施加二次矩和方向交换等式。我们保留其 90,179 个类型作为旧系数的存储方式，但不再把这些类型当成可以任意混合的独立局部观察。

对完整无四环 K⊆Q4，记 H_g(K) 为隐藏方向 g 后得到的部分类型，g=1,2,3,4。真实图必须满足：这四个观察来自同一个 K。

因此，部分类型频率 p 不仅满足旧线性等式，还必须能写成可实现四观察组合的凸组合：

p = Σ_K x_K (1/4) Σ_g e_{H_g(K)},  x_K≥0, Σ_K x_K=1。

这里 e_H 是坐标单位向量。实现时没有为每个 K 设置一个新的半正定矩阵；我们将 K 作为局部证书的检查对象，通过分离约束逐步加入当前最紧的行。

旧的 766 条方向交换等式，在每个可实现四观察组合上已经逐项抵消：Σ_g a_j(H_g(K))=0。程序检查了所有组合，未发现非零项。因此新模型不再需要这些乘子的数值优化。

这是一次真实的模型加强：保留灰边的不可观察性，但要求所有观察具有同一合法补全。不是假定灰边为红边，也不是从部分类型中凭空恢复完整空面旗。

## 3. 完整补全怎样穷举

Q4 有 16 个顶点、32 条边、24 张二维方格。

选一个隐藏方向，将部分类型写成 H=(A,B)，其中 A,B⊆Q3 均无四环。八条隐藏边用 S⊆V(Q3) 表示。令 J=A∩B，则

**补全 K=(A,B,S) 无四环，当且仅当 S 在 J 中为独立集。**

证明：两层内部已经无四环。跨层方格由一条同时在 A、B 中存在的边 uv，加上 u、v 两条连接边组成；禁止这样的方格，恰好是禁止 S 同时包含 J 的一条边的两个端点。

枚举和覆盖数据：

- 无四环的标号 Q3：2,902 个。
- 全部有序层对：2,902²=8,421,604 个。
- 按两层同步 Aut(Q3) 和层交换取商：90,179 个部分类型。
- 对每个部分类型穷举全部 256 个 S，合法的带标记补全总数：13,150,453。
- 仅保留当前隐藏方向对应最小部分类型的补全：3,312,331 个代表；仍有合法的同构重复，但覆盖全部完整 Q4 图。
- 只使用旧六矩阵时，可再按四个部分类型编号的无序四元组去重，得到 3,212,724 个系数类型。这不是完整 Q4 的同构类数。

Baber 文献中的完整 Q4 同构类数为 3,212,821。上面两个新计数使用不同等价关系，不应混称。

独立验证器重新生成 Q3 的 48 个自同构，检查每个部分代表是规范代表、各轨道不重叠，并确认覆盖全部 8,421,604 个有序层对。随后逐一枚举合法 S。

对任一完整 K，先选使 H_g(K) 编号最小的方向，再将两层同步变换成相应规范代表。这是 Q4 自同构，并诱导 S 的一个置换；由于该代表的全部 S 均已枚举，K 的等价像必在检查族中。

## 4. 两个真正新增的矩阵块

### 4.1 完整空面根的 45 阶块

固定真实空面 F，根的四条边均已知缺失。沿一个外部方向观察 Q3 延拓，记录四条连接边与平移面四条边。平移面不能有四条边，因此共有 16×15=240 个带根内部标号的状态。

同时按根方格 D4 的八个对称变换对连接顶点与平移边取商，得到 45 类。该分类只消去根内坐标名称，不增加基础类型的根位置标签。

对固定空面 F，定义 u_F 为 n-2 个外部方向的 45 类频率向量。对任意 Q_empty⪰0，u_F^T Q_empty u_F≥0。非空根面的贡献定义为零。

在 Q4 内，F 只有两个外部方向 k,l，局部贡献为

c_empty(K)=(1/24) Σ_{F为空面} Q_empty[τ(F,k),τ(F,l)]。

这是完整补全上可直接观察的统计；旧的单个部分类型一般不能恢复它。

### 4.2 顶点根的 9 阶块

固定顶点 v，观察两个方向生成的方格。15 种无四环边状态，在交换两个方向的作用下分成 9 类。

对固定 v，随机选择两个方向得到 9 类频率向量 u_v。任意 Q_vertex⪰0 均给出 u_v^T Q_vertex u_v≥0。

在 Q4 中，把四方向分成两对共有 3 种无序划分。局部贡献为

c_vertex(K)=(1/48) Σ_{v∈V(Q4)} Σ_{A⊔B=[4], |A|=|B|=2} Q_vertex[η(v,A),η(v,B)]。

第二个求和每个无序划分只算一次。16 个顶点乘 3 种划分，共 48 项。

### 4.3 最终矩阵规模

八块阶数依次为 8、7、4、64、56、49、45、9，总计 6,055 个对称矩阵上三角变量，另有一个上界变量 C。前六块沿用上一轮可观察旗定义；后两块为本轮新增。

本轮最终证书的 4 阶灰根块为零。这是计算结果，不是预先强加的限制。

### 4.4 旧六块的自包含定义与归一化

下面定义先前六块，避免验证依赖旧对话。设部分图 H=(A,B)，两层都是固定标号的 Q3。根有向边 e=(x,y) 的方向为 i。对另一个可见方向 k，定义

s_A(e,k)=1_{xx^k∈A}+2·1_{yy^k∈A}+4·1_{x^ky^k∈A}，

并同样定义 s_B。缺失根边允许 0,…,7；存在根边只允许 0,…,6。

第一族（8/7 阶）：在两层的 24 条有向边上平均。对每个根，其余两个可见方向为 k,l，加入 Q_r[s(e,k),s(e,l)]，r 为根边是否存在。总归一化分母为 48。对一张高维图，这对应固定有向根边，条件于其存在状态后，对外部方向的频率向量取平方。

第二族（4 阶）：根是未观察其状态的一条灰边，即两层的对应顶点 x。在每个 x 及两种层顺序上，对三个可见方向中的三种无序方向对平均。状态为 t_k=1_{xx^k∈A}+2·1_{xx^k∈B}。加入 Q_gray[t_k,t_l]；共有 8×2×3=48 项。注意根灰边本身不需要确定是否选中。

第三族（64/56/49 阶）：根是两层的对应有向边，方向 i；它们的存在状态为 (r_A,r_B)。其他方向 k 的联合状态是 (s_A(e,k),s_B(e,k))。若二根均缺失，有 8×8=64 类；若一缺一存，把缺失层排在前面，有 8×7=56 类；若均存在，有 7×7=49 类。对 24 条有向根边平均，并在两层同状态时额外平均两种层顺序。在高维中根使用两个坐标方向，对其余 n−2 个延拓方向取平方。

上述矩阵按根状态分别取块；对不属于某块根状态的根，贡献为零。这不引入以根频率作分母的非线性项。全部旧贡献都可以写成分母 96 的整数计数。根端点顺序与适用的层顺序均已平均，因此系数对部分图允许的自同构不变。

## 5. 最终局部不等式

设 d(H) 为部分类型的 24 条可见边密度，M_b(H) 为旧六块的同根、不同方向联合计数。定义

L_Q(K)=(1/4) Σ_{g=1}^4 [d(H_g(K))+Σ_{b=0}^5 ⟨Q_b,M_b(H_g(K))⟩]
         +c_empty(K)+c_vertex(K)。

对于检查族中的每个 K，精确整数运算确认

L_Q(K) ≤ 119941059204403 / 200000000000000。

全部表达对 Q4 自同构不变：旧系数已经对允许的根嵌入平均，隐藏方向又在外层平均；新增两类旗分别消去了根内的 D4 或两方向交换对称性。因此覆盖代表上的验证足够。

数值优化采用秩一列生成：Q_b=Σ_t w_t v_t v_t^T，w_t≥0。线性规划由 SciPy 内的 HiGHS 求解，利用对偶矩阵的负特征向量添加方向，并通过穷举查找遗漏的局部违反行。搜索过程中只保留约三千条活跃约束；每份候选上界均重新检查全部代表。

搜索日志的 min_eig 是对偶定价矩阵的最小特征值，不是最终证书矩阵的特征值。它仍可能为负，所以本文不声称最优性。

## 6. 从 Q4 到任意高维的证明

对任意 G⊆Q_n，无四环性质在坐标子立方体限制下保持。随机均匀取 Q4 限制 K，其平均边密度等于 G 的边密度；在 K 内对四个隐藏方向平均也保持该密度。

对旧六块以及新增空面块，固定根后有 q 个外部方向。令 u 为频率向量，R 为两个不同方向的有序联合分布，则精确恒等式为

u u^T = ((q-1)/q)R + diag(u)/q。

前三个旧块 q=n-1；后三个旧块及完整空面块 q=n-2。因此，每个矩阵项在对根平均后至少为 -O(1/n)，常数仅依赖这份固定证书。

对于顶点根 9 阶块，两次独立选择方向对。它们不相交的概率为

p_n = binom(n-2,2)/binom(n,2) = (n-2)(n-3)/(n(n-1))。

不相交条件下的联合分布正是 Q4 内使用的分布。相交概率为 O(1/n)，而固定矩阵条目有界，因此它的局部矩阵项平均同样至少为 -O(1/n)。没有假设真实边场中的方向独立，独立的是条件于根的抽样操作。

对所有 K 的局部不等式平均，得到 rho(G)≤C+O(1/n)，从而 pi_Q(C4)≤C。

使用各块最大对角元求和，一个未优化但明确的有限维版本为，对 n≥4：

rho(G) ≤ C + 1.279846/(n-2) + 2.350554/(n-3)
             +0.483010(4n-6)/((n-2)(n-3))。

所有小数系数向上取整。该误差对 Q8 很大，不能将渐近常数直接乘以 1,024，也不能据此宣称改善 Q8 的有限边数范围。

## 7. 精确认证与独立审计

取 D=10^7。每个矩阵为 Q_b=L_b L_b^T/D²，L_b 是 certificate.json 中的整数矩阵。因此半正定性是精确的，不依赖浮点特征值容差。

公共分母为 384 D²=38,400,000,000,000,000。全局最坏局部行的分子为 23,028,683,367,245,376。约分后即上面的最终界。

独立整数验证程序 verify_standalone.py / verify_direct.cpp：

1. 用 Python 任意精度整数从八组 Gram 因子重建矩阵。
2. 验证全部 C++ 64 位运算具有严格绝对值上界 196,354,873,990,900,224 < 2^63，排除溢出。
3. 不读取预生成旗系数表，重新构造 Q3 自同构、六种旧矩阵计数和两种新矩阵计数。
4. 枚举全部 13,150,453 个合法带标记补全，对覆盖全部完整图的 3,312,331 个代表逐一检查不等式。
5. 最坏整数分子与 certificate.json 完全相符。

另一个独立 Python 程序审计了 500 个随机局部代表的全部新增系数；在六张 Q5/Q6 无四环测试图上直接计算全局根统计，与 Q4 限制平均逐项一致，最大差异小于 6.4×10^-16。这里的抽样检查用于发现建模/实现错误，不能取代上述穷尽整数检查。

本包不是 Lean 形式化证明；理论平均引理在本文给出，程序验证有限局部证书。尚未进行外部第三方复现。

## 8. 对照与消融

以下都是找到并认证的可行证书，不是对应 SDP 的最优值：

| 模型 | 向上取整的认证界 |
|---|---:|
| 上一轮部分 Q4、旧六块及 766 交换等式 | 0.60410234 |
| 本轮完整补全共同来源、旧六块 | 0.60035060 |
| 再加入完整空面 45 阶块与顶点 9 阶块 | 0.59970530 |
| Baber 文献 Theorem 4.1 的比较基准 | 0.60318 |

六块控制证书另存 certificate_six.json，也通过独立直接整数计数验证。

另外测试了 80 条基于隐藏边独立集容量与混合面型差分的投影不等式。本轮短程求解未给这些新乘子分配非零权重，故不把上界下降归功于这组粗约束。

固定最终证书其余矩阵，仅将空面 45 阶块置零，上界变为约 0.62490443；仅将顶点 9 阶块置零，变为约 0.66450414。这证明最终证书确实使用了新增项，但这不是删除相应块后重新优化的结果，不能据此宣称它们的最优收益等于这些差值。

同样，六块控制与八块实验的优化迭代次数不同，不把两个可行界的差直接解释为新增块导致的最优值差。

## 9. 复现

最小验证包只需要 Python 标准库与 C++17 编译器：

    python verify_standalone.py
    python verify_standalone.py certificate_six.json

研究代码包包含生成器、求解器、矩阵和搜索历史。重新生成大表：

    python build_completion.py
    python build_joint_shadows.py
    python build_full_flags.py

随后可运行 solve_joint.py、solve_full_flags.py、certify_full_flags.py。大表约占 1 GB；最小验证器不需要这些大表或 SciPy。
