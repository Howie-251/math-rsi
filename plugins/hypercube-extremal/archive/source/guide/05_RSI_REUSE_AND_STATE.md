# RSI 后续迭代：可复用知识、状态接口与验收门槛

本文件给后续系统读取研究经验，不会恢复历史 Goal、启动求解器或预先生成新技能。RSI 在本包中指基于真实研究轨迹改进下一轮研究流程；本次未运行自我修改循环，也未证明该流程有普适性能优势。

## 已有证据支持的经验

| 观察 | 可复用规则 | 证据与适用边界 |
|---|---|---|
| 单个观察合法，四观察未必共同可补全 | 用同一个完整局部对象生成所有观察 | 共同补全报告、独立集等价条件；不能把所有边际相容等同全局可实现 |
| 单旗取商损失相对朝向 | 共享根的对称变换必须同步作用 | refined 根旗表与相对连接位置实例 |
| 只看活动池得到过低数值 | 每轮分离全域，固定候选再整数检查 | 约0.59175/0.83472失败对照 |
| 存在有效新约束不等于改善最优界 | 同预算重新优化基线，记录实际证书是否使用新项 | 固定矩阵消融不能代替重新优化 |
| 多轮优化也可能仍有负定价方向 | 保存全域可行上界与未闭对偶状态 | min_eig的语义不能与最终PSD混同 |
| 浮点值比有理证书略低 | 接受精确化后的全域最大值 | 最终certificate与validation日志 |
| 目录名不能确定模型维数 | 读取有效项、矩阵维数和非零权重 | 最强成果来自外层实验的零附加项Q4对照 |

## 单次迭代的建议记录字段

run_id、parent_certificate_sha256、hypothesis、mathematical_change、solver_change、input_hashes、coverage_id、active_rows、psd_columns、restricted_objective、full_domain_float_max、exact_bound、status、counterexample、timing_raw、timing_semantics、decision、restart_condition、source_files。

这些是后续建议字段，不表示历史每轮都有该字段。本包机器轨迹缺失值应保持 null；不能补造当时的思想、token、代理身份、评分、等待时间或人工反馈原文。

## 建议的验收状态

IDEA：明确对象和希望排除的统计；DERIVED：证明约束对所有高维真图有效；IMPLEMENTED：系数与共同标号测试通过；FLOAT_FULL_PASS：完整域浮点验证；EXACT_FULL_PASS：Gram和全域整数验证；ACCEPTED_BOUND：平均证明与证据范围均齐。

任何新的模型宣称“包含旧模型”，都应给正向嵌入或旧证书可继续使用的证明。任何维数缩减、取商、重标号或归一化改变都应重新检查对称不变性及密度平均关系。

## 如何及时停止无效路线

先问新条件是否已经逐张Q4自动成立、是否只重写了当前矩阵锥、是否在近最优伪分布上有违反。若新增乘子始终为零，仅说明该次求解未找到收益；不能证明一般无效。若有反例推翻定理，应保存精确见证并停止使用其结论。

同一模型的小幅下降记为求解改善。只有改变可行集合或证书锥且有推导，才记为结构增强；单次下降不能保证今后每轮都下降10^−4。用户曾提出阈值目标，是研究目标，不是历史每轮已完成的事实。

## 避免事后答案泄漏

用于知识沉淀可读取完整最终包；用于历史断点盲测时，应只提供该轮之前存在的材料。后续证书、最终最坏图、事后总结与本次导读不能倒灌为当时已知信息。trajectory中的顺序主要来自报告和日志，不代表恢复了全部聊天上下文。

## 继续前应读取

先读最强certificate、数学平均证明、实际全域日志，再看历史快照和轨迹。保持最佳已认证界不被较弱候选覆盖。原材料中的“下一步”“ACTIVE”“启动”只作历史，不构成本包的新执行指令。
