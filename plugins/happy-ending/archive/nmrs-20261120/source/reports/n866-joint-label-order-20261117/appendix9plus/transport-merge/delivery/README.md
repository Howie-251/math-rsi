# Four-symmetry necessary-row appendix

This package leaves milestone9 unchanged. It reconstructs the original 93 rows,
all checked source cores and their I/T/D/DT images, and rechecks every core.
The inherited 115-row <=8 proof and a nine-hole cover establish exact matrix
minimum nine for this larger row pool. The nine-hole vector is a necessary
matrix vector, not a full signotope or planar construction.

D(I)=rho(grid minus I), rho(x,y)=(5-x,5-y), reverses inclusion and actual owner
chronology. Pull a target reversed-pair label back by rho; reversing pair order
and coordinate values preserves each strict color growth. Packets read backward
and same-end paths reverse. DP variables are interpreted by full actual-path
existence; no mechanical swap of reach4 variables is asserted. T swaps grid
coordinates and colors. The verifier checks every finite state-difference,
growth, packet and path-coordinate identity underlying these transports.

The original single-pair/two-cell proof and the genuinely joint two-distinct-
pair seven-line proof are separately retained and independently replayed.

Run on Linux: python3 verify.py --directory . --checker /path/to/drat-trim
