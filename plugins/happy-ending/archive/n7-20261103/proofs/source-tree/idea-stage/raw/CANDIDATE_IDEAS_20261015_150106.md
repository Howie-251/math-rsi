# C_r 后续剪枝原始候选

生成日期：2026-10-15，Asia/Singapore。生成者：当前主会话（项目请求 main gpt-6-astra，实际模型/effort 未由工具独立认证）。这是供选择的方案原稿，不是实现、实测或独立审阅结果。用户要求先头脑风暴再选择，本轮 pilot budget = 0；下面预算是以后选择方案时的建议，不是已授权运行。

共同记号：H_v 是顶点 v 的精确 down-set，S[v,H] 表示其状态为 H，O[H] 表示某顶点占用 H。35 类状态、25 普通、10 例外。u<v 时 sigma(u,v)=(L_blue(u,v)-1,L_red(u,v)-1) 属于 H_v\H_u；因此状态互异，且真子集状态必须排在其真超集之前。sigma 的取值在 [1,3]×[1,4]。所有新方案以 exact+bridges+F3-main 为基础；不能与旧 bridges-only 的结果混称同一 baseline。

## N01：双锚点的实际占用容量与区间秩

方法：选择 u<v 及候选 G=H_u、H=H_v。预计算

- A(G,H)={K: K 不包含于 G，且 H 不包含于 K}，区间内可用状态的安全上界集合。
- B(G,H)={K: G 真包含于 K，且 K 真包含于 H}，若已占用则必须落在区间内的状态。

追加带两个状态守卫的必要条件：

S[u,G]∧S[v,H] ⇒ sum_{K∈A(G,H)} O[K] ≥ v-u-1；
S[u,G]∧S[v,H] ⇒ sum_{K∈B(G,H)} O[K] ≤ v-u-1。

两条均保留守卫。第一条由区间状态互异及有序非包含性推出；第二条由真包含关系强迫位置推出。A 可包含出现在区间外的类型，故只是安全放松，不能解释为精确区间状态集合。B 在 G、H 不可比时为空。

与旧 F4 的区别：旧 F4 以目录大小和全局类别预算预计算静态双锚点容量；这里在 O[K] 被搜索赋值后实时收紧。与 F3 的区别：F3 是单锚点全局前后界，这里是两个锚点共同限定的区间。共享相同状态集合的计数器；先覆盖少量 gap/小容量集合，不能全量复制每个锚点组合的计数器。

假设：剩余区间容量不足能在具体颜色未决定前否定锚点组合。最小验证：数学模板、非空 SAT 控制、guard 反向传播、对当前 baseline 的 UP 增量；选择 20–50 个不同集合上限作为首版资源限制，具体选择应以结构及传播样本确定。成本估计 2–4 工程日，首次受限筛选 2–4 CPU 小时。风险中：守卫太晚满足；计数器规模与传播成本；与已有约束 UP 等价。贡献：方法。

## N02：精确终端标签与非矩形状态差集的支持表

方法：为选定终端对 (u,v) 建立最多 12 个精确标签 Q[u,v,x,y]，用已有精确路径阈值双向定义 L_blue=x+1、L_red=y+1；不存在的阈值按路径界常量处理。保留原精确路径编码。把 sigma∈H_v\H_u 编为联合支持关系，使状态、标签及路径变量互相删值。

旧 F6 只针对相邻顶点、单元素差集给上下界；本候选处理 2–3 个元素及非相邻精选终端对，并保留坐标相关性。例如 G=(2,1,0)、H=(3,2,0)，差集为 {(1,3),(2,2)}，逐坐标上下界会错误保留标签 (2,3)，联合支持表会删去它。这只是目录层例子，不声称该状态对在每个位置均可实现。

Q 的一热性与扩展依靠真实最长长度及其阈值单调性；不能把单向路径见证当精确真值。支持表必须双向/支持式编码，不能只加完整赋值失败时才生效的禁表。使用 short supports/MDD 压缩属于实现选择，需比较实际 UP。

假设：蓝红分别看来可行、联合不可行的分支可更早消失。最小验证：先有限 12 标签语义及投影检查，再选差集大小 2–3 的关系，首批仅小间距与少数高影响对。成本 3–6 工程日，首次筛选 2–4 CPU 小时。风险中：原 bridges 已经推出大量相关事实；Q 引入后无新增 UP；正表和辅助变量可能膨胀。贡献：方法。

## N03：最大拐角的不同前驱见证匹配

方法：对状态 H 取坐标偏序的极大格点 Max(H)。每个极大格点 c 必须等于某个真实 sigma(u,v)，u<v：因为 H 是所有终端标签生成的 down-set，支配极大格点的标签只能等于该格点。一个前驱 u 只有一个 sigma(u,v)，不能同时实现两个不同极大格点。于是 Max(H) 必须能匹配到不同前驱。

3×4 盒中最多 3 个极大格点。先不引入通用匹配器，只编译 2/3 个拐角的 Hall 支持。对于某拐角子集 T，当它们所有可能前驱都落入 U 且 |U|<|T| 时排除 S[v,H]；等容量时可排除其他拐角使用 U。动态域的前提必须出现在解释子句里，或用完全定义的支持电路表达，不能把某次搜索产生的域收缩当全局事实。

例 H=(4,2,1) 的极大格点是 (1,4),(2,2),(3,1)，需要三个不同 terminal_left；若它们只剩两个可行前驱则冲突。匹配约束只要求终端对的前驱不同，不要求各见证整条路径顶点不相交，不引入错误的路径互斥假设。

与旧方案区别：F3 计数已占用状态类别；这里分配的是一个状态内部的极大标签见证。已有 cell witness 保留，需检验显式匹配是否能在 witness 未选定时新增传播。

假设：多个拐角竞争相同前驱是难分支的早期结构瓶颈。最小验证：独立提取 SAT 模型的极大格点与标签；两拐角开始，随后三拐角；人工构造支持紧张但 baseline UP 不冲突的局部赋值。成本 3–5 工程日，首次筛选 2–4 CPU 小时。风险中：真实搜索中支持通常太宽；显式条件可能长。贡献：领域结构方法。

## N04：顶点—状态的动态小 Hall 集

方法：保留顶点的一热状态表示，在当前剩余域 D_v 上检测 2–4 个顶点的状态并集。当 |union D_v| 小于顶点数立即冲突；相等时排除其余顶点使用该状态集合。初版只处理频繁/结构固定的 2–4 类型集合，可用 [H_v∈T] 的精确 membership 与容量约束表达；较重版才用完整最大匹配传播器。

与旧 F4 区别：旧版 Hall 是基于静态域计算的若干 O 计数割，这里对搜索中缩小的 S 域响应。与 F2 的逐对 AMO 区别：逐对不相等不能通过 UP 普遍发现 4 个顶点争 3 类状态。

动态删除必须记录导致域收缩的 S-literal 前提，并能在固定原公式/结构模型下认证。默认 AE 外部求解器是否提供解释传播接口未经验证；第一阶段选离线少量静态 CNF 模板，不假设存在 IPASIR-UP 接口。不得静默切换求解器。

假设：接近占满 35 状态的困难分支更容易出现 Hall 瓶颈。最小验证：先分析匹配缺口出现频率与 UP 增量，再决定是否实现重型匹配。成本小集合版 3–6 日，完整动态版 1–3 周；首次筛选 2–4 CPU 小时。风险中高：很多 Hall 集、解释和证明成本；高度重复 F2/F3。贡献：方法。

## N05：状态集合占用数与顶点位置数的守恒通道

方法：对精选状态子集 T，定义 M[v,T] ⇔ OR_{H∈T} S[v,H]，用共享精确计数建立 sum_v M[v,T]=sum_{H∈T}O[H]。等式由全局状态注入性得出。为前后缀计数保留可共享接口，使 F3 的类型计数触发具体位置域缩减。

与旧 F3-vertex 区别：T=全部例外状态、只加 sum full=e 就是已测变体，不能计为新方案。这里只针对 principal ideals/filters、N01 的少量区间集合等多类资源守恒。不能假设已占用状态都位于某前缀；限制位置需要守卫/已证明支持。

假设：O 层和 S 层分别有信息但传播通路太长。最小验证：3–5 个 T 起步，分别测试总数等式与前后缀通道。成本 2–4 日，首次筛选 1–3 CPU 小时。风险中：可能只有昂贵的重复约束；与 F3/N04 重叠。贡献：方法/诊断。

## N06：四顶点 signotope 与终端标签的局部支持闭包

方法：在选定的 3–4 顶点窗口上组合原始 signotope 子句、真实颜色扩展递推及终端标签的有限域必要条件；离线求允许关系，编译较短的蕴含/冲突。四顶点提供旧 F7 三相邻点单元素差模式未使用的 signotope 联动。

全局 H_v 和 sigma 不能由窗口诱导子图重新计算来替代。窗口外前驱产生的标签必须作为边界输入，以安全放松保留；只排除在该放松下仍无法完成的关系。可先仅处理几何 signotope 四个三元颜色，联合两个已被状态限制的标签，不一次展开 35^4 状态表。

假设：个别 triple 均可选，但四个 triple 不可能共同满足 signotope 的冲突能提前出现。最小验证：每个模板有局部推导或独立认证，SAT 控制带窗口外见证。成本 5–10 日；首轮模板发现限 4–8 CPU 小时。风险高：关系过大、边界处理错误、早已被原 signotope UP 检出。贡献：方法。

## N07：语义变量定向探测与短引理压缩

方法：只在 O、S、少量关键路径变量上做有预算的失败文字/双文字探测；从已认证的局部推理抽取短子句，做 subsumption/vivification，保留确有新增传播的少量引理。引理始终带其依赖的 cell/mode/assumption 守卫。

在不可满足的目标 F 上，“F 蕴含子句”数学上真但对一般模板外推没有信息。只有同一固定 F 的检查过推导能作为该实例证明前缀；跨 cell 的模板必须从不含目标 e/m 的共同结构基式、或明确保留条件的局部基式证明。不得把目标整体 UNSAT 当通用引理有效性的证据。

假设：当前求解器的通用预处理没有重点探测有领域含义的稀疏变量。最小验证：同样预算比较额外根传播、采样部分赋值上的提前冲突、完整求解收益；引理推导成本计入。成本 2–5 日，发现预算先限 0.5–2 CPU 小时/格。风险中：AE 已在做类似预处理；探测时间占掉收益；跨格迁移失败。贡献：方法/诊断。

## N08：拆解 F2，只保留对 F3 有增益的部分

方法：按旧代码的四个 component 分别试：equal_state（跨点同类型 AMO）、ordered_containment、static_domain、相邻双向 support。先做纯组件叠加当前 F3 baseline，不重写总体编码；以额外传播/成本挑选少量组合。

这是已测方法的消融优化，不是新数学结论。历史 F2+F3 比 F3 单独慢不能证明所有 F2 子组件都无效，也不能保证拆解就更快。

假设：F2 收益被约 21 万条冲突约束的开销淹没，较小组件可能保留收益。最小验证：四组组件、固定种子/资源配对 baseline，筛选后确认；每组与当前 baseline 比较。成本 1–2 日，首轮 2–4 CPU 小时。风险低至中（实现风险较低，加速未知）。贡献：诊断/工程。

## N09：少量完整反向终端路径及拼接预算

方法：对少量终端对构造精确 suffix 长度。若同色长度 p 的路径以 (u,v) 结束，长度 q 的路径以 (u,v) 开始，则拼接为 p+q-2 个顶点；蓝 p+q-2≥5、红≥6 时禁止两者同时成立。长度阈值可生成短二元冲突。

旧 F5 已测红 terminal4/suffix4，不能重复报告为新方法。本候选增加蓝色与其他达到禁止长度的组合，先查明哪些 suffix 变量已存在、哪些需额外递推。绝不能以名称推断 cap/cup 的颜色或端点语义。

假设：来自左侧和右侧的路径预算能比单向递推更早相撞。最小验证：先一种未测拼接与少量中间对，覆盖共享两端点的精确长度计算。成本 3–6 日，首轮 2–4 CPU 小时。风险中高：旧 F5 在某格退化，新增后缀成本大。贡献：方法。

## N10：基于有证据冲突的自适应语义切分

方法：不枚举全部 weight-e mask。先以少量高影响 O/S/路径文字构造互斥完备二叉划分，在浅层传播强而难度不平衡处自适应分裂；兄弟分支只复用有正确条件、可重验证的引理。每个叶子使用受控外部 AE 过程。

与旧 F8 区别是选择树与共享解释，而不是完整枚举掩码后顺序运行。仍需所有叶子覆盖、分支假设和证明合并认证；不能仅凭最快叶子或并行墙钟给出总提速。不是优先改善单公式传播的路径。

假设：个别困难 case 的搜索尾部和证明巨大，可通过少量平衡切分降低单任务尾部。最小验证：4–8 叶子、相同总核预算、总 CPU 与 proof/check 成本单列。成本 4–8 日，首轮总 4–8 CPU 小时。风险高：重复学习、总工作增长、分区认证成本。贡献：搜索组织。

## 所有候选共同的验收边界

不预报加速倍数。必要条件推导与实际求解收益是不同问题。先做非空 SAT 控制、投影/辅助变量扩展检查及局部传播诊断，再做当前生产 baseline 的配对计时。保留超时为截尾，不把截断时间当完成时间。求解、proof bytes、生成/预处理、checker 分列；大规模最终选择考虑 solve+check 总成本。任何改变均为新 campaign/snapshot/proof bindings；旧封存和进程不动。
