# Q7 工作流改进与 MathRSI 本地用法

本页把工作区 `AGENTS.md`、`Q7_WORKFLOW.md` 及 `RESEARCH_MISTAKES.md` §§22–24 的现行规则整理为可独立读取的执行说明。《[汇总与工作流图](../START_HERE.html)》用已证 E16 示范各步骤。

## 单一调度及局部回流

使用 `mathrsi-research` 组织主线。研判路线用 `mathrsi-route-loop`，明确子题进入 `mathrsi-prove`，局部核验由 `mathrsi-verify` 回到当前证明，完整结果经主代理对原输入回代后进入 `mathrsi-handoff`。本地前提、预算和验收规则适用于每次调用。主代理负责数学决策、判重、低成本检查、回代与止损。工程任务交 GPT-6.1-sol high 子代理，正式证明作者与独审者分离。

## 分类、旧覆盖与难余域

1. 开轮固定原输入整域、全称量词、必须保留的对象、可用依赖、同一数学缺口、操作预算和成功标准。
2. 先核已证跨层定理与合法补全。短超匹配的补边须短且端点自由，所得匹配须保留原边、严格减少孔数并进入已证层。在同一实际输入和坐标系核对各覆盖块，按并集计算。
3. 写明候选易族与剩余域，先对剩余域中最难的条件做一次预设有界的实质推导。逐项核真实来源、实际端口与配对、可删边和展开保边。通过关键检验并得到可执行路线即可采用该分类。采用后逐族证明，在最终整域验收时才要求覆盖穷尽或保边严格归约到已证终端。已证易族按实际范围回收。

## 结构先行及证书使用

优先以可复用结构定理强迫实际接口，或证明保边严格下降。只有证明得到可控且完备的有限核，才使用证书兜底。先冻结有限核的代表及索引，给出同一实际原输入的运输、覆盖证明和逆向保边。遇到首个真实构造障碍暂停原索引并分析，局部修复经独审后方续检。验收时核全索引及各构造的实际覆盖。

SAT/CP 作为一次预设有界的诊断或否定检验。结果为 UNKNOWN 时回到结构推导。局部构造、必要归约和编码分别以实际范围记账。保留同族独审与导入依赖的来源、散列及评级。

## 回代、记账和止损

主代理逐支复核同一个原输入的原边保留、单圈、实际路径配对、逆运输和分支穷尽。原始目标、必要条件、条件性工具、固定例、正式闭合分别记账。记录本轮原义务、实际所得、原域缩减、依赖和继续或暂停的依据。

连续两轮界内推导未改变整域核心障碍、未证明严格下降或可控完备终端，也未关闭事前指定整域，则暂停当前默认机制。第三轮须有新的可判定机制、边界和交付物。按同一数学缺口累计，局部 PASS 与改名沿用累计。反例否定核心规则时立即停用并复核下游。全域匹配与高孔大枚举遵循用户既有禁令。
