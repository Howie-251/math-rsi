## 原始输入与精确结论

令 $M\subseteq E(Q_7)$ 为短匹配，方向 $j$ 的规定边恰为 $aa^*,cc^*$，其中 $A,B$ 是两个 $j$ 面，$a,c\in A$ 同色，$x^*=x\oplus e_j$。记 $M_A=M\cap E(A)$、$M_B=M\cap E(B)$。取分开 $a,c$ 的方向 $i$，使 $M_B$ 恰有一条 $i$ 方向规定边 $pq$。交换 $a,c$ 名称后令

$$X=\{x\in B:x_i=a_i\}\ni a^*,p,\qquad Y=B\setminus X\ni q,c^*,$$

并要求 $p$ 与 $a^*$ 异色。该命名总能完成，因为原端口同色，而 $p,q$ 异色。定义直接由原输入决定的集合

$$L=\{\ell\notin\{i,j\}:q_\ell\ne c_\ell,\ M_B\cap E(Y)\text{ 中无方向 }\ell\text{ 的边}\}.$$

**定理 V。** 下列任一条件成立时，存在包含 $M$ 的 Hamilton 圈 $H$，其 $j$ 方向边恰四条，且 $E(H)\cap E(B)$ 中的 $i$ 方向边恰为 $pq$。

1. $|L|\ge2$，无需任何额外的 $M_A$ 自由点条件。
2. 存在 $\ell\in L$，令 $t=c\oplus e_\ell$，且满足以下至少一项：
   - (I) 存在 $d\notin\{i,j,\ell\}$，使 $s=c\oplus e_d$ 对 $M_A$ 自由。
   - (II) $t$ 被 $M_A$ 覆盖。
   - (III) $t$ 对 $M_A$ 自由，且有在 A 内与 t 相邻的 $M_A$ 自由点 $z\notin\{a,c\}$。

不要求 $a_\ell=p_\ell$，也不要求 $\ell$ 分开 $a,c$。另一面上 $i$ 方向规定边数不限。条件是原始输入的显式充分条件，并未证明穷尽所有剩余输入。

## 证明

匹配性质保证 $a,c$ 对 $M_A$ 自由，$a^*,c^*$ 对 $M_B$ 自由。我们先构造一个含 $M_A$ 的 Hamilton $a$–$t$ 路 $P$，并选 $\ell\in L$，使 $t^*$ 位于 Y 的 q 侧，而 P 在 c 处有实际边 $cs$，其方向 $d\notin\{i,j,\ell\}$。这里 $t$ 与 $a$ 异色，且 $c\ne a,t$。

**条件 1。** 取不同的 $\ell_1,\ell_2\in L$，再取 $h\notin\{i,j,\ell_1,\ell_2\}$，令

$$t=c\oplus e_{\ell_1}\oplus e_{\ell_2}\oplus e_h.$$

这样的 h 存在。t 与 a 异色；其 i 位与 c 相同、与 a 不同，故 $t\ne a$；$d(c,t)=3$，故 $t\ne c$。P6 给出含 $M_A$ 的 Hamilton $a$–$t$ 路 P。c 是内部点，P 在 c 处度二，至多一条入射边沿 i，故可取一条非 i 边 cs，记方向为 d。选 $\ell\in\{\ell_1,\ell_2\}\setminus\{d\}$。则 $d\notin\{i,j,\ell\}$，s 与 c 有相同的 $\ell$ 位；t 与 c 的 $\ell$ 位相反，恰与 q 相同。因 $d(c,t)=3$，s 也不是终点 t。

**条件 2。** 固定 $\ell,t$。t 与 a 异色，且 $t_i=c_i\ne a_i$，所以 $t\ne a,c$。

- (I)：c 与 s 均对 $M_A$ 自由，故 $N=M_A\cup\{cs\}$ 为短匹配。a 不在 cs 上：$a\ne c$，a 与 c 同色而 s 异色。P6 在自由根 a 与异色目标 t 间给出含 N 的 P。于是所需 cs 为实际路边。
- (II)：P6 对 $M_A$ 给出 $a$–$t$ 路 P。t 在 P 中度一，其唯一入射边必须为其规定匹配边；c 自由，所以 $ct\notin M_A$，从而 $ct\notin E(P)$。c 为内部点，其两条实际路边均非方向 $\ell$（c 的唯一该向邻点为 t），至多一条沿 i，故可取所需 cs。
- (III)：$N=M_A\cup\{tz\}$ 为短匹配，a 对 N 自由。P6 给出含 N 的 $a$–$t$ 路 P。其终点 t 的唯一入射边是 tz，且 $z\ne c$，所以 $ct\notin E(P)$。同 (II) 选取 cs。

上述各分支中，$cs\notin M_A$，因为 c 对 $M_A$ 自由。现在把 Y 沿所选 $\ell$ 分为

$$W=\{x\in Y:x_\ell=q_\ell\}\ni q,t^*,\qquad V=\{x\in Y:x_\ell=c_\ell\}\ni c^*,s^*.$$

X 是 $Q_5$，W、V 为两个 $Q_4$。唯一 i 规定边和 $\ell\in L$ 保证完整分解

$$M_B=N_X\mathbin{\dot\cup}N_W\mathbin{\dot\cup}N_V\mathbin{\dot\cup}\{pq\},\qquad N_Z=M_B\cap E(Z).$$

所有 P4/P5 调用的根均在实际局部匹配下自由：$a^*$ 对 $N_X$ 自由，q 对 $N_W$ 自由（其唯一原内部匹配边为 pq），$c^*$ 对 $N_V$ 自由。端点均异色：$a^*,p$ 按命名异色；q 与 $a^*$ 同色而 $t^*$ 与 $a^*$ 异色，故 $q,t^*$ 异色；$c^*,s^*$ 因 cs 为短边而异色。目标允许已覆盖。

P5 给 X 中含 $N_X$ 的 Hamilton $a^*$–p 路；P4 给 W 中含 $N_W$ 的 Hamilton q–$t^*$ 路，给 V 中含 $N_V$ 的 Hamilton $c^*$–$s^*$ 路 S。前两条路经 pq 相连成为覆盖 $X\cup W$ 的简单 $a^*$–$t^*$ 路 R。R 与 S 不交，共覆盖 B；其中唯一 i 边为 pq。

将 P 的实际边 cs 替换为 $c,c^*,S,s^*,s$，得覆盖 $A\cup V$ 的简单 a–t 路。再以边 $tt^*$、R 的逆向遍历、边 $a^*a$ 闭合，得到覆盖全 Q7 的单个简单圈。形式上

$$E(H)=(E(P)\setminus\{cs\})\cup E(S)\cup E(R)\cup\{cc^*,ss^*,tt^*,aa^*\}.$$

a,c 同色，s,t 为另一色；s,t 的 $\ell$ 位不同，故四个 j 桥互异。被删 cs 非规定边，三块路保留全部 $M_B$，规定桥 $aa^*,cc^*$ 已恢复，所以 $M\subseteq E(H)$。j 恰四桥，B 内 i 恰 pq。闭圈使用跨 j 的 tt* 和 a*a，不需要 A 中存在短边 at。证毕。
