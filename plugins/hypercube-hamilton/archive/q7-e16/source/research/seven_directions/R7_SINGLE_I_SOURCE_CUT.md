# R7 单条内部 i 桥：源面沿 l 的零／单规定桥构造

## 原始输入、缺失义务与成功标准

沿用 [定理 V](R7_SINGLE_I_FLEXIBLE_EAR.md) 的原始假设与异色命名：短匹配 $M\subseteq E(Q_7)$ 沿方向 j 恰有 $aa^*,cc^*$，$a,c$ 在同一个 j 面 A 且同色，另一面为 B，$x^*=x\oplus e_j$。取分开 a,c 的方向 i，要求 $M_B=M\cap E(B)$ 恰有一条 i 方向规定边 pq，并命名使

$$X=\{x\in B:x_i=a_i\}\ni a^*,p,\qquad Y=B\setminus X\ni c^*,q,$$

且 p 与 $a^*$ 异色。令 $M_A=M\cap E(A)$，

$$L=\{l\notin\{i,j\}:q_l\ne c_l,\ M_B\cap E(Y)\text{ 无方向 }l\text{ 的边}\}.$$

固定任意 $l\in L$，令 $t=c\oplus e_l$。记 A 沿 l 切成的两个 $Q_5$ 为 $A_c$（含 c）与 $A_t$（含 t），$N_c=M_A\cap E(A_c)$、$N_t=M_A\cap E(A_t)$。颜色记为 $p(x)=\sum x_k\pmod2$，与边端点 p 按上下文区分。

**定理 W。** 在上述原始输入下，下列任一项成立，就存在包含全部 M 的 Hamilton 圈 H，其 j 方向边恰四条，且 $E(H)\cap E(B)$ 中的 i 方向边恰为 pq。

1. $M_A$ 恰有一条 l 方向边 $rr'$，且 $a\in A_t$；命名 $r\in A_t,r'\in A_c$。不附加 r 的颜色或其他端点自由条件。
2. $M_A$ 恰有一条 l 方向边 $rr'$，且 $a\in A_c$；命名 $r\in A_c,r'\in A_t$，并要求 $p(r)\ne p(a)$。
3. $M_A$ 没有 l 方向边，$a\in A_c$，且 t 对 $M_A$ 自由。

这是直接由原始匹配检查的条件。特别适用于 V 的单 l 自由性条件全部失败后的一部分剩余输入；不要求 V 先失败。无 l 桥且 $a\in A_c$、t 已覆盖时已有 V(II)；无 l 桥且 $a\in A_t$ 时，l 分开原端口 a,c，可直接用 T（交换响应面）。故本稿列出的新构造与已有 T/V 合起来覆盖 $M_A$ 无 l 方向边的全部情形，但只在原有 $l\in L$ 假设下保留本文陈述的 B 内 i 唯一桥结论；T 本身只保证四条 j 桥，不附加 B 内 i 数量。

本轮缺失义务仍是：在具体原始输入条件下取得含 $M_A$ 的 Hamilton a–t 路，其内部点 c 至少有一条方向不在 $\{i,l,j\}$ 的实际路边 cs。成功标准是证明这一路性质并代回 V 的三块构造，得到原始 M 的单个生成圈；不是只定义接口或提供固定样本。

## 首个低成本检验与构造边界

固定 $l,t$。V 的 (I)、(II)、(III) 全部失败，意味着：t 自由；c 的每个方向 $d\notin\{i,j,l\}$ 邻点均被 $M_A$ 覆盖；t 的每个 A 内自由邻点均属于 $\{a,c\}$。这里 a 与 t 异色，故二者可能相邻，必须保留排除 a 的条件，不能无条件称 t 仅有 c 一个自由邻点。

由 P6 得到任意含 $M_A$ 的 Hamilton a–t 路 P。c 是内部点，因为 c 与 a 同色且 $c\ne a$，而 t 与 c 相邻。如果 P 在 c 处没有方向在 $\{i,l,j\}$ 之外的实际边，则 c 的两个路邻点必须恰为 $c\oplus e_i$ 和 t：c 在 A 中不可能有 j 边，每个方向至多一个邻点。沿 a 到 t 的顺序，P 必以

$$\ldots,c\oplus e_i,c,t$$

结尾。这是失败路径的必要结构，不是所有路径均失败，也不是原始 M 的反例。W 以下主动重新构造 P，使 c 的两条路边都不沿 l。

另一个有界否定检验：若 a,c 位于 $A_c$，$M_A$ 唯一 l 桥为 $rr'$，而 $p(r)=p(a)$，任何 a–t Hamilton 路若只用这一条 l 桥，则其在 $A_c$ 的部分必须是 Hamilton a–r 路。$Q_5$ 的两个颜色类各16点，所以生成路两端必须异色；若 r=a，则在唯一桥前也不能覆盖32点。因此该仅一桥构造不可能。此障碍只针对所限构造，不能推出原输入不延拓；允许额外 l 桥的路径尚未排除。

## 源面构造证明

原匹配给出 a,c 对 $M_A$ 自由。t 与 a 异色且不同于 a,c，因为 $t_i=c_i\ne a_i$。只需构造满足上述 c 处实际边条件的 P。

**W(1)：a,t 在同一半面。** r 对 $N_t$ 自由，因为其唯一 $M_A$ 边是跨 l 的 $rr'$；$r\ne a$，因为 a 对 $M_A$ 自由。也有 $r\ne t$：否则其唯一 l 邻点 $r'=c$，与 c 对 $M_A$ 自由矛盾。因此 r 是任何 a–t 生成路的内部点。

在 $A_t$ 中，a 对 $N_t$ 自由且 a,t 异色，P5 给出含 $N_t$ 的 Hamilton a–t 路 $P_t$。r 在 $P_t$ 中有两个不同邻点，选择一个 $h\ne t$。边 rh 不属于 $N_t$，因为 r 自由；它也不是唯一跨 l 规定边，故不属于 $M_A$。在另一半面中，$r'$ 对 $N_c$ 自由。短边 rh 给出 r,h 异色，同时翻转第 l 位给出 $r',h\oplus e_l$ 异色。因此 P5 给出 $A_c$ 中含 $N_c$ 的 Hamilton $r'$–$(h\oplus e_l)$ 路 $P_c$。

把 $P_t$ 的实际边 rh 替换成

$$r,r',P_c,h\oplus e_l,h.$$

替代路径内部在另一半面，所以所得 P 是覆盖 A 的简单 a–t 路，保留 $N_t,N_c$ 以及规定桥 $rr'$，未删规定边。c 不等于 $r'$（c 自由），也不等于 $h\oplus e_l$（否则 h=t，与选择矛盾），故 c 是 $P_c$ 内部点。其两条实际边均在 $A_c$ 内，不沿 l；至多一条沿 i，故至少一条所需 cs 的方向不在 $\{i,j,l\}$。

**W(2)：a,c 在同一半面且 r 与 a 异色。** a 对 $N_c$ 自由，故 P5 在 $A_c$ 给出含 $N_c$ 的 Hamilton a–r 路 $P_c$。$r'$ 对 $N_t$ 自由；r 与 a 异色，而翻转 l 的 $r'$ 与 a 同色、t 与 a 异色，所以 $r',t$ 异色。P5 在 $A_t$ 给出含 $N_t$ 的 Hamilton $r'$–t 路 $P_t$。依次走 $P_c$、规定桥 $rr'$、$P_t$ 得含整个 $M_A$ 的 Hamilton a–t 路 P。c 不等于 a，且 c 与 a 同色、r 与 a 异色，故 $c\ne r$；因此 c 是 $P_c$ 内部点，两条实际路边均不沿 l，照前选 cs。

**W(3)：没有 l 规定桥。** 在 $A_c\cong Q_5$ 中任选与 a 异色的点 w。因 a,c 同色，$w\ne a,c$。P5 在自由根 a 与目标 w 间给出含 $N_c$ 的生成路 $P_c$。t 对 $N_t$ 自由；$w\oplus e_l$ 与 a 同色，故与 t 异色。P5 在自由根 t 与目标 $w\oplus e_l$ 间给出含 $N_t$ 的生成路 $P_t$。依次走 $P_c$、边 $w(w\oplus e_l)$、反向 $P_t$ 得含整个 $M_A=N_c\dot\cup N_t$ 的 Hamilton a–t 路 P。c 是 $P_c$ 内部点，同样取得实际 cs。

以上三个分支均得到 c 内部、$cs\in E(P)\setminus M_A$、方向 $d(cs)\notin\{i,j,l\}$。h、r、w 等目标可能已覆盖时均不构成额外假设；所有 P5 根的局部自由性已逐一证明。

## 回代 B 面三块并闭圈

令

$$W_B=\{x\in Y:x_l=q_l\}\ni q,t^*,\qquad V_B=\{x\in Y:x_l=c_l\}\ni c^*,s^*.$$

X 为 $Q_5$，$W_B,V_B$ 为 $Q_4$。唯一 i 规定桥与 $l\in L$ 保证 $M_B$ 恰分解为各块内部匹配 $N_X,N_W,N_V$ 和 pq，没有遗漏跨块规定边。自由根分别为 $a^*$、q、$c^*$；q 的原匹配边为 pq，故在 $N_W$ 下自由。三对端点 $a^*,p$，$q,t^*$，$c^*,s^*$ 均异色：第一对按命名；第二对中 q 与 $a^*$ 同色、$t^*$ 与 $a^*$ 异色；第三对来自实际短边 cs。

P5/P4 分别给出含各块规定匹配的生成路 $a^*$–p、q–$t^*$、$c^*$–$s^*$。前两路以 pq 连接成覆盖 $X\cup W_B$ 的简单 $a^*$–$t^*$ 路 R，第三路记 S。R,S 不交并覆盖 B；其 B 内唯一 i 边是 pq。

把 P 的实际边 cs 替换为 $c,c^*,S,s^*,s$，再从终点 t 经 $tt^*$、反向 R、$a^*a$ 闭圈。所得圈边集为

$$E(H)=(E(P)\setminus\{cs\})\cup E(R)\cup E(S)\cup\{aa^*,cc^*,ss^*,tt^*\}.$$

耳替换保持简单路，闭圈使用另一不交块中的 R，所以最终是单个简单圈并覆盖128点。a,c 同色，s,t 为另一色；$s_l=c_l\ne t_l$，故四个 j 桥互异。被删 cs 非规定边，三个块路保留全部 $M_B$，两个原 j 规定桥已恢复，所以包含全部 M，且 j 恰四桥、B 内 i 恰 pq。定理 W 得证。

## 一个固定见证：严格超出 T/U/V 的所有允许方向

只对下面一个明确输入核验，无匹配族搜索或高孔枚举。j 规定桥为 `(0,64),(3,67)`，A 内18条边为

```text
[(1,9),(11,10),(19,18),(35,34),(6,14),(5,13),
 (15,31),(23,22),(39,38),(8,12),(16,48),(17,49),
 (20,52),(24,26),(25,27),(28,30),(40,56),(41,57)]
```

B 内6条边为

```text
[(78,79),(68,70),(72,74),(81,89),(80,84),(82,86)]
```

一次确定性核验：26条边全为短边，52个端点互异；七方向计数为 `(6,5,3,4,3,3,2)`。因此只有 j=6 可作为 T/U/V 的恰两条规定桥方向，且原 A 端点0、3均为偶色；每方向至少两条边，也排除零／一桥基线。分开0、3的方向仅0、1；A 内这两方向分别有5、3条规定边，B 内分别有1、2条，故 T 在所有允许切向和换面下均失败。

U/V 需要响应面有恰一条分开方向规定边。换面后响应 A 的计数5、3均不满足；响应 B 的 i=1计数2也不满足。唯一剩余候选为响应 B、i=0，且异色命名唯一确定 $a=0,c=3,p=78,q=79$。交换 a,c 后 p 变成79，与新的 $a^*=67$ 同色，不是合法异色命名。其 Y 内唯一规定边为81–89，方向3；q 与 $c^*=67$ 差位为2、3，其中方向3被该边阻挡，所以 $L=\{2\}$。U 的 K 是 L 的子集，而 $a_2=0\ne p_2=1$，故 K 空，U 不适用。

对 V 唯一候选 $l=2,t=7$，t 对 $M_A$ 自由，故 (II) 失败；c=3在方向1、3、4、5的邻点1、11、19、35全部被覆盖，故 (I) 失败。t=7在 A 中除c外的邻点6、5、15、23、39全部被覆盖，故 (III) 失败。$|L|=1$，V 的条件1也失败。因此对该固定 M，所有 T/U/V 允许方向、换面、命名均不适用。

但 A 唯一 l=2 规定桥为8–12，且 a=0,c=3均在 l 位为0的半面；命名 r=8、$r'=12$，r 奇色与 a 异色，满足 W(2)。故 W 对原始输入确有严格新增覆盖。该样例只区分上述 T/U/V 与低桥基线，不主张排除其他既有定理；其计算不承担 W 的全称证明。
