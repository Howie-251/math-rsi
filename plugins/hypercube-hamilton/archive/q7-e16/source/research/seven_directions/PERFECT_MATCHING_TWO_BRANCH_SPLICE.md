# 两个同奇偶分叉点的完美匹配拼接引理

日期：2026-11-02。ARIS proof-writer；证明稿，待独立审计。本文不关闭完整 T44^(6) 或七维八孔层。

## 引理

设 q≥5，N 为 K(Q_q) 的任意完美匹配，S 为 Q_q 的短边森林。若 S 中有两个不同的同奇偶顶点，其度数均至少为2，则存在 e∈S\N，使 N 可延拓到包含 e 的 Hamilton 圈，且所有新增边短。

不要求 S 的边数达到任何阈值。N 可以包含长边和同奇偶边。

## 证明

称短边 e 不可用，如果 e∈N，或 e∉N 且不存在含 N∪{e} 的上述圈。令 U 为所有不可用短边组成的图。

引用 Fink–Mütze [作者 PDF](https://tmuetze.de/papers/match.pdf) 定理11：若 xy∉N 为短边，写 a=N(x), b=N(y)，则 xy 不可强迫当且仅当

$$T=N-ax-by+ab$$

含半层。记半层大小 h=2^(q−2)≥8。以下将这种不属于 N 的不可用边称为坏边。

**N 含完整半层。** 沿其方向 j，半层覆盖集合及补集的诱导短边均仅沿 j，因此 N 中全部短边都沿 j。对任何其他方向短边 xy，删除其匹配边后 T 保留至少 h−2 条 j 边；含完整半层的匹配不可能含别的方向短边，所以 T 中可能的半层只能沿 j。但 xy 的两端分别位于两个 j 半层的覆盖集合，T 的两个孔 x,y 使两个半层都不完整。因此其他方向边均可强迫，U 包含在方向匹配 L_j 中。S⊆U 时不可能有度2点。

**N 不含完整半层。** 每条坏边 xy 对应一个半层 H，唯一缺边为 ab，新边 ab 补成 H。故 N 包含 H 的 h−1 条边。不同方向半层的覆盖集合相交于 h≥8 个顶点，而各自缺一边总共只能空出4个顶点，故 N 的所有这种近半层必须同方向 j。只有两个 j 半层，每个缺边唯一决定潜在坏边 N(a)N(b)，所以坏边最多两条。

若没有坏边，U 是匹配。若只有一条坏边 xy，则 U 是匹配加一条边。所有可能度数至少2的顶点只有 x,y，它们奇偶相反；U 的任意子图至多有一个给定奇偶类的度2点。因此不含题设的 S。

若有两条坏边，两个 j 半层均为近半层，设它们缺失的 j 边分别为 ab、cd。N 包含 L_j\{ab,cd}，其余四个顶点由 N 中另外两条边配对。因为 N 不含完整半层，剩余配对只能跨这两个顶点对。交换 c,d 的命名后写成 ac、bd。

两个潜在坏边分别就是 cd、ab。又因 b=a⊕e_j、d=c⊕e_j，ac 与 bd 具有相同的汉明距离；或者二者都长，或者二者都短。

- 两条均长时，U 恰为 L_j，是匹配。
- 两条均短时，它们沿同一方向 k≠j，四条边 ab、bd、dc、ca 构成一个方格。U 由这一四圈和其余互不相交的 j 边组成。

四圈的一个无圈子图若含两个同奇偶度2点，必须包含这两个顶点关联的全部四条圈边，因而包含整个四圈，矛盾。其余分量是独立边，不产生度2点。

全部情形都排除 S⊆U。故存在可用 e∈S，按定义 e∉N 且可强迫。证毕。

## 推论：T44 的同侧、零跨边步骤

设 Q_(q+1) 沿坐标分为 A,B≅Q_q，q≥5；规定完全图匹配 F 无跨边，B 上为完美匹配。A 内恰有四个同奇偶孔 z1,z2,a,b。若已存在 A\{z1,z2} 上包含 F_A 的圈 C_A，新增边均短，则存在整个 Q_(q+1)\{z1,z2} 上包含 F 的圈，新增边均短。

取 S=E(C_A)\F_A。F_A 非空，所以 S 是圈的真子图，从而是短边森林。两个仍被访问的孔 a,b 在 S 中度数均为2，且奇偶相同。将 S 镜像到 B，用引理得到可强迫非匹配边的镜像 e_B，以及包含 F_B、e_B 的生成圈 C_B。删去两侧对应的短边，加入两条镜像短桥，即合并为所需单圈。

该推论仅完成 T44 维数归纳的“全部四孔同侧且没有规定跨边”分支。其他分孔类型，尤其零跨边2+2分孔，仍需单独证明。基础 T44^(5) 已存在于 `../six_directions/T44_Q5_CLOSURE_DRAFT.md` 及其审计；本文不修改那些冻结文件。
