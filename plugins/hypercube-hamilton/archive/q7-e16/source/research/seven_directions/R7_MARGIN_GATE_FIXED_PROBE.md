# 指定十六孔输入：余量门的一次否定性检验

2026-11-05。仅检验主代理事先给定的一套孔几何，不枚举匹配族或高孔几何，不安装依赖，不运行 Hamilton 搜索。工程产物不是正式独立证明审计。本说明及 JSON 不修改 RUN_STATE、路线账本或冻结区。

## 输入、义务与停止边界

原始输入为 Q7 短匹配，沿 j=6 的两条规定桥固定为 (0,64)、(3,67)。两面均用局部标号 0..63，原桥端口为偶点 0、3。

- A 原孔：局部奇点 O_A={1,2,4,8,16}，局部偶点 E_A={15,51,60}。
- B 原孔：局部奇点 O_B={31,47,55,59,61}，局部偶点 E_B={12,20,40}。

每面须将孔及两个桥端口以外的54点匹配成27条短边；成功标准是实现该原始输入并逐一核验所有响应面、桥端口与内部坐标的余量门。若某面无完美匹配，输出 Hall 见证即停止，不换孔几何。成功也只产生一个原始输入诊断，不关闭完整 m=2、R7 或 P7。

## 匹配实现

脚本 `r7_margin_gate_fixed_probe.py` 仅使用 Python 标准库。每面按偶点递增、坐标递增的固定顺序做一次二分图增广匹配（实际27×27，为32×32的诱导子图），随后允许总计至多12次确定性方格换边。实际仅 A 用2次，B用0次。

| 面 | 初始方向数（0..5） | 最终方向数 |
|---|---|---|
| A | (18,2,3,1,1,2) | (14,2,3,3,3,2) |
| B | (4,7,8,2,3,3) | (4,7,8,2,3,3) |

A 的两次方格换边为：

1. 删 (32,33)、(40,41)，加 (32,40)、(33,41)。
2. 删 (10,11)、(26,27)，加 (10,26)、(11,27)。

完整56条边及各面27条边见同名 JSON。程序核验边长、端点互异、精确孔集及所有方向数。全局方向数为 **(18,9,11,5,6,5,2)**，所以 m=2 且唯一二重方向为6；每个内部方向在每面至少2条。全局孔共16个，两色各8个。面内孔无邻边，两面的局部孔集也不交，故跨面孔无邻边；程序直接核验全局孔诱导边集为空，匹配为包含意义下极大。

## 24项余量门全部失败

对响应面局部孔 O、E，桥端口 d∈{0,3}，内部坐标 k∈{0,...,5}，令 X={x:x_k≠d_k}、Δ=|O∩X|−|E∩X|。待检验的充分门要求 Δ∈{0,1}。

| 响应面 | d | Δ，按 k=0..5 |
|---|---|---|
| A | 0 | (-1,-1,-1,-1,-1,-2) |
| A | 3 | (3,3,-1,-1,-1,-2) |
| B | 0 | (5,4,2,2,3,3) |
| B | 3 | (-3,-2,2,2,3,3) |

每面原孔奇偶数差为2，因此把半面反向时余量变为2−Δ；表中亦可直接核对反向半面均不在{0,1}。两面、端口及内部坐标已穷尽本输入的全部门选择。此实现反驳“每个 m=2 原始输入都满足至少一个此门”的普遍覆盖命题，**不是 R7 反例，也不反驳旧规则与此门之并覆盖全域的命题**。

## 旧规则范围与 F 四自由补充

唯一二重方向的两面各内部方向均至少2条，故此输入排除 T/U/V/W 的零／单方向规定桥入口。两面内部均只有27边，f_A=f_B=5，排除 F7 稠密入口及 F14 的 |M|≥57 范围。孔独立使其不能增广到60边，排除 E8 的增广入口。全局两色各8孔，不能在一个坐标的两面均各留至多3个各色孔，故不满足 B 的小平衡孔入口。

**此输入仍由旧 F 的四自由 f=5 补充闭合。** 以下是主代理给出的数学回代，脚本只核验其固定几何事实，不寻找 P6 路。

响应取 A，源取 B。源根 a=3，另一桥端口 c=0。任选 z∈O_A，令源目标 t=z（局部镜像标号）。脚本核实每个这样的 t 均被 M_B 覆盖。由 P6 有含 M_B 的源 Hamilton a–t 路。c 为自由内部点；因为 t 已覆盖且 c 自由，路径在终点 t 的唯一入边必须是其 M_B 边，故不可能使用 ct。c 的六个邻点为 {1,2,4,8,16,32}，只有32不在 O_A。因此 c 的两条路边至少一条 cs 满足 s∈O_A 且 s≠t。删 cs 得源面的实际二路径覆盖。响应 A 的四端口 0、3、z、s 两偶两奇、互异且全部自由，f_A=5，正落入旧 F 四自由分支；选择不同于源镜像配对的响应配对后，四桥闭合成含原匹配的 Hamilton 圈。

因此该固定例并非“所有已证规则后的剩余输入”，不能用它说明仍存在旧 F 未覆盖的十六孔 m=2 实例。其用途严格限于停止把余量门当作每个原始输入必有的普遍选择规则。全称余量门已被否定，不继续扩大样本或寻找更高孔例子。

## 重放

在工作区运行：

```powershell
python research/seven_directions/r7_margin_gate_fixed_probe.py --output research/seven_directions/R7_MARGIN_GATE_FIXED_PROBE.json
```

省略 `--output` 会将完整确定性证书打印到标准输出。实际运行退出码0，状态 `REALIZED_ALL_24_MARGIN_GATES_FAIL`，方格交换总计2次。JSON 保存全部原始边、孔、门的分项计数与 F 补充所需几何核验。此工程检验不替代独立正式审计，不改变数学关闭状态。
