# 非平衡外切候选的固定匹配见证

2026-11-05。原 caller `/root`；工程 worker `/root/r7_unbalanced_probe`。

**本轮义务。** R7 原始短匹配的条件性非平衡外切路线；本文件仅交付一个预先给定孔集的56边匹配及直接算术，不证明候选定理、完整R7/P7或任何全称存在性。成功标准为一次有界求解取得指定方向计数的合法匹配，核供体镜像状态，并在仅加边的单调闭包下排除明确列明的旧门。新定理是否正确及其原始域回代由主代理和独立审计处理；此样本不承担该证明。

## 输入及求解前解析修正

顶点用0..127整数、坐标0..6，A为bit6=0，B为bit6=1；下列B集合用0..63局部坐标，实际顶点均加64。颜色E/O使用全局整数汉明重量的偶/奇。

- A局部孔：偶 `{5,9,17}`，奇 `{61,59,55,47}`。
- B局部孔：奇 `{31,26,22,14,62}`（全局E），偶 `{39,43,51,3}`（全局O）。

最初给定的B局部孔为 `{62,59,55,47,31,6,10,18,34}`。求解前主代理指出：全局孔短边恰 `(47,111),(55,119),(59,123)`，任加其中一条，A与B孔差均归0；A孔全在bit0=1，B孔全在bit1=1，故旧Q取外6、内0/1即可覆盖该57边超匹配。因此原几何不能提供严格新增证据，未运行其solver。

主代理明确授权对B所有孔作xor33的解析修正：偶重量平移保持B各色孔数和bit1=1，同时消除上述孔边以及全部孔邻接。这是有明确排障理由的一次修正，不是几何搜索；没有为原几何生成匹配或追加第二次求解。

## 固定结果

[数据](R7_UNBALANCED_OUTER_WITNESS.json)保存全部56条短边；[脚本](r7_unbalanced_outer_probe.py)只调用一次CP-SAT，版本9.15.6755，单worker、seed0、30秒上限，无Hamilton约束、无目标、无几何或匹配族枚举。返回 `OPTIMAL`（仅可行性模型），solver wall time `0.0336349` 秒。

直接整数验证及一次 `--verify-only` 均通过：112个端点两两不同、补集恰为16个指定孔、每条边异或为单一bit。

| 项目 | 固定结果 |
|---|---|
| 各方向规定边数0..6 | `(4,4,3,3,3,36,3)` |
| 最小方向数 | 3；无二重方向 |
| A孔全局E/O | `3:4`，故O-E=1 |
| B孔全局E/O | `5:4`，故O-E=-1 |
| 总孔全局E/O | `8:8` |
| 孔诱导短边 | 空；匹配包含极大 |
| 各坐标bit1孔的全局E-O | `(-4,-2,1,1,1,-6,1)` |
| 指定供体及镜像 | `ell=95`，`u=ell xor64=31` |
| u状态与原伙伴 | 原已覆盖，伙伴29，原边`(29,31)`方向1，完全在A内 |

A全部孔在bit0=1，因此按bit0切分时正差集中在这一半，另一半差0；B全部孔在bit1=1，因此按bit1切分时负差集中在这一半，另一半差0。供体95是B的多数全局E孔，镜像31位于A的bit0=1正差半。以上只核候选输入假设，不认证从这些假设得到Hamilton圈的证明。

## 相对列明旧规则的排除

所有坐标bit1孔差非零，而总孔平衡，因此不存在两面都孔平衡的外切向；旧Q与Q+直接门均失败。脚本逐外坐标、内坐标对作直接算术门核，不是原始匹配枚举。

更强地，孔集独立，所以不存在任何严格包含此匹配的短超匹配。仅加原孔间短边的子集只有空集：脚本对这一子集核Q/Q+均失败。因此不仅原M直接门失败，旧Q/Q+通过只加边进入门的单调闭包也失败。

无二重方向排除主代理指定的旧T/U/V/W、M/N及F7/F14两桥规则；16孔也超过列明旧B的至多12孔范围；包含极大且仅56边，不能加边达到E8要求的60边。只排除这些明确规则及其仅加边使用；不排除未知规则、删边重构或其它构造，不是R7反例。

因此，在主代理候选定理获得正确性证明及回代验收的前提下，本样本可以作为相对上述列明旧规则的严格新增见证。该新增资格不能替代定理认证，也不说明所有同孔集实现都排除依赖方向数的旧规则；孔几何排除Q/Q+及增广则对同孔集全部实现成立。
