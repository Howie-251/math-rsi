## 1. 输入、定义和准确的全称命题（A）

主要输入为 `NEAR_PERFECT_ADJACENT.md` 第 7–65 行；读取了 `BIPARTITE_NEAR_PERFECT.md` 的 N6、`FOUR_HOLE_SPLIT.md` 的 Z0、`NEAR_PERFECT_EXTENSION.md` 的 N2，以及 `SAME_SIDE_TRANSFER.md` 的完整 Z5。

本报告用 `π(v)` 表示顶点奇偶，用 `q=P(y)` 表示 y 的匹配伙伴；对应最终主稿的伙伴记号 p。其类型如下。

| 记号 | 类型及约束 |
|---|---|
| n | 整数，n≥5 |
| V | `{0,1}^n` |
| B(Q_n) | V 上按 π 分部的完整二部图 |
| L | B(Q_n) 的匹配；未覆盖集合恰为 `{r,s}` |
| P | `L∪{rs}`，B(Q_n) 的完美匹配；`P(v)` 是伙伴映射 |
| r,s,y,x,q | V 中顶点；q=P(y)；x 是后续选择的 s 的短邻点 |
| k,j,l | 坐标指标；k 是 rs 方向，j 是障碍半层方向，l 是所选短边 xs 方向 |
| H | 方向 j 的半层，边数 `2^(n−2)` |
| S,T | H 的端点集与其补集；都是顶点集合，不是坐标子立方体 |
| R_0,R_x | 压缩所得匹配，分别恰不覆盖 r,y 或 x,y |
| K,F | 含 P 的辅助 Hamilton 路径、最终含 L 的 Hamilton 路径 |

精确命题为：对每个 n≥5，每个 L⊆E(B(Q_n)) 满足 L 为匹配且 `V\V(L)={r,s}`，以及每个满足 `π(y)≠π(r)` 的 y，存在 V 的 Hamilton r—y 路径 F，使

`L⊆E(F)⊆L∪E(Q_n)`。

因此 L 中的原长边允许保留；结论不是“存在只用 Q_n 短边的路径同时包含长边”。量词是先给定 L,r,s,y，再选择 x、辅助路径和 F；没有要求同一个 x 适合所有 y。

半层的准确几何为：对某个 ε∈{0,1}，令 `χ_j(v)=Σ_{h≠j}v_h mod 2`，则 `S={v:χ_j(v)=ε}`，`T={v:χ_j(v)=1−ε}`。翻转 j 保持两侧，翻转其他坐标交换两侧。所以两侧诱导的短边都只沿 j；每个方向恰有这两个半层。证明没有把 S,T 当成普通坐标层。

## 3. N9 微观证明义务（C、G）

### 3.1 初始压缩、方向锁定

1. 两奇偶类等大，L 每条边覆盖两类各一个点；恰剩两孔迫使 π(r)≠π(s)。因此 rs 是合法二部辅助边。
2. y=s 已被单独处理。其余情形中 r,s,y,q 四点互异：y≠r 由奇偶，q=r 等价于 y=s，q=s 等价于 y=r，伙伴无自环。R_0 是合法匹配，恰不覆盖 r,y。
3. 若 R_0 含 H，则 `H\{sq}⊆P`，所以 P 至少含 `2^(n−2)−1≥7` 条 j 短边。即使 sq 不在 H，这也是正确的弱下界。
4. 对任何合法的第二次压缩，最多删除两条 P 边。因此至少保留 `2^(n−2)−3≥5>0` 条 j 短边。若 R_x 含方向 h 半层，Z0 强制这些保留边都沿 h；短边方向唯一，故 h=j。
5. 所以只需排除端点集为 S、T 的两个 j 半层。这里没有使用“不同半层一定不相交”等错误捷径；即使 R_0 原本有多个半层，任选一个 H 已足够完成论证。

### 3.2 sq 不在 H

6. H⊆P 饱和 S。r,y∈T 迫使其伙伴 s,q∈T。rs 短且同侧，所以 k=j。
7. 对任意 l≠j，x=s⊕e_l 属于 S，因而与 r,s,y,q 全部不同。P(x) 是 S 上 j 配对的伙伴，也在 S；所以 x≠P(y)，端点匹配边不同。
8. x 同 r 奇偶，异于 y 奇偶。这是 GNS 的奇偶条件；`xy∉P` 则来自 x≠P(y)，不能仅由异奇偶本身推出。
9. R_x 不覆盖 x∈S 和 y∈T，所以两个 j 半层均不可能存在。原证明用“删除 H 边且新增伙伴边跨侧”的论述也成立。方向锁定再排除所有 h≠j。

### 3.3 sq 在 H

10. s,q∈S 且 q=s⊕e_j；r,y∈T。rs 跨侧且短，故 k≠j。
11. 对任意 l∉{j,k}，x=s⊕e_l∈T。l≠k 保证 x≠r；l≠j 保证 x≠q；π(x)=π(r)≠π(y) 保证 x≠y；x≠s 因翻转一个坐标。因此压缩合法。
12. r,s 均不属于 {x,y}，而匹配唯一性进一步保证 xP(x)、yq 均不是 rs。因此 rs 在 R_x 中保留。特别地，不存在“x 不是 r，但删除 x 的匹配边仍删掉 rs”的遗漏情况：那只能发生 x=s，已排除。
13. rs 占用了 S 中的 s，却连接到 T 中的 r，因此 R_x 作为匹配不能同时含覆盖 s 的 S 半层边。T 半层由其未覆盖点 y 排除。方向锁定再排除其他方向。

### 3.4 重新拼接与新增边语义

14. n≥5 时情形一有 n−1≥4 个方向可选，情形二有 n−2≥3 个；所有这些选择均满足前述条件，没有额外至多一个的碰撞扣除。
15. 将 K 从 x 向 y 编号 0,…,2^n−1。包含完美匹配强迫 P 的边恰位于 `(0,1),(2,3),…`。K 二部且 π(x)=π(r)，所以 rs 按 r→s 出现。
16. 删除 rs 后，恰得到两个不交路径分量 K[x,r] 与 K[s,y]。反向第一段并连接 xs，所得顶点序列为 `r … x,s … y`，每点恰出现一次。x 与 s 位于不同分量，故 xs 不可能已是剩余路径边；也不可能是 L 边，因为 s 为原孔。
17. 重新拼接只删 rs；rs∉L，因为 r,s 都是 L 的孔。故所有 L 边，包括任意多条二部长边，均保留。
18. 精确边集合计算是 `E(F)=(E(K)\{rs})∪{xs}`，从而 `E(F)\L⊆(E(K)\P)∪{xs}⊆E(Q_n)`。直接无障碍分支为 `E(K)\L=(E(K)\P)∪{rs}`，其中 rs 短。y=s 分支删掉唯一辅助边后也只保留 L 及新增短边。
19. sq 和 P(x)q 只用于测试半层条件，GNS 作用对象始终是 P，不是压缩匹配。证明没有把这些可能为长边的诊断边作为必留路径边；无须额外删除它们。

## 4. Z5 删除非相邻条件的下游复核

Z5 的“z,t 不相邻”仅用于第一步调用 N6。它不参与端口平衡、唯一匹配冲突、最终展开或两个短方向条件。

保留 Z5 的其他全部前提时，B 层未覆盖点为 `X_B∪{z,t}`，其中 X_B 奇偶平衡。在 X_B 上的二部辅助完美匹配 D 使 `L_B=M_B∪D` 恰剩 t,z。目标 a 在 M_B 中已覆盖，故避开 t,z 和所有 D 端口；π(a)≠π(t)。N9 因而给出同样的 t—a 路径，新增边仍全为 B 层短边。

后续删除 D 的论证不依赖 t,z 距离：D 是匹配且不接触路径端点，所以不会产生孤立顶点。端口转移得到恰覆盖 `X_A∪{c,w}` 的 R；唯一与 M_A 冲突的点仍为 c。u,c,r,s 四点仍互异，换配得到完整图完美匹配 P_A。其端点 c,v 异奇偶、`P_A(c)=u≠v`。保留下来的两个避开 c,v 的短边方向通过 Z0 排除半层，故 Theorem 11 仍适用。

删除首边 cu 及端点 c，再将 rs 展开为 rc 加原 c—s 转移路径，恰恢复 c 一次；其他转移路径内部互不相交并覆盖 B。所有 M_B、跨边 C、M_A 中的原边最终保留，辅助 D、cu、rs 和 R 的形式边被删去或展开；最终新边均短。

极端情形 D=∅、v=r、v=s 或 v 为跨边端口都不因允许相邻 z,t 而变化。因此 N9 第 59 行的推论成立。仍不能删除：n≥6；平衡坐标切分；a,c 层内覆盖；原跨层匹配边均短；目标与根异奇偶且已覆盖；避开 c,v 的两个短方向。也未证明这样的切分总存在。
