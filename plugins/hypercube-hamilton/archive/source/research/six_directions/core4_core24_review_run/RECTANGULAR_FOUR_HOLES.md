# 距离3/5交替的矩形四孔：Z3

日期：2026-11-01。证明草稿；完整P6尚未证明。输入为FOUR_HOLE_SPLIT.md的完整图端点定理和不依赖方向条件的转移步骤。

## 精确陈述

设Q6短边匹配M恰不覆盖四点。经立方体自同构归一化，设它们为
\[
u=0,\quad z=e_i\oplus e_k,\quad
w=e_{l_1}\oplus e_{l_2}\oplus e_{l_3},\quad
t=w\oplus e_i\oplus e_k,
\]
其中i,k,l1,l2,l3互异；记第六个坐标为h。则M可延拓为Hamilton圈。

更精确地，对每个被M覆盖的奇点v，只要
\[
v_h=0,\qquad v_i=1\ \text{或}\ v_k=1,
\]
就存在包含M的Hamilton u—v路径。符合条件的已覆盖奇点共11个。此陈述对全部这类M成立，不附加方向数假设。

例如采用从0计数的坐标i=0,k=1,l1=2,l2=3,l3=4,h=5，孔集合为{0,3,28,31}。

## 1. 第一层

先考虑v_i=1，沿i分成A(bit i=0)、B(bit i=1)。于是u,w在A，z,t,v在B。令
\[
a=z\oplus e_i=e_k,\quad b=t\oplus e_i=w\oplus e_k,
\quad y=w\oplus e_i.
\]
四孔的异奇偶距离分别为d(u,w)=d(z,t)=3、d(u,t)=d(z,w)=5，故没有孔邻接另一孔。a,b,y均是相应层内匹配的覆盖点：若这些点的i匹配边跨层，其另一端必为孔，不可能属于M。d(a,b)=3，故ab不是M_A边。

按Z1在强制跨边A端口上任选二部完美匹配D，并令P_A=M_A∪D∪{uw}。设在a,b处压缩P_A后存在方向j的半层，端点集S、补集T。长边uw保留，所以u,w∈T；端点a,b也在T。由于a=u⊕e_k，若j≠k，则u,a应处于不同侧，矛盾。因此j=k。

设c=M_A(a)、d=M_A(b)。a的k邻点u以及b的k邻点w均为孔，所以ac、bd的方向分别为l,m，且l,m≠k。于是c,d∈S，压缩中配对它们的cd必须为k方向边。然而这会要求
\[
a\oplus b=e_l\oplus e_k\oplus e_m.
\]
右侧的k坐标为1，左侧a⊕b=w的k坐标为0，矛盾。故没有第一层半层。

完整图端点定理适用：A维数5、P_A完美、a,b异奇偶、ab不在P_A，且已排除压缩半层。得到K_A。

## 2. 转移及z的特殊配对

使用Z1第2步及第3步中构造P_B、核对完美性和端点非配对的部分；这些部分不依赖方向数假设。这里不使用Z1第3步最后一段的半层排除与端点定理调用；本证明将在第3—4节另行完成。得到从u到q的前缀J以及B端点之间的转移匹配R，且q≠y,v，q要么为偶点，要么等于t。记s=R(y)、r=M_B(y)，令
\[
P_B=(M_B\setminus\{yr\})\cup(R\setminus\{ys\})\cup\{rs,yq\}.
\]
这是K(B)完美匹配。y偶、v奇，且P_B(y)=q≠v。

还需要Z2第3步的奇偶事实，这里给出理由：K_A从奇点a到偶点b，P_A完美且二部，所以所有P_A边沿奇→偶出现。删掉非空辅助边族D∪{uw}后，第一段的两个端点均奇；u偶，因此不在这一段。第一段转移到B后，一端为z，另一端也为偶点。故z属于R，R(z)为偶点，且q≠z。

## 3. 第二层半层不覆盖z

设Q为P_B在端点y,v处压缩后的匹配。注意d(y,z)=4、d(z,t)=3。

若s≠z，则R中覆盖z的偶—偶边一直保留在Q中：它不接触y，否则s=z；也不接触奇点v。因此z不能属于任何半层的端点集。

若s=z，P_B中覆盖z的是zr。若r≠v，此边保留，且yr短边、d(y,z)=4蕴含d(r,z)≥3，所以仍为长边。若r=v，压缩用zq替代zr、yq；q偶时zq同奇偶，q=t时d(z,q)=3。由于q≠z，前者确为非退化长边。因此全部情形下z不被Q中的任何半层覆盖。

## 4. 唯一可能的方向也被排除

假设Q含方向j半层，端点集S、补集T。上一步知z∈T，压缩端点y也在T。

在B的五个坐标中，z,y恰好在k,l1,l2,l3四位不同，只在h位相同。对方向j，半层端点集的划分由除j以外坐标的奇偶性决定。如果j属于上述四个不同位，则z,y在其余位相差三位，必须分处两侧，矛盾。因此只能j=h。

但v_h=z_h=0，而v奇、z偶；所以去掉h后的奇偶性仍相反，v,z必分处h半层划分的两侧。这与z∈T以及压缩端点v∈T矛盾。

故Q不含半层，完整图端点定理给出K_B。使用Z1第4步的展开即得所需Hamilton u—v路径，保留全部M。

当v_i=0、v_k=1时，交换i,k；w在这两个坐标均为0，全部论证和h条件不变。

## 5. 数量、闭合及范围

奇点中，满足v_h=0且(v_i,v_k)≠(0,0)的有16−4=12个。其中唯一的孔是t；u,z偶，w的i,k位均0。因此已覆盖目标恰有11个。

v=e_i属于这11个目标。所获Hamilton u—e_i路径不能已包含两端之间的边，否则64点路径只剩两个点；加入该短边得到Hamilton圈。证毕。
