## L6 的集合差与容量核查

为消除“过程删除后重加”的歧义，直接固定最终 H'。令 J 为 H' 在 0、31 的四条边，D 为选中邻点在 H 中的四条伙伴边。所选邻点的目标度数为一，J 已占满，因此 D 是实际最终差集 R=H\H' 的子集，而不是搜索过程中的暂时切边。

令 E=R\D，G=(H\D)∪J，K=H'\G。于是 H'=(G\E)∪K，且 E、K 按最终集合差定义，不会将删后重新加入的旧边错误计入修改。G 在 S 中共有四单位缺口，在其允许顶点补集 T 中全部达到目标度数。S 内没有短边。度数平衡给出：

    deg_S(K) = 4 + deg_S(E) >= 4,
    deg_T(K) = deg_T(E),
    deg_T(K) >= deg_S(K),
    deg_T(E) <= 2|E|.

故 |E|>=2、|R|=4+|E|>=6。K 若含 T 内边，只会占用更多外部容量；额外删除若碰到 S，则增加待补缺口，也不会降低界。选中邻点是最终邻点，所以“换邻”只是改变 J,D,S 的选择，六乘十共六十种选择全部被同一论证涵盖。t 的重数用 deg_S 而非不同顶点数计算。此推导甚至不需要 F∪H' 连通，故不依赖任意 F 的连接次序。
