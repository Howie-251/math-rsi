## 3. N6 的核心义务逐项复算

1. **孔的奇偶。** 两个奇偶类等大；二部匹配每条边各覆盖一点，故两孔一偶一奇。于是 `|I|,|J|` 均奇。
2. **安全坐标至少两个。** `y≠s` 蕴含 `I≠J`；两个奇数大小集合的对称差是非空偶数集，所以 `|I△J|≥2`。又 `I△J⊆[n]\\(I∩J)`。这个下界即使取等号也足够。
3. **排除一个伙伴后仍可选。** 不同 `l` 对应不同 `s⊕e_l`，因此最多一个候选等于 `P(y)`。选到的 `x` 不等于 `r`（孔不相邻）、不等于 `s`，也不等于 `y`（奇偶不同）。`x≠P(y)` 正是 `xy∉P`。
4. **压缩合法且保留长边。** `xy∉P` 保证两条删除的匹配边互不相接，伙伴不同，压缩后恰不覆盖 `x,y`。由于 `P(r)=s` 且 `r,s` 均不是 `x,y`，被删边不可能是 `rs`。这是从“端点不同”到“长边保留”的完整理由。
5. **四点同属补集。** 若压缩中有半层，则其每个端点都已用半层短边配对。`x,y` 未被压缩覆盖，故在 `T`。`rs` 是仍存在的匹配长边，不能与半层共享顶点，故 `r,s∈T`。不允许以相邻孔替换此长边论证。
6. **方向矛盾。** 写 `f_j(q)=Σ_{k≠j}q_k mod 2`。`f_j(x)=f_j(s)` 且 `x=s⊕e_l` 给出 `j=l`。`f_j(r)=f_j(s)`、`|I|` 奇给出 `j∈I`；同理 `f_j(r)=f_j(y)` 给出 `j∈J`。因此 `l=j∈I∩J`，与选法矛盾。
7. **旋转手术。** 定向 `K:x→y`。完美匹配交替与 `p(x)=p(r)` 保证 `rs` 出现为 `r→s`。删去 `rs` 得到两个不交分量 `K[x,r]` 和 `K[s,y]`；反向走第一段并以短边 `xs` 接入第二段，构成单条 Hamilton `r–y` 路径。`xs` 两端原在不同分量，故不是已有重复路径边。只删了辅助 `rs`，原 `L` 的长短边均保留。

每一步都允许 `L` 的任意多条原长边。没有使用“原匹配短方向至少几个”或“只有一条长边”之类附加假设。

## 4. N7、N8 的闭圈与删边

N7 的相邻分支中，Theorem 2 仅保证相对于 `P` 的新增边短，但相对于 `L` 多出来的 `rs` 也短，所以恰好满足所需定义。非相邻分支中，`ry` 不属于原 `L`，因为 `r` 是孔；一条至少三个顶点的简单路径不可能已使用连接两端点的边，故加入 `ry` 确实得到单圈。

N8 中任意异奇偶孔对 `u,v` 都可直接配对；`uv∉M`，加入后剩余两孔由 N7 的相邻/非相邻两分支完整覆盖。圈中删除 `uv` 保留所有原 `M` 边，得到所要求的两个端点。该推论只解决自由终点，不自动解决已覆盖终点。

## 5. Z5 的计数、唯一冲突与展开（C）

**层内缺口与任意 D。** `M_B` 恰未覆盖 `X_B∪{z,t}`；层内二部类等大，且 `z,t` 一偶一奇，故 `X_B` 平衡，可任取二部完美匹配 `D`。`a` 已被 `M_B` 覆盖，所以不属于 D 端口或两孔。对 N6 的输入条件已全部满足；无须对 D 的长短、方向或具体配对方式另作限制。

**删除与端口转移。** D 是不接触 `t,a` 的匹配；从路径删除其边后，每个 D 端点的度由 2 变 1，不会出现孤立点。其余两端为 `t,a`。每条路径的两个端点不同，且全部路径不交。原跨边是一一对应的短边；新增 `tc,aw` 的 A 端分别是被 `M_A` 覆盖的 c 与孔 w，与 `X_A` 互异，故不会把不同分量接成圈，也不会让两个转移路径共享 A 端点。R 因此确为覆盖 `X_A∪{c,w}` 的匹配。

**四个待配点。** `V(M_A)∩V(R)={c}`。令 `r=M_A(c), s=R(c)`。`c,r` 被原层内匹配覆盖，`u,s` 不被覆盖；另外 `u≠s`，因为 u 是原孔而 `s∈X_A∪{w}`。去掉 `cr,cs` 后，其余边互不相接，且恰留下 `u,c,r,s` 四个点。加入 `rs,cu` 后，`P_A` 是简单完整图上的完美匹配；不存在环、自配对或与保留边重叠。

**端点定理必须用完整图版本。** `p(c)=p(u)≠p(v)`，且 `P_A(c)=u≠v`。边 `cu` 是同奇偶边，故这里实际总是超出二部匹配类别；正文“通常不是二部匹配”可说得更强，但它正确地调用 Theorem 11，因此不影响论证。两条避开 `c,v` 的不同方向短边均来自 `M_A`，唯一删掉的 `M_A` 边接触 c，故见证边保留。Z0 排除压缩半层。

**删 c 再恢复 c。** `K_A` 以 c 为端点且包含 `cu`，首边强制为 `cu`。删 c 后得到 A\\{c} 上的 `u–v` 路径。其中 `rs` 必保留。将其替换成 `r–c` 接转移路径 `c…s`，在反向遍历时作对应逆序；其余 R 边各按其两个端点间的原转移路径展开。B 内部点集两两不交并恰覆盖 B；唯一缺失的 A 点 c 只在 `rs` 展开处补回一次。因此结果为单条 Hamilton 路径而非多个圈或重复顶点的游走。

**原边/新增边账本。** `M_B` 全留在转移路径；C 在转移端口处恢复；`M_A` 中只有 `cr` 暂删，在 `rs` 展开时恢复，即使 `cr` 原是长边也无问题。D 已删除；`cu` 随 c 删除；`rs` 与其他形式 R 边全部展开。余下非 M 边仅来自两次层内延拓和 `tc,aw`，均为短边。
