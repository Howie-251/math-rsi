# Z7：孔{0,3,13,49}的完整匹配族，一半坐标侧的全部指定终点

日期：2026-11-01。状态：局部证明，独立审读记录见GENERAL_NEAR_PERFECT_REVIEW.md。完整P6仍开放。

## 目标与范围

对每个Q6短边匹配M，若其孔恰为{0,3,13,49}，则对每个奇顶点v满足最低位v_0=1，存在包含M的Hamilton 0—v路径。

这包含此前明确记录的全称义务v=61。量词涵盖全部具有该孔配置的匹配，而非仅保存的一个样例。最低位为0的已覆盖奇终点不在本命题范围内。

## 两个终点的半层排除引理 E1

设m≥5，P为B(Q_m)的完美匹配。三个不同顶点c,d,e满足c与d,e异奇偶，且P中接触c,d,e的边均为短边，并有cd,ce∉P。设

`J={j : d_j=e_j≠c_j}`。

若在(c,d)、(c,e)处压缩P都产生半层，则P(c)=c⊕e_j，其中j∈J。因此若P(c)的方向不在J，至少一对端点的压缩不含半层，GNS端点定理给出相应的Hamilton路径。

证明：设第一压缩含方向j半层H。P至少含H中除新增伙伴边外的2^(m−2)−1≥7条j方向短边。若第二压缩含方向k半层，Z0说明所有不接触c,e的P短边只能沿k；上述至少7条j边中至多2条接触c,e，故k=j。方向j恰有两个半层，其端点集互为补集；c被两次压缩删除，所以两个半层只能是同一个H。

记S为H端点集、T为其补集，则c,d,e∈T。在第二压缩的Z0结论中，P中接触d的短边没有接触c,e：cd∉P，且d,e同奇偶而P二部。因此P(d)=d⊕e_j∈T。第一压缩新加的P(c)P(d)不可能属于H，故H原已完整包含于P。于是P(c)∈T；cP(c)为短边，T内短边只沿j，所以P(c)=c⊕e_j。最后c与d,e异奇偶且均在T，要求其第j位分别相反，即j∈J。证毕。

## Z7证明

沿第0位切分，A为偶数编码顶点，B为奇数编码顶点（这是编码最低位，不是顶点奇偶性）。孔0在A，孔z=3,w=13,t=49在B。

令c=2、d=12、e=48，分别是3、13、49沿第0位的A内邻点。它们均被M_A覆盖：它们不是孔，跨层伙伴却是孔，不能被M跨边覆盖。c为奇顶点，d,e为偶顶点。距离d(c,d)=d(c,e)=3，所以cd,ce∉M_A。

令X_A为原跨边端口，在X_A∪{0}上任取二部完美配对D，得P_A=M_A∪D。该配对存在，因为这恰是二部匹配M_A在A内未覆盖的集合。P_A在c,d,e处的匹配边就是原M_A短边，且cd,ce∉P_A。

以A的五个坐标{1,2,3,4,5}计，E1中的J只有坐标1：c=2只在坐标1为1，而d=12和e=48的支撑分别为{2,3}、{4,5}，没有共同的1位。P_A(c)不等于0，因为c由M_A覆盖而0为原孔。因此P_A(c)的方向不是1。

由E1，P_A至少有Hamilton c—d或c—e延拓。选中哪一个，就把对应的B孔13或49作为Z6中的t，另一奇孔作为w。对任意在B中且已被M覆盖的奇顶点v，Z6（UNBALANCED_TRANSFER.md）与N10给出Hamilton 0—v延拓。

若v为自由奇孔13或49，则使用已证N8四孔自由端点定理（BIPARTITE_NEAR_PERFECT.md）。因此命题所列全部v成立。证毕。
