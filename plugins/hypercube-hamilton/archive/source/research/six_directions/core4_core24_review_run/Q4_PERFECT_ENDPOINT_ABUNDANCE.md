# Q4 完美匹配的 Hamilton 路径端点丰度

日期：2026-11-01。状态：有限证书和逆像穷尽核验 PASS；Q5 T15、P6 不由此关闭。
完整 Q5 A4 及 A6/K6 的先前已证状态不变。

## 定理

设 $P$ 为完全图 $K(Q_4)$ 上的任意完美匹配，允许长边和同奇偶边。
固定根 $0$，令 $G(P)$ 为所有满足下述条件的奇顶点 $y$ 的集合：存在 Hamilton $0$--$y$ 路径，
包含 $P$ 的每条边，且每条不属于 $P$ 的路径边都是短边。

则

$$|G(P)|\ge4,\qquad G(P)\cap\{7,11,13,14\}\ne\varnothing.$$

两条下界都能取等。平移所有顶点可得任意根 $r$ 的版本：至少四个异奇偶可行端点，
且至少一个与根距离 3 的可行端点。

所有大小恰为 4 的端点集精确如下，每种发生于 105 个完美匹配：

| 精确可行奇端点集 $G(P)$ | 个数 |
| --- | ---: |
| $\{1,2,4,7\}$ | 105 |
| $\{1,2,8,11\}$ | 105 |
| $\{1,4,8,13\}$ | 105 |
| $\{2,4,8,14\}$ | 105 |

例如 $P=\{01,23,45,67,89,(10)(11),(12)(13),(14)(15)\}$（全部位 1 方向短边）
恰有端点 $\{2,4,8,14\}$。因此不存在把“四”改成“五”或把“一个距离 3 端点”改成“两个”的普遍结论。

## 路径与避两孔圈的精确等价

若 $P(0)=y$，任何包含 $P$ 的路径在两个端点处都必须使用边 $0y$，它会成为两个顶点的独立分量，
所以不可能是 16 顶点 Hamilton 路径。

现在设 $P(0)=a\ne y$，记 $P(y)=b$。四点 $0,y,a,b$ 不同，定义

$$T=P-\{0a,yb\}+\{ab\}.$$

这是恰有孔 $0,y$ 的七边匹配。存在目标 Hamilton $0$--$y$ 路径，
**当且仅当**存在避开 $0,y$、包含 $T$ 且新增边短的 14 圈。

证明：路径的端点边必为 $0a,yb$。删去两个端点得到覆盖其余 14 点的 $a$--$b$ 路径，
加上 $ab$ 得到圈。其余边保留 $P-\{0a,yb\}$，新增的辅助边 $ab$ 已列为 $T$ 的必含边。
14 点路径的两个端点不会已经相邻，否则长度只能为一条边，所以不会产生重边。
反向从圈删除其必含边 $ab$，在两个端点分别接回 $a0,by$，即得到所需路径。
两方向都保留原匹配的所有边，所有非匹配边仍短。

## 只枚举负例逆像足以证明全称命题

给定一个不可行 $T$，对它每条边 $ab$ 及两个方向，构造

$$P=T-\{ab\}+\{0a,yb\}.$$

这些恰好是所有满足 $P(0)\ne y$ 且在 $y$ 不可行的完美匹配。
任意这样的 $P$ 经正向公式必得到一个负表记录，再选其辅助边 $ab$ 就能被逆构造找回；
反之，每个逆构造的 $P$ 在该 $y$ 不可行，由上面的等价直接得到。

四个距离 1 端点、四个距离 3 端点，共生成
$4(51+53)\cdot7\cdot2=5824$ 个带端点标签的逆像，去重后得到 **4708** 个完美匹配。
对每个候选再次遍历八个奇端点，计算正向 $T$ 并查负表，与逆生成端点集合核对，
另外加入 $P(0)$ 为奇点时的必坏端点。所得精确分布为：

| 坏奇端点数 | 4708 个候选中的完美匹配数 |
| --- | ---: |
| 1 | 2072 |
| 2 | 2180 |
| 3 | 36 |
| 4 | 420 |

候选之外的每个完美匹配，除可能的奇点 $P(0)$ 外，其余七个或八个奇端点全部可行。
因此没有扫描其余约两百万个正匹配，也没有遗漏任意一个可能有两个以上坏端点的输入。
上表最大坏数为 4，证明第一个下界。

候选内的可行距离 3 端点数分布为 $\{1:420,2:276,3:2212,4:1800\}$；
候选外至少有三个可行距离 3 端点。因此所有完美匹配至少有一个距离 3 可行端点，证明第二个下界。
不存在四个重量 3 奇端点全部不可行的完美匹配。

这里“最小端点集”如指最小**基数**，精确为开头的四种大小 4 集合；
如指在全部可能端点集中按包含关系极小，则共有 22 种（4 个大小 4、12 个大小 5、6 个大小 6），
完整列表也保存在结果 JSON 中，避免混淆这两个含义。
