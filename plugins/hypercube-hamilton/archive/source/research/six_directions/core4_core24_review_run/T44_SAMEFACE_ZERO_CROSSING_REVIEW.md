## 完美匹配端点依赖的完整重建

没有仅凭 `q4_perfect_endpoint_abundance_check.json` 的 PASS 或4708条记录
假定其分类穷尽。除阅读 `Q4_PERFECT_ENDPOINT_ABUNDANCE.md` 的等价与逆像论证外，
本次独立核验器还直接执行：

1. 读取距离1、3的两张14点避双孔圈表；每张135135个匹配，
   mate 集合与递归完整配对集合相等，正圈逐边核验。
2. 对51+53个负记录，重新枚举全部不与原匹配重叠的短补完美匹配，
   检查每个所得2-factor不连通。不存在将搜索失败当反例证明。
3. 通过坐标置换把负表传送到所有八个奇目标。
4. 对每个负匹配的每条辅助边、两个方向逆构造原完美匹配，
   重新得到恰4708个异常完美匹配。
5. 对这些匹配重新以正向等价计算全部八个奇目标的坏集合，
   逐匹配与输入 JSON 比较，精确一致；最大坏端点数为4。

等价的适用条件已检查：若 P(0)=y，任何含该边的0–y路径会只有两个顶点，
故该目标必坏。否则令 a=P(0)、b=P(y)，则0,y,a,b不同，
`T=P−{0a,yb}+{ab}` 恰有孔0,y。所需路径与包含 T 的14点避双孔圈相互转换，
人工 ab 只在中间存在，原匹配边在展开时全部恢复。

因此任何不在逆像候选中的完美匹配，至多有其奇数根伴点这个坏目标，
其余目标都由完整正表认证。候选内最大坏数4，严格推出任意根的至少4个
异奇偶可行端点；完整分类没有遗漏其他可能的多坏目标匹配。

由三个不同单位向量构成的两类集合
`{ei,ej,ek}`、`{ei,ej,ei xor ej xor ek}` 共16个。
独立程序直接生成这16个集合，并确认没有一个包含于任一精确异常坏集合。
候选外最多一个坏端点也不可能包含三元集合。故这些 triples 对所有任意完整图
完美匹配确实为 hitting sets，平移给出任意根版本。

## 语义推理与量词

固定任意 A 中四孔同奇偶匹配 L、B 中任意完美匹配 P，以及指定避孔 x,y。
把 x 平移到0，置换令 y=3或15；四孔变偶，另两孔记 b<t。
同一个 Q4 自同构必须同时作用于两面，使短桥端点对应不变。
P 经变换仍是任意完整图完美匹配，未增加约束。

由完整正路径表，对 L 存在端点集合 S，且或者 |S|≥5，
或者 S xor b 含一个 hitting triple。P 的可行端点集合 G(P,b) 至少4个，
与 S 均位于同一个8点异奇偶类：

* |S|≥5 时，5+4>8，交集非空；
* 低集合情形，由平移后的 hitting-triple 定理，同样交集非空。

选交点 q 后，两条路径独立选择：A 路径精确覆盖14个非避点，
B 路径覆盖全部16个点；都从对应 b 到对应 q，q 与 b 异奇偶，因而不同。
添加 b–bar(b)、q–bar(q) 两条短桥得到一个圈。
两个端点都在 A 路径内，绝不等于被避开的 x,y。
两个路径的顶点支持在不同面而不交，圈共30点，原匹配边全保留。
没有原交叉边需要恢复，所以新增桥不会与任何原边冲突。

量词为“对每个 L、每个 P，存在 q 和两条路径”，
不需要同一个 q 对所有 P 有效，也未把 S 中所有端点同时处方给一条路径。
