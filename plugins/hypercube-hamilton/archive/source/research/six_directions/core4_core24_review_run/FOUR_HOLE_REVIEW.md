## A：定义、量词和精确适用范围

统一取 Q_n 的顶点为二进制向量，短边为汉明距离 1 的边；B(Q_n) 为按顶点奇偶划分的完全二部图。M、L、P 均为无向边集，P 另有完美匹配性质。“人工边”指临时加入的边，未必是长边。所有哈密顿路径均为简单生成路径。

1. **F1：** 对每个 n≥5、立方体匹配 M、未覆盖点 u 和异奇偶点 v，只要存在恰好留下 u,v 的短边匹配 L 且 |M∖L|≤1，就存在包含全部 M 的立方体哈密顿 u–v 路径。遗漏边端点允许包含 v。
2. **F2：** 在 n≥5（特别是本项目 n=6）下，M 恰好留下互异的 u,z,w,t，u,z 同奇偶，w,t 为另一奇偶，zt、zw 都不是短边。若有 z–a–b–t 三边增广路，则得到包含 M 的 u–w 路径。所述 F1 条件与三边增广路的等价性仅针对这一四孔剩余类和未覆盖目标端点 w。
3. **F3：** 延续 F1 的全部前提，若目标 v 已被 M 覆盖，则 F1 所需 L 的存在蕴含 N4 的 Hall 条件，进而蕴含 N3 可用。它没有声称所有未覆盖目标点都满足 F1。
4. **F4：** 给定四孔及 P=M∪{uw,zt}，并且已经存在包含 P 的哈密顿 x–v 路径 K，x 与 u 同奇偶且不在四孔内，v∈V(M)，所有非 P 边为短边。只考虑删除两条人工边且最终不加回它们、另删除至多 k 条 K∖P 边、仅补入短边的修补方法。结论是这一方法的必要切边数下界，既不保证 K 存在，也不保证下界可达。
5. **F5：** 延续 F4 的 P、K 和短边约定；四孔与 x,v 两两互异，第三切边 ab 为 K∖P 中沿 K 定向 a→b 的边，a,b 还须避开上述六点。假设 xw、za、bt 都是短边且不在保留边集中。结论仅刻画这一指定换边操作何时连通。

说明：F2 正文没有再次写 n≥5，应按 F1 和项目 P6 的范围阅读。为便于将 F2 单独引用，建议在其首句补写“设 n≥5”；这是范围自足性的编辑建议，在当前 n=6 任务中不构成数学缺口。F4、F5 的组合修补论证本身无需使用 n≥5，维数限制来自所引存在性定理。

## B、C：逐项假设与证明步骤核查

### F1：遗漏一条边后闭圈

- 若 M⊆L，则 u,v 均未被 M 覆盖，L 是 Q_n−{u,v} 的完美匹配，n≥5⇒n≥2，D3 的全部假设满足。D3 添加 uv 后确实得到完全图上的完美匹配，故 Theorem 1 可用；删除 uv 后留下的边都是短边。
- 否则 M∖L={ab}。若 L 使用至多三个方向，则 M⊆L∪{ab} 使用至多四个方向，满足 Theorem 8 的至多五方向限制。u 不被 M 覆盖同时排除 C1、C2、C3；异奇偶端点和 n≥5 已在 F1 给出。
- 若 L 使用至少四个方向，P=L∪{uv} 是 B(Q_n) 的完美匹配。ab 为短边，故 a,b 异奇偶；ab∉L 且 ab≠uv（后者因 u 不被 M 覆盖），因此 ab∉P。这核销了 Theorem 6 的端点边限制。
- 对该 P 及端点 a,b，若压缩匹配包含半层，N0 将限制 P 的全部短边至多使用三个方向，与 L⊆P 的至少四方向矛盾。N0 适用于一般 B(Q_n) 完美匹配，故此处不需要错误地假设 uv 是短边。
- Theorem 6 给出包含 P 的哈密顿 a–b 路径 K，所有其他边均短。K 不含 ab：具有至少 32 个顶点的简单路径若包含两个端点之间的边，就不能再经过其他顶点。因此加入 ab 确实形成简单哈密顿圈。
- 从圈中删去 uv 得到 u–v 哈密顿路径；其边均为短边，并且 uv∉M，所以完整保留 M。若 uv 本来就是短边，论证仍成立。若 v 是遗漏边 ab 的一个端点，则 uv 与 ab 在圈上相邻，但仍是不同边，删去 uv 同样有效。

未发现 F1 的条件或结论发生偷换。

### F2：四孔增广与等价性

增广路的内部端点 a,b 属于 M 的边 ab，因此不属于任何四孔。删除 ab 后加入 za、bt 的两条短边互不相接，也不接触其余 M 边，形成恰留 u,w 的短边匹配 L；|M∖L|=1，故 F1 可用。

反向等价性也成立：若存在 F1 所需 L，不能有 M⊆L，否则唯一需要补入的边是不存在的 zt。因此必遗漏某条 ab∈M。|L|=|M|+1，所以恰好有两条 L∖M 边，必须匹配 z,t,a,b。将 ab 的端点命名为 a 与 z 异奇偶、b 与 z 同奇偶后，仅有两种二部完美配对：{ab,zt} 或 {za,bt}。第一种被 zt 非短边排除，只能得到正文中的三边增广路。

若 d(z,t)=5，则不存在任何长度 3 的立方体 z–t 路径；若两距离都是 5，则交换目标端点的版本也不能使用该三边判据。这个限制没有被误表述为不存在哈密顿路径。

### F3：已覆盖目标点不产生 N3 之外的新覆盖

令 av∈M。L 不覆盖 v，故 av∉L；F1 的差集上界强制所有其他 M 边留在 L 中。于是可供 L 新增边使用的顶点恰为

    (E∖{u}) ∪ O ∪ {a},

其中 a 与 u 同奇偶，v 已从可用点删除。每个 E∖{u} 的顶点都在 L 中被覆盖，其 L 伙伴必须在 O 中：所有其他原匹配顶点已经被 M∖{av} 占用，而 a 位于同一奇偶侧。取这些 L 边便得到残余诱导图内饱和 E∖{u} 的匹配。

因此 N4 的 Hall 条件全部成立，存在某个未覆盖点 w 使 M 能补成只留下 u,w 的短边匹配；N3 便对原目标 v 可用。这一推理不要求原来恰有四孔，也没有把 F1 新覆盖范围误推广到所有已覆盖目标点。

### F4：允许切口端点有额外删边的度数恒等式

设最终路径为 H，人工边集 J={uw,zt}。抵消删后又加的非 P 边后，可准确取

    D=(E(K)∖P)∖E(H),    A=E(H)∖E(K).

由于最终保留 M、最终不含 J，且操作不删除其他 P 边，得到

    E(K)∖E(H)=J ⊔ D,    |D|≤k.

N2 证明 K 中的 P 边位于第 0、2、4、… 个边位置，故 K∖P 确为匹配，D 也是匹配。所有 A、D 边均为短边。

对每个顶点 q，度数平衡的精确公式为

    d_A(q)−d_D(q)=d_H(q)−d_K(q)+d_J(q).

逐点核算如下；四孔、x、v 互异由假设及奇偶关系保证。

| 顶点 | d_H−d_K | d_J | d_A−d_D |
|---|---:|---:|---:|
| x | +1 | 0 | +1 |
| u | −1 | 1 | 0 |
| z,w,t（各点） | 0 | 1 | +1 |
| v | 0 | 0 | 0 |
| 其余点 | 0 | 0 | 0 |

特别地，z、w 或 t 可以满足 d_D=1、d_A=2；正文没有把它们错误地当成 A∪D 中必为一次点。u 即使接触 D 也没有问题，它在 A、D 中的度数仍相等。x、v 作为 K 的端点，其唯一 K 边属于 P，故它们不接触 D，这也与表中公式一致。

在每个普通顶点配对所有 A、D 半边；在 x,z,w,t 各留下恰好一条未配对的 A 半边。有限边集由此分解为交替闭迹和恰好两条交替开迹，四条未配对半边分别是开迹端点。中间经过特殊顶点或者同一顶点重复出现都不损害“迹”分解；无需误认为每条迹都是简单路径。

每条开迹首尾都是 A 边，若含 j 条 D 边，就有 j+1 条 A 边，长度为 2j+1。立方体是二部图，故其端点异奇偶。x,z 同奇偶，w,t 属于另一侧，因此以 z 为端点的开迹终点 q 必为 w 或 t。于是

    min{d(z,w),d(z,t)} ≤ d(z,q) ≤ 2j+1 ≤ 2|D|+1 ≤ 2k+1.

各不等号方向正确。得 k≥(min{d(z,w),d(z,t)}−1)/2。距离本为奇数，所以右侧在本情形中为整数。非邻接给出 k≥1；两距离均为 5 给出 k≥2。

禁止把 uw 加回是必要的作用范围限定：若允许最终保留短人工边 uw，则 J 不再是实际删边集，上述四点度数差公式不适用。正文已明确限定，故没有把受限修补方法的障碍提升为 P6 反例。

### F5：六种次序的独立核查

第三切边 ab 避开四孔及 x,v，故三条切边两两不相接，切开 K 得到四条顶点不交路径。新增边的端点互异且不在保留边集中，所以换边后 u,v 度数为 1，所有其他顶点度数为 2，所有边均短且全部 M 边保留。唯一剩余义务确为连通性。

独立验证使用八个符号端点 x,u,w,z,t,a,b,v。对每个三切口排列，将四条保留路径各压缩成一条抽象边，再加入 xw、za、bt。下表中的连字符可表示原有整段路径或新增单边，不能将其全部理解为实际立方体单边。

| 顺序 | u–v 分量的抽象遍历 | 其他分量 |
|---|---|---|
| ABC | u–x–w–z–a–t–b–v | 无 |
| ACB | u–x–w–a–z–b–t–v | 无 |
| BAC | u–t–b–v | 圈 x–z–a–w–x |
| BCA | u–b–t–a–z–x–w–v | 无 |
| CAB | u–b–t–v | 圈 x–a–z–w–x |
| CBA | u–t–b–z–a–x–w–v | 无 |

六种排列全部检查，四种连通、两种恰含一个分离圈。故连通当且仅当 A 不在 B、C 之间，正文的充分性与必要性都成立。该计算规模固定为六个抽象图，没有重跑任何立方体匹配的大规模穷举。它核验有限分类，不承担兼容切边存在性的证明。

## 依赖核查

- **N0：** 半层端点集 S 与补集 T 的诱导短边都仅沿该半层方向 i；压缩匹配未覆盖的两个指定端点属于 T。若新压缩边不在半层，整半层保留于 P，所有其他 P 边的端点在 T，短边仅沿 i。若新压缩边在半层，只有两条被压缩的 P 边可能跨 S,T；它们至多引入两个额外方向。这对允许多条长边的 P 仍成立。
- **N2：** 哈密顿路径包含完美匹配时，首边必须属于该匹配，再逐对归纳，强制交替。该证明不需要所有 P 边都是立方体边。
- **N3：** 两孔异奇偶来自二部平衡；v=w 分支使用 D3；短人工边分支使用 D2；少方向分支使用 Theorem 8；其余分支选 w 的邻点 x≠P(v)，至多排除一个候选，而 n≥5。长边 uw 确保 x≠u，奇偶确保 x≠v，且 xv∉P。N0 排除 Theorem 6 的半层障碍。N2 确保 uw 定向 u→w，删除它后 xw 跨两个分量，反转前段再连接的构造合法。
- **N4：** 残余两侧大小相等，去掉 u 后大小差一；Hall 定理在残余诱导图内给出饱和左侧的匹配，右侧恰留一个点。其充要性未混同为哈密顿路径存在性的充要性。
- **D1–D3：** D1 仅用于短边完美匹配，因此 T 中剩余顶点只能沿 i 匹配的步骤有效；含压缩边的情形迫使两个指定端点互为 i 邻点，从而仅增加一个共同方向。D2 的 Theorem 1、6、8 三分支以及 D3 的人工边删除均符合引用定理的假设。没有把 D1 错用于含人工长边的 P。

依赖关系可写为：

    Theorem 1 → D3 → F1 → F2
    Theorem 6 + N0 + Theorem 8 → F1
    D1 + Theorems 1,6,8 → D2
    D2 + D3 + Theorems 6,8 + N0 + N2 → N3
    Hall → N4
    F1 的补全假设 + N4 + N3 → F3
    N2 + 二部性 + 度数平衡 → F4
