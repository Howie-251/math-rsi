## A. 定义、类型及量词

四个“孔”是匹配未覆盖的顶点，仍属于最终路径和圈，不是从立方体中删去的顶点。M 是 64 个顶点上的 30 条互不接触的立方体边，因此恰覆盖 60 个顶点。

| 符号 | 类型与约束 |
|---|---|
| u,z,w,t | 四个互异的全局未覆盖顶点；u,z 同奇偶，w,t 为另一奇偶 |
| p(x) | 六维顶点 x 的汉明重量模 2；归一化后 u,z 偶，w,t 奇 |
| i,k | 两个不同的六维坐标；切分坐标为 i，层内坐标集合为 `I=[6]\{i}` |
| A,B | 第 i 位分别为 0、1 的 Q5 子立方体 |
| M_A,M_B,C | M 的 A 层内边、B 层内边、跨层边三个不交部分 |
| X_A,X_B | C 在 A、B 内的端点集 |
| D | X_A 上连接异奇偶点的任意完美匹配，允许长边，空集允许 |
| P_A,P_B | 分别在 K(A)、K(B) 上的完美匹配；只有 P_A 被要求二部 |
| K_A,K_B | 输入定理给出的单条哈密顿路径；未属于 P_A/P_B 的边为层内立方体边 |
| J,q | 转移后含 u 的路径及其 B 端点 |
| R | 其他转移路径的 B 端点配对；不是第一层的压缩匹配 |
| r,s | `r=M_B(y)`、`s=R(y)` |
| Q | 第二层 P_B 在 y,v 处的压缩匹配，恰不覆盖 y,v |
| H,S,T | 某个假定存在的半层、其端点集、该层内的端点集补集 |

维数 d=5 与第 43 行局部顶点名 `d=M_A(b)` 是不同类型，正文上下文足以区分；本报告需要时将后者写作 `d_b`。

规范化后的路径结论是：对每个满足四孔距离假设的 M，及对每个

`v∈T_*={e_i,e_k}∪{x∈{0,1}^6 : x_i=x_k=1, p(x)=1}`，

存在一条包含 M 的 Q6 哈密顿 u—v 路径。量词是 `∀M ∀v∈T_* ∃K_{M,v}`，没有要求一条路径同时拥有多个不同终点。圈结论是 `∀M ∃C_M`。归一化自同构的逆映射把路径和圈带回原实例。

## F. 维数与统一性

两次 Theorem 11 均在 Q5 上调用，恰达到 d≥5 门槛。半层侧别使用自由坐标 I，不能把全局六位坐标当成层内六维。全局奇偶与 B 内在奇偶相差常数 1；同奇偶、异奇偶关系保持，所以输入定理和所有比较不受影响。

Z2 的统一性是：M 除四孔位置外可任意排列，跨边个数和局部方向数不额外受假设约束；只要 M 满足所述条件就得到结论。所证辅助性质甚至不依赖 D 或 K_A 的特殊选择。没有隐藏常数或参数相关阈值。

本证明没有自动推广到任意维数。“层内对跖点排除一个坐标后相差四位”及两次文献维数门槛都在此明确使用。也没有把“十个目标”误计为全部 32 个相反奇偶顶点。
