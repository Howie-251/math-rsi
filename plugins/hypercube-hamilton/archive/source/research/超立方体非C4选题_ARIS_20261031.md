## 1. Ruskey–Savage 猜想：优先攻六方向匹配

原问题：对 n≥2，Q_n 的每个匹配是否包含于某个哈密顿圈？

已核查 [Fink–Hotmar 2025](https://arxiv.org/abs/2501.19029)：至多五个坐标方向的匹配可扩展成哈密顿圈；论文还处理指定端点的哈密顿路径，并给出以 Q_d 内若干扩展性质为前提的任意 d 推广框架。[Fink–Mütze 2025版](https://arxiv.org/abs/2401.01769)则证明任意匹配可延拓成覆盖至少 2/3 顶点的圈。

建议目标：提取前一论文全部有限扩展假设，研究 d=6 是否成立；若成立，通过其递归框架获得任意维数的六方向定理。只验证普通 Q6 匹配延拓，未必足以满足指定端点等较强假设。

价值：有限核心有机会升级为无限维定理，优于只检查一个维数。路线：对称约简、反例约束生成、可复查 SAT 证书及递归证明。风险：有限状态规模、额外假设可能为假；失败也不自动反驳原猜想。

与 OpenAI 的关系：第113族的匹配计数/熵、第120族的匹配与指定度因子提供邻近工具，但目前没有证明它们能处理哈密顿连通性。属于间接关联；核心突破仍须来自超立方体扩展结构。推荐强度：经典超立方体方向首选，完整猜想仍高风险。

## 2. 两比特最优信息量猜想：与 OpenAI 最直接衔接

令 n≥2，X 在 {0,1}^n 均匀分布，Y=X⊕Z，其中 Z_i 独立服从 Bernoulli(p)，且独立于 X，0≤p≤1/2。对任意确定映射 Q:{0,1}^n→{0,1}²，是否总有

I(Q(X);Y) ≤ 2[1−h₂(p)]？

[Mahdavifar–Beirami v2](https://arxiv.org/abs/2609.26444v2)提出 2≤k≤7 的坐标投影最优猜想，并报告 k≥8 的反例。故不能将目标无限制推广到所有输出位数。

OpenAI [第119族形式化范围](https://raw.githubusercontent.com/openai/math/main/lean/docs/119.md)直接涉及二元输出的尖锐信息收缩。候选研究是四输出分区的局部熵拼接不等式及维数归纳。关键障碍：条件于一个输出位后，X 一般不再是均匀乘积分布；不能把单比特定理用链式法则机械相加。

首阶段成功标准：发现严格反例，或证明一个跨任意输入维数且不属于已有结果的新分区类/噪声区间；低维浮点无反例不算证明。完整两比特问题为较新的猜想，经典知名度不如 Ruskey–Savage 或 FEI，但最符合“利用 OpenAI 新数学成果”。本轮不把工作区旧的 n=3 探测当作新试验。

## 3. Leader–Long 对跖测地线猜想

原问题：Q_n 的红蓝边染色若给每对对跖边相反颜色，是否总有连接一对对跖顶点、长度恰为 n 的单色路径？测地线每个坐标恰翻转一次。

[Wu–Yang 2026](https://arxiv.org/html/2607.19276v1)声称证明普通 Norine 路径猜想，但引言明确将测地线加强列为开放；它与任意红蓝染色中“存在至多一次换色的对跖测地线”的版本在全维数意义上等价。

[Hollom v3](https://arxiv.org/html/2605.20184v3)已有至多 (π/2+o(1))√n 次换色的测地线上界。因此不能把得到 o(n) 当作新成果。

建议目标：先证明一个尚未覆盖、允许任意维数的染色结构类，或研究存在性最优换色数能否降到 o(√n)。后者不能要求随机均匀起点，因为该模型已有 √n 阶障碍。更小常数也须与最新版本比较。

与 OpenAI：现阶段没有识别出可直接迁移的库内引理；主要依据是上述外部原始论文。有限染色反例及路径可独立检查，适合“反例探索—结构引理”循环；完整问题风险高，不能把拓扑连通性当作最短路保证。

## 4. Fourier 熵—影响度猜想（FEI）

对任意 f:{−1,1}^n→{−1,1}，是否存在绝对常数 C，使 H( f̂² )≤C I(f)？

[González–MacManus–Pereyra 2026](https://arxiv.org/abs/2606.00246)给出坐标限制的熵差不等式框架和新函数类。[Potapov 2026](https://arxiv.org/abs/2609.21563)已处理 plateaued 与 partially bent 类，所以不能重复推荐这些类。

两条具体路线：一是找满足熵差递归的新结构类；二是构造更强的常数下界证书。[Numaro 原始报告](https://numaro.tech/research/fourier-entropy-influence-2026/)给出18变量种子和 >6.521845710923046575 的下界；正式刷新纪录前必须复现及再次查新。有限构造改进不等于解决 C 是否有限。

OpenAI 第119族的熵归纳、132/192族的布尔函数反例构造可作方法线索，尚未建立迁移定理。特别注意互信息熵和 Fourier 谱熵不是同一对象。完整 FEI 不列短期首选；新类或严格常数改进较可操作。

## 5. Snake-in-the-box：九维最长诱导路径

经典目标 a(n)：Q_n 中最长无弦路径的边数。最新核查 [Orland 等 v3，2026-09-30](https://arxiv.org/html/2607.15270v3)报告九维191边，且九维仍为最大值未知的最低维数。

具体任务：证明 a(9)=191，或构造至少192边的蛇；若资源不足，可选择更强可认证上界或有价值的新结构定理。证明最优必须给完整排除证书，搜索不到192不能作为上界。

与 OpenAI：没有找到直接依赖的库内引理。它符合超立方体著名问题和可验证计算研究的要求，但只是旁支备选，不能包装成从722篇直接推导的方向。新记录适配度较高，精确最优性明显更难。

## 6. Szymanski 置换路由猜想

原问题：将 Q_n 每条无向边替换为两个方向的弧，对任意顶点置换 σ，是否能同时选择 v→σ(v) 的路径，使不同路径不共用有向弧？允许同一无向边以相反方向各用一次。

[West 的问题页](https://dwest.web.illinois.edu/regs/szymanski.html)给出定义、低维及对合置换结果；强制所有路径最短的版本已存在反例。该页较旧，本轮未找到一般版本的新解答，开放状态核查覆盖弱于前三项。

候选目标：研究一类超出已知对合类的置换，给出任意维数的无弧冲突路由定理。OpenAI 第238族 Thorp shuffle 的条件轨迹、坐标扫描和置换分析有方法相似性，但混合时间结论允许时间展开和重复使用空间边，不能直接推出本猜想。优先级较低。

## 排除与决策

OpenAI 第171族已声称得到超立方体 Ramsey 数线性阶，第119族声称处理单比特 Courtade–Kumar，第127族声称处理渐近 Gotsman–Linial，第132族声称反驳块敏感度的二次加强。应检查这些成果而非把相同旧目标当作新题。普通 Norine 同样已有证明预印本。这里“有证明报告”不等于本次独立验证完毕。

推荐：以经典问题及可实现突破为主，选 Ruskey–Savage 的六方向推广；以从 OpenAI 论文实际抽取工具为硬要求，选两比特信息量猜想。纯粹追求完整大猜想时，目前没有证据支持给任何一题标出高成功概率。

下一阶段应只选一个题，固定原文定理、核查最新版本、复现已知特例，再做有停止条件的小规模探索；本轮未启动长时间求解任务。
