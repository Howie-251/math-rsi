## 固定状态，避免把历史恢复成新工作

T32、T33分别是“≤32/≤33边可染”，已得 m(5)≥33/34 的完整端到端 Lean。T34是“≤34边可染”，已有完整纸面候选，但 m(5)≥35 的全 Lean 未闭合；T35是“≤35边可染”，目标 m(5)≥36，仍有八类主要数学缺口。后两项保持暂停，本指南不构成恢复授权。一般 k≥12 的增长主定理已完成 Lean；小参数新界各自依赖有限精确计算，不能借一般定理或旧五元 Lean 升级其形式化状态。

截至本次整理，m(6)≥67、m(8)≥267、m(9)≥543为已完成独核/指定静态审阅的计算机辅助结果；m(7)≥131有全量独核，未有该参数跨家族终审或 Lean；十二元4664有全域重建和20例独立分数复算，并非664355型全表第二概率实现。以归档的各结果审计与范围为准。

## 一次研究行动应能改变什么

要继续一个分支，先明确尚欠的是选点、真实库存恢复、必要域覆盖、算术严格性，还是原染色连接。输出一个分数小于1时，立即问这个输入是否由每个实际 H 产生，所有可能输入是否都在表里，扣除是否来自同一批实际边。三者齐备就装配该分支，不再追求更小的漂亮分数。

遇到分数不严格，保存输入与逐位置的 A、B、C、D。若 C−D 仍不活跃，优化 D 不会降低该位置的最终界。若新约束只是旧约束改写，先把旧松弛见证代入；仍可行就不用跑同一个更大求解器。如果数学成立而 Lean 慢，定位归约与数据表示，保留原数学域；不要因 tactic/内存失败重启数学搜索。
