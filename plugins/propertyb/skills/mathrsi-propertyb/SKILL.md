# Property B 领域插件

本技能处理有限简单一致超图的二染色研究。它把已有归约、选点、局部计数和核验经验交给正在解题的 agent；具体目标、预算和当前未解分支由单题工作区给出。
使用 [MathRSI base](../../../../base/skills/mathrsi-research/SKILL.md) 组织持续研究；本技能补充 base 不应内置的数学判断。
若只需解释定义或核对一个短引理，直接完成相应数学工作，无需建立完整研究工程。

首次接入任务时读下文对象与原题连接，再按当前困难选择策略。查旧引理或检查器时读 [来源与适配地图](references/source-map.md)；准备工作包时可参考 [局部分支使用示例](examples/local-branch.md)。
示例是行动说明，没有替用户启动研究或执行计算。

## 原目标与允许的终点

设 H=(V,E)，V 有限，E 是由互不重复的 k 元子集组成的边集。
Property B 指存在 c:V→{0,1}，使每条原边都同时含两种颜色；不要求整体颜色数平衡。
m(k) 是不具有此性质的有限简单 k 元超图的最少边数。
因此“至多 M 边均可二染”等价于 m(k)≥M+1；不能把边数预算与最后下界混写。

先从当前规格确认 k、M、原顶点域、是否允许计算机辅助证明以及是否要求 Lean。
除非原题明确限制，点对覆盖、顶点数窗口、最小度、线性、正则或平衡染色均不是输入假设。
某条方法需要这些条件时，证明任意假定反例进入该条件域，或把结果明确保留为条件定理。
文献给出的下界、论文里的充分判据、本文求值结果和当前公开纪录是不同事实，比较时读实际版本与条件。

正向终点是从任意原输入推出原二染色结论。
若合同接受反驳，终点是显式超图及严格不可染性证据；一个局部库存或松弛模型的可行解不是超图反例。
搜索没有找到反例，不足以结束正向证明。
一个概率充分界没有严格小于 1，也不表示原超图不可染，更不表示原命题为假。

## 接收任务并向 base 返回什么

按下面五类信息自然书写即可，不要求固定文件名、JSON 或状态机。
简单任务可用一段完整说明，复杂任务可在工作区维护一张带证据链接的义务表。

|信息|本插件应说明的领域内容|
|---|---|
|任务|k、M、原对象域、允许的结束方式、接受的文献进口和计算证明方式|
|义务与连接|哪些条件来自无损反例归约；实际选点如何进入局部型；局部严格界如何推出原染色|
|行动提案|当前缺失的选点／分类／联合约束，拟用方法、输入域、预期新事实、成本及停止条件|
|结果与证据|已证命题、适用范围、实际覆盖、最紧或失败输入、证据位置、实耗与剩余连接|
|验证能力|检查哪个具体义务、读取哪些实际输入、能检出什么、尚需哪些数学或语义连接|

瓶颈要足以影响下一步判断，例如“现有菜单对残型不严格，活跃上界未变”，而不是只报又增加若干行。
已有结果与本轮新增结果分别标明；历史资料的状态不能直接覆盖当前任务。
运行插件不直接修改 base 或原题验收；发现通用流程问题可提交独立维护建议。

## 先建立完整的反例归约，再选择局部策略

若走最小反例路线，先核对选择的是最少顶点、最少边还是边临界反例；这些选择提供不同性质。
不共边的两点合并在每条边上保持单射；合并重复像边不增边数，像超图的合法染色可以拉回。
因此对适用的 k≥2 原题，可从最少顶点反例推出点对覆盖。
这个一般机制可复用，某档任务的顶点窗口不能直接复用。

在实际点对覆盖超图上，度数 d 与共度 λ 满足 Σd=k|E|、Σ(y≠x)λ(x,y)=(k−1)d(x)。
由此得到 d(x)≥ceil((v−1)/(k−1)) 及 v·ceil((v−1)/(k−1))≤kM。
这些整数界给必要顶点上端和度数分流；小顶点端仍需独立染色论证。
提升边数预算后重新求整个必要域，尤其检查上端是否新增顶点数。

“反例恰有 M 边”须有证明：可由已知至多 M−1 均可染推出，或在足够多可用边时补边并保留不可染性。
不能在可用边数不足时随意补边，也不能让重复边破坏简单性。
得到新域后先与旧证明重叠部分对照，复用适用的完整结论，只重做受新条件影响的部分。

若纯解析界、平衡染色或已知一般判据已经覆盖一段，直接关闭该段。
不为使用锁点强行把所有顶点分支改写成同一形式。
剩余分支才进入选点、真实迹与概率分析；必要时保留直接构造反例的有界机会。

## 选锁点是在原超图中证明存在，不是在目录中选一个好型

锁点是原 V 中的实际不同顶点，并与随机排列的指定位置对应。
点对覆盖时 ε(x)=(k−1)d(x)−(v−1)=Σ(y≠x)(λ(x,y)−1) 是实际共度超额预算。
λ(x,y)≥t+1 的伙伴数至多 floor(ε(x)/t)，其中 t≥1；这可用来避开高共度伙伴。
低度点数量、冲突图独立集、共同单位邻点池和全局总度预算可共同保证所需锁点。

先问当前分支能保证多少锁点、何种度数和内部共度，再问哪种布局给严格界。
如选锁引理不足，概率程序里的漂亮候选布局不能代替实际存在性。
提高锁数有时会增加联合域与形式化成本；比较新增信息和完整连接成本后再决定。
若旧最坏型迫使外围点共度、度数或分组刚性，优先从同一原图的预算排除它。

可尝试从低共度伙伴转向共同中心，或用等号刚性压缩整个分支。
这些是可选研究方向，不是保证每个参数都存在单位三角形或某个固定锁数的通用定理。
已有选点引理只在其确切条件下调用；一般 k 的纸面结论与五元 Lean 接口分别核实。

## 从真实迹进入有限类型

对实际单射 f:[s]→V，迹重数 μ(T) 计数满足 e∩f([s])=f(T) 的原边。
总边数、点度、共度和较大迹重数属于同一套 μ，不能从互不相容的局部最坏输入拼出“实际型”。
恢复满足 u(T)=Σ(U⊇T)μ(U)；反向递减恢复时，自然数减法不截断须由真实分拆保证。
empty 和 singleton 也属于完整重数，不能只保存大迹后在概率调用时猜补。

目录可以包含不可实现的必要型，这会使证明更强但计算更贵。
需要证明的是任意实际输入进入目录，或经显式换标号进入已核代表。
只证明保存的每一行合法，未证明没有遗漏；检查代表数正确也不替代覆盖。
若使用对称性，保存或证明实际顶点／锁点重标号、迹映射及布局运输。

扩锁时，将旧迹按是否含新点分拆；新点度数、与旧锁共度及旧重数给出容量约束。
递归剪枝要有“真实有界分配必被枚举”的完备方向，再证明解码与完整重数恢复。
缩锁、投影和重标号应继续指向同一个 H；父型严格的分支不必再扩锁。
分类未接 actual caller 时，报告“目录算术完成”及剩余连接，不宣布整个点数分支完成。

## 概率和共同坏对：先确定样本空间，再优化实际总界

随机贪心失败可由临界单交有序边对事件覆盖；应用时说明算法、顺序、事件方向和覆盖蕴含。
固定锁点位置后，自由点在自由槽中均匀无放回排列。
左右自由集的同时落入须联合计数；不能把它们当两个独立事件。
组合数为零、槽数不足及实际互不相交条件由原事件解释，不以分母形式猜定。

逐位置可能有多种合法上界，最终取其中最小值再汇总。
因此加强一个非活跃项可能使实际总界完全不变；先检查真正控制最小值的项及严格余量。
若暂时不变，判断它能否与其他必要改进联合改变活跃界；有明确联合用途可继续，否则转向更有信息的结构、选点或事件覆盖。

避锁 link 池的相交对可给真实坏对数量下界，但不同池可能重叠。
同一坏对向量上的多个合法成本下界可以取最大值；没有额外证明时不能直接相加。
容量修复、弱对偶、共同整数约束或多布局加权可处理重叠，选择成本相称的方法。
先明确坏对是否有序、方向权重、中心是否固定，防止重复乘公共点数量或漏掉反向项。

多个布局作用于同一 H 及同一坏对集合。
分别取各布局最坏值可能丢掉共同约束；出现难型时问这些最坏情形能否同时成立。
保留共同变量后，可证明联合下界、用真实边组收费，或从选点条件排除不相容配置。
局部松弛中的坏型是诊断材料；只有实际实现为原超图并证不可染，才是反例。

## 停滞时改变什么

先保留一个最紧或失败输入及其活跃项，说明它来自实际超图、必要库存还是更宽的松弛。
若只是算术误差或错误计数，修该处并核对受影响域。
若选点保证不足，回到整数度数与共度预算，尝试共同池、替换点或等号刚性。
若局部模型太宽，恢复跨布局、跨迹或原边分组的共同约束。
若现有表示在数学上已完整但程序或 Lean 很慢，先修改表示、数据依赖或证书粒度。

同一卡点两轮无实质增量时，向 base 交代新观察和下一项可能改变决策的工作。
重新判断可以继续原法，但要说明为何这次有新增信息或资源依据。
固定域完整扫过且没有新条件时复用结论，不用新随机种子重复同一完整域。
仅因资源不足而停的完整计算，可在授权资源允许后续跑；不必强求先发明新定理。

优先关闭整段必要域或提供可调用的条件引理，不以目录、公式或日志数量代替进度。
困难条件引理有独立价值：同时记录它已证明什么，以及原题还缺哪些前提。
一个父分支已严格且已核验时停止细分；只对失败父型追加更强方法。
不要把一次便宜实例的速度外推到重复数、锁数或迹规模不同的全域。

## 验证适配与 ARIS 复用

没有单个“Property B verifier”能自动承担所有义务；每次将现有检查器接到它真正验证的那一项。
精确分数程序检查给定公式和输入的算术；注入／下降阶乘实现可独立核计数，但不会自动证明分类完整。
覆盖核检查实际域进入目录；实际调用证明把任意 H 的数据送入目录，并把严格界送回原染色。
反例检查读取实际边集，检查边大小、简单性及全部染色或其他充分不可染性证书。
审阅则针对量词、归约、选点、覆盖或数学连接；说明实际读了哪些文件、有没有执行命令。

需要 Lean 时使用已安装 `lean-formalize`，先固定原题类型并做一个非平凡实际 caller。
查 Mathlib 和现有领域模块，再决定新增模块；五元宿主接口不能因纯计数引理一般化而自动变成一般 k。
重数据、覆盖证明和小 dispatcher 可按真实依赖分开，复用未改的重核验成果。
按实测内存安排一个正式重构建执行者；多个 agent 可并行数学推导或不同模块，避免互相重复重构建。
最终显式构建当前主模块，核导出类型与传递公理；默认旧 Main 成功不证明新目标已编译。

`formula-derivation` 适合整理假设与计数链，`proof-writer` 处理缺失论证，`research-wiki` 保存可复用条件和失败边界。
关键连接用 `proof-checker` 或有明确问题的 `research-review`；不以轮数或赞同票决定数学真假。
成稿需要阅读交付时使用 `render-html`，展示保真与数学验收分别报告。
不为使用插件自动跑论文、全模型审阅或 Lean；当前合同规定的审阅和核验照常完成。

## 收回结果并交接

从当前规格出发，沿实际采用的完整论证接回原染色。若使用锁点路线，串起原 H、反例归约、必要域、实际选点、真实迹、覆盖和严格界；若解析或其它证明已经足够，不补未使用的锁点与迹。
每条条件引理说明实际前提在哪里获得；替代路线已经完成时，无需同时完成所有旧路线。
保留证据读取入口、实际运行命令及范围；CPU、墙钟、存储、独核与装配成本按已有记录说明。
没有测量的时间不反算，也不将静态审阅写成执行复现。
把通用新引理和失败重试条件写入本题 wiki；具体点数、边数、残型和进度留在工作区。
本插件来源于历史研究方法，不携带那些任务的实时状态，也不授权恢复它们的 Goal。
