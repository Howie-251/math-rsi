# 成功案例：M=65 的六元完整证明怎样落地

这个案例复放已存在的 m(6)≥66 计算机辅助证明；不是重新研究更高参数。随后M66已得m(6)≥67，旧M65仍适合展示完整链，因为379型与全部共同坏对整数向量可在数秒内独核。

## 输入与原题连接

输入不是一张漂亮超图，而是原命题“任意有限简单六元H，|E|≤65”。最小顶点nonB归约在内部给paircover，5d(x)≥v−1和总度≤390。v≤10两色类≤5；11…26均衡并集界最大780/805<1；v≥44因44·9=396>390排除。剩余27…43可补边到恰65，下面所有度数、迹、坏对都属于这一补边H。

完整分流是27…31零锁五型；32…36最低度/单位伙伴双锁，另32点最低度12的共度1/2两型；37…39低度三单位锁；40…43四单位锁六种带标签K4团划分。作者与独核重新生成域，不从“成功结果已经存在”倒推完整性。

## 调用的公式与实际选择

锁固定位置后，其余命名顶点均匀注入剩余槽，直接下降阶乘概率计算endpoint/start/ordered-single-intersection权。每h取min(A,B,C−D)，不得把不活跃的名义删除再从总和扣。六元link大小5，避R配额

    q_R=max(0,ceil((5f_R−(v−1−|R|))/4))。

37点70型/210中心逐一枚举全部整数胞，含核心singleton/singleton胞与零权胞，约束同一b向量，最小化一次双方向权。38/39及四锁用较弱全link最低q成本已够，不无条件上更贵的共同优化。

32点最低度12总超额仅6，至少26名十二度点。若另25低点对固定x全λ≥3，超额至少50>5·12−31=29，故存在λ1或2伙伴。两种实际count为(42,11,11,1)/(43,10,10,2)，位置(16,17)，独核294523/300150与898423/900450严格。它取代不strict的旧宽伙伴域，不是删坏行。

37点的三单位锁来源为低度冲突图：Z=(D+1)v−390、T=5(D+1)−v+2；20Z>(s−1)T²足够选s锁。v37/D12/s3恰1820>1800。全部70型有成功度数排列与布局，68型用(17,18,19)，两全12型用(15,16,17)，不能声称统一中央布局。

从MathRSI仓库根执行；Python程序会改写RESULTS.json，所以先拷到临时工作目录。需要Python3标准库，不需LP、NumPy、Lean或模型API。

```sh
PB_ARCHIVE="$PWD/plugins/propertyb/knowledge/archive"
PB_REPLAY=$(mktemp -d "${TMPDIR:-/tmp}/mathrsi-m6-XXXXXX")
cp -R "$PB_ARCHIVE/context/propertyb-m6-66-20261029" "$PB_REPLAY/m6"
python3 -B "$PB_REPLAY/m6/independent/check.py"
```

原脚本入口：[check.py](../../../knowledge/archive/context/propertyb-m6-66-20261029/independent/check.py)。读入父目录`ROOT_TWO_LOCKS.json`、`avoided/V37_THREE.json`、`pilot/tightened.json`、`pilot/FOUR.json`；这些文件提供已选布局，不提供独核算出的概率。程序自己计算小点数/零锁、最低度12特殊双锁、三四锁完整域，并验证保存domain键相等、度数排列与位置合法。

## 为什么能返回原命题

结构证明为每个补边最小反例产生表内实际型；表完全覆盖且所有型有合法布局和U<1；条件排列空间非空，因此存在成功贪心排列。算法不留全红边，不失败即不留全蓝边，给补边H合法染色。限制到原边、拉回识别商，得到原始任意H染色。
