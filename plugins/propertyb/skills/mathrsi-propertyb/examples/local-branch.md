# 示例：一个局部分支算术已严格，是否可以关闭整支

这是自包含的用法示例。任务是研究任意有限简单 k 元超图在至多 M 边时可二染，当前得到某个顶点数／最小度分支的严格局部表。
本页不给 k、M 固定数值，也不声称某个新下界已成立。

## 使用前明确路径

`${TASK_ROOT}` 指本题已有工作区的实际绝对目录，例如使用者新建或提供的研究目录；由执行者在命令前显式设置。
`${PROPERTYB_SOURCE_ROOT}` 指有权读取的历史 Property B 资料目录，未提供时可省略，不默认作者电脑路径。
下面引用的任务文件需按本题现有名称对应，不要求为了例子重命名原工程。

```text
先读 MathRSI base 与 mathrsi-propertyb。
TASK_ROOT：本题已有规格和研究产物的实际目录。
当前任务：证明原有限简单 k 元超图的 ≤M 边二染色命题。
当前义务：关闭实际分支 B，并把结论接回原 H。
已有材料：本题规格、B 的归约证明、局部目录及数值报告、现有 checker 说明。
写入范围：仅 TASK_ROOT 下分配给本次义务的目录。
请先确定局部表是否覆盖所有实际输入，再选择缺失证明或必要核验。
已完成的数学不重推；历史暂停项目不恢复。
```

## 一次有用的接入判断

执行者先读原规格和 B 的定义。若 B 只来自某种额外结构，检查是否已证明每个原反例进入 B 或其他已处理分支。
这一步可能发现 B 根本不是完整分流的一部分，此时新增义务是归约连接，不是扩表。

若上游连接已经成立，读实际锁点存在性。目录里有优良锁点并不保证原 H 有这种选点。
假设选点论证已经给出 f:[s]→V，再核对目录的 μ 是否就是同一 f 的迹重数，是否包含 empty 和 singleton。
如需要换标号，查实际置换是否同时运输了迹、坏对系数和布局。

若数值报告只覆盖保存代表，而任意实际型进入代表的证明缺失，把它写成独立义务。
已有覆盖核可以直接接入；缺少证明时，选择完整必要型小表、显式置换分类或容量枚举完备性等合适方法。
无需先为所有方法建立一套新验证框架。

假设覆盖和实际绑定均已有，最后查严格分数采用的共同坏对下界是否由本分支真实池保证。
独立算术核验应重算实际使用公式与输入，不只比较报告中的最大分数。
若全部已足够且合同要求的核验完成，直接装配“B 中任意 H 可染”，不再扩展已严格的父型。

## 五类信息的示意结果

```text
任务：原规格中的 k、M 与有限简单对象域保持。
义务与连接：B 的上游归约、锁点存在性及真实重数恢复已成立；
             尚缺任意实际型到已算代表的覆盖。
行动提案：复用既有容量递归，只证明实际分配进入目录并恢复重标号；
           先试一个非平凡 actual caller，再决定是否扩大形式化。
结果与证据：目前只可报告代表域算术严格，未关闭 B；
             精确表和现有核验记录保存在本题相应目录。
验证能力：现有分数 checker 验算术；覆盖证明验无遗漏；
           actual caller 将两者接到任意实际 H 的原染色结论。
```

若检查后反而发现缺的只是报告未链接已有覆盖，直接读取并接回，不重做整张表。
如果发现某行不严格，记录它是实际型还是必要松弛型，并检查哪项上界活跃。
只有新约束或新布局可能改变实际总界时，才安排有界探针；不因已写了很大表就继续加锁。

## 交付的实际含义

最终文件应说明本次新增的是覆盖、公式修正、真实调用还是完整分支证明，附已有检查器的实际命令与结果范围。
完整分支只有在上游归约和下游原染色都接通时才关闭；局部引理则作为有前提的可复用工具保存。
本示例未执行任何命令，不给出虚构的 PASS、耗时或数学完成状态。
