# 从真实案例接一个局部分支

本目录保留五份完整案例，按当前义务选用：

- 数值已strict，想确认如何覆盖原始任意H：[六元379型完整证明](m6-complete-proof.md)。
- 抽象修复门被反例击中，如何恢复实际原边前提：[十点signed反例](signed-gate-counterexample.md)。
- 21点长时间局部变细却未闭，如何证明停止无效计算：[component松弛无增量](component-relaxation-stop.md)。
- 无限参数范围如何内部消除见证/结构条件并审原题：[一般k完整Lean](general-growth-lean.md)。
- 自适应分流与定向整数算术怎样分别审覆盖/概率：[十二元664355实例](k12-adaptive-coverage.md)。

新任务的局部分支B先从实际原题输入获得，不追加未获证明的点数、度数或证书假设。若B还缺锁点存在性，先补选择；若真实库存已恢复但只有代表值，先补有标号覆盖/显式置换；若覆盖已有而某行不strict，保存活跃项与准确输入，按[失败地图](../references/practice/failure-map.md)选择新增信息；若两者都齐，直接接回原H染色。

已有条件引理可作为工具交付，保持其假设；只要实际caller尚未消掉外部证书，它不等于整支闭合。不要为新任务创建一套泛化验证平台，也不把这份案例目录当成要求重跑全部历史脚本的清单。所有可执行命令均在工作副本运行，archive保留历史证据。
