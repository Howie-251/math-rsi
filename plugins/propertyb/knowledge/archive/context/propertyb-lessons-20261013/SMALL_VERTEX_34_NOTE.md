# 下一边数的入口诊断：34条边、至多18点

2026-10-13。为经验总结核对下一步边界的新纸面推导；不是T34完整证明，也尚未加入Lean。T34指至多34边可二染色，对应m(5)≥35。

取均匀大小为floor(v/2)的红色顶点集，余下为蓝色。固定五元边的单色概率为

p_v = [C(floor(v/2),5)+C(ceil(v/2),5)] / C(v,5)。

v≤8时平衡二染色平凡成立；9≤v≤16时p_v≤1/39，故34p_v≤34/39<1。v=17,18时p_v=1/34，朴素并集界恰好为1，需要严格改进。

对于任意两条不同五元边e,f，单色事件A_e和A_f有正概率交集。若两边相交，则|e∪f|≤9，可将其并集放进9点色类；若不相交，则分别放进两个色类，并补足8/9或9/9点。因此，边数恰34时任选两条不同边，

P(∪_e A_e) ≤ Σ_e P(A_e) − P(A_e∩A_f) < 1。

这一不等式只把所选两个事件合并一次，再对其余事件使用并集界；并未忽略三重交而非法套用截断包含排斥。

可进一步给明确差额。以红色类为样本，交数t=|e∩f|取0,1,2,3,4，两个事件交集的样本数分别为：

|v|样本总数|t=0|t=1|t=2|t=3|t=4|
|---|---:|---:|---:|---:|---:|---:|
|17，红8蓝9|24310|70|1|10|55|220|
|18，红9蓝9|48620|140|2|20|110|440|

所以P(A_e∩A_f)≥1/24310，34边失败概率≤24309/24310<1。边数≤33可直接用≤33/34<1，或引用已完成T33。

这些整数由组合公式计算，未枚举超图。t=0时有2 C(v−10,floor(v/2)−5)种；t≥1时令u=10−t，同色并集的两种颜色分别给C(v−u,floor(v/2)−u)和C(v−u,floor(v/2))，不可行的组合数取0。

结合仍适用的最小反例合并点与整数度数界26×7=182>5×34=170，可在纸面上继续把34边问题限制为19–25点。下一步需将上述严格交叠连接到实际有限随机空间后才可称Lean归约完成；它不解决19–25点的剩余结构。
