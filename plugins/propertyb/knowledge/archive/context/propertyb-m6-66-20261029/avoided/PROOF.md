# Six-uniform avoided-link quota refinement at M=65

Let H be a finite simple six-uniform hypergraph on v vertices. Fix an ordered locked set S=(x_0,...,x_{s-1}), where s≤3, and a layout assigning the locks distinct permutation positions. Let ell_T count actual edges whose intersection with S is T. Fix a lock x_j and write b=2^j.

For each R⊆S\{x_j}, put f_R=Σ_{T: j∈T,T∩R=∅}ell_T and

q_R=max(0,ceil((5 f_R−(v−1−|R|))/4)).

The edges containing x_j and avoiding R yield distinct five-element links on at most v−1−|R| points. If their point degrees are a_y and there are B_R intersecting unordered pairs of links, then

5 f_R=Σ a_y ≤ (v−1−|R|)+Σ C(a_y,2)
      = (v−1−|R|)+Σ_{A<B}|A∩B| ≤ (v−1−|R|)+4 B_R.

The last inequality uses simplicity: two distinct five-element links intersect in at most four points. Hence B_R≥q_R. No point-pair coverage is needed for this lemma.

For each unordered type cell {T,U} containing j, let z_TU be its actual number of pairs overlapping beyond x_j. Its capacity c_TU is C(ell_T,2) if T=U, otherwise ell_T ell_U. The same actual vector z satisfies simultaneously

0≤z_TU≤c_TU,  z_TU integral,
Σ_{(T∪U)∩R=∅} z_TU ≥ q_R  (every R⊆S\{x_j}).

Let w_TU=w_h(T,U)+w_h(U,T), with exactly the conditional-permutation weights from propertyB_m6_certificate.py. Every w_TU is nonnegative. Thus the minimum of Σ w_TU z_TU under these necessary constraints is a rigorous lower bound for the weight of actual bad pairs. Each unordered pair is counted in exactly one cell, so imposing multiple quotas does not add multiple copies of its weight.

## Exact finite minimum used here

The pilot profiles have pairwise lock codegree one. At any center, there is a singleton type {x_j} with n edges and at most two exceptional edges (the pair blocks, or one common triple block). Consequently the center has at most four nonempty unordered pair cells: the core cell ({x_j},{x_j}), with capacity c_0=C(n,2), and at most three remaining cells. Denote their capacities c_i and weights w_i, i=1,...,r, where r≤3. The core belongs to every quota.

For each tuple of integers t_i∈{0,...,c_i}, define

t_0=max(0, max_R(q_R−Σ_{i:(T_i∪U_i)∩R=∅} t_i)).

Discard tuples with t_0>c_0, and set

D_j=min_t (w_0 t_0+Σ_i w_i t_i).

This is the exact integer minimum. Indeed every feasible vector has core coordinate at least the displayed t_0; since w_0≥0, lowering that coordinate to t_0 cannot increase cost. Conversely every retained tuple with core t_0 satisfies all constraints. The implementation exhausts the Cartesian product and uses Fraction for every objective and final comparison. It neither relies on floating-point LP tolerances nor sums incompatible separate minima.

Write A_h,B_h,C_h for the original conditional greedy endpoint/start/all-pair bookkeeping bounds. Removing the actual beyond-center-overlap pairs yields

Pr(greedy failure) ≤ U_avoid:=Σ_h min(A_h,B_h,C_h−D_h),

where D_h=D_j at lock x_j and zero otherwise. At each h only the corresponding C_h is reduced. A pair possibly meeting several locks does not cause an invalid duplicate subtraction: those are separate position-indexed bookkeeping sums with their own weights. The original event argument supplies the single-intersection greedy witness and weights; the present refinement supplies only a stronger valid deletion.

## Real-input and coverage boundary

The 195 profile list is read from ../pilot/baseline.json, generated by ../pilot/pilot.py. Its structural domain assumes the minimum-vertex non-Property-B counterexample reduction, padding to exactly 65 edges, and the declared 0/1/2/3-lock selection. This refinement does not independently certify that entire reduction. It does cover every listed profile, retains the exact given layouts, and checks U_avoid≤U_original in every case.

The complete v=39 three-lock class has 40 profiles (all nondecreasing degree triples from 8,...,11, both triple-block patterns). All 40 are now strict. To connect that class to a real pair-covering H with 65 edges, let L be vertices of degree≤11, r=|L|. Degree sum≤390 gives r≥20. On L join pairs with codegree≥2; its doubled edge count is at most 22r−390. The independent-set bound is r²/(r+2e)≥r²/(23r−390)>2 for 20≤r≤39, as checked in the pilot. Thus three pairwise codegree-one low vertices exist, and both possible block patterns are covered. This closes that stated v=39 class conditional only on the common original greedy/reduction ingredients, not all v or all M=65 hypergraphs.

No Lean formalization or new full m(6)≥66 proof is claimed.
