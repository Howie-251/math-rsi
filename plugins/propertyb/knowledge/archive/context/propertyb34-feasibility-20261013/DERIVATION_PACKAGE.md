## Invariant Object

固定实际超图H，选取具有已证明结构的锁点及其位置后，控制随机贪心染色失败概率：

`Pr(Fail) ≤ U(H) = Σ_k min(A_k, B_k, C_k − D_k)`。

A/B为实际边的端点事件界，C为临界有序边对界，D来自已证明的真实坏对。结构预算是`Σd=170`和`Σ_{y≠x}(λ(x,y)−1)=4d(x)−(v−1)`。局部数值小于1只有与实际H的选点、迹恢复和扣除连接后，才能返回染色。

## Assumptions

下述19–25点诊断假设H有恰34条不同五元边且覆盖全部点对。这些是最小反例路线的内部条件，不能加到最终原命题上。上一轮已给至多18点的严格交叠纸面论证以及至少26点的整数度数排除，参见[小点数入口](../propertyb-lessons-20261013/SMALL_VERTEX_34_NOTE.md)。

单锁、双锁、三锁计算复用旧证明中的通用条件排列公式与link计数。新结构为直接组合推导；新的有理数值通过Python Fraction计算。低点数保留行、主代理五低锁保留行另与独立标号注入公式核对。高点数代理的首轮表尚未做独立第二实现或内核核验。

## Notation

v为顶点数，δ为最小度，d(x)为度，λ(x,y)为共度。“单位”表示λ=1；非单位图以λ≥2为邻接。迹是实际边与选定锁点集的交集，含重数。文中的局部型数、位置窗口数是概率诊断范围，不是枚举原超图的数量。

## Derivation Strategy

先用度数和共度超额获得真实选点，再将这些输入送入已有精确概率引擎。通过的分支保留完整见证；未过的分支记录失败类型、位置范围和需要的新信息。只对小而有用的域计算，避免把未知选点或巨大松弛域提前搬入Lean。

## Derivation Map

1. 19点：最小度分流 → 八度点数量/共度分流 → 单锁、双锁及9种三锁型 → 全部严格界。
2. 20点：单位伙伴存在性 → 14个度数组合 → 8个严格、6个仍需加强。
3. 21点：五度点的五个四元link块 → 恢复旧三锁或强共度双锁 → 高共度支严格，旧三锁仍有数值缺口。
4. 24点无六度：内部非单位图的边数 → 五个单位七度点或强共度八度点对 → 一支严格，另一支剩3个基础型。
5. 25点：至少五低点加七度点独立集 → 普适九个单位混合锁 → 完整迹预算，概率界待研究。

## Main Derivation

### 1. 19点：从“无锁界失败”推进到完整纸面候选

点对覆盖与总度给δ=5、6、7、8。前三种各锁最小度点在位置10，上界分别为23003/24310、896/935、23589/24310，均严格小于1。

δ=8时，记八度点数为r。若r≤2，其余点至少九度，基线总度171−r，只剩r−1的总超额，所以其余点只能九或十度。每个八度点至少有4个单位伙伴，其他八度点最多1个，故能选到九或十度的单位伙伴。相应两份双锁界均严格。

若r≥3，有八度点对共度≥3就用λ=3,…,8的双锁，六份界全严格；否则任选三个八度点，三对共度均为1或2。重标后三对只有111、112、122、222，三点共同重数依次为0–1、0–1、0–1、0–2，共9型，全部有严格界。其中最大的三锁上界为707/715。

这是覆盖实际输入的有限分流，不是“找到了几个好例子”。[完整分流、计数与数值表](low-vertices/REPORT.md)及[独立结构核对](independent/REPORT.md)已保存。尚需指定数学义务的审阅及实际H的Lean连接，不能把它记成新形式定理。

### 2. 20点：有明确的六个残余输入

最小度d的单位伙伴集至少有38−4d点，总超额170−20d保证存在伙伴度数不超过d+floor((170−20d)/(38−4d))。因此14个双锁输入完整覆盖这一选点规则。

本轮纯/总link配额下8个输入严格，剩(6,9)、(7,8)、(7,9)、(7,10)、(8,8)、(8,9)。对这6行，全部190个递增位置都不能使当前界小于1；反向顺序由排列反转覆盖。最近的一行是1877/1870，最差为609721/583440。

下一步应引入第三锁、更多真实坏对关联，或证明能避开部分残余输入。重复相同双锁界的位置搜索已经没有增量；其他数学估计仍开放。

### 3. 21点：能修复选点，但选点本身还不够

当唯一五度点x之外的20点都至少八度，x的link把它们分成五个四元块，总度超额只有5。本轮证明至少有以下一项：

- (5,8,8)全单位且三点共同重数0；
- 两个九度点共度≥5；
- 九度与十度点共度≥8。

证明利用块容量与八度点共度超额12，完整推导见[独立报告§1](independent/REPORT.md)。Grok/Gemini本轮分工中，Gemini具体核对了这条分流。

新增强共度双锁的7行全部严格，而且只需不足1秒的公式诊断。可是旧(5,8,8)型在18个中央布局中最佳仍为44215/43758>1。因此新分流有价值，整条五度支尚未闭合；该失败也不是所有位置或所有加强界的不可能性证明。

另外，本轮恢复了若干新增6/7/8度分支的实际单位双锁存在性，但对应(6,8)、(7,8)、(8,8)在9个中央布局的现有界都大于1。这里需要新增概率信息，不能只做选点。

### 4. 24点无六度：压成严格双锁，或五个七度单位锁

度序只能为7^23,9或7^22,8^2。第一种中，23个七度点内部非单位图至多51边，独立数至少529/125>4，故有五个单位七度点。

第二种中，若两个八度点共度≤4，则22个七度点内部非单位图至多49边，独立数至少121/30>4；否则直接有八度点对共度≥5。这给一个完整结构二分。

强共度双锁λ=5,…,8的四份界全严格。五个单位七度锁的大迹只有五种基本型，本轮有限窗口已使单三元、两个相交三元型严格；无大迹、单四元、单五元尚未过。

因此有一个具体小问题：能否总选到五个单位七度点，使某实际边恰在其中留下三点迹？若不能，也可以针对阻止重选的实际结构或剩余三型加强。该选择命题目前未证；有相应反例时就换路线。详见[高点数报告](high-vertices/REPORT.md)。

### 5. 25点：旧低点不足可由混合锁补回，仍需新界

六度点数r≥5，七度点数t≥30−2r。所有六度点与其余各点共度1；七度点非单位图最大度≤4，所以能选至少ceil(t/5)个两两单位的七度点。

对r=5、6、7、8，所需七度点数分别为4、3、2、1，这一保证足够；r≥9时直接取九个低点。因此任意25点输入都能选出九个单位锁，度序为6^q7^(9−q)，5≤q≤9。这是比“低点数从十降到五”更积极的结构结论。

恰五低且九锁中没有四/五元大迹时，三元块数T满足5≤T≤12，每低点至少参与2个三元块，每高点至少1个；单元总重数3T−14，空迹重数12−T。一般q时对应单元总数3T−9−q、空迹7+q−T。这些都是从真实输入推出的必要预算，不表示每个局部型都能扩成实际H。

Grok核对恰五低的选择引理，并建议先试便宜的五低锁。主代理实际检查32个标签分解与9个连续位置窗口：完整五元迹一型界4172/4199<1，另外四型在该窗口仍>1。这表明只保留五低不普遍够强，混合高点信息有实际研究价值。

对九锁，设e_j为j元多点迹数。恰五低时还满足e3+3e4+6e5≤12、3e3+8e4+15e5≥14。Grok提出的41个整数类型向量及9个边数饱和值已独立复算；它们不是41个超图或41个同构型。下一步可先检验少数边界构型，再决定完整分类的成本，不直接铺开庞大目录。

## Remarks and Interpretation

这轮先导提供了希望的实际依据：19点产生完整候选；24/25点的“选点不够”至少部分转化为强而明确的新结构。此前成功积累的引擎确实能复用，有些看似复杂的强共度分支反而几秒内就得到严格见证。

与此同时，20点六行、21点旧三锁和24点三个型的失败说明：继续提高下界需要保留更多真实关联，不能只把表中的33改为34。22/23点本轮尚未全面重算，24点有六度的其他分支也未全覆盖。

本轮文献只作定向核查：[2024原论文](https://arxiv.org/html/2403.05674v3)明确讨论了多锁联合重数的困难，与本项目继续加强结构的方向一致。另读取了[2026综述官方页面](https://link.springer.com/chapter/10.1007/978-3-032-18810-6_9)的摘要及书目，未读订阅全文。未在本轮检索找到34边不可染构造或m(5)≥35原始证明，不把这当穷尽结论。

## Boundaries and Non-Claims

本报告没有给出完整m(5)≥35证明，没有证明其为假，也没有给成功概率或完成日期。Python算术、模型意见、纸面结构和Lean内核验收分开记录。原T32/T33证明保持完成，当前更高下界方向只有先导结果。

## Open Risks

最重要的未知是：残余结构能否保证足够的概率下降，以及需要多大的完整局部域。即便少数边界型通过，也不能直接断言所有型通过；若大量新混合型仍失败，应加强实际结构/事件估计，而不是无上限增加锁数和计算。

建议下一阶段先将19点候选接成实际Lean分支，同时并行攻20点残余和24/25的新结构。前者验证复用成本，后者判断全局数学障碍能否继续缩小；不按“已处理几个点数”机械估算整个问题完成比例。
