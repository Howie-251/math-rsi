# T34 的 24–25 点：有界结构可行性检查

2026-10-13。目标是判断下一下界 m(5)≥35 是否有具体可攻入口，不启动完整研究 Goal。下列对象均为恰34条边、覆盖全部点对的有限简单五元超图 H。纸面结构引理的状态为 COHERENT AS STATED；局部概率计算是精确诊断，尚未 Lean 形式化，也没有给出完整 T34 证明。

本轮读取下一下界指南及 T33 证明包第4、10、11节，使用 ARIS formula-derivation 的假设—不变量—具体义务组织方式。核心不变量是共度超额 λ(x,y)−1 及实际锁点迹的点对预算。没有运行 Lean、没有整图搜索、没有修改旧证明。

## 1. 共同记号与一个便宜的选择引理

设 λ(x,y) 为共度，d(x) 为度。点对覆盖保证 λ≥1；五元边给

    Σ_{y≠x}(λ(x,y)−1) = 4d(x)−(v−1).

在指定顶点集上，以 λ≥2 为边定义简单“非单位共度图” G。其边数不超过相应超额权重和的一半。G 的独立集恰为两两单位共度点集。

若 G 有 n 点、e 边，则 α(G)≥n²/(n+2e)：随机排序，取在闭邻域中最先出现的顶点，它们构成独立集，期望为 Σ1/(deg+1)；Cauchy–Schwarz 给此下界。另有最大度 Δ 时的贪心下界 α≥ceil(n/(Δ+1))。这些是明确的存在性证明，不依赖图搜索。

## 2. 24 点没有六度点：严格压成两个输入入口

总度170，全部度至少7，只可能有：

- 23个七度点、一个九度点；
- 22个七度点、两个八度点。

七、八、九度点的共度超额分别为5、9、13。

### 2.1 度序 7^23,9 必有五个单位七度点

令 S 为23个七度点，z 为九度点。z 对 S 的超额总和为13；S 的总超额为23×5=115。因此 S 内的超额总权为

    (115−13)/2 = 51.

非单位图至多51边，所以

    α(G[S]) ≥ 23²/(23+2×51) = 529/125 > 4.

故至少有五个彼此单位共度的七度点。

### 2.2 度序 7^22,8^2 的二分

八度点记 a,b，h=λ(a,b)−1，故0≤h≤7。它们对七度点集 S 的合计超额为18−2h，S 内超额总权为

    (22×5−(18−2h))/2 = 46+h.

若 λ(a,b)≤4，则 h≤3，非单位图至多49边，故

    α(G[S]) ≥ 22²/(22+2×49) = 121/30 > 4.

因此实际超图必满足下列至少一项：

1. 有五个彼此单位共度的七度点；
2. 两个八度点共度 λ≥5。

这是普适结构二分，不是从少量候选归纳的猜想。

### 2.3 第二入口的四份局部概率表已经严格

两个八度点的实际双锁计数唯一确定：

用项目既有精确条件排列公式，位置 (1,14)，不需要任何坏对扣除，得到：

### 2.4 第一入口只有五种基本大迹型，已经两型严格

五个单位七度锁点的多点迹分解 K5 的全部点对。大小≥3的迹两两交至多一点，故大迹型只有：无大迹、一个三元、两个交一点三元、一个四元、一个五元。三个不同三元块无法都装在五点上并保持线性；四元或五元块也排斥其他大迹。这是可以直接书写的分类覆盖证明。

## 3. 25 点：九个单位混合锁点其实始终可以保证

设六度点数为 r。总度170给 r≥5；每个六度点的超额为零，所以它与所有点均为单位共度。令 t 为七度点数；其余25−r−t个点至少八度，于是

    170 ≥ 6r+7t+8(25−r−t),  即 t≥30−2r.

七度点共度超额为4，故其非单位图最大度≤4，存在至少 ceil(t/5) 个彼此单位的七度点；这些点自动与全部六度点单位。

若 r=5、6、7、8，分别需要4、3、2、1个七度点，以上保证分别至少4、4、4、3个，足够。若 r≥9，直接取九个六度点。因此对每个25点实际输入，都能选九个两两单位共度的锁点，度数只需考虑

    6^q 7^(9−q), q=5,6,7,8,9.

这比“只有五低点，不能用旧八锁”更具体：可以改用含七度点的九锁，但新的概率界及完整局部域仍需研究。

### 3.1 恰五低的九锁预算

此时其余20点恰全为七度。选择五低和四高，九锁总度58。大迹若含四元或五元块，应先单独处理，或投影到更少锁点诊断。

若没有四、五元迹，只剩二元和三元块。设三元块数为 T，每个锁点 i 在三元、二元块中的次数为 t_i、b_i。单位共度覆盖其余八锁，故

    2t_i+b_i=8,   t_i+b_i≤d_i.

低点有 t_i≥2，高点有 t_i≥1；全部 t_i≤4。因此

    5≤T≤12.

二元块数由点对总量给出36−3T；多点块对锁点的总关联数为72−3T。继而实际计数必须满足

    单元迹总重数 = 58−(72−3T)=3T−14,
    空迹重数 = 34−[(36−3T)+T+(3T−14)]=12−T.

所以首个局部诊断域可以具体设为：九点线性三元族，五个指定低点的三元度至少2，四个高点至少1，总块数5至12，再用实际度恢复二元、单元及空迹。这既不是任意2^84个三元子集，也不需要枚举整张超图。

更一般地，九锁度序6^q7^(9−q)在没有大于三迹时满足

    T≥ceil((9+q)/3), 单元总数=3T−9−q, 空迹数=7+q−T.

每个低点三元度至少2、每个高点至少1。这些是必要且明确的完整局部域约束，不表示其中每个族都能延拓成真实 H。

### 3.2 恰五低时，第四个与第五个单位高点的二分

在20个七度点的非单位图中，最大度≤4。若独立数恰为4，则该图只能为四个不交 K5：若存在度≤3的顶点，先取它，再从至少16个剩点贪心得四点，已有五点；若每点度4而某个连通分量不是K5，则存在有共同邻居的两个非邻接点，它们闭邻域的并至多9点，剩至少11点可贪心得三点，同样得到五点。

因此可以再分：至少五个单位七度点（可选择十个混合单位锁），或高点非单位图恰为4K5。在后一种情况，每个七度点的四份超额全部由四个邻居消耗，所以团内共度恰2、团间恰1，全部低高共度1。这给一个强结构特例，不是矛盾：不能因为图形简单就判它不能来自超图。

建议先做九锁的受约束小域诊断，十锁及4K5特例是备用路线，不立即把更大的分类搬入 Lean。

## 4. 对可行性的实际判断

24点无六度的新入口已经从“两种陌生近正则序列”压成一份可证明的二分；高共度双锁的四表全严格，另一侧五单位七锁只剩三种基本类型尚未被本次便宜诊断处理。这是值得继续的具体理由。

25点也有普适九锁结构和很紧的迹预算，可优先研究真实混合低/高锁配额。当前没有证据表明九锁所有型都会严格，也没有证明下一下界；可行性来自这些明确的新结构，不来自样本或模型投票。
