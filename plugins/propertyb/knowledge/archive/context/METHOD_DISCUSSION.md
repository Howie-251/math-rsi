# 多锁定方法的首轮外部讨论

讨论范围：任务书公式、v=22/23候选link修正及后续核验义务。原始回答见 [Grok首轮](reviews/grok_r1.md)，实际型号为 grok-4.7-build、effort=xhigh。本文整理的是可继续验证的推理，不是主定理验收。

## 自由位置的公共点权重

对一条固定边，自由位置k成为末点时，需要选择该边的哪个自由顶点落在k，所以单边项有r_T/N。对一个已经固定且恰交于一个自由点的有序边对，共同顶点已由这对边决定，其落在k的概率是1/N；不能再乘r_T r_U。

Grok给出一个小排列检查：N=5、k左右各2个位置，A={u,w}、B={u,z}。120个排列中有8个满足u在k、w在前、z在后，所以固定有序边对的概率是1/15；再乘r_T r_U会多算4倍。这是通式归一化的局部检查，不是任意多锁定公式的完整独立验收。

## link扣除的具体核验线索

Grok按任务书类型手算得到：

- v=22双锁、N=20：纯类型无序边对的两个方向合计权重42/4199；混合类型只有一个方向存活，权重3/323=39/4199。因此七度中心的q≥3若已建立，对C项的候选扣除为9/323。
- v=23双锁：两个中心的最轻混合方向权重分别为11/1292和22/2261。其报告的中心A/B/C比较表明原始min由C控制，但全位置粗界仍需独立复现。
- v=23三锁：中间七度点没有零权重无序类型对，q≥2对应候选扣除6/323。最后一个七度点的(xz,yz)类型对两个方向均为零；由于这两类边各只有一条，最多消耗一个q名额，余下至少一个相交对带来3/323。
- 两个中心的坏边对不能重复：若同一对不同边同时含两个锁点，会与该点对共度为1矛盾。

Grok还手算了若干中心A/B/C数值，见原始回答。接受这些线索的条件是：本地重新推导方向、逐项算术、q下界以及全部锁点结构前提；不能以“reviewer已说成立”替代这一步。
