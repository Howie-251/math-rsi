# 从35走向36–40：第一轮数学诊断

2026-10-15。**36值得继续攻，但它已经需要新结构；40不是把35的表重复五次。** 本轮得到一个新的17点完整纸面分流、18点四个明确残型，以及几个可以跨参数复用的选点和计数引理。也构造出一个真实超图，证明旧九单位锁选点在下一档确实失效。没有发现原目标的不可染反例，也没有证明36–40的完整结论。

35的Lean Goal已按用户明确指令暂停；原下界33、34的成果保持不变。35保留完整纸面候选、局部形式证明和准确的剩余义务。暂停入口为 [检查点](../propertyb34/round02/PAUSE_CHECKPOINT_20261015.md)。本轮没有运行Lean、启动新Goal或继续那条形式化队列。

## Target / 目标与状态

对 L=36,…,40，研究原命题：任意有限简单五元超图，若边数至多M=L−1，就能二染色，使每条边均有两种颜色。目标是判断这五档的数学障碍与有效推进方法，不在一次诊断中承诺完成五个下界。

**COHERENT AS STATED，限本页明确证明的结构、计数与精确公式诊断。** 所有新全局目标仍开放。这里的M对应边数上限，而L对应m(5)下界，不混用“35边”和“下界35”。

## Invariant Object / 始终研究同一个实际超图

最小点数反例必须覆盖每对顶点。对这样一个实际H，统一保留

\[
\sum_x d(x)=5M,\quad
w(x,y)=\lambda(x,y)-1\ge0,\quad
\sum_{y\ne x}w(x,y)=4d(x)-(v-1),
\]

\[
\sum_{\{x,y\}}w(x,y)=10M-\binom v2.
\]

局部迹必须来自这同一批边，跨布局的坏边对也必须是同一批真实变量。最终仍需证明某个真实随机染色方案的失败概率严格小于1；某个孤立局部数值好看不能替代这个连接。

## Assumptions / 约化与覆盖范围

合并不共边顶点保留五元性与不可染性，所以可以归约到点对覆盖。每个点至少有 ceil((v−1)/4) 条入射边，故

\[
v\left\lceil\frac{v-1}{4}\right\rceil\le5M.
\]

本轮还直接证明：**至多16点、至多39条五元边的超图均可二染色。** 15/16点39边的平衡并集界恰为1，但390次边内点对出现迫使两边共享至少两点；把其至多8点的并集放在同一色类，产生正交叠并使界严格。更小点数直接用平衡染色计数。完整证明与组合分数见 [小点数报告](small/REPORT.md)。

因此有以下原始覆盖窗口：

|目标下界L|要处理的边数M|初始剩余点数|本轮发现的变化|
|---|---:|---|---|
|36|35|17–25|17点纸面分流已闭合；18点剩四类双锁输入；25点必须容纳无六度点的新情形|
|37|36|17–25|20点九正则、22点最小度8新分支出现；25点匹配锁保证从9降至7|
|38|37|17–26|新增26点；23点可有22个八度点和1个九度点|
|39|38|17–27|新增27点；19点十正则、21点近九正则分支出现|
|40|39|17–27|24点允许最小度8；25点旧低度匹配锁方法只统一保证2点|

窗口是必要覆盖范围，不意味着范围内每个点数都存在反例。对v≥17可以补互异五元边至M条，保持不可染性和点对覆盖，因此研究恰M条边足够；这一约化**不需要先假设35的候选已经正确**。

## Derivation Map / 本轮怎么诊断

1. 先按新M重新推总度、整数最小度和点数窗口。
2. 对实际选点方法做条件差分，并主动构造其错误推广的反例。
3. 用既有精确概率公式重算少量有理由选取的旧证书，定位失效项。
4. 将共同约束提炼成参数化引理，以减少后续逐型扩展。
5. 按真实尚未解决的数学义务确定36的下一步；对38–40只保留具体入口，不启动大表。

## Main Derivation / 四组实质结果

### 一、36的小点数现在有明确推进点

17点、35边、点对覆盖时最小度δ=4,…,10。δ4至9各有一个严格单锁界；δ10时十度点至少12个，任取其中两个，全部共度λ=1,…,10均有严格双锁界。这是覆盖整个17点内部输入的纸面分流，不是样例搜索。所有逐位置A/B/C、配额、精确分数和第二公式复算均保存于 [small/](small/REPORT.md)。尚未新增Lean证明。

18点的δ5、6、7单锁界也严格。δ8或9时，选两个度数最小的点，只需度数(8,8)、(8,9)、(9,9)。完整检查其共度和锁位置后，当前双锁方法恰剩：

|两点度数|共度|当前最佳上界|
|---|---:|---:|
|(8,8)|1|6436/6435|
|(8,8)|2|1|
|(8,9)|2|79/78|
|(9,9)|2|40/39|

这里失败的是指定的概率估计，没有构造不可染超图。它把下一步压成四个具体义务：加第三锁、增强活跃坏对扣除，或证明相应残型无法在同一H中同时出现。相同双锁位置搜索无需重做。

17/18的旧“一次正交叠”修补无法直接迁移：35边时即使取两边最大可能单色事件交叠，仍为35/34−2/221=451/442>1。因此确实需要新的累计重叠或锁点结构。

### 二、25点的旧入口有真实反例，但有新的匹配入口

在F₅²上取30条仿射直线，再加五条平移抛物线 y=x²+c。它们是35条不同五元边，每点度7。点对在同一抛物线上时共度2，否则共度1；非单位图恰为五个互不相交的K₅，故最大两两单位点集只有5点。

这严格否定了将“九个单位锁”无条件推广到35边25点的做法。该实例**有合法染色**，已保存 [完整边集、度数、共度和染色见证](high-structure/AFFINE_PLANE_OBSTRUCTION.json)，所以不是36目标的反例。

可以替换的真实选点引理是：**35边25点必有九个度数6/7的锁点，内部非单位点对只是共度2的匹配。** 证明令r、t分别为六/七度点数，则2r+t≥25；六度点与所有点单位，七度冲突图最大权度4。将七度点按最小能量分为三类，每类内部权度至多1，再把所有六度点加入三类，总大小至少25+r，必有一类至少9点。

这给出了应当研究的新局部域。匹配共度带来哪些额外真实迹、能否在新M下获得严格界，仍是数学义务。完整推导及更大点数见 [高点数结构报告](high-structure/REPORT.md)。

### 三、旧证书有余量，也有明确的数值失效

37个有理由选取的旧25点证书，保持非空迹和布局不变，仅增加空迹数后，在M=35,…,39仍严格的数量依次为 **22、12、6、4、0**。这是分层样本，不是整体成功率。

旧最紧证书从12869/12870增加到13199/12870；但同一无色族换用另一份已经保存的布局，M=35时对全部126种低点标记仍有统一上界6406/6435<1。说明不能把一个紧证书的失败当成整个方法失败。

与此同时，旧q5族56、86的空迹数从−1变0，各有126种低点标记重新进入库存可行域。即使旧表每行都通过，新覆盖仍不能直接沿用旧目录。精确数值和原始固定布局见 [数值报告](numeric/REPORT.md)。

### 四、可以减少重复工作的通用引理

**连续锁的参数分离。** 固定连续锁位置、同一个多点迹族、度数高/低两档及低度点总数q。令xᵢ∈{0,1}表示第i点是否低度。对当前总/纯link扣除方法，真正的逐位置最小值之和满足

\[
U(M,x)=F(M)+a_0+\sum_i a_i x_i,
\]

其中aᵢ不依赖M。每个锁中心只依赖自己的高低两态；所有边数增加的代价都在自由位置的F(M)，它是明确的分段二次函数。单个布局对全部q低标记的最坏界，可通过取最大的q个系数得到，不必逐颜色重算整个概率表。连续性不能删除；已有 [合法的非连续反例](numeric/NONCONTIGUOUS_AFFINE_COUNTEREXAMPLE.json)。额外自由中心扣除或跨中心优化不自动属于该定理。

**最小权子集交换。** h个同度候选点的内部总权度至多D，取内部权W最小的k点集；对每个选中点的内部权度aₓ，有

\[
(h-k-1)a_x+2W\le(k-1)D.
\]

它将新近正则分支压成稀疏四锁或六锁。例如23点37边最小度8时，可得六个八度锁，内部每点超额≤2、总权≤6。完整一般证明和其他实例见 [中点数报告](middle/REPORT.md)。

**共同槽碰撞。** q个高点在每个低标签i的至多sᵢ条实际单迹边中出现。若q=as+b、0≤b<s，令β(q,s)=s·C(a,2)+ab，则

\[
\sum_i\beta(q,s_i)\le\sum_{\{x,y\}\subseteq Q}\lambda(x,y).
\]

它用同一批实际边控制所有局部标签，推广已有三高两槽矛盾。

**真实投影的迹矩。** 在N个锁上删除h点，实际q点迹数满足

\[
\sum_{|D|=h}t_q(S\setminus D)
=\sum_{j=0}^{5}\binom jq\binom{N-j}{h-j+q}t_j(S).
\]

这保留了大迹投影成小迹的贡献，可用来排除“每个投影都处于最坏残型”。后两式的完整证明见高点数报告§7。它们是工具，不自动排除尚未识别的残型。

## 38–40：有希望的入口与真正的门槛

新增26/27点并不必然最难。37边26点只有三单位总度盈余，度谱只有三种；38边27点恰为26个七度点和1个八度点。后一情形的七度冲突图至多23条边，独立集界给至少10个两两单位的七度点；任意两边交至多3，七度点的link只有两种重数缺陷。它们给出了很强的研究入口。

更不利的是原24/25点分支：随M上升，低度点可能大幅减少。39边24点允许所有点度≥8，旧六/七度选点方法可能完全没有输入。因此本轮支持“值得研究36，并有通向更高参数的可复用工具”，**不支持预测40可沿旧方法必然达到**。

## 下一步建议

先围绕36形成三个数学小任务：18点四个残型；25点九匹配锁（优先全七度）；22/23点低度池缩小后的混合八度选点。19–21的新高最小度分支也须保留在覆盖图中，不能只处理最显眼的两个点数。

对每条线先写实际输入到概率界的短原型，并明确未过的项。优先尝试共同迹矩、碰撞和共享坏对联合约束；如果松弛域普遍不严格，先改数学表达，不提前生成巨大目录。新的自然语言证明闭合后，再单独决定哪些环节值得恢复Lean。
