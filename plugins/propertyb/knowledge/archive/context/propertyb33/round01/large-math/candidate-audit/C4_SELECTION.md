# 六度中心的 C4 选点：新增结构结论与边界

2026-10-08。受委派的有界纯数学检查；`review_independence: same-family`，`acceptance_status: provisional`。只读取现有局部槽记录，没有重跑概率、调用 MCP、修改脚本或 Lean。

## 1. 已证：每个指定顶点都在 C4 上

**引理。** 设 G 是11顶点的有限简单图，最小度至少4。则对任意指定顶点 v，存在包含 v 的四边形；不要求该四边形诱导。

**证明。** 若 v 不在任何 C4 上，那么对每个 w≠v，共同邻居数 `c(v,w)=|N(v)∩N(w)|` 至多1。否则两个不同共同邻居与 v,w 形成四个不同顶点的 C4。另一方面，按中间点计数长度2路径，

`Σ_{w≠v} c(v,w) = Σ_{u∈N(v)}(d(u)−1) ≥ 4·3 = 12`。

左边却至多10，矛盾。这里允许三角形和四边形的弦；它们不影响计数。证毕。

更一般地，同一证明给出：若 `d(v)(δ−1)>n−1`，则 v 属于 C4。对任意大小 m≥11、非单位共度图最大度≤6的单位共度池，`δ≥m−7`，有 `(m−7)(m−8)>m−1`，所以也可直接使用整个池，无需先选11点。

## 2. 无需唯一坏对，即可排除最坏槽 (19,28)

固定23点五元点对覆盖超图中的六度点 x。令 U 是与 x 共度1的七度点集合，当前分支有 `|U|≥11`。U 的单位共度图最小度至少 `|U|−7`。

先固定任意实际坏 link 对，对应两条不同的含 x 边 E,F，满足 `|E∩F|≥2`。定义两 arm

`A=U∩E, B=U∩F`。

因为 U 内每点与 x 共度1，所以 `A∩B=∅`；E∩F 中除 x 以外的点均不在 U。五元性给出 `|A|≤3, |B|≤3`，因此 `|A∪B|≤6<|U|`。

选定 `v∈U\(A∪B)`。在一个包含 v 的11点子池中使用上节引理，得到包含 v 的单位 C4，记其四点集合为 Q。于是 Q 不包含于 A∪B。

五锁取 x 和 Q。若这一个已固定的实际坏边对落入 `(19,28)` 槽，则其两条边在四个七度锁上的迹分别为两个不交的二元集，合起来恰为全部 Q。这将迫使 `Q⊆A∪B`，与 v 的选择矛盾。

因此，可对任意先固定的实际坏边对选择 C4，使它不能落入 group68 的 `(19,28)` 槽。这个结论不需要“唯一坏对”，也不需要预设两对角共度恰2；后者只在识别原 group68 表行时使用。选点依赖实际超图和实际坏对，但在随机排列前已固定，量词顺序与既有条件排列接口相容。

## 3. 原“唯一坏对”计数的核查

六度点的六条四元 link 覆盖其余22点，总 incidence 为24。因此逐点超额总数为2。

若恰一个坏无序 link 对，则任何点不可能属于三条 link，否则会形成至少三个不同坏对。所有重数2点都只能位于那个唯一坏对中；超额2说明恰有两个这种点。因此两 link 交集大小2，对应原边交集大小3。两 arm 在 U 内各至多2。

若原槽 `(19,28)` 发生，则四锁集合只能是两 arm 的并，且两 arm 都恰有2点。这至多给一个候选四点集。

原路径计数思路也成立，但上界须区分陈述：

- 若只是说“只有一个四点集含 C4”，一般上界是 `Σ_v C(d(v),2)≤55+6=61`。该唯一四点集可以诱导 K4，六个点对都可有两个共同邻居。所有其他点对至多一个共同邻居；此四点集内的点对也不能有三个共同邻居，否则产生别的 C4 四点集。
- 若进一步知道唯一例外四点集诱导 K2,2，则只有两个对角点对可有两个共同邻居，故更强的 `55+2=57` 正确。原 group68 的两个同 arm 对共度2，正好保证单位图上的这一个集合诱导 K2,2。

最小度4给出下界66，所以61或57都足够矛盾。第1节“指定顶点必在 C4 上”的证明更短，且排除了唯一坏对假设。

## 4. 对其他槽的部分选点后果

给定已固定坏对的 arm A,B：

- 若 A∪B 非空，可以指定其中一点，选包含该点的 C4。于是该坏对不能同时为两个纯单锁型，排除该次选点中的 group58 或 group68 的 `(16,16)`。
- 指定 arm 外点则排除 `(19,28)`，如第2节。

这两种选点结论不能未经证明就合并为“存在一个 C4 同时满足两者”。指定顶点引理只控制一个顶点；它没有证明任意两点都同属某个 C4，也没有证明存在同时穿过 arm 与其外部的 C4。本次没有将它误用为双指定点结论。

## 5. 仅凭当前压缩条件，不能消灭其余全部槽

下面是压缩图数据的反例，**不是23点超图的反例，也不声称能扩展为完整超图**。它说明“11点、最小度4、六个 x 边颜色类各≤4、唯一坏对的两色各≤2”这些条件本身不足以保证存在全通过的选点。

取单位共度图 `G=K_{4,7}`，两部为 P、R。所有部内 pair 赋共度2，跨部 pair 赋共度1。非单位邻居数在 P 为3，在 R 为6，均符合七度点超额预算上界6。每个 C4 恰取 P 中2点、R 中2点。

把 P 的4点都赋颜色 C；把 R 划为颜色 D 的4点和颜色 E 的3点。把已固定实际坏对对应的两种颜色称 A,B，让它们在 U 中均为空。还允许第六种颜色为空。颜色容量上界全部成立，A、B也符合唯一坏对时的≤2约束。

每个 C4 都出现以下两种情况之一：

- R 内选到同色两点：四锁的 x 边颜色型为2+2，单位图是无弦 C4，实际坏对在四锁上均为空，即 group68 的纯/纯 `(16,16)` 模式。
- R 内选到异色两点：颜色型为2+1+1，单位图仍是无弦 C4，实际坏对仍纯/纯，即 group58 的 `(16,16)` 模式。

要匹配 group58/68 的其余局部迹，可把同部 pair 的第二次出现以及剩余跨部 pair 在局部数据中全部放入二元型；这与这两类保存剖面一致。这里未主张这些局部选择能在全部超图边之间同时实现。

即使要求至少一条 arm 与 U 相交，压缩反例仍存在：保持 P 的4点为 C，令 R 的颜色为 D 的3点、E 的3点、B 的1点，A仍为空。含 B 的 C4 落入 group58 的纯/单模式，不含 B 的 C4 落入上述纯/纯模式；仍无法靠这些条件保证一个全部通过的槽。

因此，后续若要一并排除剩余7槽，需要新的真实超图条件、对多个坏 link 对同时取扣除、更多锁点的证书，或更强的全局共度/边迹关系。不能仅把本节已有度数和颜色类上界再表述为一个尚未证明的“总能选好 C4”结论。
