## Target / Assumptions

## Invariant Object / Notation

S是六度顶点组成的选定集合。对e∈E，截面B=e∩S。大小≥2的截面组成多点块族D；每个点对共度恰1时，D是K_|S|的团分解。每个多点块对应唯一全局边。多点块唯一决定精确类型：

\[
\ell_B=1,\qquad \ell_{\{x\}}=6-|\{B\in D:x\in B\}|,
\qquad\ell_\varnothing=33-|D|-\sum_x\ell_{\{x\}}.
\]

概率不变量仍为现有真实条件排列的 \(U=\sum_k\min(A_k,B_k,C_k)\)。本25点步骤没有link扣除。

## Derivation Map

总度165 → 至少10个六度点 → 共度刚性1 → 任选十点 → 有大块则六锁旧型成功；无大块则十点至少10三元块 → 平均选择八点至少5三元块 → 14个必要局部型 → 标签/位置与真实类型绑定 → 每型U<1 → 合法染色。

## 1. 十个六度点和点对刚性

每点度至少ceil(24/4)=6。若六度点r个，165≥6r+7(25−r)=175−r，所以r≥10。

对六度点x，\(\sum_{y\ne x}\lambda(x,y)=24\)，恰有24个非负且至少1的求和项。因此所有y≠x都有λ(x,y)=1。任选十个六度点为W，其多点截面形成块大小2..5的团分解。

## 2. 有4元或5元块时归入已通过六锁型

若某条全局边在W中的截面B有至少4点，选择包含B（当|B|=5）或B中四点的六点子集S⊆W。该截面在S中仍有至少4点。K6团分解解析分类（旧proofs/STRUCTURE_24_25.md）将其归入K6-7、K6-8、K6-9。标签按该代表的同构选取，位置为10..15。

本轮33边精确界依次为8373/8398、4189/4199、3979/4199，均严格小于1。这里使用新空型重数，不使用旧32边分数。见EXACT_DIAGNOSTICS.json每一行和独立注入核对。

## 3. 无大块时必能选出至少五个三元块的八点截面

现在W的块只可能为二元或三元块。对x∈W，令t_x为含x的三元块数，b_x为含x的二元块数。点对覆盖与唯一性给出

\[
2t_x+b_x=9.
\]

所有这些块来自不同含x的全局边，至多6条，所以t_x+b_x≤6，从而t_x≥3。若W的三元块总数为t，\(3t=\sum_xt_x\ge30\)，即t≥10。

对全部\(\binom{10}{8}=45\)个八点子集求和，每个三元块被包含在\(\binom75=21\)个八点子集中。因此平均完整保留的三元块数为

\[
\frac{21t}{45}=\frac{7t}{15}\ge\frac{14}{3}>4.
\]

所以存在八点子集S⊆W，完整保留至少5个三元块。没有4/5元W块，故删除W\S不会产生新的三元块。不同全局边不能在S中产生相同的多点截面，因为否则其某点对共度≥2。

S的截面依然只为二/三元块，每点多点块数≤6。因此每点至少出现在一个三元块中：若没有，则该点与其他7点的覆盖全部来自7个不同二元块，违反度6。

## 4. 精确需要的有限分类引理

令T为[8]上的三元子集族，任意两个成员交集至多一点，每点至少在一个成员中，且|T|≥5。每点至多属于3个三元块，因为其余7点不能重复使用，所以3|T|≤24，即|T|≤8。
