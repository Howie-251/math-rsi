# 24点与23点新增候选：只读数学审查

审查日期：2026-10-08。范围为 `TWENTY_FOUR_AT_LEAST_FIVE_SIXES.md`、`TWENTY_THREE_MANY_SEVENS.md`，并核查 `AVERAGED_LOCK_ORDER.md`、相关计算脚本及保存的局部证书。审查者是受委派的 Codex 子代理；`review_independence: same-family`，`acceptance_status: provisional`。未调用 Grok/Gemini，未修改候选稿、计算脚本或 Lean。

结论：本次审查未发现阻断这两条条件证明的数学错误。特别检查的随机锁序、真实中心的条件分布、局部选点覆盖、三团不等式及非负 dual 均成立。以下是实际检查证据；这份报告不构成新增 Lean 完成声明或跨家族验收。

## 1. 24点随机锁序：固定坏对后平均是合法的

对固定超图与固定四锁集合，先给四锁选择均匀标签排列 σ，再均匀排列其余20点。每个 σ 都是旧概率引理允许的条件排列空间。失败蕴含 critical pair 的确定性论证不依赖这个分布，因此可以对 σ 混合；无需混合分布等于全部24点排列的均匀分布。

全二元型的类型重数在 S4 下不变，所以固定绝对位置 k 的 A、B、C 确实不随 σ 变化。对固定中心的固定实际坏边对，原 C 中的两个有序记账项均可以删除，因为两实际边有至少两个公共点。这是扣除记账权重，而不是把坏对的非零记账权重冒充事件概率。

函数 d ↦ min(A,B,C−d) 是仿射函数 C−d 与两个常数的最小值，因此凹。于是

`E min(A,B,C−D) ≤ min(A,B,C−E D)`。

方向正确。该处没有交换不当的极小值与期望，也没有要求选出的坏对随 σ 改变。

固定位置 j 后，实际中心 X 在四中心中均匀；条件于 X=x，另外三锁的6种排列均匀。对每个固定 x，它的固定坏对恰属于纯/纯、纯/二元、二元/二元之一。三类下界对 x 一致，故再对 X 平均仍然成立。中心移动不要求超图本身具有 S4 自动同构；只要求作为 A/B/C 输入的类型重数具有该对称性。

独立按24种标签排列的中心稳定子回放，在位置12及13均得到三类平均双向权重

`42/4199, 3/323, 4/323`。

最低为 `3/323`，且 `8535/8398 − 6/323 = 441/442`。边缘锁位忽略扣除保持上界有效。该论证只用于全二元型，稿件没有把它误用于单三元或四元型。

## 2. 24点的结构分支与输入域

六度点 x 的24次 pair incidence 分配给23个正共度，所以恰一个伙伴共度2，其他共度1。该伙伴所在两边是唯一坏 link 对；若另有公共点便产生第二个超额共度，矛盾。六度点诱导的共度2图最大度1，确为匹配。

若四锁两两单位共度，包含它们的多点迹是 K4 的 pair 分解，因此仅有全二元、单三元、四元三类。四元情形下，外部六度点 z 至多有一个非单位共度邻居，故可从四锁取三个与 z 单位共度的点。原四锁边不能含 z，且在新四锁中的迹恰为三元；其余边不能再用这三点的任何一对。这确实落入单三元型。

若六度点全在原四元边内，则至少五个六度点迫使该边就是全部五个六度点。原四锁内部无匹配边，整个五点内部最多一条匹配边，得到稿件列出的两个五锁类型。未匹配中心与完整五锁边形成的边对不能是坏对，因此唯一坏对是纯/纯；五条纯 link 在19点上也独立给出这个配额。

若不存在四点单位共度集，匹配图独立数为 r−ν，故 r≥5 且 r−ν≤3 仅给出 `(r,ν)=(5,2),(6,3)`。从后者删去任一点得到五点、两匹配边，未匹配点的伙伴允许在选点集外；其实际坏对的锁迹交集仍恰为该中心。这一点没有遗漏六个低度点的情形。

对完整局部域，首个尚有剩余量的 pair 必须由某个真实剩余块承载，选该块后 pair 质量严格减少；这证明递归覆盖所有真实多重迹，而不是仅仅枚举了一些实现例子。≥3迹不能重复的理由也正确：重复三元迹会迫使共度2图含三角，与匹配矛盾。二元迹则必须保留重数。

本审查自行用 pair 余量递归重建了51个有标号类型，确认保存的18代表之全部标签轨道覆盖此域。还逐项检查了18代表的119个坏对输入：每个都满足正容量，全部正容量槽均已覆盖，锁迹交集等于未匹配中心，保存的双向损失等于类型公式所得值，119条记录均严格小于1。

单三元型的448条坏对配置记录也恰等于四中心槽位的完整笛卡尔积，数量为 `4³×7`，保存最坏界为 `4158/4199`。同时核对了五锁两特殊型的33边、六度及位置编码。

## 3. 23点的高共度排除与 P3 选点

每个七度点的共度超额为6。若 λ(a,b)=3，二者各花费超额2，故各至多另有4个非单位邻居。剩下 t−2 个七度点中，至少 `t−2−8=t−10≥9` 个同时与 a,b 单位共度。该集任一点最多6个非单位邻居，故从至少9点中可找单位共度点对。稿件的四锁输入确是“一对共度3、其余五对共度1”。双锁高共度型的空型重数 `19+λ` 及两单点重数 `7−λ` 也与33边及七度一致。

当所有七度点对共度≤2时，G 的最大度≤6。诱导 P3 的三个顶点内部度和为4，外部非单位邻居并集至多 `5+4+5=14`。外部七度点至少16个，确可取两个不同的共同单位邻居；并不需要二者之间也单位共度，它们允许组成额外 K2。这正对应保存的两种输入域。

无诱导 P3 的图每个连通分支是团：若同分支有非邻接两点，取最短路径的前三点即诱导 P3。每团≤7；t≥19迫使至少三团。至少五团和恰四团时，稿件选五锁的方法分别产生0或1条匹配边，没有使用未通过的 extra=2 表行。

## 4. 三团与大迹六锁

三团规模各≤7、总数≥19，仅有 `(5,7,7),(6,6,7),(6,7,7),(7,7,7)`。

在每边总迹大小≤5且 clip 和≤3的条件下：只占一团时 W≤2I；占两团时必有一团大小1，设另一团大小 r≤4，则 I−C=1、W=C(r,2)≤6；占三团只能是 `(1,1,1)`，两边均为0。空迹也给0。因此 `W≤6(I−C)` 对全部实际边成立。本审查还独立检查了所有非负三元整数组合、总和≤5的有限域，未发现例外。

按实际边求和后，四种团规模对应的 `W−6(I−C)` 为 `20,24,72,126`，均复算一致。因此必有边的 clip 和≥4。取该边至少四点、每团至多两点，再补足每团两点，得到六个不同锁点；各团至少五点保证补足。选点不会使原已选至少四点消失，故该真实边在六锁上确有≥4点迹。

六锁787类型的54代表中，恰22代表含≥4点迹，其中旧配额未通过者只有 group4。group20、30均没有≥4迹，正确排除于本分支之外。该域通过后，不需要声称所有三匹配六锁输入都已通过。

## 5. avoided-lock 配额及 exact dual

对子族 F_R 的 d 条四元 link，底集至多有 `22−|R|` 点。逐点重数 a_y 满足

`4d−|⋃F_R| = Σ_{y:a_y>0}(a_y−1) ≤ Σ_y C(a_y,2) = Σ_{unordered pairs}|f∩g| ≤ 3q_R`。

最后一步用简单超图保证不同四元 link 的交集至多3。即使该子族不覆盖整个剩余底集，仍有 `4d−(22−|R|) ≤ 3q_R`，因此稿件配额成立；不需要把子族另行假设为点对覆盖。

令 z_j 是各槽中实际坏无序边对数，满足 `0≤z_j≤cap_j` 和 `Σ_j a_Rj z_j≥q_R`。任取非负有理 α_R，设 θ_j=Σ_R α_R a_Rj，则

`Σ_j w_j z_j ≥ Σ_R α_R q_R − Σ_j cap_j max(0,θ_j−w_j)`。

这是逐槽不等式与配额求和的结果，不依赖浮点最优性；取该下界与0的最大值也合法。已经因共享另一个锁而得到零权重的槽仍在容量表中，dual 不会凭空把它们当成正权重坏对。

本次不调用 LP，直接从保存的有理乘子回放了8个剖面、43个中心：重建全部槽容量及双向权重，核查 avoid 集不含中心、真实子族边数与配额，检查每个乘子非负，并精确重算主项、容量罚项、损失、逐位置 min 及总和，均一致。这里包括明确未使用的3个非严格结果：P3+K2 旧位置 group23，以及六锁 group20、30。

实际使用的细化界为 `43405/43758, 7289/7293, 48453/48620, 217303/218790`，以及六锁 group4 的 `23849/24310`。它们均严格小于1；换位置的最后 P3+K2 输入使用同一实际类型及合法位置 `(8,14,9,10,13)`。
