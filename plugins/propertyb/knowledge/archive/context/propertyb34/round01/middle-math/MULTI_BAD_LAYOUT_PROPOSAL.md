# 多个真实坏对的有限布局联合界：待核对推导

## Target and status

对T34内部v=22、六个七度锁的具体迹重数，改进当前13残型（已被避锁修复2型）。本页提出一个可由精确LP对偶验证的普适条件引理；尚未取得新数值证书，未Lean。

## Fixed objects

固定实际H与有标签锁集。对每个中心i及无序迹对槽j={T,U}，z_ij是该槽的实际坏link边对数，满足0≤z_ij≤cap_ij；cap由真实迹重数得到。每个避锁子族R给出Σ_j I_R(j)z_ij≥q_iR，其中q为现有已证坏对配额。把整数z放松到该有理多面体P，不要求不同中心的向量独立或彼此可实现。实际向量属于P是唯一需要的包含关系。

对有限的具体有标签布局l，F_l是所有非锁位置贡献之和。令a_il=min(A_il,B_il)，c_il=C_il，w_ilj为该实际无序坏对的两个方向权重和。固定z的有效上界是

U_l(z)=F_l+Σ_i min(a_il,c_il−Σ_j w_ilj z_ij).

z随H确定，不能每换一个布局就另选最坏z。

## Proposed joint LP

变量z∈P，实数y_il和t。最大化t，约束：

- y_il≤a_il；
- y_il+Σ_j w_ilj z_ij≤c_il；
- 对每个l，t≤F_l+Σ_i y_il。

每个z均可令y_il等于上述min，因此LP最优值等于max(z∈P) min_l U_l(z)。我们只需一个精确对偶上界M<1，无需信任求解器最优性。对实际z，min_l U_l(z)≤M<1，所以某个固定布局的失败概率界严格小于1，返回原合法染色。

这个命题不要求先找一个对所有实际z都好的单一布局，也不要求中心坏槽独立。布局可由实际H决定，但必须在对应条件排列随机化前固定。与旧24点唯一坏槽平均不同，这里不枚举所有整数坏向量；使用包含实际向量的连续放松可能较弱，但不造成缺失。

## Exact certificate obligation

数值LP仅生成非负有理对偶系数候选。将每条原不等式写成A_r x≤b_r，验证有理λ_r≥0且Σλ_r A_r=e_t，则t≤Σλ_r b_r=M。必要时把变量上下界也作为显式不等式纳入证书。每个布局ABC与w仍用独立注入公式复算；实际P包含、完整13残型来源及原事件支配必须另行证明。

## Questions for adversarial review

该LP是否准确表示max_z min_l，而不是非法交换max/min？从单一实际H的固定z到自适应布局存在性是否有量词问题？只用连续的逐中心quota/capacity放松会不会遗漏某种真实输入？若正确，哪种低成本有效约束最可能改善v22七度、总坏对配额≥3的情况？最后一问允许建议，其余要求严格核对。
