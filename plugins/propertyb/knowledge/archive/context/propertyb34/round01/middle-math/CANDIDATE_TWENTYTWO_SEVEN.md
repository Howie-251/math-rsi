## 2. 实际迹的完整生成与标签覆盖

同构缩减仅使用明确顶点置换。原图、类型和位置一同运输；不以重量谱或启发式同构判定替代。

## 4. 其余十一型：固定真实坏向量的联合布局证书

对中心i和无序迹槽j，z_ij是实际坏link边对数。实际向量满足0≤z_ij≤cap_ij，及每个避锁子族R的Σ_j I_R(j)z_ij≥q_iR。只放松这些必要条件，构成包含实际向量的有理多面体P；不要求不同中心相互独立。

有限具体布局l给出自由位置和F_l，中心a_il=min(A_il,B_il)、c_il=C_il及坏对双向权重w_ilj。对固定实际向量，U_l(z)=F_l+Σ_i min(a_il,c_il−Σ_j w_ilj z_ij)控制真实失败概率。

每份证书给有理γ_l≥0且Σγ_l=1，0≤β_il≤γ_l，非负子族系数δ_iR。置α_il=γ_l−β_il、

    W_ij = Σ_l β_il w_ilj,
    d_ij = Σ_R δ_iR I_R(j),
    κ_ij = max(0,d_ij−W_ij).

因为min(a,c−wz)同时不超过两项，乘非负α、β相加得

    Σ_l γ_l U_l(z)
      ≤ Σ_l γ_l F_l + Σ_(i,l)(α_il a_il+β_il c_il) − Σ_(i,j) W_ij z_ij
      ≤ Σ_l γ_l F_l + Σ_(i,l)(α_il a_il+β_il c_il)
          − Σ_(i,R) δ_iR q_iR + Σ_(i,j) κ_ij cap_ij = M.

后一不等式使用z≥0、quota下界和容量上界：W≥d−κ，所以−Wz≤−dz+κz。每份实际H的z在所有布局中保持固定；没有交换max/min，也没有让对手依布局改变坏对。M<1推出至少一个有正γ的布局U_l(z)<1。先依H选择该确定布局，再随机抽取满足它的条件排列即可。

数值LP只提出γ、β、δ。代码舍入到固定十进制网格、精确归一化、截断β到[0,γ]并重新计算κ，因此最终可行性不依赖浮点残差或LP最优性。无需在Lean内形式化求解器或强对偶。
