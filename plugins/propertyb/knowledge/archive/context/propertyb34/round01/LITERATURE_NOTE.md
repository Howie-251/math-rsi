  https://arxiv.org/html/2610.07379v1 (submitted 2026-10-05), was checked in
  the primary abstract and Sections 1–3 statements, plus the start of
  Section 4. Its main guarantees are asymptotically almost sure for random

  in T34. No result from it is used to discharge a branch; the proof
  appendices were not read. This is a scope decision, not a refutation.
