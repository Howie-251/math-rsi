# 25点五低九锁：固定选择的仿射压缩

本节只使用既有的成功布局，不重新搜索锁位置。数据入口为 Q5_COLORED_CERTIFICATES.json 与 round01/high-math/V25_NINE_Q5_BOUNDS.json。脚本 q5_affine_family_pilot.py --all 保存 Q5_AFFINE_FAMILY_ALL.json。

## 数学恒等式

固定九锁的无色多点迹族 B。令 a_i 为经过锁 i 的块数。五个锁度数6，其余四个度数7，以 x_i∈{0,1} 指示低度锁，Σx_i=5。真实单点迹数为 s_i=7−a_i−x_i，多点迹各重数1。允许的低度位置必须满足 a_i≤6；高位 a_i≤7。总单点迹数为58−Σa_i，故空迹数

n_0=34−|B|−(58−Σa_i)=Σa_i−|B|−24

独立于低度标记。

固定一个锁位置布局，并且在每个排列位置预先指定使用 A、B、C 中的哪一个上界。所选表达式之和始终支配逐位置 min(A,B,C) 之和；这些固定选择无需对每个低度标记都达到最小。

假设九个锁位置连续。A、B 是各迹重数的线性和。对自由中心，其位置在整个锁块之前或之后，左右两类兼容迹中至少一侧只有空迹；因此 C 的乘积项只有固定的 n_0 乘一个仿射量，空迹对角修正也是常数。对锁中心 i，能变化的兼容迹只有本锁的单点迹，其他可兼容的多点迹重数固定。因此 C 仅可能关于 x_i 二次，而不会出现 x_i x_j (i≠j)。在 Boolean 域 x_i²=x_i，故 C 同样是仿射式。对固定选择求和即得到

F(x)=c+Σ_i b_i x_i。

这没有声称逐位置最小值的总和是仿射，也没有把 quota 罚项一并分组。当前全部 q5 既有严格证书的 bare A/B/C 即已足够。

拟合 c 和 b_i 时，必须把 n_0 固定为五低真实值。全高基点和单低测试点仅用于恢复代数系数，不能按它们自身的低点数重新计算空迹。源标签到 canonical 标签的置换为 perm，则拉回位置 positions_source[i]=positions_canonical[perm[i]]；固定行选择仍按实际排列位置编号。

## 精确复算结果

全374个无色族中，65族被一个锁经过至少8块直接排除；10族没有足够的5个合法低度位置；族56和86的 n_0<0，可整族排除，替代原252次颜色预算拒绝。余297族中，285族被已有连续布局的仿射式完全覆盖；12族剩34个低度标记未被所取连续式覆盖，可保留旧非连续布局证书。

全部 chosen 布局共1923个。完整覆盖的285族中67族只需一个布局；其他完整族需2至37个，不把初始三个成功试点推广成“绝大多数都只需一个”。对每个 chosen 布局，脚本针对本族所有合法5低子集直接调用原 BareLayout 公式，确认精确值等于仿射式；并保存 assigned_lows、assigned_max、top_five、top_five_bound。全运行60.31秒。

若只需一个布局覆盖整个族，最大值是 c 加 eligible 中最大的五个 b_i，直接给出统一严格界。多个布局时，明确保存每个低集合由哪一个布局覆盖。后续内核只检查仿射式及这一小集合覆盖，不重新恢复整套带色迹库存。

三个示范：

- 族127，复用目标4424的布局，统一界6241/6435<1；其旧目标4423曾接近1，仍被同族新共享证书包含。
- 族200，复用目标7680，统一界13303/21840<1。
- 族365，复用目标11687，统一界141/143<1。原126个颜色有118个保存的是非连续布局，但这一个已有连续布局已覆盖全部126。

## Lean 落地边界

一般接口把六个残余大小的真实 mass 写成 Boolean 指示变量的仿射函数；A 行是仿射量加权和，C 行是两侧 mass 乘积并减去真实对角项。CachedAffine 提供有限二次多项式的精确展开，核查不同变量二次系数为0，再用 x_i²=x_i 得到仿射式。该方法不用把几何连续性额外当作输入公理；有限系数恒等式本身可在内核检查。

仍须接通：真实库存 → mass 仿射绑定；零计数项处理；完整实际族 caller；全族覆盖。Python 复算和通用代数引理不等于 T34 已完成。全部旧通过模块保持不变。
