# 一般 k 的临界源、共享容量与随机横截：参数化推导及准确障碍

## Target

建立从原始非B假设到同一份真实唯一坏边源、再到参数化修复判据的完整接口，判断 τ(H)≥k、临界性、点对覆盖及共同容量是否已足够给出竞争性全域边数下界。

## Status

**COHERENT AFTER REFRAMING / EXTRA ASSUMPTION。** 下述参数化修复定理与原H接口成立；尚未证明任意小边数非B输入都能选择满足其严格不等式的源。因此没有新m(k)下界。本轮得到一条有用的 τ=k / τ≥k+1 全域分流，以及一个实际超图族，精确否定“τ≥k、点对覆盖、同一唯一坏源与少量边数已自动消除负单点”的推断。该族是**可染**的，不是m(k)反例，也不是临界非B超图。

## Invariant Object

固定同一原H、原边索引与唯一坏源 (P,B,G)。不将不同染色的平衡、私有边或owner性质拼接。要控制的是一次实际重染的失败概率，而不是独立虚构的正负迹。

## Assumptions and notation

k≥3，H=(V,E)有限简单k元；M=|E|，n=|V|。非B假设下，先取边极小非B子图；若还要点对覆盖，须在完整最小顶点反例中先完成规范化，不能对任意子图凭空保留paircover。选G∈E，利用临界性取H−G的proper染色；G必单色，规范成红色。P、B是其红/蓝类，因此G⊆P且G为唯一坏边。

记τ(H)为最小横截集大小，d(x)、λ(x,y)为该同一H的度数、共度。

## Derivation Strategy / Map

1. 用τ(H)≥k区分可取规范源的τ=k支与仍有零G边的τ≥k+1支。
2. 对同一源、同一g∈G作“g翻蓝、部分旧蓝点翻红”的精确signed接口。
3. 将已有占用乘积引理和共同逐点容量推广到任意负最小迹t，给出可核的统一不等式。
4. 检查小负迹是否被τ与paircover控制；实际构造表明没有此自动连接。
5. 与2^{k−1}及CK简式比较，决定下一实质义务。

## Main Derivation

### 1. τ(H)的真正一般后果：一个完整分流

**命题1。** 非B的k元H满足τ(H)≥k。若τ(H)=k，则存在一条既是边又是横截集的G，且染G红、V\G蓝给出唯一坏边G。若τ(H)≥k+1，则每条G∈E均有一条原边与G不交。

证明：若横截集T满足|T|≤k−1，将T红、其余蓝；没有红k边，且T击中全部边，故也没有蓝边，矛盾。若|T|=k且T不是原边，同一染色仍proper，故每个k元横截集必是原边。取最小横截集G便得τ=k支；任意f≠G既遇G又有G外点（简单k元性），所以canonical源确实仅G全红。τ≥k+1时，任意k集G都不是横截集，故有避G边。证毕。

这比仅使用τ≥k更具体：**τ=k支允许直接选P=G，不需要在H−G的未知染色上另行优化。** τ≥k+1支则保证源中存在红色外点和蓝色外点（避G边必须proper）。两支仍都要解决修复；不是新的下界。

### 2. 同一临界源到一般signed系统的无损连接

固定g∈G。将g翻蓝，允许且仅允许R⊆B中的旧蓝点翻红。

正索引族为

\[
\mathcal A_g=\{e\setminus\{g\}:e\in E,\ e\cap P=\{g\}\}.
\]

每个正集大小s=k−1，保留原边索引；m=|A_g|。负索引是**全部**避g原边f，负集B_f=f∩B。由于f≠G且原源中f proper，有1≤|B_f|≤k−1。相同负迹仍保留不同原边索引。

若R击中全部正集且不包含任何负集，则原H proper：G留下g蓝及其他点红；过g边无法全红，原来具有其他红点的边仍proper，正边因R被击中也proper；避g边原红点保持红，B_f未全选保证仍有蓝点。

对x∈B，令a_x为正出现数，b_x为负出现数。正边含g、负边避g，索引不重叠，因此

\[
a_x+b_x\le d_H(x). \tag{I}
\]

这里不需要另加“零G边出现”预算：原源已proper且修复只蓝转红，每条零G边仍完整列入负族。这与从头固定G颜色后对外点双向随机上色不同。

非B保证每g有m≥1，否则单翻g已proper。若H paircover、r=|P|，则非正的过g边覆盖P\{g}，每条至多覆盖k−1人，因此

\[
m\le d(g)-\left\lceil\frac{r-1}{k-1}\right\rceil. \tag{II}
\]

特别地τ≥k+1支有r≥k+1，从而m≤d(g)−2。若仅τ=k canonical源，则r=k，所得m≤d(g)−1。

同一g星还有

\[
\sum_{x\in B}(a_x-1)_+
\le \sigma_g:=(k-1)d(g)-(n-1), \tag{III}
\]

因为a_x≤λ(g,x)，而paircover使全部λ≥1，其总盈余恰为σ_g。式(I)–(III)均为实际H共同预算。

### 3. 参数化共同收费定理：任意负最小迹t

下面不是把D7改为k，而是对负大小、正出现与小负共享容量显式参数化。

从每个正s集独立均匀选一点，令R为所选点并。记

\[
q_x=1-(1-1/s)^{a_x}.
\]

已有自含占用耦合给Pr(F⊆R)≤∏_{x∈F}q_x。固定整数t≥1，将负族分成小迹1≤|F|<t和大迹|F|≥t，记b_x^{<t}为小迹负索引中的出现次数，并令

\[
C_{<t}=\sum_{F:|F|<t}\prod_{x\in F}q_x.
\]

对任意大小j≥t的大迹F，AMGM及0≤q≤1给

\[
\prod_{x\in F}q_x
\le\frac1j\sum_{x\in F}q_x^j
\le\frac1t\sum_{x\in F}q_x^t.
\]

因式(I)，大迹的共同出现容量至多d_H(x)−a_x−b_x^{<t}，所以总坏概率至多

\[
\boxed{
C_{<t}+\frac1t\sum_{x\in B}
\bigl(d_H(x)-a_x-b_x^{<t}\bigr)q_x^t.}
\tag{R}
\]

**命题2。** 任一真实源、任一g∈G、任一t若使(R)<1，则H可染。式(R)的减去b_x^{<t}保留同批小负迹已花掉的资源，不将它们与大负族重复收费。实际大负出现数还可以替换此容量上界，进一步加强。

若没有负迹小于t，d_H(x)≤D，a_x≤r_0，令

\[
\Gamma(s,t,D,r_0)=
\max_{1\le a\le\min(D,r_0)}
\frac{D-a}{a}\bigl[1-(1-1/s)^a\bigr]^t.
\]

由于Σ_xa_x=sm，有完全统一的充分条件

\[
\boxed{\frac{sm}{t}\Gamma(s,t,D,r_0)<1.} \tag{R'}
\]

如a_x≤1，则q_x≤1/s，(R')简化为

\[
\boxed{\frac{m(D-1)}{t\,s^{t-1}}<1.} \tag{R''}
\]

这些式子给出了明确出口：若能由同一源选择保证“负小迹少/可吸收”、正共度低，则分母(k−1)^{t−1}可以在t随k增长时远大于2^k。但τ≥k并未给出所需负小迹消除。

**负单点的正确预处理。** 令F_g为所有负单点所在的旧蓝点。任何修复R必须避F_g。应把每个正集A改为A\F_g，删去所有遇F_g的负约束（它们已自动安全）。若出现空正集，该源/中心的本类修复不可能；不能继续按原正大小s=k−1收费。其余负二迹仍保留，不得一并省略。

### 4. 实际H失败结构：τ=k、paircover、canonical唯一源仍可全中心阻塞

对每个k≥4，构造一个**显式可染**的简单k元H。取

\[
G=\{g_0,\ldots,g_{k-1}\},\qquad
B=C_0\sqcup\cdots\sqcup C_{k-1},\quad |C_i|=k-1.
\]

总点数n=k²。原边先取：

* G本身；
* F_i={g_i}∪C_i，i=0,…,k−1；
* E_{i,y}=(G\{g_i})∪{y}，所有i及所有y∈B。

这些边互异（k≥4）。F_i彼此不交，故τ(H)≥k。全部已有边都遇G。

为覆盖全部点对，固定锚g_2及z∈C_2。对每一顶点对{u,v}补一条包含{u,v,g_2,z}的k集，任意补足到k点，并把重复边去重。每条新增边含g_2、z，故都遇G。因而补后仍有τ(H)≤|G|=k，结合不交F_i得**τ(H)=k**，而且H paircover。

canonical源将G全红、B全蓝。所有F_i、E_{i,y}及新增边均proper，因此G确实是唯一坏边。

现在固定任意g_i翻蓝，并只允许旧蓝R⊆B翻红。若R为空，真实边F_i全蓝。若R非空，取y∈R，真实边E_{i,y}全红。因此**每个g_i的全部此类修复都失败**，与如何优化横截分布、收费、t或正共度无关；每个blue点都有真实负单点。

H仍有显式proper染色：将g_0,g_1翻蓝，从C_0、C_1各取一点y_0,y_1翻红，其余保持。G现在两色；每个F_i两色；每个E_{i,y}至少含一个翻蓝G点及至少k−3≥1个未翻G红点；新增边中的锚g_2红、z蓝未变。因此它是可染H，绝不是原问题反例。

边数满足

\[
M\le k^3-k^2+k+1+\binom{k^2}{2}
=\tfrac12k^4+k^3-\tfrac32k^2+k+1=O(k^4). \tag{C}
\]

对k≥18，此上界≤k^4<2^{k−1}：第一比较由k≥4易验；第二在k=18成立，且((k+1)/k)^4<2保持归纳。故即便边数远小于指数尺度，τ=k/paircover/同一canonical源也不能保证上述单中心修复成功。**缺少的是源转移/多G点同时翻色等使用非B全局性的操作；不是又一张正族收费表。**

确定性小核 `CHECK_SOURCE_OBSTRUCTION.py` 实际生成k=4,…,10的简单原H，检查全部点对、唯一源、k份不交边、G横截以及显式proper四翻色，并按真实E_{i,y}核全中心单向阻塞。结果 `CHECK_SOURCE_OBSTRUCTION.json` 为PASS。该计算是上述解析构造的重放，没有穷举超图，没有模型或Lean验收。

### 5. 最小蓝源与低共度还有一个方向性冲突

若固定G红，在H−G的proper源中选蓝点最少的一份，则每个蓝y有一条真实红私有边，且其唯一蓝点为y。若某y在g正族中出现，且λ(g,y)=1，那么该红私有边不可能含g：唯一包含g,y的边已经是具有k−1个蓝点的正边，k≥3时两者不同。因此y必被g的负单点禁止。

更一般地，设U_g是未被负单点禁止且在正族中出现的点。每个y∈U_g的至少一条红私有边必须含g，且不同于a_y条正边，故λ(g,y)≥a_y+1。于是

\[
\sum_{y\in U_g}a_y\le\sigma_g.
\]

如果正集在删除负单点后均非空，至少需要m≤σ_g。故“选择最少蓝点以取得私有容量，再利用几乎线性的g星作单向修复”并非自动相辅；小σ可能反而使全部可选点被单点阻塞。此事实只限制这种同源、单中心、单方向操作，不排除换源或共同多点修复。

### 6. 2^{k−1}与CK规模：哪些部分已经不值得作为大k主线

临界性始终提供唯一坏源，不受Mp<2限制；这一点要与随机源引理分开。

若坚持仅用任意独立公平染色的“唯一坏源＋一次翻色”计数，已存一般定理给

\[
Mp+\frac{2n_1q}{k}<2,
\quad p=2^{1-k},\quad q=2^{2-2k}=p^2.
\]

仅用n_1≤M(M−1)/2，置κ=Mp，得

\[
\kappa+\frac{\kappa^2}{k}(1-1/M)<2. \tag{P}
\]

此充分条件必要求κ<2，即M<2^k。它比最基本第一矩常数1有提升，但无法取得随k增长的κ。

本地已读CK原始简式为κ(1−p_0)^k+κ²p_0<1。对κ=2，取p_0=(ln k)/(2k)，左端≤2/√k+2ln k/k。该表达式在k≥16递减，k=16时ln16<3，故≤1/2+3/8<1。因此**CK简式对每个k≥16已覆盖M=2^k，而(P)连该端点也达不到**。不能把(P)当作新的大k改进。

R/R'本身没有这一2^k常数障碍：在共同负最小迹t为Θ(k)、正出现受控的条件下，R''可能非常强。但其未解入口恰是同一实际源中的负单/二迹，以及需要的参数在全部原H上是否能同时保证。本轮不能据此宣称与CK竞争。
