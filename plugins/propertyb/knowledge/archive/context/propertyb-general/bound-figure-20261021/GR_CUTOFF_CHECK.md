# GR参考包络起点的独立核对

结论：`BASELINE_COMPARISON.md` 引理D.2的同一证明完整适用于所有整数 **k≥17**，不是仅k≥32。结合原引理D.3及已证 `B_RS(k)≥2^k`，定义D.1中的五项参考包络在所有k≥17均等于 `B_RS(k)+1`。因此已证增长定理C在全部k≥17严格改进这五项明确参考界的包络。此结论不涉及定义D.2或定理E，也不声称比较了所有可能文献方法。这里只保存核对报告，未改规范正文或HTML。

## 完整解析核对

固定整数k≥17，令q=2^floor(k/2)、v=(k−1)q。q≥256，所以v≥2k−1，确为D.1外层最小值的合法输入。

1. 内层取整准确为 `ceil((v−1)/(k−1))=ceil(q−1/(k−1))=q`，因为k−1≥16。因此
   `S_k(v)=ceil((k−1)q²/k)≤q²≤2^k`。第一处使用整数q²作为上界，第二处使用2floor(k/2)≤k；没有遗漏任意一层ceiling。
2. 实函数f(x)=2^(x/2)/x在x≥17严格递增：其对数导数 `log(2)/2−1/x>0`（例如log2>1/2已足够）。起点 `2^(17/2)>16·17` 可由整数平方 `131072>73984` 核对。故对全部k≥17有 `2^(k/2)>16k`，于是
   `q≥2^(k/2−1)>8k`，继而 `v>8k(k−1)≥4k²`（末步k≥2）。
3. 令a=floor(v/2)、b=ceil(v/2)。这里q为偶数，所以v为偶数且a=b=v/2；即使不利用此点，原文逐因子估计也成立：对t∈{a,b}及0≤j≤k−1，`t−j≥v/2−k+1/2>v/2−k>0`，而v−j≤v，故
   `(t−j)/(v−j)≥(1/2)(1−2k/v)`。
4. 将每个二项式比写成k个因子的乘积，可得
   `P=(C(a,k)+C(b,k))/C(v,k)≥2^(1−k)(1−2k/v)^k`。
   因0<2k/v<1，整数Bernoulli不等式给
   `(1−2k/v)^k≥1−2k²/v>1/2`。因此 `P>2^(−k)`，即 `R_k(v)<2^k`。2^k是整数，故即使R不是整数，仍有 `ceil(R_k(v))≤2^k`。
5. 对同一个合法v，两项均不超过2^k，于是
   `min_w max{S_k(w),ceil(R_k(w))}≤max{S_k(v),ceil(R_k(v))}≤2^k`。
   这是上界外层min；完全不要求实际最小反例的顶点数等于所选v，也没有构造实际反例。

引理D.3原本已在全部k≥17给出 `B_pair≤B_cont≤B_RS` 与 `B_lin≤B_RS`，无k≥32依赖。上述加强遂直接给出：全部k≥17的 `L_GR≤2^k≤B_RS`，故 `L_ref=B_RS+1`。这只是已写证明的起点收紧，不依赖有限数值表。
