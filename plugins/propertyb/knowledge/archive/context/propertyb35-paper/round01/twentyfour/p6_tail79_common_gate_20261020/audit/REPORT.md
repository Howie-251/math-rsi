### 双三中心 j=2 等号换色

两个三中心 x,y 的正支持标签不交，剩 U,V；只需新补 U三、V四。迫出 j 个负三 {x,y,z} 后，剩负三双核／单核数为p,q，双核负四数为d，则

    p+q <= 2-j,   2p+q+2d <= 8-2j,
    blocked <= (4-j)p+q+d.

独立穷尽该小整数预算，j0、1、2的最大值为10、5、2。j2达到2的唯一预算型是(p,q,d)=(0,0,2)。所以两份原负三和两份阻断四红候选的原负四都含 x,y；各核正3+负4恰用满D7，别的负索引必避两核。
