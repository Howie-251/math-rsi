# 24点、35边：最小能量六锁完整输入域与唯一重复link诊断

2026-10-19。输入是主约化产生的简单五元、点对覆盖超图H，v=24，M=35。没有运行Lean、MCP或整图枚举。**没有闭合整个24点分支。** 本轮得到无六度分支的一个很小且有完整证明的六锁共度图域，以及六度中心块染色的一阶计数失败见证；现有排列机制在六锁24个指定模板中只有一个严格，故停止扩大目录。

## 1. 完整度数分流

点对覆盖使d(x)≥ceil(23/4)=6，总度为175，所以δ∈{6,7}。记r、t分别为度6、7点数，其余点度至少8，则2r+t≥17。δ7时七度点池L的大小h≥17。令w(x,y)=λ(x,y)−1≥0；每个七度点在全图的总权度是4·7−23=5，因此在L内也至多5。

δ6时任选六度点x，其行共度盈余为24−23=1。因此唯一p满足λ(x,p)=2，其他22点与x共度都为1。六条x边删去x，恰为

- A∪{p}、B∪{p}，其中A、B各有3点；
- C1、C2、C3、C4，各有4点。

六个私有组A、B、C1,…,C4两两不交，共22点。这是实际link的完整结构，不要求其余29条边具有额外性质。

## 2. δ7的最小能量选择：四锁、五锁、六锁

在L中取内部总权W最小的k点集S，令dS(x)=Σy∈S\{x}w(x,y)。对每个y∈L\S，以y替换x不会减少W，因此

W−dS(x)+Σz∈S\{x}w(y,z)≥W。

对全部h−k个y求和，右侧交叉权不超过其余k−1个锁点的全局总权预算，扣去它们在S内的权；得到

(h−k−1)dS(x)+2W≤5(k−1)。

另一方面，对全部k点子集平均，W≤floor(5k(k−1)/(2(h−1)))。两式都只使用同一实际权图，没有枚举超图。

- k=4：W≤floor(30/(h−1))≤1。因此可选四个七度锁，内部要么全单位，要么仅一对共度2。
- k=5：因h−6≥11，有11dS(x)+2W≤20，故dS(x)≤1。其内部非单位对构成至多两条共度2匹配。
- k=6：平均给W≤floor(75/(h−1))≤4，交换给10dS(x)+2W≤25。若W≥3，则dS(x)≤1，所以W≤3且W=3时恰为三边匹配；若W≤2，其全部可能图直接列举如下。

**六锁完整无标号加权图域恰由以下六种必要类型覆盖：**

|类型|正权边及权|
|---|---|
|空图|无|
|单边|01权1|
|二边匹配|01、23各权1|
|三点路|01、12各权1|
|双权单边|01权2|
|三边匹配|01、23、45各权1|

这里“覆盖”指每个实际H都能选出一个属于这六种图的S；不声称每一图或每一库存都能由实际H实现。权1、2分别对应真实共度2、3。没有额外三种匹配类型；总数就是六种。

μij=λij−ΣT⊋{i,j}μT，

μi=7−ΣT∋i,|T|≥2 μT，

μ∅=35−ΣT≠∅μT。

所有变量须非负，|T|>5的迹为零。因为每个实际H的μ就是上述变量，其映射和恢复是完整的；放松域中的额外库存只使证明更强，并不要求构造锁集外的H。

## 4. δ6：完整link颜色轨道与一阶方法的精确边界

固定x红，令pc为p是否红。私有组内红点数记(a,b,c1,c2,c3,c4)。让六条x边均非单色，当且仅当

pc=0时0≤a,b≤3；pc=1时0≤a,b≤2；始终0≤ci≤3。

在A、B交换与四个C组置换下取a≤b、c1≤…≤c4，共560个宏颜色族。每族先均匀选择对应的组角色，再在每组内均匀选指定数目红点。它们完整覆盖六link约束下的颜色轨道；没有限制总红点数。

外边e用型(ep,u,v,z1,…,z4)表示是否含p及在六组内的点数，满足ep+u+v+Σzi=5，0≤u,v≤3，0≤zi≤4，同样排序，恰39种。给定一个有角色的颜色向量r，单色概率是

1[ep=0或pc=1]·Πg C(rg,eg)/C(ng,eg)

加上

1[ep=0或pc=0]·Πg C(ng−rg,eg)/C(ng,eg)，

其中ng=(3,3,4,4,4,4)。对组角色平均得到560×39个精确Fraction。

以这些族为策略的一阶最坏边型LP约为每边0.03726708，乘29约1.080745；这仅是探索浮点结果，不承担严格结论。真正可重放的失败证据为BLOCK_TYPE_OBSTRUCTION.json中的29条外边型整数重数向量。其对全部560族的单色边期望之和均≥1，精确最小值为1。同时满足以下必要聚合条件：

|数量|该向量|实际输入必要下界|
|---|---:|---:|
|外边条数|29|29|
|p外部出现|10|4|
|A∪B私有点总出现|38|30|
|四个C组总出现|97|80|
|A–B跨组点对出现|10|9|
|(A∪B)–C跨组点对出现|107|96|
|不同C组间点对出现|100|96|

下界来自私有点外部度至少5、p外部度至少4，以及不同私有组的点对不能由x边覆盖。这个向量**不是实际超图，也不保证逐点度数/逐对覆盖可实现**。其准确作用是证明：仅记录39种轨道边型和上述聚合必要条件，再对560种对称颜色族作任意混合的一阶union bound，不能完成δ6；需要保留同一组内真实点/点对关联、使用二阶事件，或换一个证明机制。这里没有扩大颜色族或反复求相同LP。
