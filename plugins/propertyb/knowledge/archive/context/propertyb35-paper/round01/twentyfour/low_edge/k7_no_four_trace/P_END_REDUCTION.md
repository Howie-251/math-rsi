# 纯五二迹支的解析入口与实际边界

本文件只处理七个八度点 $P$、十七个七度点 $L$、四条内部五边、其余 $P$ 迹至多二的实际支。五条二迹形成保留重边的多重图 $G$。内部 missing 图为 $P_3+2K_2$；其中心内部次数二，另六点内部次数三。

## 已给完整实际染色的入口

1. $G$ 有不属于 missing 图的二点 vertex cover。`TWO_POINT_COVER_PROOF.md` 接一般五／六正约束修复，含唯一 $c_2$ 点为中心的五边多重星。
2. 两名 $c_3$ 点的二迹次数为 $(3,3)$、其对非 missing。`THREE_THREE_REPAIR.md` 完整处理共享1、2、3。
3. 两名 $c_3$ 点的二迹次数为 $(3,2)$、共享一条、其对非 missing。`SHARED_PAIR_REPAIR.md` 已给零／一重复的两种几何与原染色。
4. 两名 $c_3$ 点的二迹次数为 $(2,2)$、共享零条、其对非 missing。`SIX_FOUR_ONE_TRIPLE_REPAIR.md` 给任意六正四集、一个负三集、逐点总约束度七的一般修复及实际调用。
5. 两名 $c_3$ 点的二迹次数为 $(3,2)$、共享两条、其对非 missing。`THREE_TWO_SHARED_TWO_REPAIR.md` 用实际零／一重复 star、二匹配和双七度强共度门闭合。

全部入口的 missing 条件都只用于保证固定的两名蓝 $P$ 点击中四条内部五边，不能删去。不同入口可以重叠。

另有强共度入口：两名八度点实际共度 $c\ge6$，完整域 $c=6,7,8$。其唯一二锁库存为

$$\mu_\varnothing=19+c,\quad\mu_1=\mu_2=8-c,\quad\mu_{12}=c.$$

固定位置 $(11,24)$ 的精确界依次为

$$47167/49742,\quad88271/99484,\quad20574/24871<1.$$

完整主计数保存于 `STRONG_88_PAIR.json`；`strong_pair_replay.py` 独立重建35个实际边标签、1190个有序不同边对及72行，`STRONG_88_REPLAY.json` 为 PASS，所有扣除为零。

若两名 $c_3$ 点构成 missing 对且共享三条非内部二迹，它们共同属于四条内部边中的三条，因此实际共度恰六。故该结构也由强共度入口闭合；这一步不靠把 missing 对染蓝。

## 直接解析的度数压缩

令 $a$ 为六名 $c_3$ 点中二迹次数三者的数目，$b$ 为二迹次数二者的数目。

若 $a\ge3$，五条图边的总度十迫恰有三名次数三点及一名次数一点。记后者为 $l$，其邻点为 $u$，另两名次数三点为 $v,w$；重数方程唯一解为

$$uv=uw=1,\quad vw=2,\quad ul=1.$$

六名 $c_3$ 点的 missing 图只含两条独立边，$uv,uw$ 不可能同时 missing，所以 $(3,3)$ 入口闭合。因而未闭合输入满足 $a\le2$。

若 $a=2$，两名次数三点在五条边中必共享，且未闭合时它们必须构成 missing 对；共享三条已被强共度门排除，所以只剩共享一或二条。

无这些入口不表示实际不可染。完整有限 $P$ 端诊断与带重边运输由 sibling 的 `p_end/P_GRAPH_CALLER_COVERAGE.md` 保存，计数只用于展示剩余调用结构，不替代本文件各实际 caller。尤其存在没有任何二点 vertex cover、或所有二点 cover 都 missing 的输入，不能声称二点 cover 引理已闭合整个纯五二迹支。

一个明确的剩余 P 端障碍是 missing 图中心为0、其两叶为1、2时的五边

$$03,04,05,06,12.$$

它的所有二点 cover 均为 $\{0,1\}$ 或 $\{0,2\}$，都是 missing；六名 $c_3$ 点二迹次数全一，所以所有要求次数二或三的 caller 都不能覆盖它。这是真实的选点边界，尚未声称其外部实际布局不可染或存在反例。
