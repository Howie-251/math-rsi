# 两内部、两三迹和三四迹：补集覆盖与共享单迹度的解析修复

## 定理

设H为24点、35条互异五元边的点对覆盖超图，最小度七，无全七度边，高点集P恰七点，恰两内部五边，非内部P迹库存为

$$ (n_2,n_3,n_4)=(0,2,3). $$

则H具有Property B。

本稿给出解析候选证明，不需要未完成的630位置全源精算。原同权三蓝及蓝对fallback的失败数据保持独立，不能改称原权全过。新关键是：无蓝对时P结构唯一；在其22种proper三蓝间，外点的**总单迹频率相同**，从而迫至少一个三蓝落入已证修复门。主代理和指定审阅验收状态另记。

## 1. 实际谱和蓝对入口

总度175恰耗尽七个高点的七份盈余，故P七点全部八度，外部L恰17点全部七度。无全七度边使P击中全部原边。两内部missing二对不同；令ci为内部频率、ai为两三迹频率、bi为三四迹频率，则

$$u_i=8-c_i-a_i-b_i,\qquad \sum_i u_i=56-10-6-12=28.$$

若有蓝对Q命中全部内部／高迹，Q不可能全包含任何大小至少三的迹，故它们均proper。其蓝单迹数

$$m=16-c_Q-a_Q-b_Q\le16-2-5=9.$$

此时只有m正四、零负三和28−m负四，L17、D7。m≤7用七正4T35B，m8用L17八正3T20B（B20），m9用九正门（B19）。故有蓝对者已修复。

以下假设不存在这样的蓝对。

## 2. 无蓝对时的唯一P结构

两三迹的四点补集记A、B；三四迹的三点补集记三个三角形。内部的两个二点补集记f1、f2，互异。一个蓝对不proper，当且仅当它是某个内部missing对，或被某个高迹补集包含。因此不存在proper蓝对等价于：两个K4、三个三角形和两条missing边覆盖K7全部21条端对。

令r=|A∩B|，1≤r≤4。

* r=1：两K4未覆盖边构成两组三点间的K3,3，共九条。一个三角形至多给两条cross边，另两missing边至多给二条，所以至多八条，矛盾。
* r=3或4：两K4分别仅盖九或六条，尚余十二或十五条；三三角加两边至多十一条，矛盾。

故r=2。写W=A∩B（两点）、X=A\B（两点）、Y=B\A（两点）、z=P\(A∪B)（一点）。未被两K4覆盖的图恰为z到其它六点的星，加X、Y之间的K2,2，共十条。

设三三角中有t个含z。覆盖六条星边迫t≥2。

**t=2不可能。** 两missing边都必须是星边；两个z三角的四个端点必须互异，覆盖另外四条星边。要再覆盖K2,2四条cross边，两个z三角各须贡献一条cross，第三个无z三角须贡献两条。前两条cross因四端点互异构成K2,2的一份完美匹配；余两条cross是另外两条不交边，一个三角形不能同时包含，矛盾。

**t=3。** 若missing两边中有两条星边，三z三角最多给三cross，少于四。若只有一条missing星边，则为补足四cross，另missing边和三个z三角必须各给一cross；三个z三角的端点全在X∪Y四点，最多盖四星边，加一missing星边仍少于六。故两个missing都不是星边。

于是三z三角的六个端点必须恰各出现一次，即在W∪X∪Y形成完美匹配。为补足四cross，它至少含两条X—Y边；这些用尽X∪Y，剩W两点必须互配。两个missing边恰是K2,2的另一个完美匹配。因此所有无proper蓝对源都同构于唯一结构：

$$f_1=01,\quad f_2=23;$$
$$P3:126,036;\qquad P4:0123,0245,1345.$$

此结构给ci+ai+bi=4逐点成立，所以ui=4，每个P星恰四条单迹。不同高迹均由该分类强制，原先允许重复迹的情况没有被额外假设排除。

## 3. 恰22个proper三蓝

任意三蓝自动proper内部。每个P3排除五个三蓝：它本身（全蓝），以及四点补集中的四个三元组（全红）。两个P3交一点6，其并大小五：二者本身不可能避开另一个，且并补只有两点，故两组五个坏三元组互不相交，共十个。

每个P4另排除唯一三点补集，分别为456、136、026。这三个三元组彼此不同，均遇两个P3且不等于它们，因此不在先前十个中。合计十三坏三元组，故proper三蓝恰有

$$35-13=22$$

个。对每个这样的Q，蓝单迹数总是3·4=12，红单迹数16。三蓝本身不能直接落旧≤11正门；但下文在这22种Q之间选出可由已有门进一步固定外点修复的一种。

## 4. 十二正四系统的四个已证门入口

固定一个proper三蓝Q后，所有内部／高迹都proper，实际signed系统只有12正四和16负四，L17、逐点总signed出现≤7。

记某外点的正／负频率为p、b。以下任一条件足以修复该signed系统；都是固定该点红后应用准确现成门，没有padding：

1. p≥4。p=4恰余八正四、b≤3负三、至多16负四、地面≤16，用[恰八正L17的3T20B门](../../../../../../proofs/propertyb35/EIGHT_POSITIVE_FOUR_SET_REPAIR.md)。p≥5余≤7正四、b≤2，用[七正4T35B门](../../../../../../proofs/propertyb35/SEVEN_POSITIVE_FOUR_TRIPLES_REPAIR.md)。
2. p=3且b≤3。恰余九正四，负三≤3，用[九正门](../../../../../../proofs/propertyb35/NINE_POSITIVE_JOINT_NEGATIVE_REPAIR.md)。
3. p=2且b≤2。恰余十正四，负三≤2，用[十正门](../../../../../../proofs/propertyb35/TEN_POSITIVE_TWO_TRIPLES_REPAIR.md)。
4. p=1且b=0。恰余十一正四、无负三、负四≤16，用[十一正0T17B门](../../../../../../proofs/propertyb35/ELEVEN_POSITIVE_FOUR_SET_REPAIR.md)。

正边含该红点者已命中；负四含它者准确缩为负三，其余仍负四。其它点出现不增加，地面缩为≤16，所以全部门前提满足。

## 5. 共享单迹度迫有一个入口

对v∈L，记kv为其在全部28条单迹原边中的出现次数。这不随P上Q选择变化。记rv为其在五条高迹原边中的出现次数；内部无外点，由原度七得

$$k_v+r_v=7,\qquad\sum_vk_v=28\cdot4=112,\qquad\sum_vr_v=2\cdot2+3\cdot1=7.$$

对于每个proper三蓝，signed正负频率和恰是同一个kv，因为所有高迹proper、所有单迹都作为一个正或负索引。

假设22个proper三蓝都不满足第4节任何入口，取其中一个Q。此时最大正频率≤3，48正关联在≤17点上的正并大小只能为16或17。写n1,n2,n3为正出现一／二／三次的点数，有n1+2n2+3n3=48、n1+n2+n3≤17；仅可能：

$$16\text{个三重点};\qquad14\text{个三重点}+3\text{个二重点};\qquad15\text{个三重点}+1\text{二重点}+1\text{单点}.$$

无第4节第2项入口迫每个正三重点kv=7；无十正入口迫每个正二重点kv≥5；无十一正入口迫正单点kv≥2。

* 16个三重点已经用满16·7=112份单迹关联，第17点k=0，所有7份高迹外部关联只能落于同一个点。这不可能：每条P3原边在L有两个不同点，且这里确有两条P3边。
* 14个三重点加三二重点至少需要14·7+3·5=113份单迹关联，超过112。
* 因此只能是最后一型，且105+5+2=112恰等。十五个正三重点kv=7，唯一正二重点kv=5，唯一正单点kv=2。这等价于高迹关联谱恰为一个点r=2、一个点s的r=5，其余十五点r=0。

由于kv独立于Q，同一个s始终是总单迹频率二的点。若其余proper三蓝也均无旧门入口，那么上述分类迫它在**每个**proper三蓝中正频率都恰一。

令di为s在P迹恰为{i}的单迹原边中的频率。则di为非负整数、Σi di=ks=2；s在蓝集Q下的正频率为ΣQ di。

若这两次出现属于同一P星，ΣQ di只能为零或二，不可能为一。若属于两个不同P星，则它为一恰当Q包含这两个P点中的一个，七点全部三元组中这样的Q只有

$$2\binom52=20<22.$$

所以22个proper三蓝不可能全部使s正频率一，矛盾。至少一个proper三蓝满足第4节入口，完整修复。

## 6. 返回原H与独立小检查

选上述Q，先固定P颜色，再用第4节对应门修复L。蓝单迹边遇红外点，红单迹边留蓝外点，内部和高迹始终在P端双色。所有35条原边被覆盖，逆运最初同一P置换得到原H染色。

`ANALYTIC_CHECK.py/json`不导入域生成器，独立核对以下有限断言：对两K4交大小r=1,2,3,4各固定一代表，枚举全部7770个三三角多重集及能够补足剩端对的两missing边，结果无proper蓝对的配置数为0／2／0／0；两份r2配置均ui全4、proper三蓝恰22。它还穷核48关联的全部正频谱，以及总频率二在七P星的全部28种分配，核最大20个三元组正频率一。全部PASS。此检查支持解析分类和算术，不是外部H或负布局枚举。

原`FAILURE.json`和`FALLBACK_FAILURE.json`仍正确：它们否定原加权／pair快捷接口，并不否定此处利用共同原H单迹度的修复。新证明不需要假设一般12P4/0T16B门为真，也不声称已证明该通用门。
