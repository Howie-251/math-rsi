# 五二迹具有允许的两点击中集时的完整闭合

设H满足本目录纯五二迹的实际假设：24点、35边、点对覆盖、最小度七，无全七度边，P={d>7}有七名八度点，L为17名七度点，恰四条P内部五边，非内部P迹至多二。

把五条非内部二P迹作为七点多重图G的五条有标签边。假设存在两个不同P点p,q，它们击中G全部五条边，且{p,q}不是任何内部五边的missing二对。则H具有Property B。

染p,q蓝，其余P点红。四条内部边都含蓝点，且至少三名红点，均proper。每条G边或者跨蓝红两色，已经proper；或者其P迹恰{p,q}，这时成为潜在单蓝边，外部为三集。

设m为共享二迹{p,q}的实际边数。六名内部次数三的点，其非内部多P迹盈余至多三，所以当p,q都为c3点时m≤3；若含唯一c2点，另一名仍为c3，也给m≤3。

设c_p,c_q为内部次数。P点度八，非内部边数为8−c。令g_p,g_q为G度数。G由p,q击中，故g_p+g_q−m=5。

蓝点p的私有单P迹边有8−c_p−g_p条，q类似。加上m条共享二迹，总潜在单蓝边数为

N=(8−c_p−g_p)+(8−c_q−g_q)+m=11−c_p−c_q。

其中m条外部为三集，其余N−m条为四集。全部红单P迹边数为26−(N−m)=26−N+m，外部均为四集。没有红二P迹，因为p,q击中G全部边。

每名L点原度七，故这些正约束及红坏四集的标签总出现数至多七，符合`SMALL_POSITIVE_FAMILY_REPAIR.md`。

- 若两人都c3，N=5，红坏四集至多21+m≤24，直接调用五正约束引理。
- 若包含唯一c2点，另一人c3，N=6，其中三集m≤3，红坏四集至多20+m≤23，调用六正约束引理。

因此存在外部红集R击中全部潜在单蓝边，且不包含任一红坏四集。将R红、L\R蓝，已经proper的内部边／跨色二迹保持proper；其他边也由正约束与坏四集条件保证两色。得到原H合法染色。

该caller完整允许G的重复边，不要求P点对度最小、所选外集独立或外部布局分类。

以唯一c2点为中心的五边多重星总满足caller：选该中心，再任选与它不构成missing对的一名c3点即可。因此`c2_star/PROOF.md`的完整星支也是本一般两点击中集定理的特例；原证明保留。
