# 五个至少三元正集、三个负三集：独立修复证明

## 命题

设 L 为任意有限集。正族至多五个带索引集合，每个大小至少三。负族有至多三个三集，其余为任意数量四集。假设每点在全部正负索引中的总出现次数至多七。则存在 R⊆L，击中全部正集且不包含任何负集。

不同索引允许对应相同集合。本命题不要求正三集数量上限、负四集数量上限或底集大小上限。

本证明依赖已证 [五小正集、两负三集修复](../../../../../../../proofs/propertyb35/FIVE_SMALL_POSITIVE_TWO_TRIPLES_REPAIR.md)，其准确输入为至多五个大小二至四的正集、至多三个正二集、至多两个负三集、任意数量负四集及逐点总索引次数七。本证明不使用新的有限分类、LP 或原超图枚举。

## 1. 缩短正集与无交情形

先从每个正集任选一个三元子集作为更强的正约束。若新系统可修复，所得红集也击中所有原正集；所有逐点次数只会减少。故以下可设正集全部为三集（也可仅将大于四的正集缩短为四，以下计数仍成立）。零个正集取空集。

若正集两两不交，各组独立均匀选一点，组成红集 R。记组大小为 s_i≥3。负约束含正族并集外点或同组两点时坏概率为零。其余负三集概率至多1/27，共至多三个，贡献至多1/9。

对活跃负四集 F，各点来自不同组，AMGM 给

    Pr(F⊆R) <= (1/4) sum_{v∈F} s(v)^(-4),

其中 s(v) 为 v 所在正组大小。每个正点只有一次正出现，因此负四出现至多六。按负四索引求和可得

    sum_F Pr(F⊆R) <= (6/4) sum_i s_i^(-3)
                       <= (3/2)*(5/27) = 5/18.

这里未将负三已消耗的点度返还给负四；只作安全放宽。总坏概率≤5/18+1/9=7/18<1，所以可修。

## 2. 正出现至少三的点

若某点 x 命中至少三个正标签，令 x 红，至多余两个正集。至多余一个，或两个余集相交时，可取至多两点红集，自动避开所有负集。两个余集不交时，各取一点，加 x 给至少九份不同三点红集；至多三个负三集不能堵完，负四集不能包含于三点红集。

因此以下最大正出现次数至多二。若没有重复点，已经是第1节的不交情况。

## 3. 某个正重复点属于负三集

设 x 属于两个正标签，并属于至少一个负三集。令 x 蓝，从各正集中删除 x；删去所有含 x 的负约束，因为它们已有蓝点。余负三集至多两个。只有含 x 的两个正标签可能缩短为二集，其余正集仍为三集（若使用不全部缩短的版本则为三或四集），故至多五个二至四元正集、至多两个正二集。

逐点总索引次数没有增加。上述已有五小正集／两负三集定理的全部接口成立，故给出余红集 R；把 x 保持蓝即得到原系统修复。这里没有把含 x 的负三缩成负二：因为固定 x 为蓝，整个负约束已安全，应删除而非缩短。

## 4. 所有正重复点都避开负三集

取正重复点 x 红，它命中两个正标签，且不属于任何负三集。余正族至多三个，均避开 x。

若余族至多两个，或三个余正集中存在交点 y，可以用至多两个额外点击中全部余族：先用交点 y 命中至少两族，再补最后一族的一点。因此总红集大小至多三且包含 x。它不可能等于任何负三集，因为所有负三集都避开 x；也不可能包含负四集，所以已经成功。

唯一剩余是三个两两不交的余正集 A,B,C，大小均至少三。从各组各取一点，加 x，得到至少27份不同四点红集。每个负三集避开 x，若能堵住候选，必须恰取 A,B,C 中各一个点，所以至多堵一份候选；全部负三贡献至多三。

负四集要被这种四点红集包含，必须等于该候选，因而必须含 x，每份至多堵一份。x 已有两次正出现，且没有负三出现，所以含 x 的负四索引至多五。总堵数至多3+5=8<27，至少一份候选成功。

第1至4节覆盖全部正交形和出现数，命题得证。

## 5. 来源接口及独立性

特别地，任务要求的“至多五个正3/4集、至多三个正三、至多三个负三、至多十八负四、底集至多十七点、D7”是本命题的子情形。所有原未完成单色风险仍须由调用者完整表示；本证明不会自动消除负单集或负二集。

本文件给的是通用 signed 修复引理，不替代最后实际P6输入的35条原边分类。把固定蓝点从正集中删去、删掉含该蓝点的负约束、保持其他索引，可使第3节的来源连接逐条成立。不同原负索引即使相同仍允许重复；所有堵数均按索引给上界。

同日代理25另给只导入四小正集／三负三集门的直接证明。其最后等号分支也独立核对成立：固定重复点 x 红后，余三族有交点 y，最后 A 为三集且三个 {x,y,z} 候选全堵，便迫出全部三个原负三均含 x,y；改 x 蓝、y 红，x 星两正集缩为至少二，再加 A 共三个正集，原负三全安全，含 y 原负四最多7−2−3=2，删 y 后才成为最多两个负三；其他负四不变。由四小正集／三负三集定理修复。两种证明都不需要新增负布局枚举。
