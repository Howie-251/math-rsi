# 当前两个余键的共享外点列接口与小域边界

当前完整链见 `PROOF.md`、`LOW_TAU_KEY_REFINEMENT.json`。这里只记录下一步真正需要的有限输入，不宣称共享列LP已不可行。

- S90：$7^8,8^2,9^8,10^2,11$，当前余键τ10，实际七度外池八名。
- S95：$7^9,9^9,10^2,11$，当前余键τ9，实际七度外池九名。

所有影响这些键的未修四点库存都不含七度点；K外七度池人数因此恰为全谱的七度人数，而非任意抽象锁点数。S90可受13份新四锁失败影响；S95τ9可受其中10份影响。`IMPLICATED_THREE_KEYS.json` 保存每个输入的实际outside degree重数、每类列总量、K到外点四个row总和、剩余共享τ及全体必要row直方图；其另一个S95τ8输入已由 `LOW_TAU_PROOF.md` 排除，保留作原始输入证据。

## 统一预算

每份实际库存 $\mu_T$ 的17个真实外点view必须同时满足
$$\sum_z c_T(z)=\mu_T(5-|T|),\qquad
\sum_z\mathbf1_{d(z)=r}=\#\{z\notin K:d(z)=r\},$$
以及
$$\sum_z\sum_{i\in K}\binom{\lambda(z,i)-1}{2}\le R=\tau-q_K.$$
本批影响输入的R均为0／1／2。因而全部非K内pair共度至多三；至多R个外点可能在某个K行共度三。至少七池人数减R名真实七度点的四个K行均在一／二之间。这些约束应作为同一共享列问题的约束，不可每个view重新得到R份预算。

若K中十一度点对其余K点共度和为十，其17个外点row总和34。R=0时每个外点对它都共度二；R=1时至多一名外点共度三、至多一名共度一，其余均二。若该row总和35，则R至少一，R=1时恰一项三、其余全二。若总和33且R=0，则恰一项一、其余全二。这些是视图选择时可直接使用的真实人数保证。

已有七度点之间共度至多二的独立局部门可另导入；本批的30个strict小证书和上述R预算不依赖该更强进口。本页没有无证明地从单点视图约束推导两个七度星的实际交关系。

## 已验证的低τ小域

S95τ8时R=0的两个实际源，在九七池避K-singleton外并、再用十一度row全二，得到每源十五个必要clean7 views，30份固定证书全部独立严格；两个 $9,10,10,11$ 标签运输为同一源。这已经排除了原τ8键，不需要共享LP。

对S90τ10的无singleton最坏库存
$$\mu=(15,0,0,3,0,3,3,0,0,3,4,0,4,0,0,0),$$
六pair成本恰十，所以R=0。其十一度row总和33；八七池可选真实z避唯一该row共度一的点，故仍可用十五clean7 view必要域。只试旧四个第五锁位置，第二份必要view已经不严格，立即停止：
$$c_{(3,5,6,9,10,12)}=(0,0,1,1,1,0),\quad c_0=4,\quad
(\lambda(z,K0),\ldots,\lambda(z,K3))=(1,2,1,2).$$
四个位置上界依次为 $10159/9360,109877/102960,107519/102960,35317/34320$。完整typed五锁库存及各精确值在 `LOW_TAU_NO_SINGLETON_PILOT.json`；仅处理十五域的前二份，未称全域已跑。这是必要view未过界，不是实际H或反例。

因此最坏源的同一点七度星、同四位置、上述强行条件本身尚不能给统一cap12。下一步若继续，需要共同实际外点列／共享τ／更强原vertex-capacity，而非继续扩位置。本目录没有对其余τ9／10输入扩新七星表或LP。
