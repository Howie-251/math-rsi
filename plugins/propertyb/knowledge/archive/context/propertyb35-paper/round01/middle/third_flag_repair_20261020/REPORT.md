# 三边private flags：精确公式、共享容量与A1聚合停点

本轮没有闭合A1。独立核对了三边概率和非B下界，推得按同一实际外边对、同一点对共度收费的旗容量；一个44型小聚合仍有精确可行见证，不能推出要求的严格上界。没有枚举H、原三边全集或负布局；没有Lean/MCP。验算为same-family/provisional确定性证据。

## 1. 随机量和实际原边绑定

在n点五元H上均匀取a点红。设X为单色原边数。对单色原边G及g∈G，令m_g为原边F≠G中满足F∩G={g}、且F\{g}全为G反色的数量。令

    U = Σ_{G单色} Σ_{g<h∈G} m_g m_h.

每项是一个带 distinguished G 的无序原边对{F,H}，F/H在G上的唯一交点不同。因此F≠H；它不是任选两份独立阻塞库存。

若H非B，每份唯一单色边染色的G五点都必须有private边，否则单翻缺private的点即proper。因此该染色U≥10。其他染色U≥0。又非B使X≥1，故P(X=1)≥2−EX=2−Mp，于是

    EU ≥10(2−Mp).

对固定G,F,H，设G∩F={g}、G∩H={h}且g≠h；令j=|F∩H|。共同交不在G内，固定颜色为G的五点一色、(F∪H)\G的8−j点反色，剩n−13+j点自由。计数恰为

    beta_j = [C(n−13+j,a−5)+C(n−13+j,a−8+j)]/C(n,a).

两个分子分别对应G红、G蓝；F/H无序，不再乘二。n21,a10时分子依次为84,210,462,924,1716，分母352716。M35时p=2/57，所以非B必要EU≥440/57；等价加权flag分子至少2722720。这些公式由VERIFY.py独立整数复算。

## 2. 用同一原边对共同收费的容量

记f_j为所有上述结构flags中外边对{F,H}交j点的数量，n_j为交j点的无序原边对数量。令D为最大原点度，lambda_gh为原点对共度。

固定外边对F,H，其差集A=F\H、B=H\F各有5−j点。每条flag原边G必须各取A、B中的恰一点，并避开F∩H及A/B其余点。它占两个差集点的边关联。每个差集点在扣去自己的外边后至多D−1条原边，故

    f_j ≤ min(M−2,(5−j)(D−1)) n_j.                         (1)

还可直接用跨对(g,h)∈A×B收费。其flag边数至多lambda_gh，因此以每个跨对两次为基线，

    f_j ≤2(5−j)^2 n_j + Σ_{g<h} M_j(g,h)(lambda_gh−2)_+,

其中M_j(g,h)是实际外边对交j且g/h分别位于两差集的数量。F必须含g不含h、H含h不含g，因此

    M_j(g,h)≤(d_g−lambda_gh)(d_h−lambda_gh).

j=4更强：F={g}∪T、H={h}∪T，由简单性每份F至多对应一份H，故

    M_4(g,h)≤min(d_g,d_h)−lambda_gh.

A1的D9于是给出

    f_2≤18n_2+Σ(9−lambda)^2(lambda−2)_+;
    f_3≤ 8n_3+Σ(9−lambda)^2(lambda−2)_+;
    f_4≤ 2n_4+Σ(9−lambda)  (lambda−2)_+.                 (2)

式(1)(2)是实际共同容量，不把每个flag的高共度来源独立挑选。它们对其他已知最大度的中点支也有同样D参数版本。不能由此断言所有边对都可同时达到容量。

## 3. 完整小聚合域

A1谱6,7,8^9,9^10给

    W=Σ_v C(d_v,2)=648，R=Σ_v C(d_v,3)=1399。

点对覆盖给210个点对、Σlambda=350。记c_l为共度l的点对数，1≤l≤9，tau=ΣC(l−1,2)c_l。已有非B修复判据给n1≥397。

每个无序三原边型可由三个两两交数(a,b,c)及三重交t刻画。取0≤a≤b≤c≤4、0≤t≤a，并要求

    5−a−b+t≥0，5−a−c+t≥0，5−b−c+t≥0。

这些正是七个Venn原子非负条件；总并≤15，21点不再加限制。恰44型，VERIFY.py从三个有标签交数的独立product枚举取商确认。记型重数z_q。使用以下全部必要条件：

* Σn_j=595，Σj n_j=648，ΣC(j,2)n_j=140+tau，n1≥397；
* 每种j在三边型出现的总次数等于33n_j（每个原边对有33个第三原边）；
* Σt z_q=1399；
* Σc_l=210，Σl c_l=350，tau=ΣC(l−1,2)c_l；
* ΣC(t,2)z_q=ΣC(l,3)c_l，保留同一共度分布的三重共点矩；
* 由每型逐 distinguished 索引恢复f_j，并施加(1)(2)。

型q只有t=0且某个distinguished边的两个交数均为1时贡献flag，外边对交数决定beta_j；型(1,1,1;t0)贡献三个beta1，型(1,1,4;t0)贡献一个beta4。t>0的三边型不贡献此类flag。

AGGREGATE.py只对上述约59变量的小放松调用一次最终LP；各次诊断CPU均不足0.01秒。没有使用求解器输出作正确性证明：最终保存的精确可行分数见证及下面手工整数见证均由不导入scipy的VERIFY.py逐式核验。

## 4. 精确停点：即使所有聚合计数取整数仍不足

一个整数聚合见证为

    (n0,n1,n2,n3,n4)=(28,540,0,0,27)，tau=22；
    (c1,c2,c3,c4)=(90,102,16,2)，其余c_l=0。

非零三边型数为：

|两两交数|三重交t|型重数|
|---|---:|---:|
|000|0|308|
|111|0|4684|
|111|1|678|
|114|0|170|
|114|1|697|
|444|3|8|

总三边数6545；三重共点一阶矩1399、二阶矩24，后者恰等ΣC(l,3)c_l。所有(1)(2)容量均成立。尤其f1=14052、f4=170，且式(2)的j4右端为

    2·27+(9−3)(3−2)·16+(9−4)(4−2)·2=170。

其加权flag分子为

    14052·210+170·1716=3242640，EU=270220/29393≈9.193，

大于非B必要下界440/57≈7.719。因此这些必要条件并不能推出EU严格小于目标。这里的整数只指聚合数整数，绝不是一个已实现的H或不可染反例；没有构造35条原边。最终LP分数见证EU=4113/442也完整保留在AGGREGATE.json，整数见证在VERIFY.json。两者都只用于证明当前放松不足，不宣称LP精确最优。

## 5. 哪一级关联仍缺失

三阶flag确实比n1多保留了真实信息，尤其交四边对的旗数不能自由取33；(2)又把它与同一高共度点对绑定。但聚合见证仍可让大量不同交四边对，共同利用少数lambda3/4点对，并让各自的最大匹配式差集容量同时饱和，而未证明这些边索引、四点公共核和全体点度能由同一个关联矩阵实现。

因此最窄剩余是这种“差集点对—公共四核—原边索引”共同支持，或保留高交数边对在边星中的邻接结构；不是beta的颜色方向、无序系数或单纯新增一个全局矩。现有A1谱、n1下界、pointpaircover、二／三重共点矩和上面两种真实共享容量尚不足。此处停止，不从可行聚合数外推H存在，也不继续扫描三边全H或新增源选择。
