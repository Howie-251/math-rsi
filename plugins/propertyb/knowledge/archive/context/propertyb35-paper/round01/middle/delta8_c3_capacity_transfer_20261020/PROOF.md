# δ8真实十五度谱的三交middle容量十三迁移

## 精确结论

设H是21点35条互异五元边，所有点度至少8，且所有不同点对的共度均至多4。对任意两条交三点的原边G,J，令c(G,J)计满足F∩G={g}、F∩J={j}、g≠j的实际原边F。若c(G,J)≥14，则H有Property B。

所以在所述全部条件下，非B原H满足c(G,J)≤13；求和得C3≤13n3。本结论仍以**全局共度≤4为明确条件**，不在本文证明该条件；它不直接宣称δ8全闭。本文不需要paircover、外点的额外局部布局、六度中心、Γ低度、critical或全局n4≤13。

全体点度至少8只用于把四个selected点的度数组合压到本文完整真实谱支持；固定四锁证书本身不使用未锁17点度数的任何额外限制。

## 2. 实际middle到exactcross数量t14…16

写A=G\J、B=J\G，各二点；给K=A∪B标记0,1属于A、2,3属于B。对35条不同原边索引的精确K迹记μ_T。两实际outer给μ3≥1、μ12≥1。

每个合法middle必须在A及B各取一个点，而且不能带G∩J的点。因此其K迹是5、6、9、10之一，令

    t=μ5+μ6+μ9+μ10 ≥ c(G,J)≥14。

反向不成立：exactcross原边可能还带G∩J的点。本证明只用上述必要方向，未把所有exactcross都当合法middle。cross四个pair各共度≤4，故t≤16。

若p为所有三迹重数和、q=μ15，则inclusive cross总容量给

    t+2p+4q≤16。

因此q=0，t14时p≤1；t15/16时p=0。没有遗漏四迹、多重三迹或两个不同三迹。

同侧精确pair Acount=μ3、Bcount=μ12各1…4；若三迹占用同侧pair，剩余精确上限降到3。给定cross四个精确数、至多一个三迹与两侧pair，就得到全部高迹。给定selected原度d_i，恢复

    μ_{i}=d_i−Σ_{T∋i,|T|≥2}μ_T，
    μ0=35−Σ_{T≠0}μ_T。

只保留各项非负，完整包含每个实际H的投影；不要求每个必要库存可实现成原H。

## 3. t15／16的解析可达范围

t16时四个cross数全4，每个selected点cross行和8。再加同侧实际outer各至少1，四点度都至少9；但五个新增四点degree多重集中至少两名八度，因此t16在全部新增域不可能。

t15时四个cross数必为(3,4,4,4)的一个排列。每个side的cross行和恰7、8，故每side必须有一个degree≥9点。低八度点只能占行和7的一行。只有一个高点的(8,8,8,14)/(8,8,8,15)因此不可能；另外三个双高点型只能把两高点分到两侧。原枚举自动满足这些必要条件，所得t15标签仅24；t14标签388，总412。该解析分流不作为额外遗漏输入的未经验证剪枝。

## 4. 固定旧菜单、真标记群与全部严格证书

只使用旧c14全部证书中出现的三份固定位置：

    (8,9,20,21)，(9,10,20,21)，(9,20,10,21)。

没有调用布局求解器、SubsetEngine.solve、LP或新位置搜索。所有配额与额外扣除设零，N=21，锁4点、余17点按同一均匀排列样本计数。对每位置计算已证明条件排列判据U=Σ_k min(A_k,B_k,C_k)。

用两侧各自换位和交换两侧生成真8元标记群，运输同一个原K的全部迹和degree；不假设完整H有任何自同构。412标签恰62代表。全部62代表在上述旧菜单内有严格证书，最大

    U≤1427/1716<1。

将某实际输入同一重命名搬到代表，执行所存固定位置，并由条件排列引理返回原35条边的proper染色。证书不是只说明一个抽象迹表存在。
