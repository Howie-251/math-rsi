# S95在τ八的三个实际四点余尾：十五视图七度星修复

## 精确局部结论

设H为21点35条互异五元边的点对覆盖超图，全部点对共度至多四，点度谱为S95
$$7^9,9^9,10^2,11.$$
若全局 $\tau=\sum_{x<y}\binom{\lambda(x,y)-1}{2}=8$，则每个三交外边对的合法中间边数至多十二，或者H已经有Property B。

本页只补全该实际τ八caller；没有把一般的 $9,10,10,11$ 四点型无条件计为已证cap12。三交四点classification、其他strict证书及τ过滤的完整域，见本目录 `PROOF.md` 和 `independent/`。

## 1. 完整余尾与真实六pair预算

在S95的τ八完整必要四点域中，既有门和本次新三布局strict证书后，仅余下列三个标记库存。前两个selected degree型为 $9,10,10,11$，后一个为 $9,9,10,11$。按mask0…15重数：

$$\begin{aligned}
\mu^{(A)}&=(14,0,0,3,1,3,3,0,1,3,4,0,3,0,0,0),\\
\mu^{(A')}&=(14,0,1,3,0,3,3,0,1,4,3,0,3,0,0,0),\\
\mu^{(B)}&=(15,0,0,3,0,3,3,0,1,3,4,0,3,0,0,0).
\end{aligned}$$

它们六个K内inclusive pair的总τ成本均恰八。由 `K6_BUDGET_LEMMA.md`，所有不完全在K内的实际pair共度均至多二。

$A'$ 经K重命名 $0\mapsto1,1\mapsto2,2\mapsto0,3\mapsto3$ 运到A。实际库存、degree与固定位置一同运输。该新局部星门不依赖旧outer的A/B侧，所以允许此S4重命名；没有声称H具有自同构，也没有把旧marked四锁classification的D8扩成S4。

## 2. 一个真实七度外点必满足所用强约束

A与B的selected degree十一点都是K3；它和其余三名K点的inclusive共度和均十。故该点对17名外点的共度和为
$$4\cdot11-10=34.$$
每项已知至多二，所以17项全部等于二。

K本身不含七度点，故K外恰有九名真实七度点。A只有两条K-singleton原边，每条在K外恰四点，其外并至多八；B只有一条K-singleton原边，其外点四名。两种情形都可选真实七度点z避开全部K-singleton原边。三／四迹在这两个库存中均不存在。因此z的七条不同原边只来自K空迹与六pair迹。

对每名K点，paircover和六pair预算给
$$1\le\lambda(z,i)\le2,$$
而对K3还必须有 $\lambda(z,3)=2$。这是同一原H的真实选择；没有假设一个任意抽象度七点可避全部singleton边。

## 3. 完整十五库存

按pair顺序 $(3,5,6,9,10,12)$ 记经过z的原边重数为 $c_m$，令 $c_0=7-\sum c_m$。完整必要域为
$$0\le c_m\le\min(\mu_m,2),\quad0\le c_0\le\mu_0,\quad
1\le\sum_{m\ni i}c_m\le2,\quad\sum_{m\ni3}c_m=2.$$
两种库存的六pair原容量均至少二，所以该必要c域相同，各有十五份。它们的35条原边、五锁顺序 $(z,K0,K1,K2,K3)$ 的exact重数恢复为
$$\nu_{2m+1}=c_m,\qquad\nu_{2m}=\mu_m-c_m,$$
singleton迹的 $c_m=0$。实际H的所选z必落此域；允许不同原边有相同投影。

只用旧四个位置
$$(1,8,9,20,21),\ (10,8,9,20,21),\
(11,8,9,20,21),\ (12,8,9,20,21),$$
配额全部零，没有新位置搜索、DP或LP。十五份A全部严格，最大 $64/65$；十五份B全部严格，最大 $1413/1430$。

## 4. 独立完整域与原35索引重放

`LOW_TAU_VERIFY.py` 另枚举四个inclusive z-K行值（每项一／二且第3项二），再枚举 $c_3,c_5,c_6$，由前三行唯一恢复其他三pair重数并核第四行。两种源的十五c域与主生成逐项相等。

每份库存展开35条原边索引，以1190个有序异边对逐行计算N=16的注入界。三十份选定证书的630行与保存的精确分数全部相等，且全部小于一。`LOW_TAU_VERIFY.json` 为PASS，CPU0.221379；完整行在 `LOW_TAU_VERIFY_ROWS.json`。两个源的主算分别0.067570、0.062858 CPU秒。
