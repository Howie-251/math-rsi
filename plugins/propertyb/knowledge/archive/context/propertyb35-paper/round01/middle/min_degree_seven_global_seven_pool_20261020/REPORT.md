# 全e域共享七度池：原边行预算与最大七度池的短归约

输入为21点、35条互异五元边、覆盖所有点对、最小原度恰七，反设非B。进口前一目录已核的旧双／三锁结论：Δ≤18；若七度点数a≥3，则所有七度pair共度≤2。另进口新完整min7⇒Γmin4纸面定理。没有e≤4或全点对λ≤4假设。

本轮新增的有效结论是一个对每条实际原边的共享七度pair预算，以及最大七度池a=18的解析E下界。没有闭合某个新的整图染色分支，也没有新布局／moment扫描。三个小程序总CPU约0.025秒；原高迹必要域980项不是H分类。

## 1. 共享七度pair预算：一个无e限制的一般引理

令L为全部七度点，a≥3。对一条实际原边F，令R=F∩L，r=|R|，k=5−r，D_F=Σ_{v∈F}d(v)，q=qΓ(F)。则

**D_F−39 ≤ kq + C(r,2)。**

证明：每个R内pair已在F出现，而全局共度至多二，因此

Σ_{E≠F} C(|E∩R|,2) ≤ C(r,2)。

这数的是同一F外的实际原边与同一批七度pair，不能为每条E各花一份独立预算。令l=|E∩R|。其余F点只有k个，且l−1≤C(l,2)，所以

|E∩F|−1 ≤ k+C(l,2)。

恰单交E的左端是零，可从求和中省去；不单交的q条E逐条应用上式。另一方面，34条其他原边给

Σ_{E≠F}(|E∩F|−1)=Σ_{v∈F}(d(v)−1)−34=D_F−39。

合并即证。空交E的负贡献方向安全。若k>0，于是

qΓ(F) ≥ max{4,ceil((D_F−39−C(r,2))/k)}。

其中4只使用已得Γmin4，不需要全λ≤4。几个重要特例：

- 两名非七度点u,v加三名七度点：q≥max(4,ceil((d(u)+d(v)−21)/2))；18²给q≥8，17/18及17²给q≥7。
- 三名非七度点加两名七度点：q≥max(4,ceil((三点度和−26)/3))。
- F全七度时，实际公式给至少四条与F不交的原边；这与Γmin4一致，不虚加新改善。

这条引理覆盖任意e、任意未选点度和全部实际原边。与旧独立度数行最小／最大值不同，它使用同一F的七度pair在所有其他边中只可再出现一次的共享总预算。

## 2. 同一高点link／两高点的七度池关联

若高点h度17或18，旧完整双锁门迫每个x∈L有λ(x,h)=3。令ℓ_E=|E∩L|，则在h的全部原边上

Σ_{E含h} ℓ_E=3a，
Σ_{E含h} C(ℓ_E,2)≤2 C(a,2)。

后一式是同一七度pair最多出现两条原边的预算，不是各h边独立可选的局部库存；单用它仍很松，本轮没有由此排除整谱。

若h,k均度17/18，c=λ(h,k)，T=Σ_{E含h,k}|E∩L|，则每个x∈L的7条原边按含h/k分成四格。因为它与两高点各共度三，其避h,k的边数恰1+t_x，其中t_x为三重包含数。因此

Σ_{E避h,k}|E∩L|=a+T。

至少a−16名低点必须出现在每条含h,k的五边中（负下界取零）。结合避h,k的边数35−d(h)−d(k)+c，得到安全的共同容量限制

a+max(0,a−16)c ≤5(35−d(h)−d(k)+c)。

对a=18，简化为

c ≥ ceil((18+5(d(h)+d(k)−35))/3)。

于是18²的实际共度至少8，17/18至少6，17²至少5。这里不使用这些高点对共度≤4；恰相反，它们是必须允许的大共度。

## 3. a最多18；a=18仅五个高点度型

Δ≤18与总度175给175≤7a+18(21−a)，故a≤18。a=18时余三点总度49，每点≤18，完整度型只有

(13,18,18)、(14,17,18)、(15,16,18)、(15,17,17)、(16,16,17)。

这五型的全部高点精确迹可由三个高pair共度c01,c02,c12及三重包含数t恢复：

μ7=t；μij=cij−t；μi=D_i−cij−cik+t；μ0=35−49+Σcij−t。

PILOT.py只遍历非负上述整数，并施加各高点对整个18名七度点的真实共度和

L_i=4D_i−Σ_{j≠i}cij

处于18份旧(7,D_i)允许λ的区间。五型分别47、30、406、44、453份，合980；再显式核§2共享两高容量，没有额外删项，因为在仅三个非七点时该式已被完整精确迹与度数行蕴含。这一点不能宣传为额外980项排除。

## 4. a=18的解析Γ边数下界

令p为恰含两高点的原边数，t为含全部三高点的原边数，v为不含高点的原边数。三高总度49与原边数35直接给

p+2t=14+v≥14。

记EΓ为Γ的无序边数。Γmin4使全部35条边的行度先贡献140。

### 三高都不超过17

这时三高总度49使任意高pair度和至少32。§1给每条恰含两高点的原边q≥6，含三高点的原边q≥ceil((49−26)/3)=8。因此

2EΓ=Σ_Fq(F)≥140+2p+4t≥168，故 **EΓ≥84**。

此情形恰对应(15,17,17)、(16,16,17)。

### 恰一名18度点

两条含该18点的高pair，其度和至少32，故对应恰二高原边的q至少6；第三高pair的度和31，对应q至少5；三高原边q至少8。设p_h为恰含两高且含18点的原边数。该18点对18七度点各共度三，其原共度行给

两个高pair共度之和=4×18−18×3=18，故p_h+2t=18。

于是2EΓ≥140+2p_h+4t≥176，故 **EΓ≥88**。未计入第三高pair边的正盈余只放松上界。这处理(14,17,18)、(15,16,18)。

### 两名18度点

第三高点为13。令p0为恰含两个18点的原边数，p1,p2分别为含13和一名18的恰二高边数。两名18点的共度行分别给p0+p1+2t=p0+p2+2t=18，故p1=p2。§1分别给q下界8、5、5，三高仍8。因此

2EΓ≥140+4p0+p1+p2+4t=176+2p0≥176。

仍得 **EΓ≥88**。

故所有a=18的非B必要输入统一EΓ≥84；含18度点则EΓ≥88，等价n1≤511／507。此为真实H的解析限制，不是染色闭合。ROW_PREFIX.py在上述980必要域完整核这些下界，五型的最小下界分别88／88／88／84／84，存在必要松弛键达到它们；未断言其H可实现。

## 5. 七度池同时给τ的无全λ≤4范围

令τ=Σ点对 C(λ−1,2)。七度pair的λ≤2，所以它们对τ贡献恰零。a=18时τ全部来自七／高交叉pair和三条高pair。给定一个高点度D_i及其低侧总共度L_i，在18个实际七度点上分别使用旧允许集

D13/14：{1,2,3,4}；D15/16：{2,3,4}；D17/18：{3}。

以18次有限卷积对每个精确L_i计算Σ C(λ−1,2)最小／最大值，再加三高pair的精确费用。这是各高边际的安全松弛，不要求独立最优分配同时可实现；最小值给下界，最大值给上界。TAU_POOL.py对980必要高迹逐键完成，得到：

|三高度型|EΓ下界|τ必要区间|
|---|---:|---|
|13,18,18|88|113…187|
|14,17,18|88|104…140|
|15,16,18|88|103…171|
|15,17,17|84|89…135|
|16,16,17|84|85…167|

不能套全λ≤4才有的τ≤140；本表真实容许高pair大共度。它只收紧a=18的实际moment接口，本轮没有继续扫描moment。各键的τ范围及达到边际松弛极值的见证保存于TAU_POOL_RESULT.json。

## 6. 可复用的整个七度池恒等式与边界

对于一般a≥3，令B为非七度点集，b=21−a，C_B=Σ_{u<v∈B}λ(u,v)。七度点之间共度只有一／二，因此将共度二的pair视为简单图，其真实边数为

Q_L=Σ_{pair⊂L}(λ−1)=(57a−a²−700)/2+C_B。

这是七度行总重复8a减去同一批七／高交叉关联的恒等式：交叉总共度=4Σ_{v∈B}d(v)−2C_B，Σ_Bd=175−7a。特别0≤Q_L≤min(C(a,2),4a)。它保留了整个低点图与高点pair总量的联系，但本轮没有发现它单独迫e≤4或排a≤17。对a18给Q_L=1+C_B，与完整高迹的低pair计数相同。

本轮真正可排的是：a≥19（由旧Δ门和总度）、a18的EΓ<84，以及含18度点时EΓ<88，另有上表τ必要域外的键。没有新增整谱染色结论。继续时应把这些约束作用于同一实际高迹／七度池，而不是把各边际最优星拼成原H；原unit8自由扩表不适合a18的零八度池。
