# A1高四交：交核含六／七度点的完整修复子类

## 1. 已证范围

**PROVABLE AS STATED（纸面证明及精确局部证书，新的跨家族审阅尚待）。** 设H为21点35条互异五元边、覆盖全部点对，处于A1实际角色：唯一六度x、唯一七度p，四名八度B与x共度二，五名八度U和十名九度V与x单位，p也与x单位。如果有两条不同原边E,F满足

$$|E\cap F|=4,\qquad (E\cap F)\cap\{x,p\}\ne\varnothing,$$

则H有Property B。

这是一个完整的高交子类，没有要求指定E或F可被选作唯一坏边。下文从实际边交核恢复局部库存，概率证书直接作用于同一H并给原染色。未证明“A1任一三／四交对即可修复”。所以非B的必要结论只是：**全部四交对的交核避开x和p。** 三交对和高度点组成的四交核仍保留。

原A1角色入口见[A1_FINAL_ROLE_ENTRY.md](../../twentyone-high/unique6_with7/new_structure_20261020/A1_FINAL_ROLE_ENTRY.md)。这里没有使用旧五U残核的额外结构，只使用上述实际度数和中心共度。

## 2. 共同概率判据及强共度进口

使用既有[排列概率引理](../../../../../proofs/PROBABILITY_LEMMAS.md)：把s个不同实际锁点固定在各自记录的位置，其他21−s点均匀无放回排列。对每个位置k分别计算临界边事件的A、B、C三个支配数；C按真实不同原边索引的有向对计数，再扣除不可能临界的共同link边对。若

$$\mathcal B=\sum_{k=1}^{21}\min\{A_k,B_k,C_k-\ell_k\}<1,$$

便有实际H的proper二染色。这里不是对一个抽象库存任意补边，而是任意实际H具有该库存即受同一界支配。

本证书的每个中心i使用嵌套配额

$$q_i=\left\lceil\frac{4d_i-20}{3}\right\rceil,\qquad
q_i^{\rm pure}=\max\left(0,\left\lceil\frac{4\mu_{\{i\}}-(21-s)}3\right\rceil\right).$$

总配额来自点对覆盖的中心link盈余及不同四元link交至多三；纯配额只对避开其余锁的原边使用自由点数21−s。先在纯pair槽取足纯配额，剩余总配额在未用槽中按非负权重从小到大取，所得是实际扣除的下界，不能将两份配额直接相加。具体无放回权重和原35索引独立实现是[fixed replay](../../twentyone-delta5/replay.py)及其所用 `computations/independent_structure_bounds.py`。

首先排掉以下完整强点对。表中的共度区间包含该度对所有剩余可能值：

## 3. 四交核含x：36项完整域

若E∩F含x，其余三个交点必须属于B：它们各与x至少共度二，而A1只有B四点非单位。记其中三个为b1,b2,b3。每个xb_i共度恰二，因此含x且遇其中任一个b_i的边只能是这两条E,F；其对四锁K={x,b1,b2,b3}的迹全为K。另四条过x边均只有x迹。

将三B在29条避x边内的包含数记为

$$a=I_{b_1b_2}^{\bar x},\quad b=I_{b_1b_3}^{\bar x},\quad c=I_{b_2b_3}^{\bar x},\quad t=I_{b_1b_2b_3}^{\bar x}.$$

原B/B共度至多四，E,F已贡献二，所以a,b,c∈{0,1,2}；0≤t≤min(a,b,c)。标签x,b1,b2,b3依次为bit0…3，实际精确迹库存必为

$$\mu_{15}=2,\quad\mu_1=4,$$
$$\mu_2=6-a-b+t,\quad\mu_4=6-a-c+t,\quad\mu_8=6-b-c+t,$$
$$\mu_6=a-t,\quad\mu_{10}=b-t,\quad\mu_{12}=c-t,\quad\mu_{14}=t,$$
$$\mu_0=11+a+b+c-t,$$

其余为零。这里的整数是bitmask，不是子集大小。参数域有36项，全部库存非负、总数35、度向量(6,8,8,8)。[GENERATE.py](GENERATE.py)完整产生并计算36份固定证书，最大

$$\max\mathcal B=\frac{11676}{12155}<1.$$

因此这一整个实际子类已修复。

## 4. 四交核含p：4254项完整必要域

若四交核同时含x,p，则xp共度至少二，直接违反A1单位性；所以本节交核K不含x。给K按p,a,b,c标号，度向量是

$$(7,8,8,8),\quad(7,8,8,9),\quad(7,8,9,9),\quad(7,9,9,9).$$

无需假设两条高交边避x；其中一条可以是x星原边。令q=μ15≥2。对四个三点mask，枚举其精确迹数μT；对六个二点mask再枚举精确迹数μP。每个所选点对的总包含数是

$$c_{ij}=q+\sum_{T\supset\{i,j\},|T|=3}\mu_T+\mu_{\{i,j\}}.$$

强点对门给cij≤4，若该对度为7/8则≤3。由q≥2，任何精确三迹数至多二，故枚举μT∈{0,1,2}已经覆盖全部实际选择。先选q=2…min(pair caps)，再选四个μT，按每对余容量选择μP，即穷尽全部高迹及二迹。

单迹和空迹唯一恢复为

$$\mu_{\{i\}}=d_i-\sum_{T\ni i,|T|\ge2}\mu_T,\qquad
\mu_0=35-\sum_{T\ne\varnothing}\mu_T.$$

筛除负库存，并保留真实行盈余条件

$$\sum_{j\ne i}(c_{ij}-1)\le4d_i-20.$$

该条件只计核内行盈余，不假设自由点度数。以上每个筛选均是实际H必要条件；保留的库存可以不延拓成H，不影响充分覆盖。

四锁已严格项最大934/935<1。其余八项原结果保留在RESULT的p_nonstrict_ids，最大12234/12155>1；不将它们改写为严格项。下一节用同一H的真实x星共同扩张，完整关闭它们。

## 5. 八残的真实x星：59项完整五锁扩张

对每一残库存μ，给每个四核迹T设hT为含x原边中该迹的条数。它满足

$$0\le h_T\le\mu_T,\quad\sum_T h_T=6,\quad
\sum_{T\ni i}h_T=\lambda(x,i).$$

p和全部V点的右端恰一；唯一可能八度核点或者属于U（右端一）或者属于B（右端二）。因此对前三个(7,8,9,9)残，各保留这两个实际角色分流；其余五个(7,9,9,9)残全部单位。

发现实现把四个单位核点（若八度非单位则加它的第二份occ）划分到六条真实中心边。一个块不得含同一核点两次，块大小至多四，块数至多六；未遇核点的中心边归h0。只筛hT≤μT。由于p单位，h15≤1，含x全五核的边没有重复。这是中心边迹的完整必要表示，并没有把所有20点的link假设为分割。

把x作为新bit0、旧四核bit整体左移一位，五锁库存为

$$\nu_{(T\ll1)\,|\,1}=h_T,\qquad \nu_{T\ll1}=\mu_T-h_T.$$

这保持全部35条原边，中心度六及四核原度不变。8个残标签的扩张数依次是10、10、10、5、6、6、6、6，总59；前三项各由单位、二重两个角色的各五项组成。全部59项严格，最大

$$\max\mathcal B=\frac{11269}{11440}<1.$$

所以每份实际p四交核，要么四锁证书已经严格，要么其同一x星的真实h落在这59项之一，五锁证书严格。两种情形都给H的原染色。

## 6. 独立域与固定证书验核

[VERIFY.py](VERIFY.py)不导入GENERATE、EXTEND_EIGHT或SubsetEngine；采用两种不同的有限表示：

- 四核域：先选六个inclusive共度cij，再选四个inclusive三点数Iijk和四点数q，最后按Möbius反演恢复精确μ。单迹公式为di−Σcij+ΣIijk−q，空迹为35−Σdi+Σcij−ΣIijk+q。恢复4254个完整键，与发现域逐键集合相等；不是只比较总数。
- 五锁扩张：直接对可能迹T递归选择非负整数hT，满足剩余四个点边际及六条中心边总数，再恢复h0；与分割occ表示的全部59个(source id,角色,h向量)键相等。

随后它将每份库存展开为35个带索引stub，按保存的各自锁位置重算21行A/B/C及嵌套link扣除，核对原有分数。4295份双／四锁库存全部重放（包含八份如实非严格的诊断项），其中4287项严格；另59份五锁全部严格。15个旧强点对固定进口也逐原边重放。结果[VERIFY.json](VERIFY.json)为PASS。
