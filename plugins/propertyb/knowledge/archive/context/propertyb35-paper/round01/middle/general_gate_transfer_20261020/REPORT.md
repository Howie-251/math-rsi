# 新小正族门迁移到23点六度星：两点小负横截的实际条件支

## 结论和范围

本轮选择23点最小度六的稀少低单位支。完成一个从原H返回染色的**条件子定理**：

> 设H为23点、35条互异五元边、点对覆盖的超图，存在六度中心x；除至多一个九度点外，所有点度数至多八。若存在H删去所有含x边后的proper染色，给x选一个产生至多三个同色单色link四集的方向，使活跃负单／负二族可由至多两点击中，则H可二染色。

它完整覆盖上述实际输入条件，没有丢负单／二，也不要求signed次数七。特别适用于旧稀少低单位两全局谱

$$6^4,7,8^{18},\qquad6^5,8^{17},9.$$

**没有证明两谱都能选到这个两点横截初态，故未新增23δ6或两谱整支的无条件闭合。** 真正剩余已经可以写成：对所有六度中心、所有proper删星染色及所有至多三正块方向，小负横截数都至少三；另保留旧至少三个低单位的一般分支、23δ7，以及其他点数的开放义务。

同时保存一个精确signed障碍，证明不能仅凭本报告使用的局部关联／次数界，把“两点”直接改成“三点”。它不是实际H，不反驳存在好中心／好初态的选择式。

## 2. 一个直接的小正参数推论

**引理A。** 至多三个正集，每个大小至少三；所有负集大小至少三；正负带索引总出现次数逐点至多九。则可修复。底集与负条数任意，允许索引重复。

若有点击中至少两个正集，再从至多一个剩余正集选一点，可取至多两红，自动避开所有负集。若没有交叠，正集两两不交；正数至多二也同理可取至多两红。

只需恰三个不交正集，大小为g1,g2,g3≥3。每组独立均匀取一点，形成三红。负集大小大于三不可能包含于这个红集。按与[四正参数门](../../../../../proofs/propertyb35/FOUR_POSITIVE_AT_LEAST_THREE_REPAIR.md)相同的AMGM逐点收费，正并内每点正出现一次、负出现至多八，故

$$\Pr(\text{某负三全红})\le\frac83\sum_{i=1}^3\frac1{g_i^2}
\le\frac83\frac3{3^2}=\frac89<1.$$

没有补正集，也没有因补齐而改变D。这个引理只作本报告的短推论，不在本轮新增canonical门。

因此，若下面实际删星系统的小负族有公共点f，禁f后正四缩成至少三，全部小负整份删除，真实D≤9，即由引理A立即修复。下一节证明两点禁集也能处理，实际利用更强的中心共同link预算。

## 3. 从同一原H得到完整signed系统

固定任意六度x。六条含x边删x后记为四集A1,…,A6。点对覆盖给六块并恰为22个其他点；总关联24，故

$$\sum_{i=1}^6|A_i|-\left|\bigcup_{i=1}^6A_i\right|=24-22=2.\tag{1}$$

它们可以有交叠，不允许当作25点的六块划分。对任意子族以及任意点集F，有

$$\sum_{A\text{ 属于该子族}}|A\cap F|\le|F|+2.\tag{2}$$

理由：全族每点重数r_v≥1，$\sum_v(r_v-1)=2$；子族的点重数不超过全族。

删去所有含x边后恰有29条原边；已验至多32边可染定理保证这个删星超图存在proper染色。取任意这样的染色。六块中全红数a、全蓝数b满足a+b≤6，所以给x选择一色c，使同色单色四块数m≤3。只允许原c色点翻成对色，x保持c。m个同色四块是正族，正并记U。

对每条避x原边e，令B_e为它初始c色部分。proper性给1≤|B_e|≤4。取翻转集R⊆U，则e新变全对色当且仅当B_e⊆R；它原有的对色点不翻，所以不可能新变全c。不是给每条零迹边擅自删一个风险。

若B_e不包含于U，它永不包含于R，可将该负索引整份删除；**不能取B_e∩U作为新的小负集**。余下至多29个活跃负集，大小1…4。

对v∈U，令a_v为m个正索引含v的次数。避x原边中每条含v的边，其B_e均含v，未删inactive前负出现恰为d_H(v)−λ(x,v)。故真实signed出现为

$$a_v+d_H(v)-\lambda(x,v)\le d_H(v),\tag{3}$$

因为a_v≤λ(x,v)。删除inactive索引只减次数。两谱使除至多一个点外d_H(v)≤8，例外点度至多九。没有误用D7。

## 4. 两点小负横截的完整修复

设活跃负单／负二族有横截F，|F|≤2。可取F⊆U；若原横截含U外点，去掉它不影响击中任何活跃负集。固定F为不翻转，整份删除遇F的负索引。所有小负均已安全；剩余负集大小仍至少三，没有缩短负集。

每个正四集删F后大小至少二。若m≤2，各取一点，至多两红，自动避开剩余负集。若m=3但剩余正集有交叠，取一个交点及至多一个额外点，同样只需两红。

故只需三个剩余正集P1,P2,P3两两不交，大小g1≤g2≤g3。由式(2)，总删除关联至多四，因此

$$2\le g_i\le4,\qquad g_1+g_2+g_3\ge12-4=8.\tag{4}$$

各组取一点得到N=g1g2g3个不同三点横截候选。其最小组大小为g=g1，有

$$N\ge8g.\tag{5}$$

确实：g=2时另外两组均至少二、和至少六、各至多四，其乘积至少八；g≥3时另两组乘积至少九。

任何阻塞候选只能是恰等于该候选的负三，每个候选的阻塞索引均含最小组P1中的一点。由于删后正集两两不交，P1中的每点原来也只属于一个正块（删除F不会使其他保留点失去其原正归属），其负出现至多d_H(v)−1。至多一个点的度可为九，其余至多八，所以P1内可用于阻塞的负三索引总量至多

$$\sum_{v\in P_1}(d_H(v)-1)\le7g+1<8g\le N.\tag{6}$$

负索引重复只会降低能阻塞的不同候选数。故存在三点候选避开全部剩余负三；大小三又自动避开负四。遇F的原小负及其他原负索引均因R避F而安全。

返回原染色：翻转这至多三点R。全部m个原同色星块被击中；其余含x边原有对色点，翻转只新增对色，不会变单色；全部29避x原边由其完整负约束保证proper。因此35条原边全部proper。至此条件子定理的原H→局部→原二染色连接完整。

## 5. 三点横截的局部泛化是假的

这只否定一个宽signed接口，不是实际23点H反例或选择式反例。

取十点f,g,h,a0,a1,b0,b1,c0,c1,c2，三个正四集为

$$A=\{f,g,a_0,a_1\},\quad B=\{f,g,b_0,b_1\},\quad
C=\{h,c_0,c_1,c_2\}.$$

负单集为{f},{g},{h}；另取全部12个负三

$$\{a_i,b_j,c_k\},\qquad i,j\in\{0,1\},\ k\in\{0,1,2\}.$$

小负横截恰三。禁f,g,h后，任一正横截必须含一个a_i、一个b_j、一个c_k，因而包含某个负三，无法修复。

该系统正重复关联盈余恰二、总负15≤29、最大indexed次数仅七（a_i和b_j各为1+6），其余点更低。三个正四集可以在link层面补三个不交新四块，使六块并为22点、总关联24；但本文没有构造其余原五边，也不声称它可实现为满足全谱和全对覆盖的H。

所以不能仅用“中心link盈余二、原度≤8/9、负≤29、小负tau≤3”这些宽数值约束，证明任意固定初态可修复。欲把第4节推进到一般初态／存在式选态，须用同一实际H的其他低点星、原五边的共同外部补集或跨初态交换；不能继续扩大这个已被反例否定的裸signed门。
