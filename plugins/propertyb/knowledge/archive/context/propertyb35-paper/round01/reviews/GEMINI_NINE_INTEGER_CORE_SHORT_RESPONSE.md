### 一、第一项引理（九正四集交叠型 $|C|=48$ 整型覆盖）核验

1. **Indexed 计数与度数预算**：
   - $x$ 正出现 $3$ 次、总 indexed 度 $\le 7$，故含 $x$ 的原负集至多 $4$ 个，即 $u+v \le 4$；结合原负三集总数 $u+s \le 3$，两项共享预算成立。
   - $z$ 正出现 $2$ 次、总 indexed 度 $\le 7$，故含 $z$ 的原负集总数 $u_0+s_0+v_0+q \le 5$（避 $x$ 的原负四集唯有含 $z$ 才能包含于 $C$ 中元素，故活跃 $q$ 必含 $z$）。
   - 若原系统存在重复（indexed 同集）负边，其在度数预算中重复计入，而在阻断候选集时完全重合（只少挡、不多挡），不影响上界。

2. **单目标阻断上界与包含关系**：
   - $u_0$（含 $z$ 的 $N_2=\{z,t\}$）：$t \in A$ 挡 $12$ 个，$t \in V(K_{2,2,2})$ 挡 $4\times 4=16$ 个，$t$ 在外部挡 $0$ 个，上界 $16$ 紧确。
   - $u_1, s_0, v_0$（避 $z$ 的 $N_2$ 或含 $z$ 的 $N_3$，均等价于在 $\{a,i,j\}$ 中固定二元子集）：固定 $\{a,i\}$ 或边 $\{i,j\}$ 均恰扩展为 $4$ 个候选，其余为 $0$，上界 $4$ 紧确。
   - $s_1, v_1, q$（均在 $C$ 中固定唯一四元组 $\{z,a,i,j\}$）：各至多挡 $1$ 个。

3. **整数预算与 $u_0$ 分流**：
   - 当 $u_0 \le 2$ 时，代入 $q \le 5-u_0-s_0-v_0$、$3s_0+s_1 \le 3(3-u_0-u_1)$ 及 $3v_0+v_1 \le 3(4-u_0-u_1)$，得总阻断数：
     $$\le 26 + 9u_0 - 2u_1 \le 26 + 9u_0 + u_1 \le 29 + 8u_0 \le 45 < 48.$$
   - 当 $u_0 = 3$ 时，$u_1=s_0=s_1=0$，$v=v_0+v_1 \le 1$，$q \le 2-v_0$。删去 $3$ 条 $N_2$ 的至多 $3$ 个目标点（若有重复或落入外部则剩余更多）：当核心 $K_{2,2,2}$ 被删 $l=0,1,2,3$ 点时，余边数分别 $\ge 12, 8, 4, 2$（$l=3$ 时余 $3$ 点至多 $2$ 点同组，故至少 $2$ 条边），$A$ 余点数 $\ge 1, 2, 3, 4$，乘积 $\ge 12, 16, 12, 8 \ge 8$。剩余 $v, q$ 在 $v_0=1$ 时至多挡 $4+1=5 < 8$，在 $v_0=0$ 时至多挡 $1+2=3 < 8$，严格闭合。

### 二、第二项引理（短辅助门）核验

1. **最大正出现 $\le 2$ 分支**：
   - 各正 $3/4$ 集独立均匀选点，五类点（`33, 34, 44, 3, 4`）被选边际概率依次为 $p_v = \frac{5}{9}, \frac{1}{2}, \frac{7}{16}, \frac{1}{3}, \frac{1}{4}$。
   - 核对 $(D-\text{occ}(v))p_v^4$：
     - `33`：$5\times (5/9)^4 = \frac{3125}{6561} = 2\alpha$；
     - `34`：$5\times (1/2)^4 = \frac{5}{16} = \frac{40960}{131072} < \alpha+\beta$；
     - `44`：$5\times (7/16)^4 = \frac{12005}{65536} = 2\beta$；
     - `3`：$6\times (1/3)^4 = \frac{2}{27} < \alpha$；
     - `4`：$6\times (1/4)^4 = \frac{3072}{131072} < \beta$。
   - 因 $3\alpha = \frac{3125}{4374} > 4\beta = \frac{12005}{32768}$，在 $\le 6$ 个正集且 $\le 3$ 个正三集下，总收费上界为 $9\alpha+12\beta$。结合唯一负三集坏界 $\le (5/9)^3$，精确通分得：
     $$\frac{9\alpha+12\beta}{4} + \left(\frac{5}{9}\right)^3 = \frac{1375}{1944} + \frac{36015}{131072} = \frac{31279645}{31850496} < 1.$$

2. **最大正出现 $\ge 3$ 分支**：
   - 取正度 $\ge 3$ 的 $w$ 染红后，余 $\le 3$ 个正 $3/4$ 集。
   - **有交点（或余集 $\le 2$ 个）**：可再取 $\le 2$ 红点覆盖余集，总红点 $\le 3$，任何负四集均不可能全红；若共 $2$ 红点则无负三集可全红，若需第 $3$ 红点遍历第三个正集（$\ge 3$ 点），产生至少 $3$ 个三红候选，唯一负三集至多匹配其中 $1$ 个。
   - **三组两两不交**：各取一点连同 $w$ 形成 $\ge 3^3=27$ 个四红候选；唯一负三集（若含 $w$ 则固定两余集点、第三集至多 $4$ 选，若不含 $w$ 则至多 $1$ 选）最多挡 $4$ 个；含 $w$ 的原负四集至多 $7-3=4$ 个，各挡 $1$ 个；总阻断 $\le 4+4=8 < 27$。
