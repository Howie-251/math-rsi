# 原始模型回应

这支闭合：20 点、35 条互异五元边、点对覆盖、恰一个七度点 \(x\)、其余度至少 8 时，\(H\) 必有 Property B。下面四项都接到任意这样的 \(H\)。未重算已有独立重放；核对的是证明、生成器与已保存证书的接口。范围只到 \(r_7=1\)。

## 1. \(3a+2b\ge 10\) 与八种选点

共度盈余 \(\sum_{u\neq x}(\lambda(x,u)-1)=4\cdot7-19=9\)，故单位邻点集 \(U\) 满足 \(h=|U|\ge 10\)。度和 175 与其余点度至少 8 给出 \(\sum_{u\in U}(d(u)-8)\le 16\)。

反设不可染。五名单位十度邻点可染，故 \(U\) 中十度点数 \(c\le 4\)。八、九度点数为 \(a,b\)，其余单位邻点度至少 11，则盈余至少 \(3h-3a-2b-c\ge 3h-3a-2b-4\)。与上界 16 合起来就是 \(3a+2b\ge 3h-20\ge 10\)。\(a=0\) 时 \(b\ge 5\)，被五名单位九度邻点可染挡住，所以 \(a\ge 1\)。

整数情形都落到这八个度向量，而且五个点都取自同一个 \(U\)：

| \((a,b)\) | 选出的五邻点 |
|---|---|
| \(a\ge 5\) | \(88888\) |
| \(a=4,\,b\ge 1\) | \(88889\) |
| \(a=4,\,b=0\) | \(8888\,10\) |
| \(a=3,\,b\ge 2\) | \(88899\) |
| \(a=3,\,b=1\) | \(8889\,10\) |
| \(a=2,\,b\ge 3\) | \(88999\) |
| \(a=2,\,b=2\) | \(8899\,10\) |
| \(a=1\)（因而 \(b\ge 4\)） | \(89999\) |

三个要十度点的边界只能发生在 \(h=10\)：此时 \(U\) 里还剩恰好 6 个度至少 10 的点。若其中没有十度点，盈余至少 \(18\)、\(19\) 或 \(20\)，都超过 16。所以存在一个十度单位邻点，与已有的八度、九度点一起取出。度至少 11 的点不必进入这五个。更大的 \(h\) 只迫使 \(a\) 或 \(b\) 更大，仍然落在上表已有的行里。

## 2. 五名单位九度、十度：共同 \(\Pi\) 与包含数

两条子引理都从同一个 \(x\) 的单位星出发：\(\Pi\) 是这五个邻点按所在 \(x\)-边的划分，块大小至多 4；\(J_\varnothing=28\)，非空 \(J_T=I_T-p_T\)，再 Möbius 回非负迹。负库存丢弃。某个四点视图已经严格时，原 \(H\) 已可染，五邻点域只保留五点视图全都落在四点残域里的输入。

十度这条，`UNIT_TWO.json` 里 \((10,10)\) 的非严格库存只有共度 3 的两种划分。四点域 332 份里，非严格的 11 份我逐份看了：六条共度都是 3，四点包含数都是 0，三点包含数都是 0 或 1，划分只是一个二元块加两个单块，或四个单块。四点包含数全是 0，五点包含数只能是 0。在这个形状上遍历真实 \(\Pi\) 与十个三点数，独立域核对等于保存的 46 份；`FIVE_TENS.json` 与 `REPLAY.json` 都是 46/46 严格，最大 \(353/364\)。

九度这条，两点残域是共度 2 或 3，共 4 份。四点在共同 \(\Pi\) 与允许包含数下得到 1838 份，直接严格 1686，`JOINT_FOUR9` 的 `need_count` 为 152，其中 141 份有理 joint 严格，余 11。第五点只能新成一块，或并入大小至多 3 的旧块；另外四个四点视图的包含数必须与这份 \(\Pi\) 一致，五点包含数再取 0 和 1。`FIVE_NINES_DOMAIN.json` 记了这 11 份残域、27 条 moment join、去重后 26 份。`FIVE_NINES_DP.json` 与 `REPLAY.json` 都是 26/26 严格，最大 \(2531/2574\)。`FIVE_NINES_DOMAIN_AUDIT.json` 用对称五视图 join 得到同一个 26 域。

两点非严格共度没有 \(\ge 4\)。`UNIT_TWO.json` 全部 25 份非严格都在共度 1、2、3：\((8,8)\) 五份，\((8,9)\) 六份，\((9,9)\)、\((8,10)\)、\((9,10)\) 各四份，\((10,10)\) 两份。后面把共度限制在 \(1..3\) 没有丢掉不可染投影。

## 3. 五视图 join 与两个零域

八种五向量的四点残域合计 122 份：精细四点 114，加十度四点 8。独立核对 `NEW_FOUR_DOMAIN_AUDIT.json` 为 1537 份四点库存，`EIGHT_FIVE_DOMAIN_AUDIT.json` 为 497 份五库存，其中 \((8,8,8,9,10)\) 与 \((8,8,9,9,10)\) 都是 0，原始 join 777 条。

这两个 0 来自已经证完的四点残域，不是额外前提。

- \((8,8,9,10)\)：52 份里 48 份直接严格，4 份 joint 严格。
- \((8,9,9,10)\)：28 份全部直接严格。

`FOUR_WITH_TEN_DP.json` 为 198 份且 `complete`。`REPLAY_FOUR_WITH_TEN.json` 为 124 份直接严格、66 份严格 joint。198−124−66=8，这 8 份全是 \((8,8,8,10)\)。因此任一五邻点只要含一个 \((8,8,9,10)\) 或 \((8,9,9,10)\) 四点子集，该四点视图已经可染，五视图 join 的候选残域为空。

其余六种五向量的 497 份里，434 份直接严格，63 份 joint 严格，与 `REPLAY_EIGHT_FIVE.json` 一致，最大直接界 \(2993/3003\)。

## 4. 排列界与有理 joint 回到原染色

锁是 \(x\) 与选出的单位邻点。`recover(7, …)` 把中心度固定为 7：单点中心迹 \(7-|\Pi|\)，每块一条 \(x\)-边。邻点度、共度与高阶包含数经 Möbius 回到非 \(x\) 边的精确迹，空迹补成总和 35。

固定位置用 \(U=\sum_k\min(A_k,B_k,C_k-D_k)\)。配额
\[
q_R=\max\Bigl(0,\Bigl\lceil\frac{4f-(19-|R|)}{3}\Bigr\rceil\Bigr)
\]
与 \(v=20\) 的实现 \((4f-(19-|R|)+2)//3\) 相同；纯配额就是 \(|R|=s-1\)，底集大小 \(20-s\)。重放在调用前把剖面检查改成 20 点、35 边，并核对锁度是 \([7]\) 接上邻点度。

joint 使用同一条坏对向量、非负有理乘子和槽容量惩罚。保存的布局各自重算 \(A,B,C\) 与权重；混合界小于 1 时，至少一份具体锁位置的失败概率上界小于 1，从而给出原 \(H\) 的二染色。本目录的 joint 调用是 `Engine(20,s)`，\(s\) 为锁数，不走 22 点、6 锁的位置表。`JOINT_EIGHT_FIVE.json` 的 `need_count` 为 63，`complete` 为真，63 份都已按上述接口重放通过。
