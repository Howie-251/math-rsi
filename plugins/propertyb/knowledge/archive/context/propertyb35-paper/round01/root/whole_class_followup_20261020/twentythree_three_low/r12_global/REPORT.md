# 23点r12：共同低迹结构、可闭子情形与选边障碍

2026-10-21。有界解析诊断，未扩大三低补色菜单，未运行新DP／MILP／原H搜索。**无重复低点对(E=0)可直接保证已闭单位三低门；借源一般U7的九残型全集，还能排E3／E6的三个低高点情形。其余不能由当前共同计数关闭。** 新范围为same-family／provisional，不称r12已闭。

## 1. 十二低点必须分成两个匹配，E只能0／3／6

设H为23点／35简单五边／pair-cover、恰十二名六度点L。非B时由[四低门](../../../../../../../proofs/propertyb35/TWENTYTHREE_FOUR_LOW_EDGE.md)，原边低迹至多三。对低点z记b_z=Σ_{e∋z}(3−|e∩L|)，e_z=Σ_{y∈L\{z}}(λzy−1)。低点关联给

\[
b_z+e_z=12-11=1.
\tag{1}
\]

因此低点重复支持图为匹配，边共度二；记其边数E。重复匹配的端点e_z=1、b_z=0，六条入射原边都三低；非端点e_z=0、b_z=1，恰五条三低加一条二低。**没有一低原边**，不是只保留较弱n1+n2+E=6。

二低边恰在非重复低点上组成匹配，故n2=6−E；低总度72进一步给

\[
n_3=20+\frac{2E}{3},\qquad E\in\{0,3,6\}.
\tag{2}
\]

重复匹配边与二低匹配边合为L上的六对完美匹配。每条含重复低点对的三低原边称bad，其余称unit。一个三低集不可能含两个重复匹配对，所以bad原边恰2E条。

|E|n2|bad三低|unit三低|纯高边|
|---:|---:|---:|---:|---:|
|0|6|0|20|9|
|3|3|6|16|10|
|6|0|12|12|11|

这已经保证至少十二条unit三低边；尚需它们确实遇到度7…9高点，不能由“数量很多”直接断言。

## 2. 不存在可用选边时的高点集合与E0排除

十一名高点总度175−72=103。令R为度7…9高点，p=|R|，Q为度至少十的高点。由

\[
103\ge7p+10(11-p),
\]

有p≥3，且其真实度数和满足D_R≤10p−7。若任一unit三低原边含R点，已完整独立核的[U7／8／9单位三低门](../independent/AUDIT.md)直接给H可染。因此反设这些unit三低边全部避R。

R到十二低点至少有12p个点对关联，只能由bad三低或二低边支付。bad共2E条、每条至多两R；二低共6−E条、每条至多三R，所以

\[
12p\le3\cdot(4E)+2\cdot3(6-E)=36+6E.
\tag{3}
\]

故E0只能p3；E3只能p3或4；E6只能p3…6。

**E0可闭。** 所有三低边都unit，反设它们避R。六条二低边把全部十二低点分成六对，故每名R点必须在这六条原边中全部出现，才能与十二低点pair-cover。p≥3而每边只有三高槽，所以p3，每条二低边都含同一组三R。

任一R点与另外两R点共度各至少六，超额行至少(6−1)+(6−1)=10。pair-cover的真实行式4d−22≥10迫其d≥8。三R总度≥24，另八高总度≥80，总和至少104，与103矛盾。故E0确有可用unit三低边，并由已闭门染色。

此论证不假定存在七度点。

## 3. 九个旧U7残型能提供的条件加强

本节**额外声明进口**为源[一般U7完整诊断](../REPORT.md)第5节及[R12_RESIDUAL.json](../R12_RESIDUAL.json)：兼容低重复匹配的U7三低输入，除下述九个标号键外均已有严格补色证书。刚完成的76,401键第二实现只核低点对单位的域，**不等于重新审过这个一般U7进口**。

九残型在低点换标号下仅两形。设三低G的唯一重复低点对为ab，第三低为c，高点u度七：

* I：非G内部迹为{a,b}及{c,u,v}，d(v)=8或9。
* II：非G内部迹为{a,b,v}、{c,u}、{c,v}、{u,v}，d(v)=12。

两形都使λcu=λcv=2，恰用完低点c的共度盈余二，所以c对其他低点没有重复，即c不是低重复匹配端点。重复对ab的另一条共同原边避u。重复高点对uv的共度恰二。

**E6不能有七度高点避unit三低。** 取该七度点与任意低点的共边，必是bad三低；九残型使其第三低c非重复，但E6所有低点都是重复端点，矛盾。特别p3时D_R≤23迫至少一名R度七，所以E6、p3被排。

**E3、p3也可排。** D_R≤23保证有u度七，仍反设其所有三低入射边bad。每个重复匹配对的端点必须与u相遇；九残型使bad第三低必须非重复，又使每个重复对的另一条共边避u。因此u恰有三条bad三低边，每个重复对各一条。

设六名非重复低点中，有b个点作为这些边的第三低出现两次。每个出现过的第三低c满足λcu=2，所以不能出现三次。三个第三低槽使b≤1。若出现一次，第二cu边必须是c的唯一二低边；若出现两次，二低边不能再含u；若没出现，pair-cover迫其二低边含u。故恰6−b个非重复低点在含u的二低边中，而这些二低边来自同一个匹配，所覆盖点数必偶。于是b=0，三条bad边的第三低互异。

两条bad边若同有另一高点v，因为第三低互异、锚定的重复低对不同，它们相对G的交迹恰{u,v}。这只可能是形II，v度十二；同一v不能出现在三条bad边中，否则λuv≥3。

若Q无十二度点，三条bad边的另一高点必须为三个互异的八／九度点，但R除u外仅两点，矛盾。若Q有十二度点，D_R≤23−2=21迫三个R全七，Q最多有一个十二度点、其他Q全十度。三条bad边的另一高点只能是该唯一十二度点，却最多出现两次，仍矛盾。

上述加强没有使用错误的“第三低必须在两条bad边中”断言：其第二cu边确实可以是二低边；证明正是先按二低匹配覆盖偶性处理这个可能性。

## 4. 精确剩余与为什么当前矩不足

只用第1、2节及已独核unit三低门，剩E3的p3／4及E6的p3…6。再接受第3节明确声明的一般U7九残型进口，则进一步缩为：

* E3，p4；不保证存在七度点；
* E6，p4／5／6，且所有高点至少八度。

仍不能从当前度数、低迹数和类共度行总量推出这些情形必有unit三低碰到R。以下两份**整数类占用松弛见证**说明这一计数方法的真实障碍。行(ℓ,R,Q;数量)只记录原边中三类点数，不是实际边集；没有低点设计或原点对包含关系的实现保证。

|情形|R度数|Q度数|纯高边(ℓ,R,Q;数量)|bad三低|unit三低|二低|
|---|---|---|---|---|---|---|
|E3,p4|8,8,8,9|七个10|(0,2,3;5),(0,1,4;5)|六条(3,2,0)|十六条(3,0,2)|三条(2,2,1)|
|E6,p6|8,9,9,9,9,9|五个10|(0,3,2;7),(0,2,3;4)|十二条(3,2,0)|十二条(3,0,2)|无|

两份都满足35边、低点关联72、高点度总103以及对应n2／n3；全部unit三低都避R，而且R中没有七度点。其高点类pair／κ总量也准确一致：

|情形|w(R内)|w(Q内)|w(R,Q)|低–R重复总数|低–Q重复总数|
|---|---:|---:|---:|---:|---:|
|E3,p4|8|40|28|0|18|
|E6,p6|22|21|36|0|12|

例如E6的R行总预算4·53−22·6=80，正好是2·22+36；Q行总预算4·50−22·5=90，正好是2·21+36+12。E3同样逐类相等。包括低重复匹配E后，全点对超额均为350−C(23,2)=97。

因此仅继续压这些类总量，没有理由保证突破。下一真实缺口是：低重复匹配、二低匹配与bad三低的**同一原边／单个高点**如何连接，或度8／9高点在bad原边中的额外可复用结构。这里没有证明上述松弛可以补成H，所以也没有反驳“必有好选边”命题本身。
