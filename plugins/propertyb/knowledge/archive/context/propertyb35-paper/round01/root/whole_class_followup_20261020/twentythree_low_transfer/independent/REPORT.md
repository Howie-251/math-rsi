# 单六度中心的五四块：四形与双色冲突

状态：精确局部结论；独立确定性容斥实现通过。同家族数学核对为 provisional。

设 S 有18点，B₀,…,B₄ 是五个各4点的块，覆盖 S。记点重数为 m(v)。则

Σᵥ(m(v)−1)=20−18=2。

所以只有两种正重数分拆：一个点重数3，或两个不同点各重数2；其余点重数1。前者三个所属块可由块置换规范为 {0,1,2}。后者对应两个允许重复的块指标对，两个对的交大小只有2、1、0，分别得到同对、相邻对、不交对。除这些重复点外，所有点均为某块独有，故块置换及点重标号下恰好四形，没有其他关联参数。四形两两不等价：第一形具有三重点，后三形的两条块对的交大小不同。

这也适用于题设的实际单中心：z 度6，G 是一条过 z 的边，且 λ(z,g)=1 对每个 g∈G\{z} 成立。其余五条过 z 的原边均避开 G\{z}，删除 z 后得到 S=V\G 上的五个4块。由点对覆盖，每个 S 点至少属于一块，故恰为上述完整域。原 H 简单保证五块互异。

## 容斥公式

从 S 均匀选择 b 个蓝点，其余红点。双色冲突指至少一个全红块且至少一个全蓝块，因而这五条中心边无法同时由给 z 选择一种颜色来修复。

对非空且不交的块指标集 R,T，令 U_R=⋃ᵢ∈R Bᵢ、U_T=⋃ᵢ∈T Bᵢ。精确冲突数为

N_b = Σ_{R,T≠∅, R∩T=∅, U_R∩U_T=∅} (−1)^{|R|+|T|} C(18−|U_R|−|U_T|, b−|U_T|)。

这是全红块事件之并与全蓝块事件之并的两个容斥展开之积。指标重叠或顶点并重叠均使交事件为空；其余交事件只固定两种颜色的点集，其自由蓝点数由组合数给出。约定非法下标组合数为0。程序只遍历这两个块指标子集，不遍历实际染色。
