# r5九单位主域：40个多样轨道的有界raw诊断

## 结果

完成预先选定的40个新彩色轨道后停止，**40个普通raw严格、0个非strict**。最高费用 **179/182<1**，最低6465/8008。每个新布局的25行A/B/C均以独立标号注入公式重放并与生产者逐行相等，共**1000行**。没有以旧quota修正值代替普通raw。

全40项主体累计CPU **9.932189秒**、墙钟 **10.165954秒**，包含首5项pilot的1.199868 CPU秒/1.219220墙秒，未重复pilot。最慢单项0.339215 CPU秒。未达到60CPU秒或3分钟墙钟限制，也没有继续扫第41个。

结论仅适用于这40个所选局部必要迹轨道；不是全域通过，没有发现实际H反例，也未证明r5已闭。same-family/provisional。

## 输入与实际H绑定

读取父目录`REPORT.md`、`CHECK.py`、`DOMAIN.json`、`PROFILE.json`。本次不重建/改动原3107标记、1689彩色轨道的完整必要域；该目录的实际caller、374族覆盖和三K5例外保持声明进口。

每个选中标记均重新核35边、五锁度六/四锁度七、全部36单位锁对共度一、多点迹低交≤2。全部五低点锁定，所以“七度点私有数”直接由其通过的一低精确迹计数，保留两个私有四块区分所需的真实迹；未将r6单私有块关系移入本题。

对每一局部必要迹，由普通ABC概率引理，给出的具体锁位和严格raw值对任意具有该真实迹的原H均提供染色。抽象迹可实现性不是计算前提；这仍不是原超图枚举。

## 选样与旧证书标签运输

原汇总把一个轨道“所有旧标记都strict”才计为旧覆盖，较保守。3107记录分组实际是：270轨全部旧strict、55轨至少一个旧strict而非全strict、1364轨没有任何旧strict。已有三个旧pilot中第一轨属上述55，另外两轨才是新无旧strict轨，因此沿合法标签运输后真正未新算为1362轨。

`TRANSPORT_CHECK.py`对全部3107个记录实际核保存置换为S9排列、低标签映到canonical_lowmask、多点迹映到canonical_large，且同轨的**全部精确counts**运输后相等，PASS，CPU0.073037秒。于是旧模型证书可随位置一起运输，给55个部分旧strict轨的完整覆盖。此处仍保留旧证书的total/pure修正含义，**没有**把它们重命名为普通raw证书。

本次40轨仅从这1362轨中选择，排除全部三个旧pilot的彩色轨道。选样先以真正私有数多重集、最大锁迹、空迹数、旧界排序五分位、大迹大小重数为特征，确定性贪心增加结构多样性；不按新DP结果选样。`SELECTION.json`在DP前冻结全部40项。

实际覆盖：35个无色base家族、40个不同彩色轨道，共100个原标记；11种七度私有数多重集；最大迹3/4/5各13/20/7轨；空迹数1…8全部出现；旧界五个分位全部出现。不是随机抽样，不提供统计通过率外推。

## raw DP及独立重放

复用`SubsetEngine`，初始化后将每个optional quota库存显式设为`(0,0,[])`，求所有锁顺序及所有25点位置中的精确普通raw最小值。最终不调用会重新加入quota的`engine.verify`。

每个具体位置另由`BareLayout.bound(...,with_rows=True)`计算普通ABC，并以`independent_structure_bounds.independent_rows`逐35个不同边索引stubs、全部不同有序边对重新做下降阶乘注入计数。所有25行A/B/C逐项相等，行最小值之和同时等于DP整数缩放结果和BareLayout值。布局证书的正确性不依赖全局最优性；此处DP最优性仅服务诊断“raw门是否仍有残型”。

首5项全部strict，最高1959/2002，实测预计40项约9.6CPU秒，因此继续完成40并停止。`PILOT.json`保留首5项原结果，`RESULT.json`保留全40项精确counts、具体锁位、独立25行及各项成本。

复现：`python3 SELECT.py`生成相同冻结选样；清空本目录新RUN输出后执行`python3 RUN.py --pilot`，再执行`python3 RUN.py`续接剩余35项。正常再次运行RUN只读取已完成40项并停止，不自动重跑或扩域。`TRANSPORT_CHECK.py`可单独复核标签运输。
