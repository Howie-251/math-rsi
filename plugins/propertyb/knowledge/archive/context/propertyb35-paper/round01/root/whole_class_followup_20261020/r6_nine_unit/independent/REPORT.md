## 无 quota 的普通原始 ABC

此核只导入既有独立实现 `computations/independent_structure_bounds.py` 的 `independent_rows`。其计数以35个明确边类型桩和全部不同有序桩对展开，用指定不同自由顶点到16个自由位置的注入数作精确有理数计算，不调用主实现 `SubsetEngine.verify`、`BareLayout` 或 `multilock.rows`。

设左右自由位置数为a、b，$(x)_j$为下降阶乘，边的自由顶点数为r、q。单边自由枢轴权重为 $r(a)_{r-1}/(16)_r$，锁定枢轴为 $(a)_r/(16)_r$；B交换左右。固定一条真实单交有序边对后，自由枢轴权重为

$(a)_{r-1}(b)_{q-1}/(16)_{r+q-1}$，

锁定枢轴权重为

$(a)_r(b)_q/(16)_{r+q}$。

不可容纳的不同自由顶点数直接赋零。只允许结束边的锁点在左侧、开始边的锁点在右侧，双方锁迹交恰为枢轴的条件；对全部有序不同桩收费，逐位置取min(A,B,C)。这些正是规范正文(9)–(10)的普通原始公式，不含quota项。

全部140份实际布局、3500位置行与每份总分存于 [ROWS.json](ROWS.json)。140个独立精确有理数总分逐个等于证书 `raw_witness_bound`，也等于该文件的 `bound` 字段；128份严格，严格部分最大 **1429/1430**。其余12份均不严格。数值上限仍由通用排列染色概率引理供实际caller使用；此核不代替该引理或真实选点证明。
