# 双共度三组件的独立块事件容斥

**PASS，CPU0.023329秒。** 独立重建全部120个3×3行列和四矩阵，两个配额的240个结果和全部4680个X蓝点数分层计数均与主实现逐项相等。最大值仍为F8=5082、F9=6156。

本实现不枚举4096种X颜色。矩阵域也用不同生成方式：先生成所有三项和四的行组成，再任选前两行，由列和求第三行。

对P、Q两份三块划分分别记R_P、B_P、R_Q、B_Q为“至少一个全红／全蓝块”的指示函数。每个函数以非空块子集容斥展开为单项式。单项式用一对强制红／强制蓝的X点掩码表示；相反颜色相交时单项式为零。

核心冲突的Boolean多项式是

$C_P+C_Q-C_PC_Q$，其中$C_P=R_PB_P$、$C_Q=R_QB_Q$。

无核心冲突且两中心被迫蓝／红的多项式分别是

$R_PR_Q(1-B_P)(1-B_Q)$，

$B_PB_Q(1-R_P)(1-R_Q)$。

乘法只合并点约束，不假设块事件独立。约束强制r个红点、b个蓝点时，X蓝数j的完成数为$\binom{12-r-b}{j-b}$；线性求和得到三个准确蓝数直方图。再以主稿所证的T六点二项式完成数计两配额。这是与主实现字面X配色不同的计算方法。

最大中间最终多项式项数仅46。完整程序 [CHECK.py](CHECK.py)，逐矩阵直方图及分项 [RESULT.json](RESULT.json)。程序没有导入主实现，只在完成自身计数后读取主RESULT逐项比较；没有原H搜索、额外划分域或染色枚举。此独核验证局部计数，实际原边分类和补色接口仍以父目录REPORT的数学推导为准。
