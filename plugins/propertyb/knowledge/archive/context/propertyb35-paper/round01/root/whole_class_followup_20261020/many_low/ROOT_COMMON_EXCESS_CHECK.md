# 共同高点超额：r≥11统一闭合的独立解析核对

2026-10-20。**核对通过：在实际三低同边门M17成立的明确进口下，25点／35简单五边／pair-cover且至少11名六度点的H均具有Property B。** r≥12由一行共同预算矛盾，r=11由唯一六星整数型与全局四低关联整除性矛盾。不使用W25或r14–16的分支论证；没有修改此前规范。

## 1. 实际输入与进口

反设H非B。记实际六度点集L，r=|L|，K=V\L。点对覆盖使全部点度至少六；对z∈L，24项λzy≥1的和为4d(z)=24，故全部λzy=1。于是六条z星边删z后划分其余24点。

高点均指K中的点，故其度至少七，令t_x=d(x)−7≥0。总度计数给

\[
\sum_{x\in K}t_x=(175-6r)-7(25-r)=r. \tag{1}
\]

**进口M17：** 三名不同六度点a,b,c同属实际原边G={a,b,c,u,v}，记D=d(u)+d(v)、α=λuv−1。若D−5α≤17，则H具有Property B。非B时，由整数性必有D−5α≥18。

## 2. 同一原边的低迹成本

令ℓ(e)=|e∩L|。ℓ=5的边不可能：取其中三点为M17中心，另两低点满足D=12、α=0，直接给B。

若ℓ=4，唯一高点为x。取三低中心，另两点是一名低点和x；α=0，故

\[
D=6+(7+t_x)=13+t_x\ge18,
\quad\text{即}\quad t_x\ge5. \tag{2}
\]

若ℓ=3，两高点为x,y。写w_xy=λxy−1≥0，M17的反面给

\[
14+t_x+t_y-5w_{xy}\ge18,
\quad\text{即}\quad t_x+t_y\ge4+5w_{xy}\ge4. \tag{3}
\]

ℓ=1、2时只需使用非负性。因此所有含低原边都满足统一实数下界

\[
\sum_{x\in e\cap K}t_x\ge\frac52(\ell(e)-2). \tag{4}
\]

ℓ=1的右侧为−5/2，ℓ=2为零，ℓ=3由4≥5/2，ℓ=4由(2)恰达五。没有将不同边的高点成本独立相加：下一节固定一个实际低中心，其六星边恰好分割所有高点。

## 3. r≥12的共同矛盾

固定任一z∈L。每个高点与z共度一，故恰在一条z星边中出现。因此按同一六条原边有准确等式

\[
\sum_{e\ni z}\sum_{x\in e\cap K}t_x
=\sum_{x\in K}t_x=r. \tag{5}
\]

其他r−1名低点也各与z共现一次，所以

\[
\sum_{e\ni z}\ell(e)=6+(r-1)=r+5. \tag{6}
\]

对这六边求和(4)，得

\[
r\ge\frac52\bigl((r+5)-12\bigr)=\frac52(r-7).
\]

即3r≤35。因此整数r≤11；r≥12的非B反设均矛盾。这里的准确结论是“整数r≤11”，不是实数r≤11。

## 4. r=11的全部六星整数型

固定z，令a_i为其六条星边中低迹大小i的条数，i=1,2,3,4。全部是非负整数，且

\[
a_1+a_2+a_3+a_4=6,\qquad
a_3+2a_4-a_1=r-7=4. \tag{7}
\]

由(2)、(3)、其他成本非负及(5)，还有

\[
4a_3+5a_4\le11. \tag{8}
\]

下面不枚举程序，只按a₄作完整解析分流：

- a₄≥3时(8)左侧至少15，不可能。
- a₄=0时，由(7)a₃=4+a₁≥4，成本至少16，不可能。
- a₄=1时，a₃=2+a₁≥2，成本至少13，不可能。
- a₄=2时，a₃=a₁，(8)给4a₁+10≤11，故a₁=a₃=0；再由总条数得a₂=4。

因此唯一可能型确为

\[
\boxed{(a_1,a_2,a_3,a_4)=(0,4,0,2).} \tag{9}
\]

该结论对每名实际低点都成立。令n₄为全H四低原边数，则按同一原边的低点关联计数

\[
4n_4=\sum_{z\in L}a_4(z)=11\cdot2=22,
\]

与整数性矛盾。因此r=11也不存在非B输入。

## 5. 核对结论及范围

共同预算没有遗漏或重复高点：关键是固定低中心的六条实际星边恰把K分割一次。ℓ3处保留的更强成本4+5w只用于推出下界四，没有隐藏全共度上限。r11四种a₄情形覆盖全部非负整数六星计数，最终矛盾按实际H的四低边计数。

因此M17直接推出完整子类r≥11具有Property B；不再需要以r14、15、16分支或W门作为该范围主证明。本文没有证明r≤10、一般25点或整个m(5)≥36。对M17的有限计算、实际caller和最终审阅仍以其规范证明及原始证据为准；本次只独立核对该统一解析连接，same-family/provisional，无程序或新枚举。
