# r=3…7中所有三低／四低原边的统一染色门

2026-10-20。**独立核对通过：在M17及细宏星门的准确进口下，25点／35简单五边／pair-cover且3≤r≤7的非B输入不可能有低迹大小至少三的原边。** 证明是同一H上的解析共同收费，不运行新分类或原H搜索。新caller审阅属于same-family/provisional，不能把旧门审阅当成本稿新范围跨家族验收。

## 1. 实际对象与两项进口

L为全部r名度六点，K为其余25−r个高点，t_x=d(x)−7≥0。pair-cover给每点度至少六，总度给

$$\sum_{x\in K}t_x=r.$$

低点z的24项共度行均至少一，行和4d(z)=24，故每项恰一。六条过z原边去z后划分其余24点；固定任一高点，其所有含低原边的低迹也两两不交且覆盖L。

**M17进口：** [三低同边平衡补色定理](../../../../../../proofs/propertyb35/THREE_LOW_EDGE_BALANCED_EXTENSION.md)。原边含三个不同低点、余两点u,v时，d(u)+d(v)−5(λuv−1)≤17保证原H可染。

**细宏星进口：** [六星概率精细门](../../../../../../proofs/propertyb35/TWENTYFIVE_MACRO_STAR_COLORING.md)。固定实际低点z的六link四块，令Wz为同块点对超额和，m_z为29条避z原边中块占用分拆恰为(3,2)的条数，则

$$326W_z+308m_z\le10139\quad\Longrightarrow\quad H\text{可染}.\tag{F}$$

这里m_z计占用型(3,2)，不是“32条边”；避z的原边始终恰29条。

反设H非B。M17排除五低边，并迫

$$\ell(e)=3\Longrightarrow t_x+t_y\ge4+5(\lambda_{xy}-1),\qquad
\ell(e)=4\Longrightarrow t_Q\ge5.\tag{1}$$

固定一个低点，其不同星边的高点集合互不交，故这些下界费用都从同一个总t=r中支付。特别r≤7时，每低点至多在一条三低边中，也至多在一条四低边中，并且不可能同时在三低边及四低边中。因此三低、四低原边的低迹彼此两两不交。于是n3≤⌊r/3⌋，若有四低边则n4=1、n3≤⌊(r−4)/3⌋。

令n_j为低迹大小j的原边数。准确低点关联为

$$\sum n_j=35,\qquad\sum jn_j=6r,\qquad
\sum\binom j2n_j=\binom r2.$$

消去n1、n2得

$$\boxed{n_0=35-\frac{r(13-r)}2-n_3-3n_4.}\tag{2}$$

全H的点对超额wxy=λxy−1非负，总和350−300=50；涉及低点的超额均零。任一高点x的超额行和是

$$\rho_x=\sum_{y\ne x}w_{xy}=4d(x)-24=4+4t_x.\tag{3}$$

## 2. 含低边不能成为(3,2)型的共同理由

固定低中心z及任意避z原边f。若f含低点y，则z星中含y的那个四元块与f只能交于y。否则另一个交点x会使y–x点对同时出现于f及该星边，违反低点单位共度。所以f有块占用一，不可能是(3,2)型。

因此m_z只需计纯高原边；以下再利用某些高点所在块的占用一，把这些原边压到同一批避指定高点的纯高边。

## 3. 所有四低边统一排除

r≤4时，四低边要求t_Q≥5>r，立即矛盾；r<4本来也容不下四低边。只须r=5、6、7。

设四低边的唯一高点为Q，t_Q≥5、d(Q)≥12。由第1节n4=1。Q这条边已经覆盖四名低点，其其他含低边各至少消耗一个此前未覆盖的低点，所以

$$d_F(Q)\le1+(r-4)=r-3,$$

其中F为全部含低原边。故纯高Q边数至少12−(r−3)=15−r，纯高且避Q的原边数至多

$$n_0+r-15.$$

由(2)及n4=1，准确上界为

|r|n0|n0+r−15|
|---|---|---|
|5|12|2|
|6|11|2|
|7|11−n3|3−n3≤3|

取四低边中任一低点z。Q所在的z-link块其余三个点均低，所以Q的超额行完全不进入Wz；其他费用非负，故

$$W_z\le50-\rho_Q\le26.$$

由第2节，(3,2)型只可能纯高；若它含Q，则含Q的块只能占用一，同样不可能。因此m_z≤纯高避Q边数≤3。于是

$$326W_z+308m_z\le326\cdot26+308\cdot3=9400<10139.$$

(F)给原H染色，矛盾。故r≤7的非B输入没有四低边。

## 4. 所有三低边统一排除

现已从同一实际H排掉四低、五低边，n4=0。若r=3，任一三低边的高点t和s≤3，M17分数14+s−5w≤17，直接给染色。以下处理r=4…7。

设实际三低边G的两高点为x,y，令s=t_x+t_y。由(1)与总t≤7，

$$4\le s\le r\le7,\qquad\lambda_{xy}=1.\tag{4}$$

取G中的任一低点z。x、y在同一个z-link块中，其他两点均低，且wxy=0；所以所有涉及x、y的费用都不进入Wz。行和扣除没有共享超额，因为wxy=0。由(3)，

$$W_z\le50-(\rho_x+\rho_y)=42-4s\le26.\tag{5}$$

第2节排除所有含低(3,2)型。若纯高f含x而不含y，它在G\{z}块的占用恰一，也不是(3,2)；含y同理。而f不能同时含x、y，因为(4)的唯一共边已是G。因此

$$m_z\le\#\{\text{纯高且避x,y的原边}\}.$$

G已用三个低点，x的其他含低边各消耗至少一个不同低点，所以d_F(x)≤1+(r−3)=r−2，y亦然。两者的纯高边族又互不交，由λxy=1且唯一共边G含低。因而纯高避x,y的原边数至多

$$\begin{aligned}
n_0-\bigl[(d(x)-d_F(x))+(d(y)-d_F(y))\bigr]
&\le n_0-[14+s-2(r-2)]\\
&=n_0+2r-18-s.\tag{6}
\end{aligned}$$

这使用同一个实际纯高边族，未将两个高点的边重复扣除。代入s≥4、(2)及1≤n3≤⌊r/3⌋，得到完整标量域：

|r|n3|n0|m_z上界|
|---|---|---|---|
|4|1|16|2|
|5|1|14|2|
|6|1|13|3|
|6|2|12|2|
|7|1|13|5|
|7|2|12|4|

故全域m_z≤5，结合(5)，

$$326W_z+308m_z\le326\cdot26+308\cdot5=10016<10139.$$

(F)再次给原H染色。原宏星失败概率至多(5220+10016)/15360=15236/15360<1，余量124；这是同一实际z的两个安全上界，不需要证明两界同时取等。

## 5. 准确收益与仍需处理的范围

综上，3≤r≤7且存在至少三低原边的实际H全部可染。非B必要条件统一化为所有原边低迹仅0、1、2，并且

$$n_1=r(7-r),\qquad n_2=\binom r2,\qquad
n_0=35-\frac{r(13-r)}2.$$

r=7时n1=0，任何高点都必须用二元低迹不重复覆盖七低点，矛盾，所以这条统一门还可接成r=7整支染色。它与另存的[r7完整五库存证明](../r7/REPORT.md)是不同证明组织，原稿完整保留。
