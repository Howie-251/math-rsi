## 4. 撤回的W候选及精确缺项

设q_xy为五个低中心中有多少中心的link四块把x、y放在同一块，则准确恒等式是

\[
q_{xy}=\sum_{e\supseteq\{x,y\}}|e\cap L|,
\qquad \sum_{z\in L}W_z=\sum_{xy\subseteq K}w_{xy}q_{xy}.
\tag{6}
\]

一条二低原边同时支付两个低中心，所以一般**不能使用q_xy≤λ_xy**，只能直接得到q_xy≤min(5,2λ_xy)。同理，七度K5内λ=2并不自动把q界为二。

故原候选

\[
\sum_zW_z\le60+F(w)
\]

尚未证明；特别“Y全w2时共同W≤120”的推论撤回。局部形式上，两条共同xy边可分别带两名不同低点，共给四个低中心，而λ_xy仅二；这说明旧收费不能由当前假设推出，但不是完整H反例。

可以准确标出遗漏费用。记a_j(xy)为同时含xy且低迹j的原边数，j=0,1,2，则q=a_1+2a_2，而λ=a_0+a_1+a_2。记

\[
D_2=\sum_{e:\ |e\cap L|=2}\ \sum_{xy\subseteq e\setminus L}w_{xy}.
\]

按“含低共同边数”a_1+a_2≤λ收费，原候选可以安全修正为

\[
\sum_zW_z\le60+F(w)+D_2.\tag{7}
\]

这里60来自三个七度K5的三十对、每对w=1且共同含低边数至多二；D2准确补二低边的第二次计费。若右侧≤129，才由整数平均保证某低点W≤25，接[宏星门](../../../../../../proofs/propertyb35/TWENTYFIVE_MACRO_STAR_COLORING.md)。例如均匀w2仍须另证D2≤9；现未证明。不继续计算错误的无D2版本。

## 5. 旧单K5证明：真正保留与真正断裂的位置

已读取[单K5正文](../../../twentyfive/K5_SINGLE_COMPONENT.md)、[27迹生成源码](../../../twentyfive/GROUP5_CATALOGUE.py)、[分拆边际独立核](../../../twentyfive/GROUP5_PARTITIONS_REPLAY.py)、[245单外点独立核](../../../twentyfive/GROUP5_EXTERNAL_STAR_REPLAY.py)、[双外点域](../../../twentyfive/K5_SINGLE_COMPONENT_DOMAIN.py)及[135双外点独立核](../../../twentyfive/K5_SINGLE_COMPONENT_REPLAY.py)。本轮只读这些旧证据，没有重跑。

**无需all7、可直接保留的部分：**

1. 固定任一真实七度K5组G。它内部λ=2、与所有20外点λ=1，组内点度七，故27个G迹μ的目录及singleton／empty恢复完全不使用外侧度数。
2. 每个外点x的非空G迹组成G上的划分Π_x，不能有五点块。实际边际ν_T=(5−|T|)μ_T，只依赖20个外点及原边大小。GROUP5_PARTITIONS_REPLAY的51划分分离证书因此仍排除库存0、2、3、4、6，27→22完整成立。
3. 库存23的边际计数仍给二点块关联30、2n_A0+n_A1=10；每条二G迹边e_T含三个外点，仍能迫出同边B–B外点对。此实际选点不要求外点全七度。

**确实用到all7、不能原样迁移的最早算术：**

1. 245单外点证书把空G迹过x重数固定为7−|Π_x|，并断言六个锁都度七；还在x处用q_total=2。实际外点度可为6、7、8，正确空迹数分别是d(x)−|Π_x|，q_total也不同。旧strict partition集合不是这些新profile的证书。
2. 所以用“某个必需真迹不在任何残partition中”排除整μ，及库存12的残partition分离，只对**全部20外点均已受相应旧残partition约束**的情形成立。本例最多直接约束另外十名七度外点，五低和五八度尚未接受这些证书。不能直接从22降到正文中的十个末库存。
3. 对三G迹原边取两外点x,y时，旧域恢复式的p0=7−|P|、q0=7−|Q|及七锁全度七都需改为真实d(x),d(y)。真实三迹边并不保证其两外点七度。若两者均七度，旧90份raw证书可原样复用；当前没有保证这种实际选点。
4. 外点ρ≤4给出的λ≤5在一般外点上也曾用到all7。此例已有更精确实际分类：带低点的对λ1；七度对λ1或2；七度与八度λ1；两个八度现在由第2节也得λ≤5。因此**λ范围这个缺口已补上，但度数profile缺口仍未补上**。
5. 库存23最后B–B对的存在仍真；两外点各自可能为6／7／8度，其四格恢复和12参数旧数值表仍要重新绑定真实度，不能仅据B–B存在就套表。

最小共同缺口是**带真实外点度标签的G星证书／边际排除**，而非G目录完整性，也不是另找一个非单位外点。每个G恰有5名六度、10名七度、5名八度外点，可在同一个边际中分三类；尚无该混合边际的全strict结论。
