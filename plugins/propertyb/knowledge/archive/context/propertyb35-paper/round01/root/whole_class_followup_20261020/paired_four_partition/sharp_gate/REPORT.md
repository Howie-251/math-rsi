# 配对四块补色的精确锐门：最大失败数12324

2026-10-20。**完整局部域的精确最大值是12324，低于新caller所需12763。** 465个行排序交矩阵终态归为43个行列置换轨道，全部完成字面计数；唯一最坏轨道为全1矩阵。给定主代理的固定费用79614，总费用为91938<92378，严格余量440。本次只枚举两份划分的局部交矩阵与局部颜色，不枚举实际超图，也未增加第三中心。

## 1. 准确对象及结论

S=X⊔T，|X|=16、|T|=3。P、Q各为X的四个四元块划分，两份划分允许重合。在S均匀选九个蓝点，其余十点红，样本空间

$$N=\binom{19}{9}=92378.$$

补两个中心a、a'的颜色，分别使四条a+P块、四条a'+Q块及{a,a'}∪T均两色。F(P,Q)为不存在这类联合补色的样本集合。

本次完整精确核给

$$\boxed{|F(P,Q)|\le12324}\tag{1}$$

对任意实际P、Q成立，并可取等。旧解析15228及更短16212门保持原先结论；本次新增的是对更紧caller足够的准确12324门。

## 2. 同一X蓝集上的准确失败判定

给定X蓝集B，令b=|B|、t=9−b。只须t∈{0,1,2,3}，T的具体蓝点选择有C(3,t)种。

令R_P表示P有全红块，B_P表示P有全蓝块，Q类似。单中心冲突是C_P=R_P∧B_P、C_Q=R_Q∧B_Q。联合补色失败准确分成三个互斥部分：

1. C_P或C_Q发生；
2. 两者均无冲突，t=3且R_P、R_Q都发生：两中心均被迫蓝，与全蓝T冲突；
3. 两者均无冲突，t=0且B_P、B_Q都发生：两中心均被迫红，与全红T冲突。

若T混色，配对原边自动proper；若T单色且某中心仍可取反色，就能同时修复配对原边。故不存在遗漏的补色失败方式。

[CHECK.cpp](CHECK.cpp)对16点的全部蓝集遍历，只保6≤b≤9，共

$$\binom{16}6+\binom{16}7+\binom{16}8+\binom{16}9=43758$$

个不同X蓝集。每个按C(3,t)加权，准确覆盖92378份S染色，而非独立概率近似。全程序每个X蓝集还显式枚举(a,a')的四种颜色，逐块检查九条边，并断言“存在补色”恰为上面失败判定的否定。没有将T的某一种排列假装代表不同计数；T内具体选点只影响t，C(3,t)正好是完整乘数。

## 3. 完整4×4交矩阵域与无损去重

任意P、Q给Mij=|Pi∩Qj|，它是非负整数4×4矩阵，行列和均四。反之任意这样的M可按格展开为16个不同点，行与列即两份所需划分。计数在X点重标下不变，只依赖M。

程序的完整生成过程如下。

* 四元非负整数组成行和四，共C(7,3)=35行，按字典序排序。
* 按非降顺序递归选择前三行，列和超过四时才剪枝；最后一行被四个列缺额唯一确定。
* 最后一行非负、行和四且不小于第三行时保留，得到465个不同的行排序终态。重复行允许出现；每个合法矩阵的行排序必且仅在这里出现一次。
* 对每个终态穷尽24个列置换，并分别重新排序四行，取完整矩阵字典序最小值作为规范代表。两终态代表相同当且仅当行列置换等价，不使用双lex启发式或部分置换筛。

最终恰43个轨道。全部465个终态及它们的规范key保存在[DOMAIN_MAP.tsv](DOMAIN_MAP.tsv)，key为16个0…4格的唯一五进制编码；[RESULT.json](RESULT.json)保存所有43个矩阵及计数。

[REPRESENTATIVES.json](REPRESENTATIVES.json)另列每轨道所含全标号矩阵数。对行排序终态，完整行标号数是4!除以各重复行重数的阶乘；逐终态相加得10147个全行列标号矩阵。这只是对已生成域的重数核对，没有重新枚举10147个标签或扩大局部对象。

固定M后，按行优先给每格的Mij个点编号0…15，显式构造四个行块和列块。所有点都不同，且每份块族确为16点上的四个四块划分。格内点重标不改变样本空间或补色可行性，所以无需逐一重新计数其标签排列。

## 5. 最坏矩阵的手算取等核对

取X={1,…,16}，P为连续四行，Q为四列，T={17,18,19}。

P若有一全红行和一全蓝行，每个Q列都同时遇红、蓝，故Q无双色块冲突；反向亦然。因此两个根冲突事件互斥，各5226，和10452。

T红时X蓝九点，任一全蓝行与全蓝列并大小七，还能从其余九点补两蓝，16种行列对各C(9,2)=36份。两全蓝行加一全蓝列已需十蓝，不可出现，故没有重叠，计576；这类样本不会有全红行或列。

T蓝时X红十点，任一全红行与全红列给16C(9,3)=1344份。两全红行加一列、或一行加两列恰需十红，各有C(4,2)·4=24份重计；更大选择超出十红。准确core为1344−24−24=1296，也不会有全蓝行或列。

故该具体划分对确实取得10452+576+1296=12324，(1)是该局部问题的准确最大值，而非仅未见反例的上界。
