# 23点四低原边：两个互不相交的共度三低对

本稿只处理指定原边 $G=\{x,y,a,b,h\}$：$x,y,a,b$ 度六，$\lambda_{xy}=\lambda_{ab}=3$，$h$ 度数记$d$，原H为23点35条简单五边且pair-cover。

低点的行重复盈余是 $4\cdot6-22=2$，已被它的共度三配对点用尽。因此其与其余所有点共度恰一。特别地，除xy、ab外，G中涉及低点的各点对共度一，非G边不能混合两个配对组件，不能同时含h和低点，也不能含三个G点。

在 $S=V\setminus G$ 上，$|S|=18$。两个额外ab原边为 $\{a,b\}\cup T_1$ 与 $\{a,b\}\cup T_2$，$|T_i|=3$。由a到S每点共度一，$T_1\cap T_2=\varnothing$，a的另外三条边删a后给 $X=S\setminus(T_1\cup T_2)$ 上三份互不交四集，恰分12点；b同样给同一X的另一份三块划分。两划分由一个行列和皆四的非负整数3×3交矩阵描述。不得假设两份划分相同或独立。

固定x红、y蓝、h蓝，只待补a、b。G及xy的两个额外三迹边恒proper。其余固定边与待补组件的原边索引完整分类如下。

| 类别 | 原边数 |
|---|---:|
| 额外xy边，恒proper | 2 |
| x的四点单迹边 | 3 |
| y的四点单迹边 | 3 |
| h的四点单迹边 | $d-1$ |
| 纯S五边 | $19-d$ |
| ab组件：两条三迹边与六条四迹边 | 8 |
| G | 1 |

总数35；所以$6\le d\le19$。下限来自pair-cover。不同配对组件没有共同非G原边，固定边均不含a、b。

均匀选择S中q个蓝点。令 $F_q(M)$ 为ab组件无法补色的精确样本数。固定边各自并界加上组件给

- q=9（9蓝9红）：$37180+572d+F_9(M)$，样本总数48620。
- q=8（8蓝10红）：$40898-572d+F_8(M)$，样本总数43758。

q9下红/蓝四迹单边坏数都是2002，纯五边1430；q8下红四迹3003、蓝四迹1001、纯五边1573。上述是各固定边独立收费之和，尚未扣其组内重叠；后续若扣，必须保持同一实际原边索引分组。

组件失败条件也可直接写成三事件类型。令 $C_a,C_b$ 为各自私有三四块同时出现红块与蓝块的冲突。若两者均不冲突，只有两中心都被迫同色c，且至少一个T_i全为c时失败；被迫蓝等价于有红私有块，被迫红等价于有蓝私有块。因此

$F=C_a\cup C_b\cup[(\text{a,b均被迫蓝})\cap(T_1或T_2全蓝)]\cup[(\text{a,b均被迫红})\cap(T_1或T_2全红)]$。

在先排除$C_a\cup C_b$后，后两类互斥。对X的每种颜色只需记其蓝点数j及这三种状态，T六点的完成数可解析求出：普通完成$\binom6{q-j}$；至少一蓝三块完成数$2\binom3{q-j-3}-\mathbf1_{q-j=6}$；至少一红三块完成数$2\binom3{q-j}-\mathbf1_{q-j=0}$。这给独立局部精算方法，不搜索H。
