# r=8且无四低边：共同低迹缺失与两星W门

2026-10-20。**在M17和W25两项明确进口下，25点／35简单五边／pair-cover、恰八名六度点、没有低迹大小四原边的整个C0子支具有Property B。** 本报告独立核对b=4、7的实际论证，并给b=1的新短矛盾。没有H枚举、MILP、局部表或r=7计算。

## 1. 同一实际H、低点单位共度与完整三种库存

令L为全部八名度六点，其余高点集K有17点；对高点x写t_x=d(x)−7≥0。pair-cover给每点度至少六，故

$$\sum_{x\in K}t_x=(175-6\cdot8)-7\cdot17=8.$$

对低点z，24项共度λzy≥1之和为4d(z)=24，所以每项恰一。其六条星边去z后划分其余24点；尤其每个高点恰与z共现一次。

**进口M17：** [三低同边平衡补色门](../../../../../../proofs/propertyb35/THREE_LOW_EDGE_BALANCED_EXTENSION.md)说明，实际边含三个不同低点，余两点u,v满足d(u)+d(v)−5(λuv−1)≤17时，原H可染。反设H非B，则没有全五低边；任意三低边的高点对uv满足

$$t_u+t_v\ge4+5w_{uv},\qquad w_{uv}=\lambda_{uv}-1\ge0.\tag{1}$$

本任务另假定无四低边，所以全部低迹大小ℓ≤3。固定低点z，令a_j为其六条星边中低迹大小j的条数。低点单位共度及同一高点预算给

$$a_1+a_2+a_3=6,\qquad a_3-a_1=1,\qquad4a_3\le8.$$

所以仅有

$$A=(a_1,a_2,a_3)=(0,5,1),\quad B=(1,3,2).$$

令B型低点数为b、A型为8−b，n_j为原边低迹大小j的条数。全局准确关联给

$$n_1=b,\qquad n_2=20-b,\qquad3n_3=8+b,\qquad n_0=15-n_3.$$

故b只能1、4、7，其完整计数分别为

|b|n0,n1,n2,n3,n4|
|---|---|
|1|12,1,19,3,0|
|4|11,4,16,4,0|
|7|10,7,13,5,0|

这是三个必要库存，不是三份实际H，也不以其可实现性为前提。

记三低边族为F3。每名B型低点恰在两条F3中，其高点集互不交，且各支付至少四份t。因此两条边已花完同一高点总预算八：**每个t>0的高点必须在这两条F3之一中出现。** 此结论对全部实际B型点同时成立。

任一高点x的不同F3低三元迹彼此不交，故其F3次数k_x≤⌊8/3⌋=2。

## 2. b=7不可能

存在t>0的高点x，因为总t为八。前述共同预算迫x通过F3覆盖全部七名B型低点；但k_x≤2，只能覆盖至多六个低点，矛盾。

## 3. b=1：唯一小低迹的缺失二点直接矛盾

令唯一B型点为z。它的两条F3记为e1、e2，第三条为e3。

e1、e2的低三元迹都含z，其他四名低点互异。其余低点全为A型、各恰在一条F3中，所以可以把七名A型点分成互不交的U、V、T，大小分别2、2、3，使

$$e_1\cap L=\{z\}\cup U,\quad
 e_2\cap L=\{z\}\cup V,\quad
 e_3\cap L=T.$$

又n1=1，唯一一条一低原边的唯一低点是z（仅B型点有一低入射）。

z的两条F3已支付全部t，故所有t>0高点都位于e1或e2。e3的高点t和至少四，由(1)必有一个t>0高点x∈e3。于是x也位于e1或e2；不妨x∈e1。

x与e1、e3中的六名低点已经分别共现一次。这六点恰为{z}∪U∪T，剩下两名低点就是V。

为了覆盖x与V的两个点对，还须有其他含低原边过x。它不能是一低边，因为唯一一低边含z，而x–z共度已经被e1占用；也不能是其他三低边，因为只剩e2，而e2同样含z。没有四低、五低边。因此只能由二低边补盖V。低点单位共度禁止补盖任何已覆盖低点，故必须存在一条低迹恰为V的二低原边。

但V的两个低点已经同属e2，这条二低边重复覆盖同一低点对，矛盾。

本步只用实际低迹分拆及同一个正t高点，没有选择多个不兼容视图，也不需要W25。

## 4. b=4：四边图只剩两个不交三点路径

此时F3有四条边。任意t>0高点x都通过F3覆盖四个B型点，所以k_x≥2；上界k_x≤2给k_x=2。

把每条F3的高点对作为一条图边，起初允许重边，记为X。由(1)，

$$16+5\sum_{F3}w_{uv}\le\sum_xk_xt_x=2\sum_xt_x=16.$$

故四条高点对的w都零，端点t和都恰四。重复高点对会有λ≥2，所以X实际上是四边简单图，最大度二；每条边至少遇一个t>0顶点，而所有t>0顶点度二，故不可能有单独的一边分量。

最大度二的四边简单图没有单边分量时，仅可能：四圈C4、一条四边路径P5、两条二边路径2P3。三圈加单边等情形已由单边分量排除。

每名B型低点使用两个顶点不交的X边；不同B型点不能使用同一对X边，否则两条F3共享两个低点，违反低点对共度一。C4只有两对不交边，P5只有三对，都不足提供四名B型点。因此

$$X=2P_3.$$

两条P3的叶子度一，故t=0；每条边端点t和恰四，两个中心A、B各t=4，其余高点t全零。两条路径分量的顶点本来互不交，不需要额外的叶子分离假设。

## 5. b=4的同一H点对超额给W≤17

**进口W25：** [六度宏星染色门](../../../../../../proofs/propertyb35/TWENTYFIVE_MACRO_STAR_COLORING.md)说明，某实际低点的六link四块内点对超额和Wz≤25即给原H染色。

中心A、B度均为11，在F3中各出现两次，覆盖六名低点。每个B型低点在两个不同路径分量各用一边，因此与A、B都通过F3相遇；每个A型低点仅用一条F3，所以通过其中一个中心相遇。故八名低点均已通过F3与至少一名中心共现。

任何含低原边都不能同时含A、B，否则它含有的任一低点与至少一个中心重复共边。因此A–B共边全为高-only边。又每个中心的两条F3只覆盖六名低点，为覆盖剩余两低，它还至少有一条其他含低原边。所以各自高-only度至多11−3=8，得

$$\lambda_{AB}\le8,\qquad w_{AB}\le7.$$

全H的点对超额总量为350−300=50，涉及低点的超额均零；高点x的超额行和是4d(x)−24。A、B各行和20，故删去A、B后其余高点间的超额总量为

$$50-(20+20-w_{AB})\le17.$$

取任一B型低点z。它两条F3的link高点对都是中心–叶，已证明w=0；其余四个link块因单位z–中心共度而避开A、B。涉及低点的费用也零。因此Wz只从上述其余高点对取非负费用，每对最多取一次，得Wz≤17≤25，W25给原H可染。

## 6. 结论及验收边界

b=1、4、7全部排除，所以r=8无四低原边的C0整个实际子支在M17、W25进口下可染。b=1的闭合是唯一B点的一低边约束与缺失二低点的共同覆盖矛盾，b=4是同一实际四边图及共享超额，不是新增必要表的通过率。

本次仅解析推导，无程序或新有限分类计算。root给出的b=4／7草案已逐步独立核对，未发现实质缺口；b=1新增短证同属same-family/provisional。本报告不单独声称全部r=8或r≥8，因为有四低边的C4/C8子支由另一代理负责装配；也不声称r≤7、全25或m(5)≥36已闭合。没有调用MCP、Lean或v2。
