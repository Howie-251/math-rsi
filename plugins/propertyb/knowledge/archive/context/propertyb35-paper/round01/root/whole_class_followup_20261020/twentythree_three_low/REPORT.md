# 23点三低原边门与恰十三六度点的闭合候选

## 结论与范围

## 1. 四低门的全局后果

H为23点、35条互异五元边的点对覆盖超图，且最小度至少6。令L为全部六度点，r=|L|。假定H非B。已核四低原边定理使每条边至多含三个L点。

固定z∈L。其六条边最多提供12个其他L点的关联；点对覆盖要求至少r−1个不同L点，所以r≤13。

若r=13，每个z的六条边都恰有三个L点，且其余12个L点恰各出现一次。因此：

1. 每条含L点的原边恰含三名L点；
2. 每对L点共度恰1；
3. 三低原边数n3=6·13/3=26；其余九边无L点；
4. 其余十个顶点全部度至少7，总度175−78=97，故存在一个高点u满足7≤d(u)≤9。

点对覆盖保证u与任取的低点同属某条原边G。该G恰含三名六度点及u、另一高点h，且G内低点对共度恰1。下述三低局部门适用，矛盾。因此r=13可由完整局部门排除；结合r≤13，候选结论为非B⇒r≤12。

## 2. 新局部门的准确合同

设G={0,1,2,3,4}是原边，0、1、2度为6，3度U∈{7,8,9}，4度d≥7。假设G内三对低点共度均为1。则H具有Property B。

本程序实际证明的数值门对全部d≥7有效，不要求d≥U。没有对低点—高点的内部重复作零假设。

令S=V\G，|S|=18。每低点共度盈余恰2，高点3盈余4U−22。非G边的G迹大小不能≥4，因为任何四迹必含低点，并在那里消耗≥3。非单迹仅二迹、三迹。低点对共度1又使非G边不能同时含两个低点。

因此每个低点z的内部迹恰有以下七种多重集之一：空；{z,3}；{z,4}；两份{z,3}；{z,3}+{z,4}；两份{z,4}；一份{z,3,4}。另有m份高高迹{3,4}。这是完整结构分类，不是样本。三低各七种与m=0,…,U−1的笛卡尔积，经过实际高点行预算及度数非负过滤后，给出全部必要域。

记I为内部非单迹多重集，c_i为其边关联数，w_i为Σ_{T∋i}(|T|−1)，K=21−U+Σ_T(|T|−1)。真实原边计数为：低点单迹5−c_i；3的单迹U−1−c_3；4的单迹d−1−c_4；纯外五边K−d。故保留条件c_3≤U−1、w_3≤4U−22，且

max(7,1+c_4,ceil((22+w_4)/4))≤d≤K。

后三者分别来自高点4非六度、实际单迹非负、点对覆盖重复预算、纯外边非负。外部重复可消耗内部预算剩余，不能要求内部预算恰等号。

## 3. 实际补色费用

枚举一、二、三名自由低点，但只选没有内部共同原边的自由集合。其非G星边按真实原边索引互异，各中心恰五条。其余G点固定配成非单色，保护G；其余34−5f条非G边避开所有自由中心。三低零重复子域总能选三自由；较少自由可能给更强界，因此菜单同时比较。

自由低中心内部pin数仍至多2，其完整单星外部域正是已独立逐颜色核对的14型。重用该实际失败数表，不重新计算或扩大其适用范围。异色pins的原边恒proper，其他pins的颜色决定强迫方向。

固定原边按真实G迹计费。外点数s、固定pins同为蓝时坏样本C(18−s,q−s)，同红时C(18−s,q)；混色pins收0；纯外五边收两色之和。只扣固定单迹红组与蓝组各自已验证的普遍重叠下界。自由失败组、其他固定边及两单迹组之间继续取并界，不扣跨组交。

所有计算为整数，比较两个配额的归一化费用使用交叉相乘。对每键给出具体自由集合、固定颜色、配额和费用，见RESULT系列的rows。严格小于C(18,q)使同一个S染色避开全部失败事件；每条非G边至多含一名自由中心，故逐中心补色相容，得到原H的完整proper染色。

## 5. r=12的准确剩余

对每个低点z，令b_z为其六条边中对“每边另有两低点”的缺额总和，e_z为到其余11低点的总重复，则b_z+e_z=1。因此e_z≤1，低点重复图是匹配，每条重复对共度2。令E为全体低对重复数，n_i为恰含i低点的原边数，则求和给

n1+n2+E=6，且n1+2n2+3n3=72，故n3≥20。

一般三低+七度合同并不含低点对零重复。本次也完整生成此更大域：3084库存、42,344键，4,872,836个颜色/自由选项，42,312键strict，32残键。施加r12必需的每低点到其他低点重复≤1后，留下九个标号残键，恰是以下两种形状（低点重标号下）：

1. 非G内部迹为{0,1}及{2,3,4}，U=7，d=8或9。各有三种低点标号，共六键；最佳菜单分别48946/48620、43831/43758。
2. 非G内部迹为{0,1,4}、{2,3}、{2,4}、{3,4}，U=7，d=12。三种低点标号，共三键；最佳菜单43783/43758，超25。

完整九键存R12_RESIDUAL.json。这些是必要库存松弛的未覆盖键，不是实际H反例；当前菜单未证明这两型可染，也没有证明r12必有可套已闭局部门的原边。因此r12继续开放，不据本次结果排除。
