# r6中统一换选三个七度点：避开首失败的必要关系

2026-10-20。本稿只证明一个实际选锁引理，不把它单独称为整个r6闭合。设H为25点／35简单五边／pair-cover、恰六名六度点，且所有原边低迹至多二。沿用[r6纯低迹结构](../r6_pure_pair/REPORT.md)：六个一低原边、十五个二低原边、十四个纯高原边。

## 1. 首失败base23的可读签名

原九锁低标签{0,1,3,4,5,6}依次重命名为l1,…,l6，三名七度锁点为A=2、B=7、C=8。固定高点x，含低边的低迹分解是六低点上的匹配M_x及私有单点S_x。

|七度点|匹配M|私有低点S|私有数s|含低度dF|纯高度d0|
|---|---|---|---|---|---|
|A|{l1l2}|{l3,l4,l5,l6}|4|5|2|
|B|{l3l5,l4l6}|{l1,l2}|2|4|3|
|C|{l1l3,l2l4,l5l6}|空|0|3|4|

三对七度点的唯一共同原边都是同一条纯高五边E={A,B,C,p,q}；原九锁mask388，p,q在未锁的16个高点中。没有含低原边同时含这三点中的一对。三对matching没有共同配对、private集合也互不交，故三对在六个低星中同块次数qσ全零，λAB=λAC=λBC=1。

这与既有完整高点必要约束没有直接矛盾：选中点的私有半关联预算为2+1+0=3，全部19高点总预算十二，余十六高点仍有九份；选中C只给一个无固定点匹配点，不强迫三个满匹配类，也没有六次私有点。其纯高度2、3、4与真实trace计数一致；三个七度点各t=0，且相互w=0，不直接超额行容量。

上述只是必要约束检查，不是十六个自由高点的完整补全证明。不能把“未直接违反”改成实际H存在，也不能以单profile未排掉就断言不能换锁。

## 2. 通用选择引理

令V7为全部七度点，N=|V7|≥13。对V7的每点x赋其真实私有次数s_x∈{0,2,4,6}。由六个私有四高块，全部高点满足Σs=24，故在V7上

$$g_2+2g_4+3g_6\le12,$$

其中g_j为V7中s=j点数。令J连接所有λxy>1的七度点对。每个七度点的超额行和四，所以普通图Δ(J)≤4。非邻点对由pair-cover知共度恰一。

**引理。** 存在一个J独立三元组I，使得以下至少一项成立：

1. 其私有次数多重集不是{0,2,4}；
2. I不包含在任何纯高原边中。

因此可以选到三个七度单位点，避免“s多重集{0,2,4}且三点同属纯高边”这个比首失败base23更宽的必要关系。

## 3. 同私有类有非邻点时立即换选

先反设每个J独立三元组的s多重集都是{0,2,4}，且都包含于某纯高边。

若有s=6七度点v，它有至少N−1−4≥8个非邻点。这八点不可能成团（最大度四），故其中有一对非邻点，与v构成s含6的独立三元组，矛盾。因此g6=0。

若某同s类有非邻点u,v，在N≥13、最大度四下，除去u,v及它们的全部邻点至多十点，尚有至少三点可取为共同非邻点w。于是{u,v,w}是有两个相同s的独立三元组，再矛盾。

所以g0、g2、g4三个类各自都诱导一个团，大小各至多五。又g0+g2+g4=N≥13，g2+2g4≤12，得到

$$g2+g4\ge8,\quad 3\le g4\le4.$$

若g4=3，必(g0,g2,g4)=(5,5,3)；若g4=4，必(5,4,4)。两者均N=13，没有更大N的例外。

## 4. 十四条五边不够覆盖全部独立彩虹三元组

**(5,5,3)情形。** 两个K5类的每个顶点内部已占普通度四，无其他七度邻点。故任何跨三个s类各选一点的三元组均独立，共5·5·3=75个。

**(5,4,4)情形。** g0的K5没有外邻点；其余两个K4类的每点内部已占三度，所以它们之间的边至多形成四条匹配边。因此两K4之间至少16−4=12个非邻点对，与K5任一点合成至少5·12=60个独立彩虹三元组。

对任一纯高五边e，记它分别含a、b、c个s=0、2、4的七度点。未计入的非七度高点只减少a+b+c，故a+b+c≤5。e中的彩虹三元组数是abc，非负整数条件给

$$abc\le4,$$

最大出现在(2,2,1)及其排列。这里**没有**假设同s类的两个点不能同时位于e；虽然同类在冲突图中是团，它们仍可共原边，所以保留(2,2,1)并按乘积四收费。

十四条纯高五边至多覆盖14·4=56个不同彩虹三元组（重复覆盖只降低并的大小），不足覆盖至少60或75个独立彩虹三元组。矛盾，证明引理。

## 5. 应用边界

此引理对每个实际H提供一次统一换选，不需枚举所有独立三元组，也不依赖首失败的具体M排列。它能避免所有同时满足上述两项必要关系的失败profile，而非仅避免一个标签。

它是否足以装配r6，取决于九锁完整必要域中**全部**非严格DP轨道是否都落在这同一宽类中。若另有失败s型或没有共同纯高边的失败型，本引理不能自动排除它们。完整DP结果及投影另存，本稿不预设该条件成立。

证明完全解析，未枚举原H、2SAT或新布局。独立核查属same-family/provisional，实际完整装配与新scope跨家族审阅由主代理负责。
