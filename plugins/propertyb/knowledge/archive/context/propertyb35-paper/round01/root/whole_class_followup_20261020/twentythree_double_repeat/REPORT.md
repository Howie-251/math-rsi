# 23点四低原边：两个共度三配对组件的完整条件子族

**结论。** 设H为23点35条互异五元边、覆盖全部点对。若存在原边
$G=\{x,y,a,b,h\}$，其中$x,y,a,b$均度六且$\lambda_{xy}=\lambda_{ab}=3$，则H具有Property B。第五点度数任意，无需另外假定非六度。

本结论只处理这两个互不相交的共度三低对，不覆盖其他内部重复图或全部23点最小度六情形。数学接口及完整局部域如下；本次没有MCP、Lean或原H搜索，证据为same-family/provisional。

## 1. 从实际H导出的原边分类

[预先写出的实际分类与公式](ACTUAL_CLASSIFICATION.md)给出完整计数。令$S=V\setminus G$，$|S|=18$，$d=d(h)$。每个六度点z有

$\sum_{v\ne z}(\lambda_{zv}-1)=4\cdot6-22=2$。

已知配对点贡献恰二，所以与其余所有点的共度均恰一。非G边不可能含三个G点，也不可能混合xy和ab两个组件或同时含h与低点。

额外ab边是$\{a,b\}\cup T_1$、$\{a,b\}\cup T_2$，其中两个三集互不交。a到S每点共度恰一，故a的另外三个四点私有迹恰划分

$X=S\setminus(T_1\cup T_2)$，$|X|=12$；

b的三个私有四迹划分同一个X。二者的全部共同数据由3×3非负整数交矩阵M记录，行列和皆四。这里不假设两份划分相同。

固定x红、y蓝、h蓝，仅补a、b。G恒proper，xy两条额外边恒proper。原边索引分为：

| 类别 | 数量 |
|---|---:|
| G | 1 |
| xy额外边 | 2 |
| x的私有四迹边 | 3 |
| y的私有四迹边 | 3 |
| h的四迹边 | $d-1$ |
| 纯S五边 | $19-d$ |
| ab组件：两三迹及六四迹边 | 8 |

总计35，故$6\le d\le19$。下限来自pair-cover。分类没有重复收费：ab组件原边均含a或b，其余固定边均不含a、b；固定类别又按与G的精确交集区分。

## 2. 单个ab组件的精确失败条件

在X的一个蓝点集合Z下，记$R_a,B_a$分别为a的某私有四块全红、某私有四块全蓝，b同理。若$R_a\cap B_a$或$R_b\cap B_b$发生，则相应中心无法补色，称为核心冲突。

若无核心冲突，则有红块迫中心蓝，有蓝块迫中心红，均无则可任选。若两中心可取异色，ab两额外边自动proper；唯一剩余失败是两中心都被迫同色c，且至少一个$T_i$全c。因此失败事件严格分为：

1. 核心冲突；
2. 无核心冲突、a和b均被迫蓝、至少一个$T_i$全蓝；
3. 无核心冲突、a和b均被迫红、至少一个$T_i$全红。

这三类互不相交。该判据等价于实际两中心无法补色，不仅是并界。

对每个$Z\subseteq X$，令$j=|Z|$。在S需选q个蓝点时，T六点的蓝数为$k=q-j$。普通完成数为$\binom6k$；至少一个三块全蓝的完成数为

$2\binom3{k-3}-\mathbf1_{k=6}$；

至少一个三块全红的完成数为

$2\binom3k-\mathbf1_{k=0}$。

非法下标组合数取零。这三个二项式分别乘上述三种X状态数，得到精确组件失败数$F_q(M)$。T配色没有逐个枚举；它与X的组合通过固定蓝数绑定，不使用独立概率假设。

## 3. 3×3矩阵完整域与精确最大值

任意行列和四的3×3非负整数矩阵均由左上2×2的四个数唯一决定。完整生成取$a,b,c,e\in\{0,1,2,3,4\}$，构造

$M=\begin{pmatrix}a&b&4-a-b\\c&e&4-c-e\\4-a-c&4-b-e&a+b+c+e-4\end{pmatrix}$，

只保留全部非负者。这得到**120个有标签矩阵**，不取商、不依赖canonical库。每个矩阵在格内用不同点标签实现，形成两份X12三块划分；给定任意实际两划分，同格内双射使它与对应实现同构。该重标号保持全部组件事件及蓝点总数。两个T三块也只需分别重标号。

[CHECK.py](CHECK.py)对全部120矩阵的全部$2^{12}=4096$个X颜色状态检查上述等价判据，再用T完成公式分别计算q8和q9。完整覆盖491520个局部X状态，不是原H枚举。

[RESULT.json](RESULT.json)逐矩阵保存核心冲突、两种被迫颜色的精确分项及蓝数直方图，得到

$\boxed{F_8(M)\le5082,\qquad F_9(M)\le6156.}$

两配额的最大值均只在六个4倍置换矩阵达到，即两份三块划分相同（允许块顺序置换）。因而这些是该组件问题的精确最大值。

先取三个矩阵profile，CPU0.007280秒，预估全部0.2912秒；最终完整运行及整数断言**PASS，CPU0.293312秒**，远低于30秒预算。[PROFILE.json](PROFILE.json)保留先测记录。

## 4. 接回实际固定边与原染色

S上q8即8蓝10红时，固定红点的四迹坏数为3003，固定蓝点的四迹坏数为1001，纯五边坏数为1573。因此上述完整固定原边分类给固定坏样本并界

$3\cdot3003+3\cdot1001+(d-1)1001+(19-d)1573=40898-572d$。

再并上组件失败事件，不要求固定事件与组件独立，得到

$\text{总失败数}\le40898-572d+5082=45980-572d$。

实际$d\ge6$，所以

$45980-572d\le42548<\binom{18}{8}=43758$，

最小余量为**1210**。于是存在S配色使所有固定边proper且ab组件可补色；按第2节选a、b颜色，连同已经固定的x、y、h，得到同一原H的proper二染色。整个指定子族闭合，无需任何固定同色组重叠扣除。

供比较，q9时固定四迹坏数均为2002，纯五边1430，故

$\text{总失败数}\le37180+572d+6156=43336+572d$。

该界在$d=6,7,8,9$分别余1852、1280、708、136，$d\ge10$不严格。q8已覆盖全部实际度数，正式结论无需分度数切换。程序保存$d=6,\ldots,19$两配额的全部算术，仅作接口复算。

本证明没有假定x/y私有四迹与h四迹互异，也没有扣这些组间的重叠；即使它们给相同外部集合，各自正费用仍构成合法并界。它也没有对其他内部低点重复形状提出结论。
