# r5九单位锁：完整必要域与四七度选点边界

2026-10-20。**只完成有界结构诊断与三个profile，不闭合整个r5，也不启动全域DP。** 实际入口除一个明确三K5例外外可选五低＋四七单位锁；完整必要域有3107标记／1689彩色轨道，明显大于r6。所有结果为same-family/provisional。

## 1. 同一实际H的五低分解

设H为25点／35简单五边／pair-cover，恰五名六度点；假设每条原边低迹至多二（非B时由[SMALL_LOW_TRACES](../../../../../../proofs/propertyb35/TWENTYFIVE_SMALL_LOW_TRACES.md)保证）。记低集L，高集K，|K|=20。每个低点z与所有其他点共度一。高点写d(x)=7+t_x≥7，则

\[
\sum_{x\in K}t_x=175-5\cdot6-20\cdot7=5.
\tag{1}
\]

低点对唯一，故二低边n2=C(5,2)=10；低关联30给一低边n1=10；纯高边n0=15。固定低点z，其四条二低边各覆盖另一低点，另恰有两条一低边。删去z后的这两个私有四高块互不交。

对高点x，含低边的低迹划分五个低点：二低迹是匹配M_x，剩余私有低点集S_x满足

\[
s_x=|S_x|\in\{1,3,5\},\quad |M_x|=(5-s_x)/2,\quad
d_F(x)=(5+s_x)/2,\quad d_0(x)=(9-s_x)/2+t_x.
\tag{2}
\]

十条一低边各含四高，给Σ_K s_x=40。若h_j计s_x=j的高点，则

\[
h_1+h_3+h_5=20,\qquad h_3+2h_5=10.
\tag{3}
\]

**与r6的重要区别：** 同一个低点z有两个不同私有四高块。两高点的S_x、S_y都含z，并不表示它们位于同一条一低边中。因此不能把r6的“私有点交数＝共同一低边数”或其s6点行预算直接迁移到此处。后续若使用私有签名，必须保留每个z的两块归属。

## 2. 四名单位七度点：精确唯一结构例外

令V7为全部七度点，N=|V7|≥15。七度点的超额行和为4，故连接λxy>1的冲突图J满足Δ(J)≤4。其独立集是两两共度恰一的点集。

设J含s个K5分量。任何K5分量内部已经用尽每点四个普通邻点，故没有外邻边。其余部分的每个连通分量按Brooks定理可用至多四色（奇环也至多三色），因此

\[
\alpha(J)\ge s+\left\lceil\frac{N-5s}{4}\right\rceil.
\tag{4}
\]

若N≥16，该式至少四；N=15且s≤2时也至少四。**唯一可能没有四独立点的图是N=15且J恰为三个不交K5。** 反之此图的独立数确为三。这是完整图论例外，不是仅提“Brooks大概够”。

在这个例外的实际H中，剩余五名高点Y都满足t=1、度八：它们t为正且总和五。每个七度点所在K5内四个点对超额都至少一，行和恰四，所以每对超额恰一（共度二），与其余全部点的超额为零。于是

\[
w(Y)=20,\qquad \sum_{y\in Y\setminus\{x\}}w_{xy}=8
\quad(x\in Y),
\tag{5}
\]

其中w=λ−1为非负整数。三个七度K5内部超额共30，加(5)为全H的50。

**(5)不推出Y内每对超额均二。** 例如从十条权二的K5开始，在四个顶点组成的四环上按交替符号加减一，所得权仍非负整数、每点行和仍八，却已有权一和三。这个只是加权图层面的松弛见证，不是实际H构造；它说明不能靠行和把Y擅自当成第四个均匀组。

旧[K5_SINGLE_COMPONENT](../../../twentyfive/K5_SINGLE_COMPONENT.md)明确要求全25点度七；本例有五低及五八度点，不能直接引用其结论。这里没有证明三K5例外不可能或可染，仍需一个实际单组／多组染色或结构义务。

除该例外外，取J独立四元组，与全部五低点组成实际九单位锁。以下必要域覆盖的正是这个caller。
