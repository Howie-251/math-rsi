# 七名六度点的共同低迹补盖证明

2026-10-20。**在明确进口M17下，25点、35条互异五元边、pair-cover且恰七名六度点的整个实际子支具有Property B。** 新证明只用同一原H的七份高超额、低点单位共度、整数关联及缺失低迹补盖；不需要宏星W门或新局部计算。以下为完整纸面候选，same-family/provisional，尚未审阅新scope的跨家族意见不被计入。

## 1. M17与同一六星的高超额预算

令H满足上述条件，L为全部七名度六点，K=V\L有18点。pair-cover使每点度至少六，故K中每点度至少七。写

$$t_x=d(x)-7\ge0\quad(x\in K),\qquad
\sum_{x\in K}t_x=(175-6\cdot7)-7\cdot18=7.\tag{1}$$

任一低点z与其他24点的共度至少一，而共度行和4d(z)=24，故

$$\lambda_{zy}=1\quad(y\ne z).\tag{2}$$

六条过z原边删z后划分其余24点。特别，每个高点在同一六星中恰出现一次；对任一固定高点x，所有过x的含低边的低迹也两两不交并覆盖L。

**唯一进口M17。** [三低同边平衡补色定理](../../../../../../proofs/propertyb35/THREE_LOW_EDGE_BALANCED_EXTENSION.md)：若原边G含三名不同六度点，余两点u,v满足

$$d(u)+d(v)-5(\lambda_{uv}-1)\le17,$$

则原H可染。此门不要求三名中心是全部低点，已有完整原H到Bool染色接口。

反设H非B，记ℓ(e)=|e∩L|。全五低边由M17的D=12、α=0排除。

* 四低边的唯一高点Q必须t_Q≥5。
* 三低边的高点对uv必须t_u+t_v≥4+5w_uv，其中w_uv=λuv−1≥0。

由(1)，三低边高点对还必须满足

$$\boxed{w_{uv}=0,\quad\lambda_{uv}=1,\quad t_u+t_v\ge4.}\tag{3}$$

因为w≥1会要求t_u+t_v≥9>7。本结论只对实际三低边的高点对，不是全图共度上限。

## 2. 三种六星型与五份完整必要库存

对任一低点z，令a_j为其六条星边中低迹大小j的条数。由(1)(2)，

$$\sum_{j=1}^4a_j=6,\qquad
 a_3+2a_4-a_1=0,\qquad4a_3+5a_4\le7.\tag{4}$$

最后一式在同一六星中收每个实际高点的t恰一次。非负整数解只有

$$A=(0,6,0,0),\quad B=(1,4,1,0),\quad C=(2,3,0,1).$$

确实a4至多一；a4=0时a3=a1且a3≤1；a4=1时a3=0、a1=2。

令A/B/C型低点数分别为a,b,c。记n_j为原H低迹大小j的边数。精确关联次数给

$$a+b+c=7,\qquad
n_1=b+2c,\quad2n_2=42-2b-3c,\quad3n_3=b,\quad4n_4=c.$$

所以c=0或4，b为三的倍数，恰有以下五份必要库存。

|c,b|a,b,c|n0,n1,n2,n3,n4|
|---|---|---|
|0,0|7,0,0|14,0,21,0,0|
|0,3|4,3,0|13,3,18,1,0|
|0,6|1,6,0|12,6,15,2,0|
|4,0|3,0,4|11,8,15,0,1|
|4,3|0,3,4|10,11,12,1,1|

这些只是对同一H的穷尽整数后果，不声称五库存均可由实际H实现。下面全部排除。

## 3. 无四低边：b=0的奇数低点覆盖

此时n1=n3=n4=0，全部含低边低迹大小二。固定任一高点x，其含低边低迹根据(2)必须彼此不交并覆盖全部七低点。因此2d_F(x)=7，其中F是含低边族，矛盾。

## 4. 无四低边：b=3的一低边关联不足

此时唯一三低边G的低迹恰为三名B型点，高点对为u,v；一低边仅三条。

对任何其余16名高点x∈K\{u,v}，它没有三低入射，只能用一低或二低原边覆盖全部七低点。由(2)覆盖不重复，故其一低入射数必须为奇数，尤其至少一。

因此三条一低原边需要为这16个不同高点提供至少16次关联；但每条一低五边仅有四个高点，全部仅3·4=12次，矛盾。没有把关联下界当作不同原边数。

## 5. 无四低边：b=6的缺失唯一低点

两条三低边G1、G2的低三元迹由各有一条三低入射的六名B型点组成，故互不交；剩下一名低点z为A型，其全部六条星边均为二低边。

两条三低边的高点对各须支付至少四份t。若高点对不交，总预算至少八，与(1)矛盾。因此存在高点Q同时属于G1、G2。

Q已经在这两条边中与六名B型点分别共现一次。为了覆盖Q–z，它需要另一条含z原边；但z的所有边都是二低边，所以该边另有一名B型低点y。这会再次覆盖Q–y，违反(2)，矛盾。

这里无需预设共享高点度数，也不用把两条F3视图分别优化；它们就是同一个H的两条原边。

## 6. 有四低边：b=0的缺失三低点

此时唯一四低边的低迹恰为四名C型点，高点为Q，t_Q≥5。剩余三名低点均为A型。

Q已经与四名C点共现一次，任何其他含低Q边都必须避开这些C点。一低边只以C点为唯一低点，不能含Q；没有三低边。因此Q只能通过二低边覆盖剩余三名A点。它们的低迹必须彼此不交并覆盖这三点，迫二整除三，矛盾。

## 7. 有四低边：b=3的共同高点与无全高余边

此时四低边的低迹是四名C点，唯一三低边的低迹是另外三名B点；两低迹互不交。四低边高点Q满足t_Q≥5。

若三低边不含Q，其两高点最多共享总t−t_Q≤2份t，与(3)的至少四矛盾。因此三低边必须为这三名B点加Q,R，其中R是另一高点。

Q通过四低边和三低边恰覆盖全部七低点，根据(2)，其他过Q原边全部为高-only。此库存只有十条高-only边，故

$$12\le d(Q)\le2+10=12.$$

因此d(Q)=12、t_Q=5，并且全部十条高-only原边都含Q。

(3)又给λQR=1，唯一共边是上述三低边。因此R不在任何高-only原边中，否则那条边也含Q，导致λQR≥2。

R的所有原边都含低点，其低迹彼此不交并覆盖L。已有一条三低边覆盖三名B点，剩下四低点每条其他R边至少消耗一个，所以

$$d(R)=d_F(R)\le1+4=5.$$

但R是高点，应有d(R)≥7，矛盾。
