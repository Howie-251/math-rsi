# 标记共同四横截集：独立字面计数核验

**PASS_WITH_DECLARED_IMPORTS，same-family／provisional。** 本次只导入此前已独立完整核对的264个交矩阵及其J=|B_P∩B_Q|，不重新生成矩阵域或重算J。另行完整生成所有正格四匹配，直接用20个不同点的红蓝样本数计算K，没有调用主实现的容斥或marked计数函数。

## 实际对象与计数语义

P、Q是同一20点集上的两份五四块划分。T是一个四点集，在两份划分的每个块中至多取一点，因此各遗漏唯一一行r₀和一列c₀。K(M,T)计数以下10红10蓝染色：T全部红，且P、Q都同时有全红块及全蓝块。

T已在其他四行、四列分别有红点，所以唯一可能的全蓝行、列恰是r₀、c₀。因此这两个块必须全蓝。它们的并大小为8−M[r₀,c₀]，介于4和8之间，与T不交。

固定T红、该并蓝以后，尚有8…12个自由点。只须从中选择6点红，使总红点数为10，再逐块字面判断P有全红块、Q有全红块。全蓝块已被强制保证，所以这与完整双冲突事件严格等价；没有遗漏其他蓝块选择，也没有重复计数。

## 独立实现与完整标记覆盖

[prepare.py](prepare.py)只读取早先冻结的[264代表及J](../../../global_reassessment_20261020/three_low_extension/partition_joint/REPRESENTATIVES.json)，将其逐矩阵写为独立输入；没有读取producer的marked结果生成计数。

[CHECK.cpp](CHECK.cpp)将每格展开成不同点，采用**列优先**编号，区别于producer的行优先编号。对每个遗漏行，按另四行递归选择不同的正格列，剩余列即遗漏列；这直接生成全部四行四列的正格双射，不读取producer的支持模式。

每个支持模式在四个被选格中各取第一标签为T。它代表该支持的所有点选择：每格内部任意标签置换均保留P、Q及均匀10红样本空间，并将任何选点T送到首标签T。因此K仅取决于四个正格的支持，不取决于格内所选标签。若格大小分别为m₁,…,m₄，该支持对应m₁m₂m₃m₄个带点标签的T；本实现额外记录此乘数。

所有自由红点选择均用递归生成实际六点子集，而不是容斥、独立概率或组合数上界。每个红集只出现一次。检查条件仅为“某行块全在red中、某列块全在red中”；T与强制蓝集已经保证其余部分。

## profile、完整范围与结果

首5矩阵profile：[PROFILE.json](PROFILE.json)，共55支持、31052个六红子集，CPU0.000586秒。按该成本继续完整域，没有触及60CPU秒上限。

[完整RESULT.json](RESULT.json)与[LITERAL_PATTERNS.tsv](LITERAL_PATTERNS.tsv)记录：

* 全部264个输入矩阵；
* 另行生成的17304个不同格支持模式；
* 2239230个字面六红子集；
* 逐矩阵支持数、maxK、独立最大见证及J−15maxK；
* 最小J−15maxK为324，在source262；完整literal CPU0.017558秒。

**17304不是带点标签横截集数。** 所有支持乘格大小后，对应112089个带点标签共同四横截集；不应把这两个口径混用。只核每支持的首标签不会损失其他点选择的K值，理由是前述格内标签对称。

[COMPARE.py](COMPARE.py)只在独立计数完成后读取producer结果。它核：全部17304个模式键逐项相等、全部K逐项相等、全部264个maxK与J−15maxK相等；每个producer所存maximizer在独立模式表中的计数都等于maxK；还按其行优先编号重新构造并核了全部producer point_mask元数据。若存在多个最大见证，不要求两个实现恰选同一个，但producer的见证均被实际重放。

[COMPARISON.json](COMPARISON.json)为PASS，比较CPU0.041161秒。source262为J=624、maxK=20、差324；J−I的source263为J=400、maxK=4、差340。没有发现反例或未覆盖模式。

## 精确进口与边界

唯一数值进口为已验的264交矩阵完整域和其J值；本次既不借用producer的K，也不借其选择的最大支持。producer只在最后用于逐项比较。独立输入、模式和值均保留在本目录；没有改动producer文件。

这验证的是完整两划分／标记横截集局部引理，未直接枚举、构造或染色任何原H。原三低同边的实际T对应、系数15及q=D−5α≤17的原H概率连接仍由上层证明负责；本报告不把局部PASS冒称为该装配已完成或完整36已证。
