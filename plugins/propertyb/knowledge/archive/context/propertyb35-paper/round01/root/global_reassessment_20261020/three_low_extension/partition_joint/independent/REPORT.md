# 两划分共同冲突引理的独立确定性核对

**PASS。** 对20点的两份五个四元块划分，10红10蓝样本中，两份划分都同时具有全红块和全蓝块的样本数至少400。独立实现逐代表得到的全部264个计数与生产者完全一致；最小值400仅一个行列置换轨道，代表为J−I。4I控制计数16980，J−I控制计数400。

核对者为独立GPT-6.1 Sol子代理，模型关系same-family/provisional；以下为保存了源码、完整域与实际执行结果的确定性检查，不是额外模型审阅。未枚举原超图H，也没有推出任何上层25点整类结论。只写本`independent/`目录，没有接触v2或Lean。

## 独立方法与完整域

`VERIFY.cpp`没有使用生产者的容斥计数。每个给定交矩阵都在格子中依次放入总计20个不同标签点，生成五个行块和五个列块的20位掩码。Gosper算法生成全部184756个恰含十个1的20位红集；对每个红集，直接判断行块是否同时有全红及全蓝块、列块是否也同时有两者，二者成立则计一。

全部264代表检查了**48,775,584**个“代表×红集”对；另两个控制矩阵检查369,512个红集。没有抽样、容斥、概率近似或浮点计数。

覆盖核对也独立重做：穷举全部5⁵个数字向量，取总和四者，得到70个行向量。递归选择全部五行，要求行非降、列累积和不超过四；第五行也从70行中真实选择，不由列余量直接填写。恰有19834个满足列和四的终态。**每个终态均进入规范化，不做列排序/doublelex提前筛选。** 对120个列置换逐一计算，再排序行取最小五进制展开值。每个终态的规范值均属于给定264代表；规范值集合反向也全部相等。每轨道对应终态数保存在逐代表记录中，总和19834。

逐代表结果及轨道终态重数见`RESULT.json`，生产者双JSON的再次逐项比对见`COMPARISON.json`。输入由`prepare.py`仅作JSON读取与整数导出，未计算任何事件值。源`REPRESENTATIVES.json`及`RESULT.json`均未修改。

## 运行与CPU

实际执行：

```sh
python3 prepare.py
clang++ -O3 -std=c++17 VERIFY.cpp -o VERIFY
./VERIFY profile
./VERIFY full
python3 compare.py
```

profile先完成两个控制及前五代表的全部红集重放：CPU 0.004889秒，其中literal计数0.002592秒；未生成全矩阵域。之后完整运行生成域CPU **0.018666秒**，完整逐红集及控制计数CPU **0.039491秒**，总CPU **0.059339秒**，均为程序`std::clock()`实际测量。编译约0.99秒墙钟，未计入该算法CPU值。没有接近120 CPU秒预算，也没有截断、重试或未覆盖项。
