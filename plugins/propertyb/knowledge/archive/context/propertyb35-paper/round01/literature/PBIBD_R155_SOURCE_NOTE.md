# a5的另一个正确文献入口：two-associate PBIBD / R155

2026-10-19。这是术语与范围核对，没有新增a5染色结论。

原始来源：Dinesh Sarvate, Nutan Mishra, Kasifa Namyalo, *Group Divisible Designs with Block Size Five from Clatworthy’s Table*, accepted author manuscript (2016), DOI [10.1080/03610926.2016.1179763](https://doi.org/10.1080/03610926.2016.1179763)。本次由[作者所在大学库](https://ir.must.ac.ug/items/0fe590b0-242d-4ecb-93b9-150d0917a355)实际下载29页PDF，ref/literature-20261019/sarvate_mishra_namyalo_clatworthy.pdf，另有pdftotext文本。

实际阅读仅§1定义与§1.2交型，§8.2（稿件p19）和Table7（p28），未精读其余构造。此文的GDD是two-associate PBIBD，允许内组指标λ1非零；我们的a5确属这个意义的GDD(5,5,5;2,1)，并且参数与Clatworthy R155相同。此前“不是GDD”的表述须限定为Burgess文中的内组共度0的标准k-GDD，不能作为排除全部GDD文献的理由。

§8.2给R155的一族构造：30条RBIBD(25,5,1)边，再加入一份已有平行类的5个块。它得到35个带重数块，但那5块已有，因此这个所述构造不属于本Goal的35条互异边。Binary block只说每块内部无重顶点，不等于全体块互异。它是参数构造，不是全部同参数设计的完整分类，更不能推出任意simple a5 H都来自仿射平面加组。

后续检索可用regular group divisible design、PBIBD two associate classes、R155等关键词；本轮没有因此闭合至少一组非边的a5分支。
