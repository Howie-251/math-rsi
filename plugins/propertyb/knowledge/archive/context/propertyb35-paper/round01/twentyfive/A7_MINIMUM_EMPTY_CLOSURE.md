# 以最小空迹势能闭合25点全七度的 a=7 分支

**定理。** 设 H 是点对覆盖的简单五元超图，恰有25点、每点度数7，最大单位集大小为7，则 H 具有 Property B。单位集指其内部每对共度都为1。

证明由全局选点、最小空迹势能和916个完整局部输入上的固定排列界组成；不枚举完整 H，不要求二级最大化私邻居，不增加第三外点。所有新最终界均使用原始ABC，不作配额扣除。

## 1. 全局私邻居与最小空迹

反设H不可染。令w_uv=λ_uv−1≥0，则每点的加权度为4。对任意七单位集I，每个外点z的w_I(z)至少1，18个外点共贡献28。私邻居指w_I(z)=1的点，设其数为h；于是

    28≥h+2(18−h)，故 h≥8。

私邻居x有唯一伙伴i∈I，权w_ix=1，与I其余点全部为单位对，所以I−i+x仍是七单位集。

旧完整七单位迹目录22核中，19核的原始ABC界严格；唯一五点大迹核由 `A7_TRIANGLE.md` 及其443输入独立重放排除。因而在不可染假设下，每个七单位集都只能是core0（空迹7）或core19（空迹6）。

在全部七单位集中取空迹数μ_0最小的I。若最小值为7，则I为core0。对私邻居x，设r为其空迹度、s为其单迹{i}度；私换的空迹数精确为

    μ_0(I−i+x)=μ_0(I)−r+μ_i−s=8−r−s。

最小性给r+s≤1，故每个私邻居r≤1。对非私外点z，设p、q、r为其单／二／空迹度；core0没有更大迹，故

    p+q+r=7，p+2q=7+w_I(z)，
    2r+w_I(z)≤7。

非私点w_I(z)≥2，所以r≤2。七条空迹边在外点上的度数总和因此满足

    35≤h+2(18−h)=36−h≤28，矛盾。

所以最小值为6，I为core19。这只选择了一个core19的I，不声称H内没有其他core0单位集。

## 2. 最小势能压缩每个私邻居星

以I={0,…,6}标号，其唯一三点迹为C={4,5,6}（掩码112）。core19的完整库存是：空迹6；C内单迹各2、C外单迹各1；C迹1；所有不含C内点对的二点迹各1；其余0。

固定一个私邻居x及其伙伴i。设a∈{0,1}表示x是否属于C迹边，s表示过x的单迹{i}数，r为其空迹度；q_i、q_out为其过点二元迹中包含／不含i的数目，q=q_i+q_out。度数及I关联数给

    q+2a−r=1。

若i∉C，λ_xi=2给q_i+s=2，因此

    μ_0(I−i+x)=6−q_out−2a。

最小值6迫a=q_out=0。全部可能私星只有21个：15种两条i二元迹、四条单迹、空度1；6种一条i二元迹、六条单迹、空度0。

若i∈C，q_i+s+a=2，因而

    μ_0(I−i+x)=7−q_out−a。

最小值6迫q_out+a≤1。完整形状计数为95个：a=1时5个；a=q_out=0时10个；a=0、q_out=1时80个。后一计数允许同一单迹{i}出现两次；不能误当成普通集合划分。细分证明及全部4140个标记incidence划分的独立计数见 `A7_MINIMUM_EMPTY_CORE.md` 与 `A7_EMPTY_MIN_CORE19_CHECK.py/json`。

## 3. 真实异常三角形与完整916输入

至少八个私邻居分给七个伙伴，故某伙伴i有两个不同私邻居x、y。若λ_xy=1，则I−i+x+y为八单位集，矛盾；另一方面x的加权度4已含w_ix=1，所以

    λ_ix=λ_iy=2，c=λ_xy∈{2,3,4}。

其余九锁点对共度均为1。这里没有要求全部伙伴类大小≤3，也没有把c固定成2。

两点的星p_T、r_T都须满足第2节势能条件。对每个旧I迹T（含空迹），共同过点数q_T的完整容量为

    max(0,p_T+r_T−μ_T)≤q_T≤min(p_T,r_T)，Σ_Tq_T=c。

    μ_T−p_T−r_T+q_T，p_T−q_T，r_T−q_T，q_T，

## 4. 八个固定布局给出原 H 的染色

九锁顺序为原I的0,…,6，再x、y。使用以下八个固定位置向量：

    [6,7,8,12,9,10,11,24,25]

C外的101输入只需前两个；C内使用全部八个。对每个输入n，计算

    U(n)=min_布局P [Σ_{k=1}^{25} min(A_k(n;P),B_k(n;P),C_k(n;P))]。

这里先对每个完整布局求和，再取布局间最小值，不把不同布局的逐位置最小值拼在一起。自由点数为16，整数版本的共同分母是16!。上表给出各完整域的max U，均严格小于1；所有C均为原始项，无配额扣除。

最后一个布局也有直接的私换解释：一项输入在I−i+x后，取旧i与y为新外点，以旧x为新伙伴，同一九点库存经换标号[5,6,2,3,7,0,1,4,8]即为另一项已有严格库存；布局按该置换运输，原始界为38583/40040。此时换后空迹仍为6，不涉及与最小势能不相容的二级选择。完整运输恒等式在 `A7_MINIMUM_EMPTY_REROOT.py/json` 中检查。
