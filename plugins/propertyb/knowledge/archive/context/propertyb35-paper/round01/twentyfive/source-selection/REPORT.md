# 六度星源态选择：严格规约与当前边界

## 1. 完成的两个不同选择命题

规范正文为 [TWENTYFIVE_SIX_STAR_SOURCE_NORMAL_FORM.md](../../../../../proofs/propertyb35/TWENTYFIVE_SIX_STAR_SOURCE_NORMAL_FORM.md)。其中有两个各自完整的命题：

- 对任意六度中心，proper删星染色经三个字典序目标择优，要么某方向至多一个全同色四块；要么为两红、两蓝单色块及两个2/2块，删星29边的1/4型边数16至19、跨色盈余至多六。无需其余点D上界。
- 非B假设下，若含六度点的边数至少19，则12/13平衡染色中存在唯一坏边且该边含六度点。单边单色概率为9/230，实际概率下界为(9L−170)/230。覆盖r5全支的源态选择，以及r4且有三低共边的源态选择；不等于覆盖这些输入的二染色证明。

## 2. 正规形的共同预算，同时也是单向修复的真实障碍

在最小单色块总数的proper删星初态，每个单色块点均有同源私有边。选一个方向，正并U由m个四块组成；每个x∈U的私有边的该色部分恰{x}，故产生一个活跃负单集。所有这些原私有边不同，全部小负集又均位于U中，所以

$$\tau(\mathcal N_1\cup\mathcal N_2)=|U|=4m.$$

因此两正块正规形的两个方向都恰有横截数八。其至少八个红少数点私有边与八个蓝少数点私有边是**同一29边中的十六个不同索引**。E≤19只容许合计至多三个额外1/4型索引。两方向的2/3型负集也由同一剩余10至13个原边相互补色恢复，不能各自另取29份负预算。

正规形可以为联合交换提供紧预算，却不能直接满足同事已证明的tau≤3修复门。真正的存在式选择若由那个门实现，必须允许离开该单向局部最优初态。

一个更小的交换边界也可直接证明。若异色点x,y在同一proper初态均受私有边保护，且λ(x,y)=1，则同时翻x,y不可能仍proper：合法交换要求x的每条私有边都含y，且y的每条私有边都含x；两种私有边因初态少数颜色相反而不同，从而λ(x,y)≥2矛盾。所以包含一个六度点的这种受保护异色双交换不能直接出局部最优；这只排除该指定双交换，不排除其他初态或更长交换。

## 3. 唯一坏边含低点的全局最小蓝源：b13刚性

本节额外设恰r∈{3,4,5}个六度点，其余点度至少七。因此高于七的总盈余为r。假设非B，且已经存在唯一坏边含六度点的平衡初态，例如第1节命题覆盖的范围。

在所有“唯一坏边G含至少一个六度点”的完整染色中，将G规范为全红，并最小化蓝点数b。至少一份平衡初态可选，所以b≤13。每个蓝点y都有一条原边F_y，其蓝部分恰为{y}：否则单翻y红不产生新坏边，G仍是唯一坏边且含原六度点，蓝数减一，违背最小性。不同y的F_y不同。

下面仅分析b=13；它与第2节字典序删星初态是不同优化问题。

令r_B为蓝色六度点数，e_B为蓝色高于七的度数总盈余。蓝总度为

$$D_B=7\cdot13-r_B+e_B=91-r_B+e_B.$$

G含低点给r_B≤r−1≤4。其余34边全部proper。令N_j为其中蓝点数恰j的边数，j=1,2,3,4。私有边给N_1=13+z，其中z≥0。由总边数及蓝关联数，

$$3z+2N_2+N_3=6+r_B-e_B. \tag{5}$$

红12点、蓝13点的156个跨色对都必须由这34条边覆盖。它们的跨色关联总数为

$$4(N_1+N_4)+6(N_2+N_3)=136+2(N_2+N_3),$$

故N_2+N_3≥10。与式(5)合并得

$$10\le N_2+N_3\le2N_2+N_3\le3z+2N_2+N_3
=6+r_B-e_B\le10.$$

所有不等式均须取等号。因此唯一可能是

$$r=5,\quad r_B=4,\quad e_B=0,\quad z=N_2=0,\quad
(N_1,N_2,N_3,N_4)=(13,0,10,11). \tag{6}$$

换言之，G恰含一个六度点，其余四个六度点全蓝；蓝点谱为6^4、7^9。所有高于七的盈余五全在红侧。跨色关联数恰156，所以**全部红蓝点对共度都等于一**。每个蓝点也恰有一条私有边，不只是至少一条。

因此r4含三低共边时，上述唯一低源的全局最小蓝数必≤12。r3若另行取得同种唯一低源，亦必≤12；本文没有证明r3总能取得该源。

式(6)还迫G内唯一六度点g的六星形状。除G外的五条边中，设蓝数为4、3、1的边数分别为u,v,w；全局N_2=0已排蓝数2。因g与每个蓝点单位共度，

$$u+v+w=5,\qquad4u+3v+w=13,$$

故(u,v,w)为(0,4,1)或(2,1,2)。前者翻g蓝直接消去G而不产生蓝坏边，违背非B。故必为(2,1,2)：删星初态有一个红单色块、两个蓝单色块、三个混色块。这是第1类“最少方向一个”的一个严格剩余结构，仍未被染色排除。

## 4. 尚缺的准确义务

有两条不同的可靠后续入口，不能并成一份不存在的共同最优初态：

1. 任意六度z：一个方向恰一正四块，或两方向各两正四块且共同1/4索引16至19、跨盈余≤6。最小单色总数使各正点被负单强制，须做多向/换源交换。
2. r5及r4有三低共边：存在真实唯一坏边含低点。可再全局最小化蓝数；b13仅允许式(6)，其余情况b≤12。仍需利用同一批私有边和低点单位共度完成交换。

这两条均没有证明存在tau≤3的某个源态，没有关闭r3/r4/r5原H分支。局部最优态的tau4/8不是存在式命题的反例。本文没有抽取临界子图，所有度数、六星分块和共度均属于原H。
