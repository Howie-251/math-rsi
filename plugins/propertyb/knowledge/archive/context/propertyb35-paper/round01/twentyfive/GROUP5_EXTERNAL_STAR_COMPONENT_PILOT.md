# 七份现有外点分拆见证的强制同组图诊断

本节只检查 GROUP5_EXTERNAL_STAR_REPLAY.json 中剩余七类的一份既有20分拆正见证。每类仅该一份见证，不穷尽所有分拆安排。结果：六份通过此必要条件，代表10的旧见证失败；**没有因此新增组类型排除**。

## 必要条件的真实来源

固定G，若某个非空真迹T有μ_T=1，就只有一条真实H边具有此G迹。如果外点x、y的Π都含T，则这条唯一边同时含x、y。

因此，若Π_x、Π_y有两个共同的单容量块T、U，两个不同G迹对应两条不同边，都覆盖{x,y}，故λ_xy≥2。在真实a5结构里这强迫x、y同属另外四个K5组中的一个。若共同的单容量块至少三个，则λ_xy≥3，直接不可能。

将20个外点副本作为顶点、共同单容量块数至少2的点对连边。每个连通分量都必须落在同一个外组，大小不能超过5；所有分量还必须能整体装入四个大小5的组。这仍只是必要条件，不恢复所有外点对、边槽及完整H。

代表10失败的具体原因是原见证中各有两份相同Π={2,9,20}与Π={4,10,17}，且这六个块在对应库存中都为单容量。每对重复副本因此共享三个不同的唯一G迹边，违反λ_xy≤2。这说明旧正见证不能扩张为真实H，不表示该库存的其他分拆见证也都失败。

代码 GROUP5_EXTERNAL_STAR_COMPONENT_PILOT.py 直接展开每份多重集的20个副本，核对190个点对和强制连通分量，实耗时约0.0014秒。没有重新求解同一分拆整数模型、没有全H枚举，也没有新增类型排除。若下一步使用两外点单位星，需要实际控制两点所属外组或证明可选点条件，不能把两个Π任意独立拼接。
