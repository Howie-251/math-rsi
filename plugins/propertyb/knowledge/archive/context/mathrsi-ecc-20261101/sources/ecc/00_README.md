## 问题是什么，已经取得什么

[n,k,d]₂ 表示长度 n、维数 k、最小距离至少 d 的二元线性码。实际构造可以用一个满秩 k×n 二元生成矩阵表示：任意非零消息与矩阵相乘，所得码字至少有 d 个 1。

| 课题 | 当前结论 | 验收范围 |
|---|---|---|
| 原题 [43,10,17]₂ | 已证明不存在 | 原始完整对象域；明确依赖已发表分类、相关不存在性定理及通常的软件信任 |
| 新题 [45,11,17]₂ | 仍未解决 | 找到一份秩11的11×45矩阵，全部2047个非零消息重量≥17；或证明整个原始对象域不存在 |

旧题结合已有构造得到 d₂(43,10)=16，并推出 d₂(44,10)=17、d₂(44,11)=16，以及 16≤d₂(45,11)≤17。这些是本项目证明及下界构造的推论，不表示公开码表已经采纳。新题若找到合格矩阵，就能闭合 d₂(45,11)=17。

## 新题的四条主要路线

新题等价于偶 [46,11,18]₂ 码的存在性。我们通过缩短、局部线性关系及第四广义汉明重量 d₄ 的35/36分流，组织了以下主要入口。它们有重叠，不能按四个等份计算完成百分比。

| 路线 | 实质进展 | 尚未解决的部分 |
|---|---|---|
| 含 [40,7,18] 的标准六尾 | 172类对应计算全部齐备、均无目标；共享两点、四点集合降低重复计算 | 整172例的证明组合及正式审计 |
| 九尾／14类 [37,5,18] | 统一成39位母码上的二维线；一例从约7.85万亿原始配对压到26,665,846个代表，已完整检查；得到17,403份实际中间码 | 完整外层输入、后续 Q→E 扩张与整批成本 |
| 十一尾／3类 [35,4,18] | 剩余入口为3个核心×3种关系型；已有共同约束和9个完整局部试验 | 七个新增头的联合条件；9个局部试验全部非空，没有关闭母码—尾型输入 |
| d₄=36 | 完整120类 projective 39位母码→7类中间码的子路线已排除 | 其余203个38位源母码的中间分类与联合扩张 |

17,403是保存的中间码记录数，不是不等价类数，也不是最终目标码。新题的172例标准六尾，与旧题完整证明中的172类，承担的是不同的扩张问题。

## 值得优先讨论的三个问题

**九尾路线的外扩张是否有共同障碍？** 已经能够廉价地产生一批实际 Q42，但还需要处理它们扩到 E46 的联合条件。希望寻找对整个输入族适用的结构条件，减少逐个固定中间码扫描。

**十一尾的不同局部约束怎样真正耦合？** 少量母码并不意味着搜索便宜。当前局部条件各自都有解，需要让它们共享同一个全局头矩阵，或得到能排除整类输入的新限制。

**d₄=36 的203源能否像120→7子路线一样整体压缩？** 这里的中间41位码确实存在；关键是分类、共同表示与后续扩张相容性，而不是假设这一层为空。

直接构造的机会也始终保留：一份通过完整验证的目标矩阵就能解决存在性，不需要先完成全域分类。研究选择以降低整题难度和实际成本为准。
