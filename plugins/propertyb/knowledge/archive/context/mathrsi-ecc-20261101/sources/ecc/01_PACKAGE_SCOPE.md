# 本包范围与复查说明

这是覆盖两道题背景、成果与当前进展的**阅读和证据包**。主要正文、证明、文献、关键源码、矩阵、计算摘要和审阅记录已经收录；它不包含项目所有大型计算缓存，因此不是一键全量复现环境。

## 实际包含的材料

- 两道题的原始规格，旧题完整证明与人工交接，新题完整进展报告；两份主 HTML 保持原件。
- Research wiki 的文献、ideas、experiments、claims、图关系及研究经验快照。保留历史记录；当前状态以本包入口与2026-10-13报告为准。
- 旧题172类实际40位母码的完整矩阵快照、覆盖清单、两套扫描核、配对检查器、逐例运行摘要、正式证明审计，以及主证明引用的文献 PDF 和原文页图。
- 新题四条主要路线的归约、证明审计、核心算法源码、可携带的输入与结果。新162例附总摘要和每例保存的最终 FULL_VERIFY.json、完整域运行摘要及紧凑输入。
- 九尾实例全部17,403份实际8×42矩阵、对应255个非零码字重量，以及保存的配对命中记录、完整307块报告和核验代码。`work/goal-45-11-17-20261007/wave6/n37_pair_swap_compression/` 是其入口。
- 两道题已有的 Grok、Gemini 意见、具体审阅范围、核正和 HTML 保真记录。本次打包没有再次要求模型审阅不变的数学材料。

`FILES.tsv`列出本包文件的相对路径和大小（清单自身除外）。证据沿用项目相对目录，主 HTML 的本地链接可从解压目录打开。某些历史 Markdown 把路径按项目根目录书写，需从本包根目录定位；历史源码与 JSON 中也保留原机器绝对路径，它们是当时的运行记录。

## 没有附上的大型数据

旧题保存的619,053,789个配对拒绝见证流，实际读取总量约1.68GB；新162例的完整 F/P/Q 集合及展开联合输入占用远大于阅读材料。本包没有把这些大型原始载荷全部复制进来，也没有复制虚拟环境、编译二进制、模型登录配置或整个冻结 harness。

因此，查看一个 PASS 摘要不等于重新执行其完整计算。需要重跑旧题全部域或重放全部配对时，应按旧题 [REPRODUCE.md](work/goal-20261006-wave2/global_closure/REPRODUCE.md)及覆盖清单补齐原数据，并重定位绝对路径。新162例同样需要补齐其完整输入／F/P/Q载荷；本包的单例摘要不能代替这些文件。

[选取及未收录路径记录](PACKAGE_SELECTION.json)说明自动归集过程中遇到的体积限制或历史未能解析的链接；未被文档直接链接的巨型载荷不逐个列出。它是打包范围记录，不是数学覆盖证书。

## 可直接进行的轻量检查

阅读 HTML 无需任何 Python 依赖。若要实际核验旧题172份母码快照，可以复用原有 `catalogue` 子命令。它不需要大型拒绝流，也不会启动完整陪集扫描。

需要 Python≥3.10 和 `pynauty`（原项目使用2.8.8.1）。在本包根目录运行：

```sh
python3 work/goal-20261006-wave2/global_closure/reproduce/reproduce.py catalogue \
  --snapshot work/goal-20261006-wave2/global_closure/actual172_matrices.json \
  --output-dir catalogue_check_new
```

输出目录必须尚不存在。该命令重新检查秩、偶性、距离、满支撑及全码字图不等价性，预期得到172个不同母码、21,844个非零码字重量检查。它**不证明外部分类总数172**，也不重跑扩张域；分类完备性仍是总证明列明的文献进口。

包内保留的其他脚本主要供源码审阅。不要把旧路径上的批处理启动器直接当成本包的便携运行器；具体依赖、输入域和执行成本应按对应报告准备。
