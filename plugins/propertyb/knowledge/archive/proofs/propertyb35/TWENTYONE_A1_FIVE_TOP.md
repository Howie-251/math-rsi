# 二十一点A1：六点五元top缺一条边仍可修复

## 定理与进口

设 $H$ 为21点、35条互异五元边、覆盖所有不同点对的超图，处于A1实际角色：唯一六度点 $x$、唯一七度点 $p$、九名八度点、十名九度点；$x$ 与 $p$、五名八度点及全部九度点共度一，与另四名八度点共度二。若某六点集 $Q$ 的六个五子集中至少五个属于 $H$，则 $H$ 具有Property B。

使用两个已证实际进口：[A1强共度引理](TWENTYONE_HIGH_FOUR_CORE_LOW.md#2-a1非b的强共度引理)保证非B反设下所有点对共度至多四；[完整六点top](TWENTYONE_K6_TOP.md)已排掉六个五子集全在H的情况。因此以下只需证明**恰五条top**。这不是任意五条两两高交边的假设：五条边必须确为同一六点集的五子集。

将缺少的五子集写成 $Y=\{y_1,\ldots,y_5\}$，令 $Q=\{q_0\}\cup Y$。恰五条top原边为 $Q\setminus\{y_i\}$（$i=1,\ldots,5$）；$q_0$ 在五条中全出现，各 $y_i$ 在四条中出现。下文保留这些原边以及其他30条原边，不抽临界子图、不改原度谱。

## 1. 由点对覆盖强制低维迹表示

任意 $q_0,y_i$ 已在四条top边中共同出现。非B下共度至多四，故任何非top原边若含 $q_0$ 就不能含 $Y$ 点。令 $L=V(H)\setminus Q$，$|L|=15$。为覆盖全部15个 $q_0$–$L$ 点对，至少还需四条形如 $\{q_0\}\cup A$、$A\subseteq L$、$|A|=4$ 的原边。最大点度九迫

$$d(q_0)=9,$$

并且恰四条这样的边。它们的四个外块总关联16、并集15；不将它们假设为分割。

每个 $y_i$ 的四条top边不遇 $L$，每条非top原边至多覆盖四个 $y_i$–$L$ 点对。因此 $d(y_i)\ge4+\lceil15/4\rceil=8$；最大度九给

$$d_i:=d(y_i)\in\{8,9\}.$$

所以 $x,p$ 都在 $L$，但后面的六锁证书不再使用它们的位置或星结构。

对每条非top原边，记其在 $Y$ 上的精确迹。若该迹大小至少二，就不含 $q_0$。任意两个 $Y$ 点已在三条top边中共同出现，其余原边中至多再共同出现一次。因此：

- 每个大小至少二的精确迹最多出现一次；
- 任意两个这样的迹至多交一点，即它们包含的 $Y$ 点对互不重叠；
- 大小五的迹会是原来缺少的边 $Y$，已由完整top情形排除。

故全部非top高迹组成 $Y$ 上的二、三、四点块族 $\mathcal P$，各块所含点对两两不重。这是 $K_5$ 的clique packing；二点块允许组成三角形，但不能把三个二点块擅自合成一条三迹原边。

记 $h_i=\#\{T\in\mathcal P:y_i\in T\}$。每个 $y_i$ 的单迹边数唯一为

$$u_i=d_i-4-h_i.$$

这些非top边在 $L$ 上的总关联为

$$4(d_i-4)-w_i,\qquad
w_i:=\sum_{T\in\mathcal P,\ y_i\in T}(|T|-1).$$

点对覆盖要求它至少为15，故有真实必要条件

$$w_i\le4d_i-31.\tag{1}$$

特别是八度 $y_i$ 有 $w_i\le1$，只能参加至多一个二迹，不能参加三／四迹。九度点的上界五不进一步限制clique packing，因为每个伙伴至多用一次，自动 $w_i\le4$。这一步显著缩小八／九度标记域，没有给自由点另加假设。

## 2. 全部clique packing的短结构分类

五点集的点对共十个。大小至少三的块只有以下四种结构，其余点对可各自独立取作二点块或不取：

1. **没有三／四点块。** 十个点对任意取子集，共 $2^{10}=1024$ 份。
2. **恰一个三点块。** 选块有十种，其占三对，余七对任取，共 $10\cdot2^7=1280$ 份。
3. **恰两个三点块。** 它们只能交一点。共同点五选，其余四点分两对三选，共15种；占六对，余四对任取，共 $15\cdot2^4=240$ 份。
4. **恰一个四点块。** 五种选四点；其占六对，余四对均连接块外点，任取，共 $5\cdot2^4=80$ 份。

不存在两个四点块，因为其交至少三点而重用点对。一个四点块与一个三点块也必交至少两点，因而不能共存。若有三个点对不重的三点块，它们共占九对；每个点在这些三角形点对中的度为偶数，而 $K_5$ 删一条边有两个点度为三，矛盾。故上述分类穷尽全部高迹族。四类按其原三／四点块区分，彼此不重，即使其二迹图另有三角也不重复。

完整有标签域恰为

$$1024+1280+240+80=2624.$$

固定八度点数 $r=0,\ldots,5$，给 $y_1,\ldots,y_r$ 度八，其余度九；保留满足(1)的clique packing。这样覆盖所有实际度标记，因为实际八度点可先按锁标签排在前面。对每种度标记，只按保持度标记的真群 $S_r\times S_{5-r}$ 重标号；$q_0$ 始终固定。

这里不要求这些锁点置换是H的自同构。它们只是同一个实际H的锁标签重新命名：点数、度标记、top边族、clique packing和恢复库存共同运输，所以代表证书可回用原输入。未选点之间的关系完全不受限制。

## 3. 每份packing唯一恢复全部35条原边迹

给 $q_0$ 以bit0，$y_1,\ldots,y_5$ 以bit1…5。子集以下用其bitmask表示，$63$表示全部六锁。五条top的迹为

$$\mu_{63\mathbin{\mathrm{xor}}2^i}=1\quad(i=1,\ldots,5).$$

非top边的所有非空迹唯一为

$$\mu_{\{q_0\}}=4,\qquad \mu_T=1\ (T\in\mathcal P),\qquad
\mu_{\{y_i\}}=d_i-4-h_i.$$

其余非空迹为零，空迹数由总数35补齐：

$$\mu_\varnothing=35-5-4-\sum_i(d_i-4-h_i)-|\mathcal P|
=46-\sum_i d_i+\sum_{T\in\mathcal P}(|T|-1).$$

上述必要域中的各项非负；所选度向量恰为 $(9,d_1,\ldots,d_5)$，总边数35。三／四高迹对应外部部分大小二／一；二迹对应外部三点；空迹对应外部五点，均保留。没有省略空迹边可能单色的风险，也没有把这些迹任意补边的可行性当成证明前提。

每个实际H给出的packing和度标记都在第2节完整域内；所以它恢复的真实六锁库存，必等于某代表库存经过同一锁重标号所得。

## 4. 一份固定六锁布局统一严格

对全部177份代表，统一固定

$$\operatorname{pos}(q_0)=9,\qquad
\operatorname{pos}(y_i)=9+i\quad(i=1,\ldots,5),$$

其余15个实际点均匀无放回排列。采用[共同条件排列P引理](../PROBABILITY_LEMMAS.md)的三种同事件上界 $A_k,B_k,C_k$，**全部额外link扣除均取零**。因此此处没有配额优化或私有边假设；只计算

$$\mathcal B=\sum_{k=1}^{21}\min\{A_k,B_k,C_k\}.$$

完整177项的固定有理证书全部严格，最大为

$$\boxed{\quad\mathcal B\le\frac{2036}{2145}<1.\quad}$$

最大值出现在六锁全九度的一份packing：高迹为一个四点块及块外点到其中两点的两个二点块。保存代表以Y的0…4编号为blocks1234、01、02；相应非空非top迹是四块、两pair、各singleton以及 $q_0$ 单迹四，空迹六。该最大值不是选样最大，而是完整177真度轨道的逐份固定界最大。

由P引理，存在满足锁位的一份实际排列使贪心算法不失败。算法从全红开始，逐点在当前点为某条仍全红原边的最后点时变蓝；P1保证失败之外全部35条原边均含两色。故每份实际输入都得到原H染色，与非B反设矛盾。

若原Q另有第六条top，已经由进口完整top定理给染色；否则上述论证覆盖全部五top缺一情形。定理得证。∎
