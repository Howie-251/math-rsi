# 五个正三／四集与三个负三集的修复

## 定理

设 L 为任意有限集。正族至多五个带索引集合，每个大小为三或四；负族至多三个三集，其余为任意数量四集。假设每点在全部正负索引中的总出现次数至多七。则存在 R⊆L，击中全部正集，且不包含任何负集。

不同索引允许对应同一集合。本定理不要求底集大小上限、正三集数量上限或负四集数量上限。唯一进口是[五小正集、两负三集修复定理](FIVE_SMALL_POSITIVE_TWO_TRIPLES_REPAIR.md)：至多五个二至四元正集、至多三个正二集、至多两个负三集、任意数量负四集、逐点总出现至多七时可修复。

没有正集时取空集。以下记 a_x 为点 x 的正出现次数。

## 最大正出现至少三

若 a_x≥3，固定 x 红，至多余两个未击中的正集。余至多一个，或两个余集相交时，至多再选一点即可，红集大小至多二。两个余集不交时，从各组取一点，加 x 得至少九份不同三点红集。至多三个负三集不能堵完，负四集不能包含于三点红集，故成功。

因此以下 a_x≤2。

## 正族两两不交

若没有正重复点，正族两两不交。记其大小为 s_i≥3，各组独立均匀选一点，组成红集 R。负集含正族并集外点或同组两点时坏概率为零。其余负三集的坏概率各至多1/27，全部负三贡献至多1/9。

对活跃负四集 F，四点位于不同组。由AMGM，

$$\Pr(F\subseteq R)\le\frac14\sum_{v\in F}s(v)^{-4},$$

其中 s(v) 是 v 所在正组大小。每个正点已有一次正出现，故负四索引出现至多六；按负四索引求和可得

$$\sum_F\Pr(F\subseteq R)\le\frac64\sum_i s_i^{-3}
\le\frac32\frac5{27}=\frac5{18}.$$

这是忽略负三已消耗点容量的安全放宽。总坏概率至多

$$\frac19+\frac5{18}=\frac7{18}<1,$$

所以存在合法红集。

## 正重复点属于负三集

若有 a_x=2 的点 x 属于某个负三集，令 x 蓝。从正集中删除 x，并删去所有含 x 的负约束；这些负约束已有蓝点而安全。

只有含 x 的两个正标签可能缩为二集，其他正集仍为三或四集。余系统至多五个二至四元正集、至多两个正二集、至多两个负三集、任意数量负四集；其他点的总索引出现次数不增加。因此已有五小正集／两负三集定理适用，给出余红集 R。将 x 保持蓝，即修复原系统。

这里含 x 的负三集不是缩成负二集，而是因已有蓝点被整个删除。

## 全部正重复点都避开负三集

最后取正重复点 x 红，它命中两个正标签，并避开全部负三集。余正族至多三个，均避开 x。

若余族至多两个，或三个余集中存在交点 y，可用至多两个额外点击中全部余族：有交点时先用 y 命中至少两族，再补最后一族的一点。总红集大小至多三且含 x；它不可能等于任何负三集，因为所有负三集均避开 x，也不可能包含负四集，所以成功。

唯一剩余是三个两两不交的余正集 A,B,C，大小均至少三。从各组取一点，加 x，得到至少27份不同四点红集。每个负三集避开 x，若能堵住候选，必须恰取 A,B,C 各一点，因而至多堵一份；全部负三至多堵三份。

能被这种四点红集包含的负四集必等于候选，必须含 x，每份至多堵一份。点 x 已有两次正出现，所以含 x 的负四索引至多五。总堵数至多3+5=8<27，至少一份候选成功。

全部正出现数与交形均已覆盖，定理得证。∎

## 至少三元正集的推论

正集不要求大小上限：若至多五个正集各至少三元，从每个正集中任选一个三元子集作为更强正约束。新系统每点总索引出现次数只会减少，故可用本定理；其红集击中这些子集，也击中所有原正集。

## 原染色接口与证据

调用时，每个尚未排除的全蓝风险须有相应正约束，每个尚未排除的全红风险须有相应负约束；本定理不自动处理负单集或负二集。所有固定蓝点从正集中删除，含这些蓝点的负约束整体删除，逐点总索引出现次数须仍由七支配。将 R 染红、其余未固定点染蓝，即补全原染色。
