# 二十一点A1：原边非单交图的孤立边至多三条

## 定理与实际角色

设H为21点、35条互异五元边、覆盖所有点对的超图，具有如下实际A1角色：x为唯一六度点，p为唯一七度点，B为四名八度点，U为其余五名八度点，V为十名九度点；lambda(x,b)=2（b∈B），x与p、U、V各点的共度均为一。

在35条原边上连边，当且仅当两条原边的交大小不等于一。则此图的孤立点数N34至多三。

这里N34也正是[共同中间边预算](GLOBAL_TWO_FLIP_SHARED_MIDDLE.md)中的同名量：对原边F，s(F)是与它交恰一点的其他原边数，故s(F)=34当且仅当F是上述图的孤立点。本结论不要求反设H不可二染色。

## 1. 三种孤立原边

若F孤立，它与其余34条原边各交一点，因此

    sum_{v∈F} d(v)=5+34=39.

一条避开x和p的五元边度和至少40，故F必须含x或p。按它们的出现情况，度和39迫F恰为下列一种：

    X: x + 三名八度点 + 一名V；
    P: p + 四名八度点；
    Z: x+p + 一名八度点 + 两名V。

任何含x的孤立原边不能含B点：lambda(x,b)=2会给另一条原边同时含x,b，使交大小至少二。因此X的三名八度点以及Z的八度点都属于U。

所有孤立原边两两交恰一点。两X已共x，因而它们的三个U点必须不交；U只有五点，所以X至多一条。两P已共p，它们的四个八度点必须不交；八度点总共九名，所以P至多两条。Z包含单位点对xp，所以至多一条。

## 2. 排除四条孤立原边

若有四条，以上上界迫类型恰为一X、两P和一Z。记Z的U点为u。每条P已与Z共p，故均避u；X已与Z共x，也避u。

两P的八度四集彼此不交，并避u，因此恰好分拆其余八名八度点。X的三个U点均属于这八点。X与每条P的交只能来自这三个U点，而孤立性要求两次交大小各为一。因此两P与X的总交数应为二；但它们的八度四集分拆了包含X三个U点的集合，总交数实际为三，矛盾。

所以N34≤3。∎

## 3. 同一原H的共同预算推论

令nj为H中无序不同原边对交大小为j的数量，P为共同中间边预算中的全部无序外边对—中间原边旗标数。该预算的一般不等式为

    P≤(132n1+66N34)/5.

本定理立即给出P≤(132n1+198)/5。若再反设H非B，准确导入[三交中间边修复](THREE_INTERSECTION_MIDDLE_NEAR_SATURATION.md)的C3≤13n3，以及既有A1强点对结论所给C4≤4n4，则相同两次翻色判据给

    5016n1+2520n2+4368n3+3192n4+2376 ≥2722720.

写tau=sum_{u<v} binom(lambda(u,v)−1,2)。A1原度数与点对覆盖给n1=368−2tau+3n3+8n4、n2=140+tau−3n3−6n4，代入后为

    2201064+11856n3+28200n4−7512tau ≥2722720.

由于左侧变量部分可被24整除，得到准确的整数必要条件

    494n3+1175n4−313tau ≥21736.

本推论加强同一实际原H的必要结构，不宣称整个A1分支已可染。旧共同预算规范的原证据与审阅范围保持不变。
