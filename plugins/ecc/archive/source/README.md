# 五个二元线性码不存在性证明发布包

2026-11-03。建议先阅读 [联合论文 PDF](paper/main.pdf)，中文详细论证从 [主证明](proofs/01-main-43-10.md) 开始，再读 [三个推论](proofs/02-three-corollaries.md) 和 [第五个 case](proofs/03-case-42-16.md)。运行方法见 [REPRODUCE](REPRODUCE.md)，实际执行范围见 [验证记录](verification/RELEASE_CHECK.md)。

## 精确结论

本包的对象是所有二元线性码，允许零坐标，不预设系统形、自同构、准循环结构或固定残码。

1. 不存在 `[43,10,≥17]₂`，结合所附生成矩阵得到 `d₂(43,10)=16`。
2. 不存在 `[44,10,≥18]₂`，结合所附生成矩阵得到 `d₂(44,10)=17`。
3. 不存在 `[44,11,≥17]₂`，结合所附生成矩阵得到 `d₂(44,11)=16`。
4. 不存在 `[45,11,≥18]₂`。本包只得到 `16≤d₂(45,11)≤17`，没有声称距离 17 已被构造或排除。
5. 不存在 `[42,16,≥13]₂`，结合所附生成矩阵得到 `d₂(42,16)=12`。这一结论由 2020 年已发表的命题推出，本包不主张其新颖性或优先权。

前四项是一个主证明及其推论，不是四个独立的分类证明。

## 文件内容

- `proofs/`：中文主证明、三个推论、第五个 case 的完整归约。主证明含全部 172 个七行生成矩阵。
- `paper/`：16 页联合论文 PDF、LaTeX 正文及参考文献。使用 ICML 2026 样式仅是排版；不表示已投稿、录用或通过本次外部审稿。作者栏仍为匿名占位。
- `data/`：172 个母码的实际矩阵、完整码字/重量数据、五个下界生成矩阵和历史汇总。
- `evidence/manifest.json`：包内相对路径清单；`evidence/cases/` 包含全部 172 例的两套扫描输入/完成结果/接受集合，以及全部 619,053,789 个配对拒绝见证。149 份二进制流及 23 份 TSV 共 1,679,770,064 字节，无需另外合并补充包。
- `computation/`：两套完整扫描 C++ 源码、独立证书重放器、母码规范化及保存集合检查程序。
- `formal/ecc43/`、`formal/ecc42/`：Lean 源码、审计入口、工具链及依赖锁文件；不包含机器工具链或 `.lake` 缓存。
- `references/`：E1/E2/E3 的精确陈述、来源定位、DOI、公开访问链接及 BibTeX。
- `verification/`：本次发布包复验记录和源文件来源/改动说明。

## 证明依赖与“自包含”的含义

所有本项目特有的数学论证、矩阵、扫描程序、接受集合及拒绝见证均在本目录，运行不需要原研究仓库、发现阶段模型服务或 API 密钥。Python、C++ 编译器、pynauty 和 Lean/mathlib 是明确列出的通用软件依赖，需自行安装；本包不内置它们的运行环境。

主证明仍引用 E1（不存在 `[41,8,18]₂`）和 E2（满支撑 `[40,7,18]₂` 至多 172 个坐标等价类）；第五项引用 E3（不存在 `[41,14,14]₂`）。各定理的范围与原文定位均列于 [文献说明](references/REFERENCES.md)。本包没有重做这三项已发表分类，也没有将其包装成本项目从零证明的结果。文献原文未作为第三方 PDF 全文转载；准确的引用和输入陈述已随包保存。

Lean 核验数学归约、实际母码参数及前四项的下界矩阵。最终定理仍显式接受 E1/E2、目录两两不等价与穷尽计算事实，或接受 E3 作为参数；没有 `sorryAx` 不等于这些参数在内核内已被证明。42 位下界矩阵由独立 Python 全枚举核验，不在 ECC42 归约定理内。有限计算还信任编译器、运行时与 pynauty 图规范化。详见 [形式化范围](formal/README.md)。

证书重放检验所有保存的拒绝见证，但不能单独证明接受集合无遗漏。无遗漏由两套完整的 `172×2³²` 扫描承担；本次是否重跑全域与历史完成记录明确区分。

