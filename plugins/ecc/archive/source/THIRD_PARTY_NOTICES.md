# Attribution and distribution scope

This bundle contains project proof text, original project verification code, literal mathematical data, and pinned Lean project metadata. It does not assign a new blanket license or invent author identities. No software license is granted on behalf of a copyright holder by this packaging step.

Published classification results E1, E2, and E3 remain attributed to their authors in `references/REFERENCES.md` and `references/references.bib`. External article/thesis PDFs and historical model conversations are not redistributed here.

The LaTeX directory includes the official ICML 2026 formatting files copied from the existing manuscript source. Their original notices are retained; using this format implies neither submission nor acceptance. See `paper/STYLE_SOURCE.md`.

Lean, mathlib, pynauty/nauty, Python, and C++ toolchains are separately obtained dependencies and retain their own licenses. No dependency binaries, toolchains, API credentials, or local configuration files are included. Literature-derived lower-bound constructions retain their attribution in the manuscript and bibliography.
