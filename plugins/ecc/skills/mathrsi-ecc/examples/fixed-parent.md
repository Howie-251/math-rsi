# 示例：固定母码上的完整 pair 判定

本例说明如何提出可核验的联合行动，以及如何限制结论范围。它不宣称所有 ECC 扩张都需要同一种 pair，也未执行历史计算。

## 工作区与已有输入

`${TASK_ROOT}` 是使用者提供的单题工作区实际绝对目录；`${ECC_SOURCE_ROOT}` 是允许读取的历史资料根，如未提供可只用本题已有输入。
在实际命令前由执行者明确这些值，不能把代号原样当目录，也不默认作者机器路径。
本例假设工作区已经有：原 n/k/d 规格、固定母码 Q 的显式矩阵、相关尾型的推导、合法陪集 F 与它的完整性证明、已有程序说明。
文件实际名称沿用本题工程；无需另建一套搜索器。

## 给领域执行者的任务

```text
读取 MathRSI base 与 mathrsi-ecc，并读取 TASK_ROOT 的原规格。
当前义务：判断固定母码 Q、指定尾型是否可能扩张。
已知数学：任意该范围内的目标扩张，必产生不同 a、b，
           满足 a∈F、b∈F 且 a+b∈F。
已有 F：来自完整域生成；实际坐标、母码及阈值在本题说明中给出。
本次行动：先验证上述必要蕴含及输入绑定，
           再按授权预算完整检查相关 pair，保留实际拒绝见证。
写入范围：TASK_ROOT 下分配的本次义务目录。
不要运行整个历史研究，不要把固定 Q 的结论扩大为全域排除。
```

执行者可选择现有位集成员查询、排序查询或其他合适实现；先读真实接口与参数，再写具体命令。
若 F 的无遗漏只有作者口头说明，应先查现有证据是否足够。单独重验全部保存成员不能补这个缺口。
若必要 pair 蕴含尚未证明，本轮先完成该论证，不因工具快就跳过它。

## 哪些结果会改变下一步

若 pair 图完整为空，任何要求该 pair 的扩张均不可能，直接停止此输入的更高阶枚举。
若图非空，它只说明此必要门没有结束证明；可以将保留 pair 接入下一项真实组合约束，或先测下游联合成本。
不得把一个 pair 当成已经存在满足原规格的最终矩阵。
若找到可恢复的目标候选，尽快导出原 n 列矩阵并完整验秩和距离；构造成功可结束原合同允许的存在性路径。

## 五类信息的示意回交

```text
任务：原规格保持；当前只处理固定 Q 和指定尾型。
义务与连接：目标→Q/尾型→必要 pair 的数学蕴含已给出；
             此 Q 是否覆盖所有目标，仍是独立上游义务。
行动提案：在本题 F 的共同坐标中完整遍历全部相关 i<j，
           不先展开三行；预算含输入准备、读回和拒绝核验。
结果与证据：按真实执行报告空图／保留 pair／未完成区块；
             附实际输入、覆盖数、终态、失败见证和实耗。
验证能力：pair checker 验拒绝；F 完备性证据验无遗漏；
           母码归约证明负责该局部结论能影响哪些原目标。
```

如果两种成员查询共享同一个 pair 循环，报告这个共享范围；不把它写成两套完全独立全流程。
如果只有一套完整 F 生成与部分独立扫描，也按实际范围描述，是否足够由当前证明合同和具体风险判断。

## 合适的结束语义

“固定 Q、指定尾型全部被排除”可作为完成的局部数学结果保存。
原题不存在仍需其他母码／尾型的覆盖与排除，以及全部局部输入到原对象的连接。
若相同固定域已完成，不换基或换种子再扫；只有新约束、未处理范围或成本依据改变时重新安排工作。
本例未运行检查器，不提供虚构的计数、PASS 或效率结论。
