一、minor的简短可手验形式

p=(u0,u1,u2,s,v0,v1,v2)。对循环索引i,j=i+1,k=i+2(mod3)，取
 u_i: rows[i,3,4+j,4+k], cols[3,4+i,k,j]，得到
 [-u_i, 0,   0,    0  ]
 [  0, u_i, -v_k, -v_j]
 [ v_j, 0, -u_i,   0  ]
 [ v_k, 0,   0,   u_i ]。
按首行及其余稀疏列展开，det=u_i⁴。

 v_i: rows[4+i,3,j,k], cols[3,i,4+k,4+j]，得到
 [ v_i,  0,   0,    0  ]
 [  0, -v_i, u_k,  u_j ]
 [-u_j,  0, -v_i,   0  ]
 [-u_k,  0,   0,   v_i ]。
同样det=v_i⁴。这六式在任意域上成立，供特征3 cross路由使用。

二、任一非零null点的projective cross核最多91点

若p≠0、Q(p)=u·v-s²=0，则u与v不可能同时为0，否则s²=0迫s=0。故至少一个u_i或v_i非零。对应minor非零，rank A_p≥4。
于是ker A_p的线性维数≤3。F9上一个k维线性子空间的projective点数为(9^k-1)/(9-1)，因此projective ker A_p至多91点。

另由先前准确cross恒等式，若p非零null且C(p,q)=0，则β(p,q)=0，且Q(q)=0：
 C(p,C(p,q))=-β(p,q)p-Q(p)q给β=0；
 C(q,C(q,p))=-β(p,q)q-Q(q)p再给Q(q)=0。
因此此kernel本身也完全由null向量组成，但下面的有限star计数不依赖先证明整个null点枚举完备。

三、把“cross0”变成“同一条实际缓存线”

对每个实际缓存点p，假定已经准确绑定十条不同的缓存线经过p，而且每条确为一个二维线性子空间的完整projective线（F9上恰十点）。这些线各自都有独立basis a,b且C(a,b)=0。
双线性/alternating给：对该线任意两个向量x=αa+βb、y=γa+δb，C(x,y)=(αδ-βγ)C(a,b)=0。特别是它们经过的p与每个行内点q满足C(p,q)=0，所以整条线的十个projective点全在ker A_p中。

两条不同projective直线通过p时只在p相交。因此十条线的并恰有
  1+10×(10-1)=91
个不同projective点。它们都在至多91点的projective kernel中，所以并=整个kernel，且rank A_p实际恰4。

结论：对任意实际p，以及任意非零向量q，若C(p,q)=0，则[q]属于十条实际缓存线之一，因而有实际PointID；若[q]≠[p]，该缓存线同时包含p、q。
这消除了原显式路由证明中“构造出来的cross中间点虽然在Q上，但是否出现在字面缓存，以及它与端点的span是否是缓存线”的缺口。

五、全null点枚举完备的独立计数（可作更强输入校验）

F9³的projective点有9²+9+1=91个。
若u≠0，把u的首个非零坐标规范化成1，有91种u；s任取9种；u·v=s²是一条非零线性方程，v有9²=81解。共91×9×81=66339个规范化null点。
若u=0，null迫s=0；v非零规范化有91种。总计
  66339+91=66430。
因此，若现存66430条点坐标均为不同的规范化非零null点，则它们恰枚举整个projective Q。

但这项强结论并非当前路由的必需进口：第三节已经从每个实际p的91点star强迫整个ker都由实际缓存点表示。给定实际p和实际线L，在L的span中取β(p,-)的非零kernel点q，因为该行完整span，q已有PointID。再取y=C(p,q)，它属于ker A_p，第三节立即给实际y及缓存p-y线；同理C(q,y)=0给缓存q-y线。于是原先≤5点—线路线全部落到原缓存，而非抽象未知几何。
这可使形式化只承接小型线性代数/行列式证明与实际star有限证据，不必再将全Q枚举基数作为新的承重前提。
