## Counterexample-oriented checks

- A cross-cell repeat edge cannot survive the two harmonic level partitions; their ordered value pairs separate all five cells.
- A nonzero N diagonal cannot evade the triangle identity: its parity and the adjacent-pair bound force zero before any global B≤2 result is available.
- An omitted type in the direct cases cannot remove the contradiction: each selected source and target type has Npq=0 and therefore exactly one vertex.
- Arbitrary copy permutations cannot split a Wi: each two-point fiber is connected by its forced twin edge and the contracted type graph is connected.
- A Q edge escaping its complementary block would spend an already exhausted or forbidden marginal; Q cannot escape V because V is B-closed.
- Using only closed unions instead of actual components would be insufficient for the trace argument; the explicit connectivity proof supplies the missing distinction.
- Treating all 32 remaining vertices as one component still gives the contradiction, so no assumption on their connectedness or finer decomposition is needed.
