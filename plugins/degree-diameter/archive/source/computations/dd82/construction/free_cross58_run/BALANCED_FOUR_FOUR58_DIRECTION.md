# 平衡4+4的58点构造：短解析矛盾，不启动模型

2026-10-18。已读最新comments、当前wiki及相关旧证明。**本次纸面推导排除整个所提族：不存在58点、最大度≤8、直径≤2，且可分成29+29两部分、每点恰有4个同侧邻居和4个跨侧邻居的图。** H0、H1及C全自由亦不可能，因此不需要4+4模型、CNF或solver。本结论为本次推导，未冒称新增外审或Lean接受。

## 旧范围核对

在所查wiki及构造记录中，未找到这个全自由4+4模型已有相同输入或完整排除。旧[双诱导Hamilton29结果](../../../../proofs/dd82/construction/FREE_CROSS58_HAMILTON_BRIDGE.md)要求内部恰为两个C29；本候选内部全4度，不能套用。旧[60点零跨缺陷C5定理](../../../../proofs/dd82/construction/CYCLIC5_QUOTIENT_TWELVE_PENTAGONS_EXCLUSION.md)要求指定圈型及跨块缺陷为零，也不同于这里的同侧缺陷为零。[等纤维单匹配界](../../../../proofs/dd82/construction/EQUAL_FIBER_SINGLE_MATCHING_CAPACITY.md)亦不是当前每点跨侧4度的模型。

无需据此登记新计算：下面的计数已经直接关闭候选。

## 1. 根代理的精确同侧公式正确

令H0、H1为两个29点简单4正则图的邻接矩阵，C为跨侧二进制矩阵，行列和4。全图邻接矩阵为

`A=[[H0,C],[C^T,H1]]`。

同侧路线矩阵为`H0²+H0+CC^T`，另一侧为`H1²+H1+C^TC`。每行总数为`16+4+16=36`，对角项为8，故其28个非对角项的总和恰为28。直径二要求各项至少1，因此准确地有

`H0²+H0+CC^T=7I+J29`，

`H1²+H1+C^TC=7I+J29`。

换言之，任何同侧不同点u、v满足

`1[u~v] + |N(u)∩N(v)| = 1`。

内部无三角形、无四圈，C任意两行或两列交集至多1，都是这些等式的直接后果。

## 2. 整图无三角形，任何非邻点对至多两个共同邻居

若存在三角形，其三个顶点中至少两个同侧；这两个点既相邻又有共同邻居，违反上式。因此整图无三角形。

同侧非邻点对已知恰有一个共同邻居。若某个跨侧点对有至少三个共同邻居，则其中至少两个共同邻居x、y同侧。x、y又都邻接原点对的两个不同端点，从而具有至少两个共同邻居，违反同侧公式。因此跨侧点对也至多有两个共同邻居。

在目标图中，非邻点对至少有一个共同邻居，所以只有1或2两种；相邻点对没有共同邻居。

## 3. 203个双共同邻居点对，无法配成四圈

实际缺陷矩阵定义为

`B=A²+A−7I−J58`。

由上两步，B对角为0，其他项只可能0或1，值1恰表示一对非邻点有两个共同邻居。同侧块全零。全图八正则，故每行缺陷和为

`64+8−7−58=7`。

因此这类无序点对总数为

`58×7/2 = 203`。

每个这样的点对，与其唯一的一组两个共同邻居，确定一个四圈。反过来，每个四圈有两条对角；两条对角都是非邻点对，而且各有恰好这两个共同邻居。因此

`203 = 2 × 四圈数`，

与203为奇数矛盾。这里计数的是无向四圈，不需要循环作用、内部图分类或有限搜索。

同一计数也给出一个一般必要条件：任意58点八正则直径二图，必有三角形，或某个非邻点对至少有三个共同邻居。当前4+4等分同时禁止了两者，所以不可行；并未证明任意58点目标必有这种等分。

## 4. 条件推论：任意非平凡二块等分只剩内部2度、跨侧6度

这里的等分指equitable partition，即每个部分中的顶点通向另一部分的邻居数为常数；**并未预先假设两部分一样大。** 设一个58点目标具有两个非空部分，大小为a和`58−a`，跨度分别为b、c。目标图必八正则：若有点度数≤7，其半径二球至多`1+8×7=57`点。因此`1≤b,c≤8`；正性来自图连通及两个部分非空。

跨边握手等式为`ab=(58−a)c`。令`g=gcd(a,58−a)`，则`a/g`与`(58−a)/g`互素，故存在正整数t使

`b=t(58−a)/g`，`c=ta/g`。

所以`58/g≤b+c≤16`。又`g|58`且`0<a<58`，g只能为1、2、29；前两者不满足不等式。因此`g=29`、`a=29`，进而`b=c=d`。

两侧内部均为`r=8−d`正则图。因每侧有29点，内部握手定理要求`29r`为偶数，故`r∈{0,2,4,6}`。从一侧任一点出发，到另一侧的长度至多二路线共有

`d + rd + dr = (2r+1)(8−r)`

条；分别为直接跨边、先内部后跨边、先跨边后内部。覆盖另一侧29点必须满足该数至少29。四个r的容量依次为8、30、36、26，所以只剩r=2或r=4。第1–3节已经排除r=4，因此必有

**两侧各29点、内部各2正则、跨侧各6正则。**

再结合已完成独立LRAT认证的[双诱导Hamilton29排除及桥接](../../../../proofs/dd82/construction/FREE_CROSS58_HAMILTON_BRIDGE.md)，两侧的诱导二正则图不能同时为C29；至少一侧必须由多个圈组成。这只刻画**具有非平凡二块equitable partition的58点目标**，没有证明任意目标都存在这种划分，也没有排除剩余圈型。

本节是根代理建议后的纸面核对补充，未登记为新增跨模型接受，不声称新颖性，不启动圈型枚举或新模型。

## 结果与执行边界

跨侧矩阵`K=H0C+CH1+C`的行列和确为36、超出29的余量为7；这与上面的B一致，但并不能解除四圈计数矛盾。

本候选解析否决，不登记新预算，不生成4+4模型，不枚举内部4正则图。本次没有计算、外部调用、旧定理重证或全局wiki修改。原58–61目标和未满足该等分条件的58点图仍开放。
