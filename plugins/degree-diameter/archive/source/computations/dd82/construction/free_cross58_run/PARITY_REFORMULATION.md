# 双Hamilton29跨边条件的模2改写

2026-10-18。**结论：所提模2可逆性和两种行模式均成立；列条件把失败位置进一步组织成非平凡置换循环。它们没有给出有解或无解结论。** 本文仅作有界纸面推导，未改实际CNF、未做矩阵消元、P枚举、局部搜索或新solver调用。

记H为C29邻接矩阵，J为29阶全1矩阵，`L(X)=X+HX+XH`。以下明确区分F2运算与提升后的普通整数路线计数。

## 1. L在F2上可逆

`2^7≡12`、`2^14≡−1`、`2^4≡16≠1 (mod 29)`。28的每个真因数都整除14或4，故2模29的乘法阶恰为28。因此任意原始29次单位根ζ的Frobenius共轭`ζ,ζ²,ζ⁴,…`有28个，`Φ29=1+x+…+x²⁸`在F2不可约。

在包含ζ的有限域中，`x²⁹−1`有29个互异根，故循环移位矩阵及H可用傅里叶基对角化。L在双模式(r,s)上的乘数为

`1+ζ^r+ζ^(−r)+ζ^s+ζ^(−s)`。

若此数为0，把指数取模29并在F2抵消相同项，得到次数≤28、至多5个非零项的多项式f。它不是零多项式：原来五个项在x=1处的和为1。不可约性迫使f为Φ29，但后者有29个非零项，矛盾。因此所有乘数非零，L可逆。

所以**每个置换矩阵P恰好决定一个F2矩阵**

`C(P)=L⁻¹(J+P)`。

逐位提升为0或1后，这是唯一候选二进制C。这里不保证其整数行列和为6。例如P=I时，F2中`L(J)=J`、`L(I)=I`，故`C(P)=J+I`；其0/1提升是对角0、其余1，每行度28。

可逆改写保留全部原目标：任意整数解`L(C)=J+P`模2后必是这个C(P)。反向只得到奇偶条件，须保留下面的整数检查。

## 2. 另加真实行列和6后，每行恰有两种模式

现在假设提升后的C每行每列都恰有6个1，并在**普通整数**上重新计算`K=C+HC+CH`。其每行每列和为30。写P在第i行的1位置为π(i)。模2关系给出：K在π(i)处为非负偶数，其他28处为正奇数。

先给其他28处各分配1，总和已为28；剩余仅2。因此第i行只有：

- **正确行：** `K[i,π(i)]=2`，其他28项全1；
- **失败行：** `K[i,π(i)]=0`，某个`q(i)≠π(i)`处为3，其他27项全1。

不会出现4、5或多于一个3。正确行等于`(J+P)`的该行；失败行有且仅有一个未覆盖跨侧点对。转置得到完全相同的列分类。

因此奇偶条件加行列度6并不等于覆盖条件。还必须排除失败行，才有整数`K=J+P`。

## 3. 列条件使失败组成置换循环

设R为失败行集合。其全部零格恰为`(i,π(i))`、`i∈R`。由列分类，失败列恰为`π(R)`；每个失败列也恰含一个3。因此3格定义一个双射

`q:R→π(R)`，且`q(i)≠π(i)`。

令`P_R`只保留P在R行的1，Q为3格组成的部分置换矩阵，就有准确整数恒等式

`K=J+P+2(Q−P_R)`。

`σ=π⁻¹∘q`是R上的无固定点置换，故若R非空，则`|R|≥2`，其失败按长度至少2的循环分组。未覆盖跨侧点对数与3路线点对数都恰为`|R|`。这比单独行分类更精确，但没有迫使R为空，也没有迫使R非空。

## 4. 能说明什么，不能说明什么

这提供了对当前受限模型的一种无损参数改写：置换P经固定F2线性逆唯一决定C，之后检验真实行列度6、R为空，以及两侧的完整共邻覆盖。即使R为空，也还没有保证同侧直径二。

它没有证明存在满足度数和覆盖的P，没有排除它们，也没有证明这一表示比当前联合CNF更快。`MATH_CHECK.md`中“给定P唯一实解”的结论与这里的“唯一F2解”不同；仅通过奇偶检查的0/1提升未必等于那个实解。

本次没有发现短矛盾，也没有启动该参数域的生成、枚举或优化。现有唯一共同模型保持不变；是否由实际返回对象支持下一种生成办法，留给后续基于证据的决定。
