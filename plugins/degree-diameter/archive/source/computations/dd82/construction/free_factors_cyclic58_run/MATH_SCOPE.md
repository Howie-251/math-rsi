## 1. 反例对象的全部定义

左点记为 $L_i$（$0\le i<28$），右点记为 $R_j$（$0\le j<30$）。固定来源

$$A=\{0,3,6,10,14,19\},\qquad
C^{(0)}_{i,j}=\mathbf1_{i-j\in A\pmod{28}}\quad(j<28).$$

实际跨矩阵 $C$ 由以下规则唯一确定：

1. 旧28列保留全部 $C^{(0)}$ 关联，唯独删除 $(i,i)$，$i=2,3,\ldots,11$。这些确为来源边，因为 $0\in A$。
2. 新列28的支撑为 $\{2,3,4,5,6\}$。
3. 新列29的支撑为 $\{7,8,9,10,11\}$。

左二因子 $H_L$ 取下列单一28圈，末点接回首点：

```text
0, 8, 4, 7, 11, 15, 20, 27, 5, 9, 13, 18, 12, 3,
16, 17, 6, 21, 22, 10, 23, 24, 14, 25, 26, 19, 1, 2
```

右基础二因子 $F$ 取下列单一30圈，末点接回首点：

```text
0, 1, 2, ..., 26, 28, 29, 27
```

右匹配取

$$M=\{\{2,7\},\{3,8\},\{4,9\},\{5,10\},\{6,28\},\{11,29\}\}.$$

这里 $H_L$ 的列表用左点标签，$F,M$ 用右点标签；两侧标签相同不表示同一顶点。这个具体对象只用于核对容量推断和后续语义，不把其圈序、删除位置或新列支撑固定到完整共同模型中。

## 2. 全部结构和度数合法

左圈列表恰好使用0至27各一次，右圈列表恰好使用0至29各一次。因此两者都是简单二正则图。

每个左行原有6条跨边。行2至11各删一条并从恰一个新列补回一条；其他行不变，所以所有实际跨行和仍为6。

旧列2至11各降为5度，其他18个旧列仍为6度；两条新列各为5度。因此低度列集合恰为

$$D=\{2,3,\ldots,11,28,29\}.$$

上述六条 $M$ 边的端点恰好各使用 $D$ 一次，没有公共端点。它们也都不是 $F$ 边：前四条分别跨越五个标签，后两条为 $6$--$28$ 和 $11$--$29$，均不在已列明的右圈中。

于是左点度数为 $2+6=8$；右高列度数为 $2+6=8$，右低列度数为 $2+1+5=8$。跨边数为 $168-10+10=168$，全图边数为

$$28+30+6+168=232.$$

这是完整简单58点八正则图的手算构造，不是未保持度数的覆盖草图。

## 3. 旧高列0的两个基础邻点均旧，却覆盖全部左侧

列0、1、27均未删关联，都是旧高列。令它们的实际支撑分别为

$$T_0=\{0,3,6,10,14,19\},$$

$$T_1=\{1,4,7,11,15,20\},$$

$$T_{27}=\{27,2,5,9,13,18\}.$$

这三个六点集两两不交，其并的补集为

$$B=\{8,12,16,17,21,22,23,24,25,26\}.$$

从明确的左圈列表读出 $T_0$ 六个顶点的两个左邻点：

| 左点 | 两个 $H_L$ 邻点 |
| --- | --- |
| 0 | 2、8 |
| 3 | 12、16 |
| 6 | 17、21 |
| 10 | 22、23 |
| 14 | 24、25 |
| 19 | 26、1 |

故旧高列0通过直接跨边或先跨边再走左因子一步，可到达的集合恰为

$$W_0=T_0\cup N_{H_L}(T_0)=T_0\cup B\cup\{1,2\},$$

大小为18。右圈 $F$ 中，顶点0的两个邻点恰为1和27，都是旧列。经由它们的两步路再覆盖 $T_1,T_{27}$，而

$$W_0\cup T_1\cup T_{27}=\mathbb Z/28\mathbb Z.$$

更精确地，两个旧邻列各在 $W_0$ 外贡献五点：

$$T_1\setminus W_0=\{4,7,11,15,20\},$$

$$T_{27}\setminus W_0=\{27,5,9,13,18\}.$$

两组互不相交，恰补齐十个缺口。因此 $R_0$ 的全部28个跨侧点对都已被覆盖，它没有任何新列作为 $F$ 邻点。
