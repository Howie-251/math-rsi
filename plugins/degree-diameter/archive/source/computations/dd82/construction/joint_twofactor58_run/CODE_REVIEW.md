## 真实图与规范代表

H0、H1 分别为406个独立无向边位组成的对称零对角矩阵，C 的841位全部自由。
全部1653个主变量恰好对应58点简单图的全部可能边。每侧每点内部度恰2，
C 的每行每列恰6；代码未固定内部圈、圈型、相对顺序或 C 对角。

对于原目标，跨侧路线数 K=H0C+CH1+C 的行列和为30且逐项至少1，
故 K=J+P，P 为置换矩阵。取 Q=P^T 后 C'=CQ、H1'=Q^T H1 Q、
H0'=H0，直接得到 K'=J+I。两内部图自由，因此变换保留完整编码域。
`normalize` 中 `order[i]` 是 P 第 i 行中1所在的旧右侧标签；按
`Q[old,new]=1` 的列重标约定，这确为 Q=P^T，而不是错误地使用 P。

原来 P≠I 的合法已标号图不一定直接满足规范 CNF；须先作上述右侧重标。
代码与文档正确区分 `target_graph` 和 `normalized_target`，没有把两者
误称为逐标签等价。反向则由任何满足的规范三元组直接展开目标图。

## 每一对点的路径语义

每个跨侧(i,j)含 Cij、28个 H0ik∧Ckj 和28个 Cik∧H1kj，共57项，
精确计数为1+δij。仅排除不可能的内部自环中点；没有漏掉真实路径。
841个跨侧点对全部处理。

每侧406个无序点对都编码直接 Hij、27个内部两跳和29个跨侧共同邻点，
以57项 OR 覆盖。右侧跨路径正确使用 Cki∧Ckj。共812个同侧点对，
与跨侧841对合计覆盖全部1653对。没有用单独宏观必要条件替代共同实现。

通用 AND 的三子句是双向等价。前缀阈值的递推也双向编码实际计数，
`enforce_exact` 将第 t 阈值置真、第 t+1 阈值置假。因此不存在以虚假
辅助位伪造路径或计数的自由度。导入的旧文件只提供通用定义，未调用旧
ABEncoder 或任何旧几何／Hamilton／补全模型。
