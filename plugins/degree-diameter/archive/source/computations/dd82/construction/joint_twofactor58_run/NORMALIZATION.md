# 两个完全自由二正则块允许无损令P=I

设H0、H1为任意29点简单2正则图的对称邻接矩阵，C为任意行列和6的二进制
矩阵。完整图邻接为`A=[[H0,C],[C^T,H1]]`，因此全8度。若从原题出发，8正则
无需额外假设：度至多7的根在两步内至多达到`1+7+7*7=57`点，不可能覆盖58点。

跨侧端点的真实一步或两步路线数是`K=H0*C+C*H1+C`：中点在左侧、在右侧、
以及直接边，三种情形完整且不混淆。K各行各列和均为`12+12+6=30`。
故跨侧全部覆盖等价于`K=J+P`，其中P是某个置换矩阵：K−J非负整数且每行
每列和为1。

将右侧以置换矩阵Q重标，按新列对应旧列的约定，令

`C'=C Q, H1'=Q^T H1 Q, H0'=H0`。

则`H0'C'+C'H1'+C'=(H0C+CH1+C)Q=J+PQ`。
取`Q=P^T`，所得路线矩阵恰为J+I。H1'依旧是某个简单2正则图，C'行列和
仍为6，完整图仅作右侧顶点重标，所以度数、距离和全部同侧覆盖不变。
H0、H1均为自由变量，因此H1'仍在同一个编码域内。这就是无损归一化；
不固定任一内部圈型或圈顺序，也不再施加P之外的对称限制。

相反，满足编码的H0、H1、C直接给出实际图：精确块度保证全8度，
跨路线计数J+I保证跨侧覆盖，同侧所有无序点对的真实边/AND覆盖保证其余
距离至多2。给定归一化后的真实图，按真实前缀阈值和真实AND赋所有辅助位，
即可满足完整CNF；双向定义反过来禁止伪造路径或计数。因此

`该二正则块族存在目标 <=> 归一化共同CNF可满足`。

旧Hamilton模型同时固定H0=H1=标准C29时不能无条件令P=I，因为右重标改变
固定H1。本模型完整释放两侧所有内部边，正好消除了那个障碍；但没有使用
旧Hamilton排除作为剪枝。C的对角也不预定，所有841位由共同条件决定。
若目标有多个29+29见证划分，任选一个即可作这次重标；存在至少一个划分
的所有目标都被覆盖，不要求预选原顶点标号。

可手验的归一化正例取m4、跨度1：C=I，H0圈为0–1–2–3–0，H1圈为
0–1–3–2–0。此时K=H0+H1+I=J+P，P交换0/1及2/3；完整8点图全3度、
直径2。按Q=P^T重标后C'=P、K'=J+I。程序还先任意重标右侧再从实际
K−J恢复P，比较完整边表的精确同构及BFS，不只对预先写死的P做代入。
这里`5*1=4+1`，与正式29点块模型有同一个余量1；不是正式58点目标。

本说明是该共同模型的纸面语义，不是存在性或排除证明。对一般58点图仍未
证明非平凡二块equitable partition必然存在；本模型结果不得越过该范围。
