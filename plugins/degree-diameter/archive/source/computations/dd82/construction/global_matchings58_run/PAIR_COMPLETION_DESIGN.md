# 六轮实际前缀的任意二正则补全：条件性设计

2026-10-18。按项目 `formula-derivation` 组织精确编码与范围说明。**本文只给设计，未生成正式CNF、未调用求解器，未批准下一批实验。** 根代理结合实际容量诊断及Gemini第2轮意见后选择是否实施。

## Target / Status

**COHERENT AS STATED。** 给定已保存的真实六正则前缀 F，完整编码所有包含 F 的58点、八正则、直径至多2简单图。新增边允许任意二正则图，包括奇圈；不要求拆成两个完美匹配，也不固定旧第7、8轮的任何选择。

条件性示例是 `pilot/seed3/rounds.json` 的前六组匹配之并。只读重建确认58点、174边、全6度、639坏对。实际容量记录 `prefix_capacity/prefix_capacity.json` 给出seed3的修复上界645；seed0为645坏对、上界649。其余六个seed的r6前缀被该记录的容量界排除。这里只使用诊断结果确定设计候选，不把“界未排除”解释为存在补全，也不在本文重审容量证明。

## Invariant Object / Assumptions

固定顶点集 V={0,…,57}，固定边集 E=E(F)，最终图为 G=(V,E∪A)。目标是实际 G 的度数和全部点对距离，不是单边收益总和。

- E仅取保存记录中的第1–6轮边；检查每轮29条边覆盖全部顶点、六轮互不重边及并图全6度。第7、8轮只可作为已有失败输出作比较，不进入约束。
- 当前任务保留 E 的174条边，这是明确的额外构造限制。F来自空图的非单调生成，**不等于** polarity73幸存点诱导图；几何旧边中不在 E 的边也必须自由。`ambient_labels`仅用于回溯标签。
- 任意58点、最大度≤8、直径≤2的图实际上全8度：若某点度数 d≤7，其半径二球至多 `1+d+7d=1+8d≤57`，无法包含58点。因此精确8度符合原目标；固定此前缀才是本设计的限制。

## Notation

令 N_F(u) 是前缀邻域，

`B = { {u,v}: u<v, uv∉E, N_F(u)∩N_F(v)=∅ }`

为原坏对集合，`Q = binom(V,2) \ E` 为全部缺边。对每个无序对 `e∈Q` 建唯一布尔变量 `X_e`，表示实际新增边；两个端点的度数约束和所有路径约束共用同一个变量。

任何六正则58点前缀均有 `|Q|=1653−174=1479`，每点恰有51个可选新邻居。没有有向副本、匹配颜色、几何边筛选、收益门槛、指定圈数或圈长限制。

## Derivation Strategy / Map

1. 全部缺边变量与每点精确新增度2，刻画所有二正则新增边集。
2. 原先已覆盖的点对由固定 E 保持覆盖；只需完整表达 B 中各点对的一跳或两跳路径。
3. 两条新增边的路径使用双向AND等价；所有实际路径作一个OR子句。
4. 分别证明模型到图、图到模型，得到对固定 F 的精确等价。全程无近似；容量界及先前贪心分数不是本编码的约束。

## Main Derivation

### 1. 新增度数与所有二因子

每个 `u∈V` 加入

`sum_{v≠u, uv∉E} X_{uv} = 2`。

故A是无重边、无环的二正则图，`|A|=58`，最终 `|E∪A|=232`、全8度。有限简单二正则图恰为顶点不交的长度至少3的圈之并，奇圈自动允许。不要引入要求这些圈为偶数的两色匹配分解；这会漏掉合法A。

用现有 `enforce_exact(em, incident_variables, 2, ...)`。其阈值递推为双向等价；最终要求“至少2”且“不是至少3”。这与新增度2等价，无需单独加入总新增边数58的冗余约束。

### 2. 原坏对的真实覆盖公式

对 `{u,v}∈B`，其原邻域均有6点、互不相交，且不含对方。令

`Z_uv = V \ ({u,v} ∪ N_F(u) ∪ N_F(v))`，故 `|Z_uv|=44`。

G中距离至多2，精确等价于

```text
C_uv = X_uv
       OR (OR_{z∈N_F(u)} X_zv)
       OR (OR_{z∈N_F(v)} X_uz)
       OR (OR_{z∈Z_uv} (X_uz AND X_zv)).
```

四部分分别是直接新增边、旧边u–z加新边z–v、新边u–z加旧边z–v、两条新增边。因为原来是坏对，不存在两条旧边的路径。中点遍历全部 `V\{u,v}`，没有固定“负责修复”的边或中点；一个点对允许同时被多条路径覆盖。

不同于最后一轮完美匹配，任意二正则A可以含相邻新边，最后一项不能省略，也不能用各单边收益之和代替C_uv。

对每个 `z∈Z_uv` 建辅助变量 `P_uvz`，用三条子句编码双向等价：

```text
P_uvz <-> (X_uz AND X_zv)
(-P_uvz OR X_uz)
(-P_uvz OR X_zv)
( P_uvz OR -X_uz OR -X_zv)
```

然后把C_uv中的AND替换为P，直接加入一个OR子句并要求其为真。无需另设覆盖变量；OR本身就是覆盖约束，不存在只定义一个方向的遗漏。每个坏对恰有 `1+6+6+44=57` 个不同的OR项。对不在B中的点对不需添加覆盖子句，因为旧的一跳或两跳路径始终保留。

seed3示例有639个覆盖子句和 `639×44=28116` 个两新边AND辅助变量；1479个主变量覆盖全部缺边。这些计数来自读取实际前缀后的集合计算，不代表已生成正式求解输入。

### 3. 双向等价及范围

**模型⇒图。** 由所有真值X取A。主变量只对应Q，保证最终图简单且包含E；精确度约束给出全8度。每个坏对的OR至少有一项为真。直接或混合项给出实际路径；P为真时，两条AND蕴含子句强制相应两条边为真。其余点对的旧路径保留。因此最终图直径至多2。

**图⇒模型。** 任取包含E的58点八正则直径二图G，把 `A=E(G)\E` 对应X设真，其余X设假。每点新增度恰2；把阈值辅助位设为真实计数值，把每个P设为对应两条新边的合取。AND双向定义及度数子句成立。每个原坏对的实际一跳/两跳路径必属上述四类之一，所以覆盖OR成立。整个CNF可满足。

因此该CNF可满足，当且仅当存在包含**这个固定F**的目标图；不要求新增边有完美匹配分解，不要求保留原第7、8轮，不要求与几何有给定重叠。

## Remarks / Boundaries / Open Risks

本设计为当前新生成机制的固定前缀补全。它与旧polarity73单调族的区别在于固定的是从空图生成的F，而不是幸存几何诱导图；但它仍限制最终图包含F，不能据失败排除58点全空间。

既有r6容量界没有排除seed3，不等于可满足，也不能保证短预算内会返回模型。本文不增加几何优先级、手选新增边、先固定M7或求解加时。正式执行仍需根代理作出具体有界选择。

若之后无证明日志运行返回UNSAT，只登记此输入的未认证结果；若UNKNOWN，不是固定F或整个58阶的排除。只有实际模型通过独立图检查，才能声称找到目标图。编码的数学等价是本文设计结论，实际实现正确性及运行结果仍待相应阶段检查。
