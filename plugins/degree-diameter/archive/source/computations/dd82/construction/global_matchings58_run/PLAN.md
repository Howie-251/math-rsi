## 完整规则和范围

使用 refined58 已保存删除集的58个幸存标签，对应旧几何诱导图H，但从空图F开始。每轮在完整补图中选29条互不相交边组成完美匹配，共8轮；旧边也可以始终不选。每轮后F为相应度数的简单正则图，最终58点232边、度数全8。

对可用边uv，单独加这条边的精确新覆盖数为：

`g(u,v) = 1[uv是坏对] + |N_F(u) ∩ Bad_F(v)| + |N_F(v) ∩ Bad_F(u)|`。

Bad只含当前真实图距离大于2的点。匹配首先最大化收益之和，然后最大化旧几何边数，最后用确定性seed打破平局。整数权重 `(30*g + old_flag)*30000 + random_integer(0,999)`；匹配29边，所以随机项总差小于30000、旧边总差至多29，保证前两级不被后级颠倒。

不同新边可能修复同一坏对，收益之和只是优化启发式；逐轮实际重算坏对，报告预测与真实改善，不伪称精确最大覆盖。可用图最小度57-r至少50，必有完美匹配，具体增广路论证见方向说明。八个匹配并的初始限制不覆盖任意八正则图；不据失败排除整个58阶或一般非单调几何族。
