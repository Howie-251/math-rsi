- `single_edge_gain` 正确。单独加入缺边 xy，新覆盖只能是 xy、x 与 y 的旧邻居、y 与 x 的旧邻居；以当前 bad mask 筛选后三类互不相交。现有 sanity 记录覆盖五张小图的49条缺边，并保存预测6、实际4的共享修复例子。

- 每轮候选恰为当前完整补图；已有 r 个不重复完美匹配时可用图度数为57−r≥50，方向说明的增广路论证保证完美匹配存在。代码检查29边、58点各出现一次、无已有边，并检查更新后所有度数为 r+1。八轮确得58点、232边、度数全8的简单图。

- `runner.worker()` 用 `runpy` 在同一子进程内运行生成器和已有独立邻接表 BFS；继承 `bounded()` 对这一进程设置60 CPU秒、90墙钟秒、单CPU affinity、4 GiB地址空间及每文件256 MiB限制。BFS独立读取候选边表，并核对58点、232边、全8度及全部坏对与生成器一致。没有自动重启或局部交换。
