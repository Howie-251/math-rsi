# 两个29点二正则图与自由六正则跨边：条件性方向

2026-10-18。**仅作范围核对和数学设计，未实现、未生成CNF、未运行枚举或solver，也不继承旧批次预算。** 按已读`formula-derivation`整理。当前状态：公式与给定范围一致；存在性未知。

## 旧结果究竟覆盖了什么

检索当前wiki的idea/experiment/claim记录及相关构造证明，没有找到已针对“29+29、内部全2度、跨边为任意行列和6的二进制矩阵”运行或完整排除的记录。这是基于所查材料的范围判断，不是对所有历史文件的穷尽证明。

三个最接近的旧结果均不直接覆盖本族：

- [双C29循环作用排除](../../../../proofs/dd82/construction/CYCLIC_LIFT_CONSTRUCTION.md)要求整个图保持共同循环平移，跨边由同一个offset集决定。自由跨边矩阵没有这个要求。即使两侧都编号成标准29圈，也不能因此认定整图有C29自同构。
- [等大纤维容量界](../../../../proofs/dd82/construction/EQUAL_FIBER_SINGLE_MATCHING_CAPACITY.md)要求每对纤维间只有一个完美匹配；本族每点有6个跨侧邻居，不是该模型。
- [两侧二正则图的旧Sylvester排除](../../../../proofs/dd82/construction/CYCLIC5_QUOTIENT_TWELVE_PENTAGONS_EXCLUSION.md)用于60点，要求指定的C5/C25圈型以及零跨缺陷，方程右端为`J30`。本族为58点，右端为`J29+P`，不满足其承重条件。六个10点纤维的旧归约也没有覆盖当前两个29点部分。

因此这是一个尚可讨论的具体受限域，不能仅凭换名称称为突破；其价值要由实际联合实现条件是否可解决定。

## 对象、精确恒等式与范围

设H0、H1分别为29点简单二正则图的对称邻接矩阵；C为29×29二进制矩阵，每行、每列和均为6。构造

```text
A = [ H0   C  ]
    [ C^T  H1 ] .
```

A必为58点232边、度数全8的简单图。H0、H1不需相同或同构，C不需循环、对称或分解成预先指定的匹配。

跨侧一跳/两跳路线的精确计数矩阵为

`K = H0 C + C H1 + C`。

两条跨边走回原侧，所以跨侧没有遗漏的“两条跨边”项。每行、每列的路线总数为`12+12+6=30`。因此

`K ≥ J29  ⇔  K = J29 + P`

其中P为某个置换矩阵：非负整数矩阵K−J的每行每列和均为1。这是必要且充分的跨侧覆盖条件，不是整个图的充分条件。

同侧还必须同时满足

```text
(H0^2 + H0 + C C^T)_(u,v) ≥ 1,  u≠v;
(H1^2 + H1 + C^T C)_(u,v) ≥ 1,  u≠v.
```

以上三组覆盖条件连同行列度数，精确等价于这个固定H0/H1构造的直径至多2。只解跨侧近铺砌、随后发现同侧坏对的矩阵仍只是失败候选。

## 两种归一化不能混用

若将右侧用置换矩阵Q重标，

`C'=C Q, H1'=Q^T H1 Q, P'=P Q`。

取`Q=P^T`可无损使`P'=I`，但H1随之改变。此时不能再任意强制H1与H0采用同一标准圈顺序；这会丢失相对排列。

**最小实施建议是不归一P。** 若先选“两侧都为Hamilton29圈”子族，可以分别独立编号两侧，使`H0=H1=H(C29)`为标准圈，同时保持C的841位全部自由、P完全自由。这对该Hamilton子族无损，因为两侧有独立重标自由；并未额外要求C是循环矩阵。

更广的二正则域可按每侧的圈长分拆（各长度≥3、总和29）选择规范代表，再保留自由C及自由P。固定一种圈型对只覆盖该对圈型；没有执行这些圈型选择或枚举。若坚持P=I，则至多先规范化一侧，另一侧需保留全部相对标号。本设计不使用这种较复杂入口。

## 最小共同SAT规则：先限定两侧为C29

唯一主变量为`c[i,j]`，`0≤i,j<29`。所有下标按模29理解。

1. 对每行与每列分别约束`sum c = 6`，共58个精确计数。复用现有通用`enforce_exact`。
2. 对所有841个跨侧点对加入五项正子句：

   `c[i,j] OR c[i−1,j] OR c[i+1,j] OR c[i,j−1] OR c[i,j+1]`。

   结合行列和6，这些子句已经推出K=J+P。无需另建P变量或固定它，也无需额外加入“每格至多2”。
3. 每侧的圈距离1或2点对已由固定内部边覆盖。对左侧其余348个无序点对`{i,k}`，加入

   `OR_j (c[i,j] AND c[k,j])`。

   对右侧其余348个点对`{j,l}`，加入

   `OR_i (c[i,j] AND c[i,l])`。

   每个AND使用现有`add_iff_and`的完整三子句双向等价。共696个同侧覆盖OR、20184个两跨边AND辅助位。

该模型SAT当且仅当存在两侧均为29圈的目标图：赋值直接给实际C及完整A；反向对任意该子族目标分别按两侧圈序重标，所有主变量、计数及路径辅助位均可取其真实值。因此不会固定某个任选P或跨侧匹配，也没有收益目标、旧几何边或旧种子的冻结部分。

`refined/completion.py`的计数、AND及显式赋值检查思想可复用，但不能直接用`build(58, 两个圈的边, 8)`替代本模型：那个函数还会放开侧内缺边，改变此处声明的范围。这里必须显式规定侧内恰为两个固定圈、仅841条跨边自由。

一个直接推论可用于解释失败结构：H0相邻两行的C支撑必须不交；否则两行在同一列同时出现重复覆盖，违背P每列只有一个1。右侧对称结论也成立。它由核心条件已推出，不需要先追加成另一套搜索规则。

## 若以后实际执行，如何验收对象

联合SAT模型只接受跨侧和同侧同时可行的C。完整模型检查后，展开左侧`0…28`、右侧`29…57`的实际232条无向边，保存H0/H1/C及由K−J直接算出的P。独立BFS从完整边表检查58点、简单性、全8度和全部1653个点对；同时直接核对K−J确为置换矩阵，不用必要条件代替距离检查。

最小准备检查应使用显式小矩阵核对三种路径类型与BFS一致，并逐项检查AND双向真值；本次仅提出这些检查，没有执行。找到只有跨侧覆盖的C不算成功，UNKNOWN或有限试验无目标也不排除这个族。即使将来关闭Hamilton子族，也不关闭一般二正则圈型，更不关闭任意58点图。

当前未发现可直接由上述恒等式推出矛盾的已证明结论；也没有声称它可解。下一步是否值得设置一个新的有界实验，由根代理结合旧匹配机制的最终实际复核决定。
