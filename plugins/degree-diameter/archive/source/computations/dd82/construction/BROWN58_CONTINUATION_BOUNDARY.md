## 2. 固定八个 hub 邻点时必须真正改变什么

沿用 Brown 记号：C 为 8 个绝对点，I 为 21 个没有 C 邻居的内部点，E 为其余 28 点。原 C 独立，只有 C–E 边；每个 E 恰接两个 C，每个 I 接四个 I、四个 E。直接依据是 [Brown 扩展证明](../../../proofs/dd82/construction/BROWN_EXTENSION_OBSTRUCTION.md:11) 和 [八删除证明的有限前提](../../../proofs/dd82/construction/BROWN_EIGHT_DELETE_OBSTRUCTION.md:14)。

若最终仍固定 N(57)=C，则每个 I 至少需要一条新增 C–I 边，否则 hub 到它仍没有二步路。因此至少新增 21 条 C–I 边。每个 C 的旧点度须仍为 7，而原有邻点全在 E，故至少删除 21 条旧 C–E 边。允许新增 C–C 或新的 C–E 边也不会降低这个删除下界。

这说明只改 I/E 内部而保留全部 C–E 的方案必然无效。旧统一的“任意 Brown 扩展至少删十条旧边”仍有效，但没有排除超过该下界的重连，见 [BROWN_NINE_DELETE_OBSTRUCTION.md](../../../proofs/dd82/construction/BROWN_NINE_DELETE_OBSTRUCTION.md:1)。固定八绝对点入口应直接处理 C 的端口重分配，不能靠改写小交换次数来宣称新机制。

## 3. 一张完全指定的全局重连图：规则无自由选择

这里仅给完整纸面定义，没有把它生成到边表。它用于检验“全局重分配”是否已有具体内容，不声称产生目标。

**固定标签与几何映射。** 取既有 [brown57.edges](brown57.edges)，加入 hub 57，令

\[
(c_0,\ldots,c_7)=(17,18,23,26,30,33,38,39),\qquad N(57)=C.
\]

对不同 a,b∈{0,…,7}，定义 e_{ab}=e_{ba} 为 Brown 中 c_a、c_b 的唯一共同邻点。这个定义没有匹配选择：从原边表取两邻集的唯一交点即可。等价坐标算法是取 [Brown57 证明](../../../proofs/dd82/construction/BROWN57_PROOF.md:13) 给定的两个 F7 代表向量的叉积，令首个非零坐标归一为 1，再按该证明的标签规则解码。所有 e_{ab} 恰好给出 E 的 28 个点：两条独立正交方程给唯一射影解，每个 E 又恰有两个 C 邻点。

固定 [triangle_edit_obstruction.json](triangle_edit_obstruction.json:88) 的**第一**个已列出的 III 分割，顺序和各三角内顺序固定为

\[
\begin{array}{c|rrr}
t&a_t&b_t&d_t\\\hline
0&0&49&56\\
1&1&27&34\\
2&6&22&29\\
3&7&45&46\\
4&10&11&42\\
5&16&40&55\\
6&19&37&50
\end{array}
\]

**完整删除与新增规则。** 除下面明确删除者外保留所有 Brown 边；hub 边全部保留。

1. 每个 t 删除 a_t b_t、a_t d_t，共 14 条 II 边。
2. 在标签 0,…,7 上固定锦标赛：差 j−i mod 8 属于 {1,2,3} 时定向 i→j；四条对径边定向为 4→0、5→1、6→2、3→7。每条 a→b 删除 c_a e_{ab}。这恰删 28 条 CE，每个 E 恰失一条 CE。C 的删除度依次为 (3,3,3,4,4,4,4,3)。
3. 对 t=0,…,6 新增 a_t c_t、a_t c_{t+1}、b_t c_{t+2}、d_t c_{t+3}，这里 C 下标**模 8**。这恰加 28 条 CI，C 的新增度也为 (3,3,3,4,4,4,4,3)；每个 a_t 得两条，其余 I 得一条。
4. 对 t=0,…,6 加入以下两条 EE 边，此处 t+1、t+3 **模 7**，下标 7 是固定的 c_7：

   \[
   e_{t,t+1}e_{t,t+3},\qquad e_{t+1,t+3}e_{7,t+1}.
   \]

   三元组 {t,t+1,t+3} 把 K7 的 21 条边分割为七个三角；第一条配对使用每组的两条边，第二条把余下那条与唯一对应的 K8 星边配对。因此全部 28 个 E 点恰出现一次，得到实际指定的完美匹配。每对 E 共享一个原 C 邻点；原 CE 不属于任何三角，所以它们原先不相邻，新增 EE 确为非边。

这些规则没有待选择的分割、定向、循环起点或匹配。共删除 42 条旧边，新增 42 条旧旧边；全部 58 点度数为 8，简单且有 232 条边。hub 直达 C，每个 I 有新 C 邻点，每个 E 保留一个 C 邻点，所以 hub 与所有旧点的距离至多 2。旧 Brown 核已被实际改动，不能视作“保留 Brown57 再加一点”。

在本次核读的旧执行记录中，没有看到按这一全局公式生成并检查的任务。这个说法仅限明确记录：没有证明该图与所有旧随机中间状态不相同，也没有把它与旧 joint-boundary 域的换标号包含关系判定为不相交。

## 4. 这张明确图的失败点，以及共同指派必须满足的条件

不必生成图即可给出失败见证。第一组三角删除 0–49、0–56，但点 0 的三个旧三角

\[
(0,50,55),\quad(0,51,52),\quad(0,53,54)
\]

全部保留。规则 3 新增 0–c_0=0–17。原 E 点 53 的两个 C 邻点为 17=c_0、39=c_7；定向 7→0 只删除 39–53，保留 17–53，原 0–53 也保留。因此又出现三角 (0,17,53)，从而 t(0)≥4，违反任何 58 点、最大度 8、直径至多 2 图必须满足的 t(v)≤3。原边可直接定位于 [brown57.edges](brown57.edges:2) 的第 2–9、125、206、223–225 行；本轮没有重新计算三角或 BFS。

失败揭示了后续共同规则的必要条件，不能仅独立配平度数。每个 I 原有四个三角；所选 III 分割只使它损失其中一个，另外一个 III 和两个 IEE 都保留。因此**不能在任何 I 处新增三角**。对每个 i∈I，它的四个原 E 邻点各对应一对 C，这四对把八个 C 恰覆盖一次：每个 C 与 i 有唯一原共同邻点。

于是新增 ci 前，必须已经删除 c 与这个唯一原 E 共同邻点之间的 CE 边，否则立刻形成新的 CIE 三角。还必须防止同一 c 新接某条保留 II 边的两个端点，否则形成 CII 三角。这要求 CE 删除与 CI 指派共同设计；本稿的独立循环填充不满足它。该条件没有排除所有联合指派，但本轮只检查上面这一张明确图，到此停止，不自动换分割、换定向或续试循环公式。

## 5. 同一模板放宽到共同指派后的精确必要条件

本节不改图或试新参数，只核对一个统一条件。保留同一 III 三角分割，每块删两条 II；每个 E 恰删一条 CE；CI 按真实 C/I 缺口共同指派；E 上加入任意一个由原非边组成的完美匹配；hub 的邻集仍恰为 C。除此之外不改原边。记 Z⊂I 为七个在各块中损失两条 II 的中心，X=I∪E，故 |Z|=7、|X|=49。每个 Z 点新增两条 CI，其余 I 点新增一条，每个 E 保留一条 CE。

**条件：如果这种共同指派得到真正的直径至多 2 图，则 X 内每一对非邻点恰有一个共同邻点。** 证明如下。

每个 I 恰损失所选分割中的一个 III 三角，另一个 III 和两个 IEE 都保留。E 原有的三个三角都是 IEE，也全部保留：本模板没有删除任何 IE 或 EE，CE 原本不在三角中。因此 X 的每点已有三个保留三角。目标的 t(v)≤3 禁止增加任何涉及 X 的三角。C 仍独立，hub 只接 C，原先也没有经过 C 的三角；故最终

\[
t(v)=3\quad(v\in X),\qquad t(v)=0\quad(v\in C\cup\{57\}).
\]

令 A 为最终图的邻接矩阵，定义缺陷矩阵

\[
B=A^2+A-7I_{58}-J_{58}.
\]

在 8 正则、直径至多 2 的目标中，B 非负且对称，对角为零，每行和为 7。邻点位置上的行和为 2t(v)，所以非邻点位置的行和为 7−2t(v)。因此 X 各点的非邻预算为 1，C 和 hub 各点的非邻预算为 7。

hub 与每个 Z 点恰有两个共同邻点，与 X\Z 各点恰有一个共同邻点。故 B(57,z)=1（z∈Z），其余 hub 缺陷为零。七个 Z 点各自唯一的非邻预算已经用在 hub。

不同 c,d∈C 的共同邻点包括 hub。每个 E 和每个 I\Z 只接一个 C，不贡献额外共同邻点；每个 z∈Z 接两个 C，恰贡献一个无序 C 对。因此无论这些 C 对是否重复，均有

\[
\sum_{c\ne d\in C}B_{cd}=2|Z|=14.
\]

八个 C 的非邻预算合计 56，扣除上述 C–C 的 14，剩下的 42 全部指向 X。利用 B 的对称性，再合计 X 的非邻预算，得到

\[
49
=\underbrace{7}_{X\text{ 到 hub}}
 +\underbrace{42}_{X\text{ 到 C}}
 +\sum_{\substack{u,v\in X\\u\ne v,\;uv\notin E(G)}}B_{uv}.
\]

最后一项为非负数之和，故每个该类 B_{uv} 都为零。对非邻点 B_{uv}=|N(u)∩N(v)|−1，这证明了所述条件。

计数还精确说明：七个中心除 hub 外没有任何非邻重复；其余 42 个 X 点，各恰有一个 C 中的非邻点与它有两个共同邻点，其余非邻点都只有一个共同邻点。这些都是**假设完成了全图覆盖后**的必要条件，不是任意保度指派自动具备的性质。本节没有证明共同指派模板整体无解，也没有生成新图或续试其他指派。
