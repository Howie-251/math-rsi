# 左侧覆盖与十字缺陷之间仍缺一条定量联系

2026-10-18。同一28＋30构造的有界纸面诊断；不运行枚举、solver或外部调用。已有唯一求解返回UNKNOWN，本文不据此解释失败原因或要求加时。

**结论：没有得到空洞数严格大于60的下界，也没有排除当前族。** 一个可以明确定位的障碍是：左侧共同邻居数据不记录右圈列的相邻关系，而基础十字空洞数恰依赖后者。下面给出同一共同邻居矩阵对应 $Z=12$ 与 $Z=282$ 的手算例子，并指出低空洞例为何仍不能被自由匹配修补。它们只是诊断反例，不是固定循环子族的新搜索。

## 1. 需要联系的两个量

保留 [前一诊断](MATH_DIAGNOSIS.md) 的记号

$$F=H_{28}C+CH_{30}+C,\qquad K=F+CM.$$

每行跨侧度6，18列跨侧度6、12列跨侧度5，故

$$\sum_{i,j}F_{i,j}=840,\qquad
\sum_{j=0}^{29}\binom{\deg_C(j)}2=390.$$

后一个量是所有无序左点对的跨侧共同邻居数之和。左圈距离大于2的322对必须全部获得至少一个共同邻居；但390与322的差68并不直接计数 $F$ 的空洞或重复。前者计数在同一右列中共同出现的左点对，后者计数在方格十字中重叠或缺失的覆盖。

令 $Z$ 为 $F$ 的零项数。因为 $F$ 非负整数且总和840，

$$Z=\sum_{i,j}\max(F_{i,j}-1,0).$$

完整跨覆盖使 $Z\le60$，并要求每个零项实际落在对应的 $CM=1$ 位置；数量界不替代位置约束。

## 2. 同一个左侧共同邻居矩阵允许两种完全不同的空洞数

先取

$$C_{i,j}=1\iff j\equiv2i\pmod5,
\qquad 0\le i<28,\quad0\le j<30.$$

每行有6个1。列剩余类 $0,2,4$ 的列度为6，列剩余类 $1,3$ 的列度为5，正好符合指定度数轮廓。

对内部行 $1\le i\le26$，五项十字分别贡献列剩余类 $2i,2i\pm1,2i\pm2$，所以该行 $F$ 全为1。左圈接缝的两行有所不同：

- 第0行的五个剩余类为 $0,1,2,4,4$，缺类3，重复类4，故有6个空洞。
- 第27行的五个剩余类为 $4,3,0,2,0$，缺类1，重复类0，故也有6个空洞。

所以 $Z=12$。

现在只把右侧跨邻接的列顺序改为按模5类连续排列，令

$$\widetilde C_{i,6r+t}=C_{i,r+5t},
\qquad 0\le r<5,\quad0\le t<6.$$

右圈仍是标准 $C_{30}$；这改变了跨边相对右圈的位置，并非把完整图一起重标。全部跨侧度数保持不变，而且

$$\widetilde C\widetilde C^T=CC^T.$$

因此每一对左点的共同邻居数，包括全部远距左点对的覆盖与重数，都完全不变。

对 $\widetilde F=H_{28}\widetilde C+\widetilde CH_{30}+\widetilde C$，内部行的自身与两个相邻左行覆盖三个互不相交的6列区段，共18列；自身区段相邻的两个区段都不在这三者中，故右圈的一步移位再补两列，共覆盖20列，所以每个内部行有10个空洞。接缝行0、27的自身区段已与一个邻行区段相邻，移位只补一列，各覆盖19列、各有11个空洞。故

$$\widetilde Z=26\cdot10+2\cdot11=282.$$

这证明相同的全部左共同邻居数据可以对应截然不同的基础十字缺陷。两张矩阵均只覆盖65个不同远距左点对：同模5的左点对有共同邻居数6，其他对为0，故390次共邻计数集中在65对，仍有257对未覆盖。它们都不满足完整左覆盖，因此这个例子**没有反驳**“完整覆盖全部322对会迫使 $Z>60$”这一尚未证明的命题。

## 3. 低空洞例也不能靠匹配任意搬运修补资源

原矩阵的12个低度列为

$$D=\{j:j\equiv1\text{ 或 }3\pmod5\}.$$

任何合法匹配弦 $M$ 的端点集都必须恰为 $D$。第0行只邻接列剩余类0，第27行只邻接列剩余类4，二者均完全不邻接 $D$。因此不论这些端点如何配对，$CM$ 的第0行与第27行都全为0，不能修补正好位于这两行的12个空洞。

所以即使 $Z=12\ll60$，跨侧覆盖仍可能不成立。真正需要的不是“共有60条弦路线”这一总量，而是这些真实路线能否出现在全部缺口的准确位置。

## 4. 准确的未闭合义务

若继续尝试用当前计数直接取消整个输入，一条足够强、但目前未证明的命题是：**任意满足本构造跨侧度数轮廓、并覆盖全部322个远距左点对的跨矩阵 $C$，都必须具有 $Z\ge61$。** 本文既不声称该命题成立，也不声称它是排除此族的唯一办法。

要证明它，须把“不同远距左点对确实被覆盖”与“右圈相邻列造成的局部十字缺陷”联系起来。旧无缺陷十字传播只处理 $F\equiv1$；一旦允许缺口或重叠，就不能不加证明地把相同orientation传播过这些位置。现有计数还没有控制一个缺陷能中断多少段传播、影响多少远距点对，因此没有形成足以超过60的计数收费规则。

这就是本次留下的具体缺口。本文没有给编码追加计数筛选，没有固定循环矩阵继续搜索，也没有把UNKNOWN归因于这一缺口。完整跨覆盖与同侧覆盖的共同可实现性仍由原来的完整构造域承载。
