## 原图范围与计数约束

`encode.py:55–110` 建立左侧诱导 C28、右侧固定 C30 的全部 405 条非圈弦变量，以及全部 840 条跨边变量。左侧其他内部点对固定为非边；右侧无额外内部边类型。弦端点、配对、长度与跨矩阵均未被预设，也没有 J＋P、P＝I、周期性、equitable 或排序约束。沿两个实际圈分别编号，为所声明构造族中的每张图得到一个合法重标代表；该族仍不等于任意58点图。

右侧每点弦度至多1与弦总数恰6共同给出六边匹配。左侧跨行和恰6，右侧跨列和加弦度恰6，所以全图每点度8；168条跨边加58条圈边和6条弦，共232边。通用 `unary_thresholds` 双向编码精确前缀阈值，`enforce_exact` 将第6阈值置真、第7阈值置假；弦匹配把第2阈值置假。没有把“至多”误当“恰好”，也没有遗漏弦对右侧度数的贡献。

## 所有点对的真实覆盖

`encode.py:112–145` 遍历全部1653个无序点对及所有不同中点。固定直接边或两条固定圈边已经覆盖的116对可合法省去恒真子句；其他1537对保留真实直接变量及全部两跳见证。常量使用 `is True` / `is False` 区分，不会把编号1的变量误认成布尔常量。一条固定边与一条自由边的路径直接使用自由位；两条自由边的路径用三子句双向 AND，不能凭空开启见证。最终 OR 正确处理重复项，并涵盖左右同侧与跨侧。

保留匹配约束下不可能为真的两弦路径不会缩小或扩大模型。它解释了相对纸面简化版多出的9000个 AND；不是继承旧模型限制。按源码的循环与阈值递推独立计数，得到51840个两自由边 AND、20616个计数辅助变量，加1245个主变量，共 **73701变量／235491子句**，与当前预测一致。此处是组合核算，未建立正式模型。
