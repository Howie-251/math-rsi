# 每个特殊行一次独立 incidence trade 的两分支排除

证据更新：实际第4轮直接 SCOPED ACCEPT；回执 reviews/dd82/20261018_nonuniform58_final_direction_review.json。仅接受本文精确纸面范围，非Lean或完整58阶排除。

2026-10-18。本文只核对下面定义的“每个特殊行各一次独立 incidence trade”这一统一范围；没有运行计算、构造新参数或继续增加交换次数。

**在第 1 节的独立性假设下，这整个交换族均不能完成目标。** 若至少一个特殊行删掉完整平行类中的列，该行留下至少三个 cross-disjoint 普通点；加上另外两个特殊行，至少五个点超过左 C28 的四个近邻位置。若三次都删除 promotion，则三个特殊六集仍各保留完整平行类，落入 q=1 的跨侧重复路径矛盾。两个分支穷尽每个原特殊六集中的删除选择。

## 1. 前端与交换范围

采用旧 F5 仿射前端：25 个普通行是 `AG(2,5)` 的点，30 个右列是其仿射直线，普通行初始按点线关联。三个特殊行记为 `s∈{a,b,c}`，其初始六邻域为

```
T_s = P_s ∪ {p_s},
```

其中 `P_s` 是一个包含五条平行线的完整平行类，三个 `T_s` 两两不交，`p_s` 为该行的 promotion 列。高列集合为 `H=T_a∪T_b∪T_c`，低列集合 D 是其补集。

每个特殊行只进行一次 2×2 交换，精确假设为：

- 取 `h_s∈T_s`，即删除的是该特殊行原有的高列；
- 取任意旧低列 `d_s∈D`，三个 `d_s` 互不相同；不限制 d_s 的方向；
- 取普通点 `x_s∈d_s` 且 `x_s∉h_s`，三个交换的普通行互不相同；
- 删除 `(s,h_s),(x_s,d_s)`，加入 `(s,d_s),(x_s,h_s)`。

这三次交换不含其他关联改动。每次交换前的四格为所需的 `1,1,0,0`，各次使用不同的特殊行、普通行和列，故互不覆盖。交换保持每行和、每列和；交换后的特殊六邻域为

```
S_s = (T_s \ {h_s}) ∪ {d_s}.
```

它们仍两两不交：原 `T_s` 两两不交，而新增 `d_s` 是三个不同的旧低列。H、D 不变，每个特殊行的 `q_s=|S_s∩D|` 从 0 变成 1。

## 2. 分支 A：至少一次删除完整平行类中的列

固定一个满足 `h_s∈P_s` 的特殊行 s。此时

```
S_s = (P_s \ {h_s}) ∪ {p_s,d_s}.
```

四条保留的平行线 `P_s\{h_s}` 恰好覆盖不在 h_s 上的 20 个普通点。

由于 `P_s` 是完整平行类，`p_s∉P_s` 且旧低列 `d_s∉P_s`，p_s、d_s 的方向都与 h_s 不同。它们在 h_s 上最多覆盖两个点；两交点也可能重合。因此按原始仿射关联，S_s 覆盖至多 22 个普通点，未覆盖集合是

```
U_s = {ordinary points on h_s} \ (p_s ∪ d_s),
|U_s| ≥ 3.
```

具体地，两个交点不同时 `|U_s|=3`，重合时 `|U_s|=4`。仅有这项几何计数还不够；必须检查普通行自身的交换是否改变结果。

## 3. 分支 A 的普通点缺口在真实交换后仍然存在

**自身交换不能补洞。** 因为 `x_s∉h_s`，自身被交换的普通行不属于 U_s。U_s 内的普通行均未受到 s 的这次交换。此外，x_s 在 `P_s` 中的唯一关联线不是 h_s，仍属于 S_s，也没有被此次交换删除。因此，虽然 x_s 删除了与 S_s 共同的 d_s，它仍与 S_s 相交，不会产生额外缺口。

**其他两次交换不改变与 S_s 的交集。** 对 `t≠s`，另一次交换只在普通行 x_t 上删除 d_t、加入 h_t。这两列均不属于 S_s：

- `h_t∈T_t`，原 `T_t` 与 `T_s` 不交；h_t 是旧高列，也不等于新增的旧低列 d_s；
- d_t 是旧低列，所以不属于 `T_s`；又因 `d_t≠d_s`，它也不是 S_s 的新增列。

因此，无论 x_t 是否恰好落在 U_s 中，其交换都不改变它与 S_s 的交集。特别地，落在 U_s 内的 x_t 不可能通过加入 h_t 来补上缺口。

以上覆盖了所有普通行的改动。这不要求另外两次也删除平行类列；只用了 `h_t∈T_t` 和 d_t 为不同的旧低列。所以对交换后的真实交叉矩阵 C，仍有

```
S_u ∩ S_s = ∅  当且仅当  u∈U_s,
```

其中 u 遍历 25 个普通行；至少三个普通行与 s cross-disjoint。这不是把交换后的普通行继续当作原始仿射行来计数。

## 4. 分支 A 至少五个 cross-disjoint 左点超过 C28 的四个位置

另外两个特殊行的邻域也与 S_s 不交。因此这个特殊行 s 至少有五个不同的 cross-disjoint 左顶点：U_s 中至少三个普通点，以及另外两个特殊点。

对任何这样的左顶点 u，`S_s∩S_u=∅` 排除了经过右顶点的两跳路径。左点对的一跳或两跳覆盖只能来自左内部图本身，即它们必须在左 C28 上相距至多 2。右侧圈或新增匹配均无法作为两个左顶点之间长度至多 2 的路径中的内部边。

但 C28 上任何点在圈距离 1 或 2 内只有四个其他顶点，即两侧各两个位置，不能容纳这五个不同的必需点。矛盾。

所以只要有一个特殊行删除完整平行类中的列，就无法满足全部左侧点对覆盖；跨侧覆盖尚未成为需要继续检验的条件。该失败与右侧圈顺序、匹配配对及左点标签顺序无关。

## 5. 分支 B：三个特殊行都只删除 promotion

剩下的可能是三个 `h_s=p_s`。此时

```
S_s = P_s ∪ {d_s}.
```

所有普通行仍与每个 S_s 相交：普通行的交换只删除旧低列 d_t、加入旧 promotion 列 p_t，没有改变任何一个 P_s 中的原有点线关联。三个 S_s 仍两两不交、各有 `q_s=1`。

这满足 [INCIDENCE_TRADE_DIAGNOSIS.md](INCIDENCE_TRADE_DIAGNOSIS.md) 第 3–5 节的结构引理，其证明不要求 d_s 与 p_s 同方向。为明确本分支的覆盖矛盾，简述如下。

令 `H_L,H_R` 为左右基础内部图的邻接矩阵，`M` 为右侧六边匹配。它们在原任务中分别是 C28、C30 和非圈弦匹配。由于 C 的列和在 H 上为 6、在 D 上为 5，目标总度数 8 要求匹配端点恰为 D。跨侧一跳和两跳的计数矩阵为

```
K = H_L C + C H_R + C + C M.
```

每条特殊行的行和为 `12+12+6+1=31`。若覆盖所有 30 个右点，则只允许一次重复路径。因此，若 u、v 是该特殊行 s 的两个左邻点，三个六集 `S_s,S_u,S_v` 的总重复数最多为 1。

如果 u 是普通行：

- 若 v 也是普通行，u、v 都与 S_s 相交，至少贡献两次重复；即使交于同一列，该列的三次计数也贡献两次重复。
- 若 v 是特殊行，S_s 与 S_v 不交，但 u 与它们分别相交，在不同列上至少贡献两次重复。

两种情况均矛盾。所以每个特殊行的左邻点只能是另外两个特殊行，迫使特殊 C3，已经与左 C28 冲突。

即便把左内部图放宽为任意简单 2-factor，这个特殊 C3 也无法完成跨覆盖。三个原 promotion 列 p_s 仍是高列，但交换后都不属于任何特殊六集。取其中一个高列 h。在三条特殊行上，`H_L C+C` 的 h 列为 0；h 不是匹配端点，`C M` 的 h 列也为 0。要分别覆盖三个特殊点与 h 的跨侧点对，h 的两个右基础邻点必须分别命中三个互不相交的 S_s，要求至少三个不同邻点，与右基础度数 2 矛盾。

## 6. 统一结论与边界

每个原特殊六集恰好由完整平行类的五列和一列 promotion 组成。因此，“至少一次删除完整平行类列”和“三次都删除 promotion”穷尽第 1 节允许的全部选择。前者违反左 C28 容量，后者违反跨侧覆盖。任意方向的不同旧低列 d_s 都已包含在结论中；这不是只排除了一个新的坐标实例。

故在第 1 节明确的独立性假设下，**每个特殊行各做一次 2×2 incidence trade，不能把旧仿射前端修成目标 28+30 构造。** 被交换普通行可能改变普通行之间的交集，但不能消除上述两分支障碍。

本文不声称排除了其他交换次数、相互作用的交换或所有自由交叉矩阵，也不提出自动追加试验。
