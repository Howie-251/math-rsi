# 28＋30非均匀固定圈、自由弦及跨边共同编码

左侧0..27诱导为固定C28；右侧28..57含固定C30，全部405条非圈点对
均为自由弦变量，恰选六条且每点弦度至多1。全部840条跨边自由。
左侧跨行和恰6；右侧跨列和加弦度恰6。因此每点全度8、总边232。
没有固定弦端点、配对、长度、跨边循环性、额外排序或旧J＋P归一化。

对任意属于此族的原图，分别沿两个实际圈编号即可得到本模型代表；
反向从满足赋值直接展开同一张图。右侧圈之外的边必须是六边匹配，
这是明确构造限制；模型不覆盖所有58图，也不覆盖任意内部2/3度右图。

`build(a,b,d,q)`参数化固定Ca、Cb、q条右侧匹配弦及目标全度d＋2，
要求 `ad=bd−2q`。每个实际无序点对都检查直接边及全部其他中点。
固定边或两条固定圈边已经覆盖时可省去恒真覆盖；一条固定边与一条
自由边的路径保留该自由位；两条自由边以三子句双向AND表示。
同侧与跨侧统一处理，未仅保留跨侧必要覆盖。

此实现保留通用全部中点，包括匹配约束下不会为真的“两条右弦”路径。
它们不添加额外数学限制，也无需依赖匹配推论去删除路径。与纸面最简
模型相比多375×24＝9000个AND，仍是同一完整图族。

其余116个点对由圈边或两圈边路径固定覆盖。正式prepare会断言总数。
计数器复用通用精确前缀阈值；弦度上界把“至少2”阈值置假。

只导入 `joint_boundary_completion_run/encode.py` 的通用赋值检查和
`load_helpers()`中的CNFEmitter、enforce_exact、unary_thresholds、
add_iff_and；未调用旧模型build，也没有继承旧输入、缺陷限制或排除子句。

小语义的正例取a=4、b=6、d=2、q=2，弦为(0,2)、(1,3)，四条跨行
邻集依次为{0,1}、{3,4}、{2,5}、{4,5}。实际十点图全4度且直径2。
完整赋值核对所有辅助定义、计数器及覆盖，并直接以真实邻接/BFS比较。
另有保持全部度数但产生坏对的跨边交换、删跨边、删弦、违反弦匹配的
小例。每个实际发出的路径位还逐项对照两条真实边，包括圈边＋弦、
弦＋跨边、两条跨边，以及非法匹配赋值中确实出现的两弦路径。
AND另检查8个真值。结果及CPU/墙钟时间保存为 `small_sanity.json`。

`encode.py sanity`只建立这些小模型；`prepare`才建立28＋30正式输入，
用纸面设计中的完整八正则失败赋值逐条检查保存的CNF，该赋值只作检查，
不限制搜索域。`decode`要求明确SAT状态、全变量赋值、逐条满足保存CNF，
再解码弦、跨矩阵、完整边表并独立算全度及全源BFS。输出candidate.json、
candidate.edges；右弦按完整图28..57标签保存。

runner准备限20CPU／30墙钟秒；唯一solver无proof，soft28秒、
hard30CPU／45墙钟秒，默认单核CPU1、4GiB地址空间、每文件256MiB。
SAT后decode及已有独立边表BFS各另限10CPU／15墙钟秒。无自动重启、
换seed或弦模板遍历。UNSAT只标RAW未认证，UNKNOWN不作排除。
