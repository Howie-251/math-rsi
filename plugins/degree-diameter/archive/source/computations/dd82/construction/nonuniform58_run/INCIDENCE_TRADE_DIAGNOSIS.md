这个实例确实修改了普通行的仿射关联，且把三条特殊行的低列数同时从 0 提升到 1。因此它不再满足 [ZERO_SURPLUS_PATH_OBSTRUCTION.md](ZERO_SURPLUS_PATH_OBSTRUCTION.md) 中“三条零余量行、其余行两两相交”的前提。不过，一条新的低余量必要条件仍使它不能使用左侧 C28：任何特殊行都不能接普通左邻点，三条特殊行被迫形成 C3；第5节进一步用未覆盖高列排除这个C3，所以放开两侧二因子也无效。进一步，未被这三个特殊六集覆盖的高列又排除了该 C3；所以即便放宽成任意左右简单 2-factor，这一具体前端仍不能完成所需跨侧覆盖。

## 1. 一个完全指定的 F5 前端

普通左顶点是 25 个点 `(x,y) ∈ F5²`。右侧 30 列是六个平行类中的仿射直线：

- `V_t: x=t`，其中 `t∈F5`；
- `L_{m,t}: y=mx+t`，其中 `m,t∈F5`。

普通行起初采用点线关联，每行 6 个 1，每列 5 个 1。增加三个特殊左顶点 `a,b,c`，其初始六邻域为

```
T_a = {V_t : t∈F5}       ∪ {L_{2,0}},
T_b = {L_{0,t} : t∈F5}   ∪ {L_{3,0}},
T_c = {L_{1,t} : t∈F5}   ∪ {L_{4,0}}.
```

它们两两不交。高列集合 `H` 是这三个六集的并，共 18 列，每列度数 6；低列集合为

```
D = {L_{m,t} : m∈{2,3,4}, t∈{1,2,3,4}},
```

共 12 列，每列度数 5。初始每条特殊行的 `q_s=|T_s∩D|` 为 0。这是 [PROJECTIVE_PLANE_FRONT_OBSTRUCTION.md](PROJECTIVE_PLANE_FRONT_OBSTRUCTION.md) 所讨论前端的一组具体仿射坐标。

## 2. 同时作三次独立的 2×2 交换

以下每行指定一次交换 `(s,x,h,d)`：把 `(s,h),(x,d)` 的 1 删除，在 `(s,d),(x,h)` 加入 1。

| 特殊行 s | 普通行 x | 高列 h | 低列 d |
|---|---|---|---|
| a | `(0,1)` | `L_{2,0}` | `L_{2,1}` |
| b | `(1,4)` | `L_{3,0}` | `L_{3,1}` |
| c | `(2,4)` | `L_{4,0}` | `L_{4,1}` |

表中的普通点分别满足 `1=2·0+1`、`4=3·1+1`、`4=4·2+1`（均在 F5 中）。每对 `h,d` 是不同的平行线，所以各普通行在交换前属于 d 而不属于 h。特殊行在交换前属于 h 而不属于 d，四个格子的初值正是所需的 `1,1,0,0`。三组普通行、特殊行及六列各自不同，三个交换互不覆盖。

交换后所有行和、列和保持不变；H、D 也保持不变。特殊邻域变成

```
S_a = {V_t : t∈F5}       ∪ {L_{2,1}},
S_b = {L_{0,t} : t∈F5}   ∪ {L_{3,1}},
S_c = {L_{1,t} : t∈F5}   ∪ {L_{4,1}}.
```

三个六集仍两两不交，且 `q_a=q_b=q_c=1`。

这不是只更换三个 promotion 参数。普通行也实质改变了：普通点 `u=(0,1)` 与 `v=(1,3)` 原来唯一共同关联列为 `L_{2,1}`。u 删除该列、加入平行列 `L_{2,0}`，而 v 不在 `L_{2,0}` 上，也不是另两条被交换的普通行。因此交换后 `S_u∩S_v=∅`。旧证明中其余 25 行两两相交这一前提确实失效。若最终图直径为 2，这一普通点对必须在左 C28 上相距至多 2；下文的跨侧矛盾已先排除了整个左 C28，无需寻找其具体排布。

另一方面，每条普通行仍与每个特殊六集相交：三次交换没有改变任何普通行在竖直、斜率 0、斜率 1 这三个平行类中的唯一关联。这一保留性质是新的失败原因。

## 3. q=1 时，三个左侧六集最多重复一次

先把左内部图放宽为任意简单 2-factor，右内部图也放宽为任意简单 2-factor 加六条两两不交、且不在该 2-factor 中的边。以 `H_L,H_R` 表示两侧基础 2-factor 的邻接矩阵，`M` 表示右侧新增匹配邻接矩阵。原任务的 C28、C30 是其中的特例。由于完整图要求度数 8，匹配端点恰好是 D；高列 H 上没有匹配端点。

所有跨侧一跳或两跳的条数矩阵为

```
K = H_L C + C H_R + C + C M.
```

这是当前图的直接路径计数，没有引入旧两块等度模型的 `J+P` 归一化。对左行 s，每个交叉邻域大小为 6，左右基础内部度数均为 2，因此

```
sum_j K_sj = 12 + 12 + 6 + q_s = 30 + q_s.
```

若所有跨侧点对都在距离 2 内，则 `K_sj≥1`。当 `q_s=1` 时，30 个右顶点上的重复路径总数只能为 1：

```
sum_j (K_sj-1) = 1.
```

特别地，令 u、v 为 s 的两个左内部邻点，先只计直接跨边和经左邻点的跨路径：

```
B_j = 1_{S_s}(j) + 1_{S_u}(j) + 1_{S_v}(j).
```

因为其余路径只能增加 `K_sj`，上述覆盖条件必然推出

```
sum_j max(B_j-1,0) ≤ 1.                 (∗)
```

这个限制与右基础 2-factor、匹配配对无关；它们不能消除已经重复的路径。

## 4. 此实例每个特殊行都被迫以另外两个特殊行为左邻点

考虑任意特殊行 s，假设它有普通左邻点 u。另一个左邻点 v 只有两种可能。

- **v 也是普通行。** u、v 都与 `S_s` 相交。在 `S_s` 内累加 B 的重复数，至少得到
  `|S_s∩S_u|+|S_s∩S_v|≥2`。即使两次相交发生在同一列，该列也有三条已计路径，仍贡献两次重复。因此违反 (∗)。
- **v 是另一特殊行。** `S_s` 与 `S_v` 不交，但普通行 u 与它们分别相交。两处相交位于不同列，各贡献至少一次重复，所以仍违反 (∗)。

故任一特殊行都不能有普通左邻点。三个特殊行的两个左邻点只能是另外两个特殊行，于是它们形成一个独立的 C3。这与左内部图是一条 C28 矛盾。

这是本实例第一个已经无法共同满足的条件：**在左 C28 上安排三条特殊行，并同时满足它们的跨侧距离 2 覆盖。** 不必再检查普通行的跨覆盖或右侧点对，也不依赖普通行之间仍然相交。

## 5. 特殊 C3 也不能完成跨侧覆盖

即便允许左内部图有 C3 分量，上述被迫产生的特殊三角形仍导致矛盾。三个特殊六集两两不交，每个恰有 5 个高列和 1 个低列，所以它们的并只覆盖 H 的 15 列。剩余三个高列正是 `L_{2,0},L_{3,0},L_{4,0}`；具体取 `h=L_{2,0}`。

对于 `s∈{a,b,c}`，直接项 `C_sh=0`。s 的两个左内部邻点是另外两个特殊点，它们也不连接 h，故 `(H_L C)_sh=0`。又因 h 是高列，它不是新增匹配端点，故 `(C M)_sh=0`。

因此，三条特殊行在列 h 的跨侧覆盖分别要求

```
(C H_R)_ah ≥ 1,
(C H_R)_bh ≥ 1,
(C H_R)_ch ≥ 1.
```

也就是说，h 在右基础 2-factor 中至少各有一个邻点属于 `S_a,S_b,S_c`。这三个集合互不相交，所需邻点必须是三个不同顶点，与 h 的基础内部度数为 2 矛盾。

因此，对这个前端，任意左简单 2-factor、任意右基础简单 2-factor、任意以 D 为端点集的六边匹配，都不能完成跨侧距离 2 覆盖。这个加强结论仍只使用同一组坐标和同三次交换。

## 6. 诊断范围

三次真实 incidence trades 解除旧零余量前提，还确实产生了原先没有的普通行不相交对；这些变化仍不足以救活上述明确实例。所保留的“每个普通行都交每个特殊六集”，结合三个特殊六集两两不交及 `q=1`，已经迫使特殊三角形；三个六集之外的高列又排除了该三角形。这也给出一条准确的结构引理：在本行列度数及内部度数配置下，只要存在三个两两不交、各有 `q=1` 的特殊六集，且其余每行都与每个特殊六集相交，就不可能完成全部跨侧覆盖。引理不要求其余行彼此相交。

因此，这个实例不能同时满足左 C28 和三条低 q 行的跨覆盖。本文没有证明所有一次或三次 trade 都失败：例如从特殊行的完整平行类中移走高列，会改变本文使用的普通行—特殊行普遍相交性质，其结果不在本结论内。当前 nonuniform 28+30 结构仍可继续纸面分析；这里没有提出追加求解或参数搜索。
