# 非相邻双缺陷的完整原图实现

2026-10-19。实现对应本目录 `PLAN.md`。本轮只运行了一次有界 sanity；没有正式准备、求解器调用或证明产物。

`encode.py` 直接表示原 61 点无向图：u=0，v=1，S=2..4，U=5..9，V=10..14，R=15..60。16 条根邻边固定为真；根的其他边、S/U/V 内部和 S–U/S–V 固定为假。25 条 U–V、598 条 (S∪U∪V)–R、1035 条 R–R 全部自由，共 1658 个主变量。端点无三角和选中双缺陷边在端点处孤立是本模型的明确分支前提，未推广到全图。

七个约束组依次为全点度 8、真实共同邻接与覆盖定义、1830 对全部覆盖、所有共同邻数 c≤3、相邻点 c≤1、u/v 与非对方点 c≤2、R 父邻接向量非递增 lex。共同邻数由同一原图的 59 个邻接 AND 项精确计数；全图允许其他三角形、其他双缺陷共端和所有 U–V 边数/三组 W 的交叠模式。只有 R 的 13 位父向量排序，向量相等允许；不比较 R 内部邻接行。

`CNF`、`neg`、`truth` 通过 importlib 仅导入已核 `../joint_six_star_h35_run/encode.py` 的库，不调用旧 main。新 `count_thresholds` 沿用同一完全等价递推，保留共享的 1..4 层；常量偏移及重复/带符号输入按重数计数。新增 lex 定义用逐位相等前缀：此前相等时禁止左 0 右 1。`common_cap_constraint` 同时用于正式约束组和小真值验证。

`check.py` 不导入编码器，独立从实际边表重建集合邻接，整数计算全部共同邻数、分支条件及 lex，并从全部 61 个根做 BFS。SAT 解码先逐条验证保存的 CNF，再输出 `candidate.json` 和实际 `candidate.edges`；检查器逐边核对两份输出，要求 244 边、全度 8、直径不超过 2 和全部模型条件才报告验收。

实际 sanity 通过，11.926561 CPU 秒、11.939843 墙钟秒。限制为 60 CPU / 75 墙钟、1 核、4 GiB、每文件 256 MiB。内存中构造了 504158 变量、1816574 子句，未写 `input.cnf`。验证内容：

- 原门/计数器 1952 个真值赋值；共享阈值 160 个赋值，含常量、重复与互补文字。
- 条件共同邻数限制 128 个赋值，覆盖边存在/不存在、是否受根限额及 c=0..5。
- lex 289 个赋值，含全等、长度 0/1/4 的穷尽，以及完整 13 位每个首差位置的两个方向。
- 五份实际原图赋值：自由边全空、固定种子稀疏/密集赋值、8 正则圈图重标、同图反转 R 名称。每份逐组比较 CNF 与独立整数语义，并逐项核对全部 1830 对的邻接、共同邻数、各阈值及覆盖。
