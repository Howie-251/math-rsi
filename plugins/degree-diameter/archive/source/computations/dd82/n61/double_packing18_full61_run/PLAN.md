## 完整规范化和自由度

35点为A_s、A'_s（s=0..5）、P_i（i=0..4）、R_(s,j)（s=0..5,j=0..2）。固定匹配A_s–A'_s与A_s–R_(s,j)。每个R另自由选择唯一A'父点，每个A'恰接三个R。R–R及P–R边共同自由，P内部无边；每个P度4，每个R在P∪R中的度2。因此H简单四正则，P∪R是5个4度点和18个2度点，H[R]恰8边。核允许环、平行边和不连通；无需预先选一个核。

颜色采用与旧输入不同的合法规范化：沿P横截重标第二色，使f(P_i)=g(P_i)=i。此时只要求交矩阵M逐项≥J，不再额外固定其超额匹配为I。每色大小7保证M−J是2正则二分多重图，含任意两个匹配。A、A'第一重复色由不同普通S类的缺陷匹配得知互异，允许同步重标为0和1。固定f(A_s)=(0,0,1,2,3,4)，f(A')重数为(1,2,1,1,1)，其对应到s的次序自由；g在两中心类的重复色互异但全部位置自由。每个闭H邻域在f/g下都恰含五色。可把同一A_s下三个R按第一色递增标号，这是点名规范化，不是固定邻边或配色。

S六类固定为A、A'、Q、B1、B2、B3，大小6、6、5、6、6、6。P和R在后四类中共同自由。T固定特殊类P，其余为Y1、Y2、Y3、Tq1、Tq2，各6点。ε=0的七边K通过父类重标固定为A-p-A'，q-Tq1、q-Tq2及Bk-Yk三条独立边；不固定缺陷置换或η。

所有S/T类H独立。对z∉P，闭H邻域含五种S色各一次；其唯一缺色若为Bk则T父类必须为Yk，若为q则在Tq1/Tq2中自由。三个Yk由同一H/S决定各6点，缺q集合12点的二分也放在同一个共同输入中选择，不能先固定一份二分再外推失败。P闭邻域在后四S色中各有至少一次，恰一个重复；各P的自身S色不重复；重复端口在q出现两次、各Bk一次。

S/T真实交矩阵Γ满足K边处为0、其余处至少1。结合真实行列大小，Γ−J+K自动是置换矩阵，完整保留η=0/1。可保留这一必要条件帮助共同实现，不将其视为充分目标判定。
