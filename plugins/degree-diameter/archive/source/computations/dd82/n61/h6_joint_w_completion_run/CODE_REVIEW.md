## 1. 前提、重标与全称范围

范围准确限于无三角的两根u、v、两端孤立的所选非邻双缺陷、h=6、两个不同R端口。这里“两根无三角”不要求全图无三角，也不要求其他双缺陷孤立。继承不同端口完美匹配定理及已有端口排除后，当前完整剩余端口范围为不同双W端口。

`H6_SPECIAL_PARENT_EDGE_EXCLUSION.md` 给出QP非边，其证明允许所有端口位置；关键是QP为边时实际父R缺陷的Q行全零，三份S覆盖产生至少两个正重复邻点，根传播又将它们变成Q与a的共同邻点，违反该零行。因此按实际UV分量命名为两份P3及两份K2合法；固定六条UV边没有额外选择父色，端口父点仍允许x=Q、y=P。

对三份实际完美匹配，任意编号W1，沿W1–W2、W1–W3分别传递编号，必可同时得到两份identity匹配。余下W2–W3仍是任意六元排列；编码使用全部36个位置、两侧各恰一邻点，覆盖全部720个排列，包括固定点及任意圈型。此处没有把同时共轭后的代表当成额外自同构，也没有再固定端口的组别、位置或父点。

所有端口父边及C–W边随上述重标一同搬运。随后独立排列C，使其10位U/V父向量非递增；相等向量允许，C内部边和C–W边随C点名搬运。这不影响已固定的W匹配，因此每张所选范围原图都有满足编码的合法命名。没有保留旧R的13位父向量lex，也没有对W父色作排序。

`H6_TWO_W_PARENT_FRONTEND.md` §5所写1342个位置对应第三匹配已经给定时的计数；本模型共同保留第三匹配的36个位置，故为1378，二者不能混用。本目录计划与源码采用正确的1378。

## 2. 固定边、自由边与真实计数

点集为根2、S3、U5、V5、W18、C28，共61点。固定边与自由边不相交；未列入两者的400个位置固定为0。

| 边类 | 固定位置 | 自由位置 | 满足前端及8正则后的真实边数 |
| --- | ---: | ---: | ---: |
| 根–S/U/V | 16 | 0 | 16 |
| S–W | 18 | 0 | 18 |
| U–V | 6 | 0 | 6 |
| U/V–W | 0 | 180 | 2 |
| U/V–C | 0 | 280 | 56 |
| W–W | 12 | 36 | 18 |
| C–W | 0 | 504 | 88 |
| C–C | 0 | 378 | 40 |
| 合计 | 52 | 1378 | 244 |

U–W与V–W分别全局恰一边，W点最多一个U/V父邻点，所以两个端口自动不同；没有固定端口位置或父点。每个C点恰一个U父点、一个V父点。所有61点的度数均直接对全部真实原边计为8，包括固定边，未使用简化残余度数代替原度。

每个W点有一个S邻点和两个W邻点，故其C邻度为5减端口指示；C–W总数为90−2=88。C父边56条，C总度224，因此C内部边为(224−56−88)/2=40。对父点p，其C邻度由原度等式自动给出7−deg_UV(p)−端口父点指示。

每个C点至少邻每个Wi一点，是S–C原对覆盖；W邻度至多5对应τ≤2，来自所引前端的根传播必要式。没有要求每组邻点唯一，也没有消掉τ=2。父表F、B/T各块和父类内部限制无需独立猜测：所有父点、端口、C、W之间的共同邻点均由同一张原图直接计算。

## 3. CNF与独立验收

对全部1830个不同点对，每个共同邻点项均为同一原边数据的 `edge(a,w) AND edge(b,w)`，w遍历其余59点。因此根、S、UV及自由父边贡献全部计入，未漏掉父点贡献，也未复制交叠路线。

复用的布尔门为等价门；计数递推为阈值等价 `sum >= j`，常量用精确偏移，输入重数保留。覆盖为原边或阈值1；全域共同邻数≤3、原边共同邻数≤1及所选两根其他点对共同邻数≤2分别落到阈值4、2、3。最后一项只约束根端，其余点没有附加“所有双缺陷孤立”。全域两项使用已有结论，本复核不重开其历史证明。

旧 `assignment` 只读取传入的新模型和61点边集；旧 `decode` 临时将输出目录换为本目录，只读取本目录保存的CNF与边变量映射，未调用旧main或旧几何构造。解码逐条检查保存的CNF子句后，才输出两种实际边表。

`check.py` 不导入encoder，独立用邻接集合计算度数、全部共同邻数、覆盖和前端；SAT路径另外从每个顶点进行BFS，并核对JSON边表与文本边表一致。只有244边、全8度、简单无向、所有点对距离≤2及所选分支条件全满足才接受。其 `exact_common_and_coverage_definitions=True` 是整数语义中没有辅助变量的占位项；对应CNF门已由语义程序逐项和解码逐子句检查，不能把该占位项单独当成CNF检查。
