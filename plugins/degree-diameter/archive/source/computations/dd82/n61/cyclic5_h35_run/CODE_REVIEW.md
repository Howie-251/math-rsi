# C5-H35 源码独立审查

2026-10-18。结论：**PASS；无阻断问题。** 本审查由区别于实现作者的新代理完成，采用项目 `experiment-bridge` 的源码审查步骤。已读 `AGENTS.md`、`PLAN.md`、`enumerate.cpp`、`check.py`、`run.py` 及 `H35_POINTWISE_GEOMETRY_DIAGNOSIS.md`。本代理未编译、未执行 sanity 或生产，未修改源码。

- **范围与枚举。** 对所声明的自由 C5、分别保持两套分区的作用，7点色类不能被整个 C5 固定，故两套颜色作用均为5轮换。独立重标颜色后可写成 `f=i,g=i+d_r`。交矩阵减去 J 是循环的非负整数矩阵、行和为2，因此其偏移重数只能是一次加2或两次各加1；平移、共同缩放颜色及重标七轨道后得到 `0001234`、`0011234`。按第一色差 +1、+2 取唯一邻点，C5 不变性和反向唯一性分别给出 `p,q∈S7`。源码各生成全部5040个排列，未施加额外连通性或全61对称性条件。
- **签名拼接。** `signature` 的两个第二色差分别来自正向邻点和逆排列确定的反向邻点。零差或重复差必不合格；其余两个差占据一个4位块。七个块共28位，与 `0x0fffffff` 异或恰好要求 q 补齐另两个差。因此拼接对两套局部双射既必要又充分，不遗漏任何合格 p/q。
- **实际 H 与 ρ。** 每个点的四个邻点具有互异第一色差 +1、−1、+2、−2，故展开始终无环、无重边、四正则，共70边。位集合准确求实际一步、两步终点并删除根；合格双五色使图内覆盖与父点覆盖不交，故 `16−终点数+count(d_r)−1` 正是定义中的 ρ。每轨道五点相同，`total += 5*rho[r]` 的归一化正确。
- **停止与报告。** 首个满足逐点≤4且总量≤130的对象立即保存；否则保存字典序最小 `(max_rho,sum_rho)`。只有两个外层类型均遍历结束才输出 `EXHAUSTED_NO_FRONTEND`；软资源终止使用明确的未完成状态。软检查每1024个相容组合进行一次。`run.py` 仅发起一次子进程，设置30 CPU秒、45墙钟秒、4 GiB地址空间及256 MiB单文件上限，并记录退出和实际用时；没有重试逻辑。
- **独立 checker。** 从边表重建35×35邻接矩阵，检查边表与参数展开一致、70边、四正则和两组闭邻域颜色；直接计算完整35行的 `H+H²+UUᵀ+VVᵀ` 重复量，与输出轨道值及总量核对，输出两组颜色和交矩阵。结果模式要求局部双射成立，并核对是否真正通过前端门槛。
