<h2 id="section-2">二 3750点图如何构造以及为什么三步可达</h2>
<h3>顶点数由覆盖结构确定</h3>
<p>采用一个30点、四正则、带端口标记的控制器 C，每个控制器顶点替换为125点纤维 F5³。顶点为 <code>(a,x)</code>，其中 a∈V(C)、x∈F5³，因此阶数为30×5³=3750。</p>
<p>这里的域大小5有具体结构依据：相邻控制器对的三步回退路线提供六个平面，商空间 PG(1,5) 恰有六个方向；非回退三步路线则用三个独立噪声方向覆盖三维纤维。域、维数和控制器的选择共同决定最终点数。</p>
<p>控制器、端口框架及原F4上的1920点构造来自 <a href="https://raw.githubusercontent.com/rmizuno42/ddp/main/results/degree16-diameter3/certificate/PROOF_ja.md">Ryosuke Mizuno 的原始证明</a>。本项目的增量是下面的具体F5矩阵及互补覆盖实例。原作者已有一般 route-chart 框架和其他F5实例，不将“使用F5”或一般仿射提升作为首创。</p>
<h3>全部边的确定性规则</h3>
<p>取四个方向：</p>
<pre><code>ℓ0=(1,0,0)，ℓ1=(0,1,0)，ℓ2=(0,0,1)，ℓ3=(1,1,1)。
反向端口 inv=(1,0,3,2)。

T0 = [[0,2,4], [1,0,0], [0,1,3]]
T1 = [[0,1,0], [4,0,3], [2,0,1]]
T2 = [[2,3,1], [0,4,1], [1,0,1]]
T3 = [[2,1,2], [3,3,4], [3,4,4]]</code></pre>
<p>全部运算在F5中。若 a 的端口 p 指向 b=C[a][p]，连接：</p>
<pre><code>(a,x) — (b, T_p x + t ℓ_inv(p))，t∈F5。
顶点编码：125a+x0+5x1+25x2。</code></pre>
<p>四个目标控制器互异，每个端口给出五个不同目标，所以每点恰有20个邻点。所有端口均满足 <code>T_inv(p)=T_p⁻¹</code> 与 <code>T_p ℓ_p=ℓ_inv(p)</code>，保证反向关系一致；控制器无自环，因此生成简单无向图。沿控制器闭路的矩阵乘积无需等于单位矩阵，此处定义的是边之间的线关系。</p>
<p>完整30行控制器与所有字面参数见 <a href="F5_D20_D3_3750_20261029/PARAMETERS.json">PARAMETERS.json</a>，不依赖未公开的搜索状态。</p>
<h3>非相邻与相同控制器对的三维覆盖</h3>
<p>非回退指相邻两步不立刻沿原边返回。若三步端口依次为 p₁、p、p₃，令 i=inv(p₁)、j=p₃，则非回退条件为 i≠p、j≠inv(p)。去掉最后一步的可逆线性变换后，其噪声像的维数归结为中央端口 p 的三列：</p>
<pre><code>rank [ T_p ℓ_i, ℓ_inv(p), ℓ_j ]。</code></pre>
<p>四个中央端口各有3×3种允许转向，共36种；具体矩阵使它们全部秩为3。因此沿任一这样的控制器路线，三个F5系数可以到达整个125点目标纤维，而非只到达某几个代表点。</p>
<p>30×30个有序控制器对中，780个非相邻或相同端点对均有这种三步路线；它们的整纤维覆盖由上面的满秩条件提供。</p>
<h3>相邻控制器对由六个平面互补覆盖</h3>
<p>剩余120个相邻有序控制器对，使用前两步回退或后两步回退的三步路线。六个可达仿射平面具有公共仿射线；平移后，它们在二维商空间中对应全部六个一维方向。任意两平面交于该公共线，故并集大小为：</p>
<pre><code>6×(25−5)+5=125。</code></pre>
<p>这正好补全相邻对的纤维。两部分路线承担不同控制器对，形成全部点对的三步覆盖。最后，最大度20、直径至多2的 Moore 上界为 <code>1+20+20×19=401&lt;3750</code>，因此实际直径恰为3。</p>
<h3>实际核验与形式化范围</h3>
<p>独立程序仅从完整边表重建邻接，对全部3750个根做距离检验，确认简单、连通、20正则、直径恰3，距离超过3的无序点对数为0。该程序不读生成器矩阵或生产缓存。证据见 <a href="F5_D20_D3_3750_20261029/INDEPENDENT_VALIDATION.json">独立验收结果</a>。</p>
<p>Lean 已证明固定公式图在 Fin 3750 上有3750点、每个顶点度数至多20，且任意两点存在长度至多3的真实图上 walk；另证直径不能至多2。控制器证书与有限域解码证书已在 kernel 检查，最终定理无额外假设，无 sorry、新公理或 native_decide。Lean 结论针对字面公式定义的图，未声称已形式化磁盘文本解析或每点度数恰20。边表与生成器全边集一致另有既存复现证据。</p>

<h2 id="section-3">三 成功机制的迁移对象与严格停止边界</h2>
<h3>33点控制器是可以直接动手的未决对象</h3>
<p>固定11个不交三角形，块b的顶点为 <code>{3b,3b+1,3b+2}</code>，b=0,…,10。另选择不与三角边重合的简单2因子F，构成4正则控制器C。要求对每个不同且不相邻的u,v，都存在长度恰为3的控制器路线；因为端点不相邻，这样的三步路线自动非回退。相同端点由各自三角形给出三步闭路，相邻端点由六平面束处理。</p>
<p>对三角形和F中的每条圈分别定向，赋予互逆端口0/1及2/3，便可使用第二节已经成功的四矩阵、四方向与全部36种转向证书。如果找到这样的C，便得到 <strong>33×125=4125点、20正则、直径恰3</strong> 的完整公式候选，再做实际生成与独立核验。目前没有得到这个C，也没有4125点图。</p>
<p>普通直径3不够：距离2的非邻控制点对若没有三步路线，现有满秩证书不能覆盖其整个纤维。这个更强的路线条件是当前控制器生成器必须解决的对象。它是该迁移方案的充分证书要求，未证明是所有仿射提升成功的必要条件。</p>

<h3>固定图不能靠纯删边降度</h3>
<p>对上述3750点图的37500条边，每条边都有删除后失去三步连接的点对。因此保留顶点与其余边、只做删边，不能把它降到19度或18度并保住直径3。这个结论针对这张固定图；重连、改变矩阵或改变控制器仍可研究。</p>
<p>一个显式见证是原图中 <code>0→2250→3625→625</code> 为对应点对唯一的三步以内路线，删去边0—2250便破坏该点对。完整见证与短路分析见 <a href="EXPERT_HANDOFF_20261029_files/refresh_20261029/f5_d20_edge_criticality_20261029/RESULT.json">关键边结果</a>。</p>
<h3>固定十度规则已被整体排除</h3>
<p>此前两组各100张图的降度试验，曾发现三元系数确实能修好一类闭路平面，却始终留下同纤维反例。后续已完成全部短闭字分析，结论比200个样本强得多。</p>
<p>固定成功图的控制器、四矩阵与方向；每条三角形控制边独立选择一个三元集，每条外部控制边独立选择一个二元集，反向使用负集，选择不随纤维坐标变化。这个域有 <strong>10⁶⁰组字面赋值，全部不能得到直径至多4的3750点10度图</strong>。这是利用小型精确证书的范围排除，没有枚举10⁶⁰张图。</p>
<p>核心原因是不同源坐标的共同覆盖。对控制器根 a，长度0、2、4闭字的位移并集 B_a 与源坐标无关；正反三角闭字的并集为</p>
<pre><code>F_a(h,Z) = (h+Z) ∪ [−H_a⁻¹(h+Z)]，h∈im(H_a−I)。
G_a(Z) = ⋂_h F_a(h,Z)。
同纤维全源覆盖 ⇔ B_a ∪ G_a(Z) = F5³。</code></pre>
<p>在三角噪声坐标中 Z 是三个三元集的笛卡尔积。像空间维数 r≥2 时，任一仿射r维子空间与Z相交至多3ʳ点，而两种三角方向最多服务2·3ʳ个源像值，小于5ʳ，所以 G_a(Z) 为空。其余秩一根用完整有限证书处理。</p>
<p>沿外部五环 <code>0—20—28—22—9—0</code>，每个根的必要覆盖条件都迫使相邻两条外部边取不同的二元差集形状。形状只有 <code>{0,±1}</code>、<code>{0,±2}</code> 两类，奇环无法交替，产生矛盾。见 <a href="EXPERT_HANDOFF_20261029_files/refresh_20261029/f5_d10_closed_route_diagnosis/PROOF_PACKAGE.md">完整命题与推导</a>、<a href="EXPERT_HANDOFF_20261029_files/refresh_20261029/f5_d10_closed_route_diagnosis/CYCLE_RESULT.json">最终有限结果</a>及同目录源码、逐根数据。这项局部定理尚未形式化为Lean。</p>
