2. 构造技巧：把填补点的余度交给hub

真正前提是一个实际有限GQ(s,t)，s,t≥2；有实际line spread S，大小R=st+1，以及实际partial ovoid O，大小p。本稿取p>0；三例均有full ovoid p=R。设δ=(s+1)(t+1)，U为point×line的经典opposite-incidence图，顶点(p,L)与(q,M)在p∈M且q∈L时相邻，删除selfloop。

已接受filled源H保留U，并给每条spread line加一个filler F_j，连接该spread上所有point对应的flags。H有δR²+R点、全δ度、D≤3。选center code C=O×S，共pR个中心；恰p个diagonal是incident flag，真实diagonal由spreadowner决定，不假owner(i)=i。

旧full-H-copy规则在diagonal clone处包含一个filler邻点。新规则让每个clone只连原U的open neighborhood N_U(c)；diagonal少连这一条F边，再新增一个hub连全部R个fillers。每copy相对旧规则删p条diagonal–F边、加R条hub–F边，得到多1点。p=R时边数恰不变；p<R时不能照抄这个等边数结论。

统一k≥1份时，每个center有k个独立clones，另有k个独立hubs。所有H边保留，没有clone–clone、clone–hub或hub–hub边；这些不是任意s,t上的GQ/ovoid存在性声明。

n = δR² + R + k(pR+1)
m = δ(δR²+R)/2 + k(δpR+R−p)
maximum degree = δ+k

不同center的U邻域不交：共同邻点会迫使两个选中ovoid点同线、两个spread线相交，分别迫使center相同。同center的重复copy则刻意共享同一非空邻域，所以它们距离2，旧U负载是k而非1。

由于s,t≥2，以上degree值不冲突；原fillers实际达到δ+k，所以不是只有degree上界。通用推导及全部条件与独立纸面反例攻击分别保存。

3. 为什么删边仍覆盖，以及为什么直径恰3

clone–U和clone–clone只用U内点：替换经典U的≤3路径端点；center相邻时用clone(c)–d–c–clone(d)。同center两copy通过一个共同U邻点两步相通。

diagonal clone到被删去的own filler，改走clone–(o,M)–F_owner(o)，M取经过o、不同于原spreadline的线，长度2。到另一filler的H短路不能先走own filler，因为不同fillers无边、flag-neighborhoods不交、彼此无1／2路线；首步因此仍在U，可交给clone继承。

hub到filler一步，到flag两步；对非flag使用GQ projection找到相邻flag，因此到U或任意clone至多3步。两个hubs通过任何filler两步相通。这些路线内点都已在H/U，不依赖未来clone，所以每prefix成立；不能从删去最后顶点的最终图BFS推断。

最简非D2理由是hub与clone：hub邻居全在F，clone邻居全在U，F∩U为空，二者既无边也无共同邻居；结合D≤3得距离恰3。不声称把hub映回H有collapse homomorphism。83实际hub–clone Walk为350741–342225–5265–342290，已在本次原定hub BFS中得到。

对k2还有一个可复用接口：把k1整图G1作为源，复制其第一copy clones和第一hub这些新role中心的完整邻域，而不是复制演化中的原GQ centers。它恰等于新规则G2，且保留G1全部边；其邻域在原H中冻结且不交。这个识别为83具体Lean提供接口，其实际完成状态逐目标列在第6节。
