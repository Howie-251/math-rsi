# 保边扩张的网络价值：待检验提案

建议节点类型：idea / experiment-proposal，非性能结论。日期：2026-10-29。

## 问题

已有图能在保留旧边时扩张，不等于能接更多服务器或改善吞吐。需要把路由器总端口r、图的网络度数、端点映射、负载和路由分开。

## 最小研究入口

先用三族已有成果的一族进行原图/中间/最终图对照。先算端口账`P=rn−2m`以及扩张净变化，再在一个明确路由与需求模型下诊断瓶颈。没有端口映射不声称有效扩容，没有排队与硬件模型不声称实测延迟。

旧业务保持与新增容量评价分开。新设备成本必须计入；只比较跳数不够。抽样流量可以作诊断，但不能替代严格图直径验收。

## 成果与资源边界

试验可支持收益、推翻收益或仍未决，都有价值，但不算新度数—直径下界。先一次有界诊断，不自动建立第三条主线或大型仿真平台。进一步投入由实证问题与人工意见决定。

## 背景

Slim Fly官方研究组页面、Jellyfish NSDI官方摘要、PolarFly作者摘要提供低直径网络/扩容的研究背景，不替本项目作工业背书。完整试验定义见ENGINEERING_PILOT，关联已有三格成果与实际生成证据。
