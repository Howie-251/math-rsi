## 文件说明

- `registry/cases.json`：候选及基线的可合并数据，不是自动批量作业队列。
- `wiki_import/`：3份 idea/策略草稿，按项目真实 wiki schema/helper 合并，不直接注册为已证 claim。
- `GOAL_UPDATE_MESSAGE.txt`：可直接发给当前研究对话的指令；默认只合并、不擅自恢复已暂停任务。
- `GOAL_LAUNCHER.txt`：当你决定恢复研究时，用于同一个 Goal 的入口文字。
- `upstream/`：小份原文和选定证据副本；没有把103图大数据重新打包。原103图生成器、源边表、完整缓存仍复用原工程/旧ZIP。
