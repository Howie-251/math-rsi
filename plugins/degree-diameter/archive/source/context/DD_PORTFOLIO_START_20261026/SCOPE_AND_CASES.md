# 范围与问题清单

## 1. 定义与任务边界

对象是有限简单无向连通图G；目标只要求最大度≤Δ、直径≤D，不要求正则、Cayley、顶点传递、指定分区或特定缺陷。

设 L(Δ,D;t) 为截至所标日期实际核查到的公开构造下界，M(Δ,D)=1+ΔΣ_{i=0}^{D−1}(Δ−1)^i 为Moore上界。每个任务寻找

    |V(G)| > L(Δ,D;t),  Δ(G) ≤ Δ,  diam(G) ≤ D.

这是开放参数的新下界任务，不是要求确定每个N(Δ,D)的精确值。L+1只是第一条数值门槛；构造阶数可能因代数参数而跳跃，允许任何真正超过基线的合法阶数。不得因为正则生成器受奇偶限制，就把原题也限制成必须正则。

本轮范围：4≤Δ≤12，D∈{3,4,5}。先用下列12个有对象/公式/来源的入口，再按新机制在范围内选择其他15格。不是12格都“容易”，也未证明这12格一定有更大图。分配依据是验证规模、来源多样性和可落地的结构，而不是纪录年龄、Moore缺口或主观成功率。

为什么不直接采用Δ≤16、D≤10：该范围对选题有价值，但包含极大图。首次新Goal先限制到能在用户CPU机上方便生成、检查和比较的范围。12个起始基线最大5334点；这不是原题的点数上限。储备中的大阶数只有在生成机制和验证成本明确时激活。扩大Δ、D需用户指导，不因当前失败自动外扩。

## 5. 首次选择而非机械排序

建议首次比较两类可实际输出完整对象的机制：

- 小底图/多轨道电压覆盖，以(6,3)、(7,4)为直接文献锚点；必要时参照(4,4)。优先让主代理理解如何同时覆盖全部底点对及纤维位移，不只是增加局部边。
- 轨道/陪集或仿射覆盖，以(5,4)、(6,4)、(12,3)为来源；选择其中有原文与实际可运行实现的一个，不同时复建所有有限群工具。

本包的四张Cayley图可立即用于验证器与群乘法回归；它们不要求“默认只搜Cayley”。能说明更好数学依据的其他机制可替代上述建议，说明一次即可，不需用户每次点名。

对每个机制先给参数→(Δ,D,n)的关系，判断在哪一格有超过基线的可能，再投入构造。不强制必须先有完整存在性定理才允许试验；也不能只因基线和Moore界差得远就声称有希望。
