四张Cayley图的群乘法：

    (x,y)*(u,v) = ((x+u) mod m, (y*a^u+v) mod n).

从所列生成元取逆闭包，检查参数合法后展开全部无向边。之后的两个验证程序均只读边表，不利用该群作用跳过根。

C++逐根BFS与Python位集递推是两个独立实现；后者用R_(k+1)(v)=R_k(v)∪⋃_{w~v}R_k(w)计算所有长度≤k可达关系。每一层有序点对累计数与BFS距离直方图累计数逐项一致。

本次部分合并shell调用碰到工具超时；已完成的单项输出另行读取、校验、合并。`baseline_verification.json`的各项是完整结果，不把工具超时伪报为数学结果，也不据此声称总研究墙钟时间。没有后台作业、外部solver、proof日志或哈希层。

## 复算入口（不要求启动研究前机械重跑）

在本包根目录：

```bash
# 编译本包验证器；使用独立输出目录，不覆盖研究文件。
mkdir -p /tmp/ddp-check
c++ -O3 -std=c++17 tools/verify_graph.cpp -o /tmp/ddp-check/verify_graph
/tmp/ddp-check/verify_graph baselines/d6_D3_known.edges 6 3
python tools/verify_bitsets.py baselines/d6_D3_known.edges 6 3

# 四张公开Cayley基线从公式重新生成；输出目录必须为空/未含同名文件。
python tools/reproduce_known_cayley.py --out /tmp/ddp-known-regenerated
```

边表格式统一：第一行`n m`，随后m行无向边`u v`，0≤u,v<n，每条边恰一次。不得用自动去重来悄悄修复非法候选；两个检查器都会检查基本输入条件。Python检查范围之外的直径不返回伪精确值，而是返回null及失败状态。

本包不包含编译后二进制、工具链、缓存、凭据或外部作者代码。三个短源码仅服务本次基线复现与验证，不是另一套搜索平台。
