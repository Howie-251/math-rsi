## 可迁移的东西

1. 简单无向表示、生成器、实际逐点度数和全源BFS/精确可达验证；按新D改验收，不能继续写死两步。
2. 用失败点对识别真实瓶颈，让它改变下一次生成；不只事后写反例报告。
3. 完整对象优先；群、提升、关联不是禁词，但“模型更自由”不等于得到新生成规则。
4. 区分找对象与取证，避免proof日志达到上限而杀掉发现任务。
5. 旧RAW、已检查证书、纸面推导、跨模型审阅和Lean分别记账。
6. 每小时汇报不是每小时换题；新Goal允许暂停一个不适配参数，不要求先证明它的整个构造族不可能。
