# 反例引导研究：先检验关键推断，再决定往哪里证明

**节点类型：** research idea / 方法提案，不是已证明 claim。  
**当前实例：** 最大度数 8、直径 2，重点 n61 的完整谱算术路线。  
**建议归档：** `research-wiki/ideas/dd82-counterexample-guided-research.md`。实际项目已有同主题节点时合并，不分叉维护。  
**状态：** 方法与候选任务已整理；本文件未启动新搜索、未产生新反例、未改变现有 Goal。  
**依据：** 已有研究稿、上一轮谱测试报告，以及用户关于避免长尾、加强人工指导和未来建立题目列表的意见。来源见文末。

> **核心问题不是“AI 能否随便造一个反例”，而是：我们准备继续花时间证明的那一步，究竟是真的，还是从现有前提根本推不出来？**
>
> 反例搜索用于检验承重推断、暴露缺失条件和选择下一步。反驳“61点目标图不存在”仍然需要完整目标图，不会因改名为“找反例”就变容易。

## 1. 为什么增加这条路线

此前研究积累了很多局部必要条件，随后容易形成“再推一条约束—再细分—再求解”的循环。新的谱路线也可能重复这一问题：行列式、谱区间、不可约因子、整数重数都可以不断增加，但尚不清楚它们是否足以排除真实目标图。

本节点增加一个互补方向：在证明方提出关键推断时，让反例任务主动寻找满足全部所列前提、但违反结论的对象。反例若成立，直接指出推断错误或前提不够；若搜索没有命中，只记录未决定，不把它当作对推断的证明。

这不是重新开启无限的构造模板搜索，也不要求每个小引理都先被攻击。优先选择会决定研究方向、是否继续分类、是否投入较长计算的关键推断。

**不预设 AI 找反例一定比证明更强。** “构造少数成功实例”不能证明对任意指定问题都有稳定求解能力。这条路线首先是一种研究方法，需要用实际返回对象判断效果，而不是用专家评价或其他题目的成功率背书。

## 2. 必须先说清楚：反驳的是哪句话

设一项待检验主张为

\[
\forall z\in\mathcal D,\qquad H(z)\Longrightarrow L(z).
\]

反例必须给出同一对象域中的一个明确对象 \(z\)，并分别检查 \(H(z)\) 成立、\(L(z)\) 不成立。每个任务都要写清对象域 \(\mathcal D\)、前提 \(H\) 和结论 \(L\)，不能只写“找反例”。

| 所攻击的主张 | 合格见证 | 允许得出的结论 |
|---|---|---|
| 不存在合法61点原图 | 完整61点图，最大度数≤8，全部点对距离≤2 | 解决61点存在性，得到下界突破；不自动确定整个 N(8,2) |
| 任意合法原图都满足性质 L | 一张满足原题和全部附加前提、却违反 L 的完整图 | 反驳对应原图引理 |
| 仅凭当前列出的局部或谱条件 H 就能推出 L | 满足 H 且违反 L 的矩阵、块系统或谱数据，属于该主张明确的对象域 | 反驳 H⇒L；不自动反驳有更多前提的原图命题 |
| 某一生成规则保证完整覆盖 | 一个按该规则生成、却出现坏点对的实例 | 反驳该规则的保证；不说明该族所有实例都失败 |
| 某个“条件通过就能补全”的断言 | 一个条件确实通过、且有严格证据证明无法补全的对象 | 反驳该充分性断言；仅有补全超时还不够 |

**同一个对象，对不同主张可能有不同地位。** 一个不可能来自原图的 B，可以反驳“这些 B 条件已经足够”，却不能反驳“所有真实原图满足某性质”。

### 2.1 放松模型的正确逻辑

若已证明每个原图对象都映入一个放松域 \(\mathcal R\)，并保持需要讨论的性质，那么在 \(\mathcal R\) 中找 \(H\land\neg L\)：

- 找到对象：说明放松域里的 H 不足以推出 L；必须继续检查它是否有真实原图来源。
- 完整证明这个反例输入不可满足：结合正确的映射与覆盖，可以证明原图中的对应引理。
- 超时、UNKNOWN、数值未收敛或搜索未命中：没有决定该蕴含。

若只是限定循环、对称性或固定种子，则实际搜索的是 \(\mathcal R\) 的一个子族。子族没有反例，不能升级为整个放松域没有反例。

## 3. 当前 n61 的统一对象定义

原图用邻接矩阵 A 表示：

\[
A=A^{\mathsf T}\in\{0,1\}^{61\times61},\quad
A_{ii}=0,\quad A\mathbf1=8\mathbf1,
\]
\[
(A+A^2)_{ij}\ge1\qquad(i\ne j).
\]

这里八正则性是 n61 原题的已有后果，不是擅自缩小对象域：若某点度数≤7，最大度数8下其两步范围至多 \(1+7+7\cdot7=57\) 点，不能覆盖61点。

定义

\[
B=A^2+A-7I-J,\qquad X=2A+I.
\]

对合法 n61 原图，有

\[
B=B^{\mathsf T},\quad B_{ii}=0,\quad B\ge0,\quad
B\mathbf1=4\mathbf1,\quad AB=BA,
\]
\[
X^2=29I+4B+4J,\qquad X\mathbf1=17\mathbf1.
\]

项目的缺陷连通性、条目上界等更强结论，应按现有证明及证据等级调用；它们不是仅由上述定义自动推出。若调用“权重2的边只能构成匹配”等依赖旧 RAW 的结果，必须显式标出依赖，不能写成已认证的无条件前提。

### 3.1 谱必要条件

当前 n61 的平方行列式条件是

\[
\boxed{\frac{\det(29I+4B)}{45}
=\left(\frac{\det(2A+I)}{17}\right)^2\in\mathbb Z_{\ge0}.}
\]

**分母是45，不是旧 n59 的53。** 这是一般公式在 n61 的实例化，不登记为本节点的新发现。[S1，§2；S2，§7.2]

令

\[
q_B(t)=\frac{\chi_B(t)}{t-4},\qquad
r_A(x)=\frac{\chi_A(x)}{x-8}.
\]

删去的是全一向量上的一份主特征值。n61 中有

\[
\boxed{q_B(x^2+x-7)=r_A(x)r_A(-1-x).}
\]

r_A 是60次首一整系数多项式，其根 \(\lambda_1,\ldots,\lambda_{60}\) 必须满足

\[
\sum_i\lambda_i=-8,\qquad \sum_i\lambda_i^2=424.
\]

这两个数分别来自 \(\operatorname{tr}A=0\) 与 \(\operatorname{tr}A^2=61\cdot8\)，扣去主特征值8的贡献。检查时可等价使用

\[
r_A(x)=x^{60}+8x^{59}-180x^{58}+\cdots.
\]

最后一式只是前两项迹条件的牛顿恒等式表达，不是额外的新约束。完整谱还必须全实，并满足实际使用的合法谱范围。[S1，§2]

**自动恒等式警告：** 若先给任意八正则 A，再由它计算 B，上面的矩阵平方和多项式关系本来就成立，即使 A 的直径大于2；此时 B 可能有负项。因此不能把它们重新作为同一 A 的评分，声称获得了新筛选。反例与谱实现检查的主要价值在于独立提出的 B、谱数据及尚未落实的真实图条件。[S1，§6]

## 4. 已有回归例：行列式过关，但完整谱不可能

**来源与状态：** 上一轮 `spectral_route_review/README.md` §4 记载了下面的精确测试；本节点继承报告，不声称本轮重新运行、独立认证或发现了它。[S1]

取顶点为 \(\mathbb Z_{61}\) 的候选缺陷图 B，边为

\[
i\sim i\pm1,\ i\pm2\pmod{61}.
\]

它是连通的简单四正则图。报告记载：

- \(\chi_B(t)=(t-4)f(t)^2\)，其中 f 为30次首一整系数多项式。
- \(\det(29I+4B)/45\) 是完全平方数，行列式检查放行。
- \(g(x)=f(x^2+x-7)\) 在模7下不可约，因而在有理数域不可约。
- 范数分解因而强迫 \(r_A=g\)；g 的次高项系数为30，要求非主特征值和为−30，与原图要求的−8矛盾。

这个对象的正确用途是：

> 反驳“连通四正则 B 加平方行列式条件，就足以对应目标 A”的充分性判断；作为检验器回归例，要求基础行列式层放行、完整因子与迹层拒绝。

它没有反驳行列式必要条件，也没有构造目标图，更没有排除全部简单四正则 B。是否已被项目中别的定理排除，应沿用实际记录，不因新检查方法再次登记为新增范围。

报告还保存了明确的多项式数据、模7不可约检查和一个已知合法图的正对照。需要复算时先取这些原件，不从本摘要猜系数、编造证书或重新设计同一测试。若移植正对照，必须使用其实际阶数和对应符号，不能沿用 n61 常数。

## 5. 下一阶段可执行的反例任务

以下都是**建议任务，尚未在本节点执行**。优先挑选与当前承重推断直接相连的一项，不把三项同时变成长期队列。

### CE-S1：攻击“这整套谱条件已经足以产生矛盾”

先由主代理写出当前实际打算使用的有限条件清单 \(H_{\rm spec}\)。例如包含：B 是61阶对称非负整数矩阵、零对角、行和4；所采用的条目界与连通性；平方行列式；存在满足完整复合因子关系、实根条件及迹要求的60次首一整数多项式 r。

**攻击目标：** 构造一个明确的 \((B,r)\) 同时满足这套条件。

它挑战的是“仅这些条件已经无解”，而不是直接挑战“原图不存在”。不能临时删掉难满足的条件，得到对象后仍报告完成原反例任务。

若先只找抽象多项式数据 \((q,r)\)，必须把它另记为“形式谱层”的任务。该对象即使满足全部已列谱等式，也没有证明存在真实 B；不能把它冒充 \((B,r)\) 见证。

**有用反馈：**

- 若真实 B 与 r 全部通过，就停止尝试仅从同一套条件推出不存在；研究还缺哪项原图条件。
- 若只有形式谱数据通过，说明这些已列代数条件本身允许解；下一义务是 B 的矩阵实现，而不是宣称图论条件已全部兼容。
- 若某一候选失败，找出失败是通用的因子／重数障碍，还是该候选特有性质。只否定一张 B，不算全域推进。
- 若完整条件域确实被严格证明无解，再连接原图到该域的归约；有限样本未命中不能代替它。

不得把这项任务默认实现为枚举全部61点四正则 B。先给出候选来源、精确检查方法和范围；循环或对称族只用于探索，不能暗示代表所有 B。

### CE-S2：攻击准备投入的下一条“必要结构”猜想

证明方若认为“某类谱因子必须出现”“某种重数一定为偶数”“全部缺陷只能按某结构安排”，先将这句话写成完整命题，再让反例任务攻击。

输入需包括完整前提、已证明依赖和准确对象域；必要时区分“任意满足这些代数条件的矩阵”与“真实目标图导出的矩阵”。不要攻击一条已经完整证明、当前也没有具体疑点的命题来凑流程。

若结论属于真实原图命题，而构造出的对象只满足放松条件，则记录为“所用前提不足的见证”，不是原图反例。它应帮助定位：究竟哪条真实图条件在当前推导中尚未使用。

若发现具体反例，应提取其可解释的结构原因，并修改或撤回受影响推断。新增排除条件必须另证对全部目标成立；不能为了赶走眼前样本，任意加入自同构、简单谱、循环或固定端口假设。

### CE-S3：对通过谱检查的 B，尝试恢复真实 A

这是一个有明确输入的原图构造任务，不是无起点地另试一张图。

对通过 CE-S1 的 B，可尝试求解

\[
X=X^{\mathsf T},\quad X_{ii}=1,\quad
X_{ij}\in\{0,2\}\ (i\ne j),\quad X\mathbf1=17\mathbf1,
\]
\[
X^2=29I+4B+4J,\qquad A=(X-I)/2.
\]

若 B 非负且这些式子精确成立，所得 A 具备原题的代数条件；最终仍直接读取显式边表，独立检查所有1830个无序点对的距离与所有顶点度数。

B 有简单谱时，可利用交换关系限制 A 在各特征方向上的选择；有重特征值时，必须保留整个对应特征空间内的矩阵自由度。不能用每个特征值一个正负号冒充全部实现。

- 恢复出合格 A：它才是“61点不存在”猜测的真正反例，应立即按完整原图验收。
- 严格证明这份 B 无法恢复 A：排除的是这份 B 及有证明覆盖的类；可用于识别谱条件遗漏的实现障碍。
- 恢复求解超时或 UNKNOWN：不能说 B 不可实现，也不能说已经找到“谱充分性”的反例。

## 6. 执行闭环：提案、攻击、独立核验、改变下一步

### 6.1 先写最小任务说明

每项任务只需写清：待攻击的原句；对象域与完整前提；预期见证的层次；已有相关失败与回归例；实际计算预算和检查入口。不新增庞大的评分或任务卡平台。

主代理必须确认这项猜想真是当前推导需要的关键一步，而不是专门挑一条容易打破的错误命题来制造反例成果。

### 6.2 搜索器可以不完美，验收必须完整

允许 LLM 提出解析对象、专用生成器、SAT／SMT／整数约束及有方向的启发式。选择依据是对象结构和返回物，不预设必须新建神经网络系统。

先短时 profile，再按已有授权给出有界资源。不要把此前网页工具的短时限当作开发机固定上限，也不要把未命中当作自动加时的理由。新的对象、算法或预算可以有理由地继续，不强制“一族只试一个”。

**防循环：** 反例输入不得预装待证明结论 L，或仅依赖 L 推出的后果；若某约束已有不依赖 L 的独立证明，可以按该证明使用。保存实际前提清单，防止搜索目标被悄悄改掉。

### 6.3 按对象层次核验

| 对象层次 | 最少需要核验的内容 |
|---|---|
| 形式谱数据 | 阶数、整数系数、精确因式恒等式、实根／区间要求、重数、迹及实际声明的全部矩条件 |
| 真实 B | 显式完整矩阵、对称性、对角、条目、行和、要求的支撑性质；由该矩阵重新计算实际谱多项式并检查对应 r |
| 完整原图 A | 简单无向、61点、每点八度、完整1830对距离；由同一 A 重算 B 并检查所攻击性质 |
| 某对象“不能提升”的证明 | 输入对象绑定、全部合法补全的覆盖、实际矛盾或可独立检查的完整证据；不得以一次求解失败代替 |

谱的严格结论使用精确整数、代数数或具有证明依据的区间／模素数检查。浮点近似的特征值、数值秩和很小的残差只作线索，不能承担反例验收。

独立检查直接读取保存对象，不复用搜索器可能出错的缓存；外部模型认可不替代该检查。记录“主代理检查”“独立程序检查”“外审”“Lean”各自实际状态，不把一个状态扩成全部完成。

### 6.4 每个结果必须改变一项明确的研究判断

| 返回结果 | 下一步 |
|---|---|
| 满足全部前提的真实反例 | 撤回或缩小对应猜想，标出依赖它的下游；研究反例为何成立 |
| 放松层见证但未提升 | 停止从同一组弱前提硬推矛盾，寻找有证明的缺失条件或研究提升 |
| 覆盖完整对象域的已认证无反例结果 | 将其与原图归约连接，形成对应引理；保留证据依赖 |
| 仅指定子族无反例 | 只关闭或记录该子族，不推广 |
| UNKNOWN／未命中／中断 | 记未决定；比较继续投入与改变推断，不能计为支持猜想的证明 |
| 对象不满足前提或验证器错误 | 修正生成、表示或验收；不登记为数学反例 |

如果结果只是不停排掉随机 B，没有形成通用障碍、有效提升办法或对关键猜想的真实修正，就应明确说明这条试验尚未产生路线优势。

## 7. 与三个“收尾方式”的连接

**全图算账：** 攻击正在使用的总数不等式或迹关系。若反例通过，只说明该放松允许这种账本；必须定位未用的真实图条件。不能把一组可行整数总数当成可实现图。

**局部传播到全局形状：** 主动寻找满足局部规则、却不形成预期周期或分块的对象。这样的对象能精确显示传播论证缺了哪一步；只有对象同时满足原图前提时，才反驳原图定理。

**理论压缩后的有限判定：** 用已知正例、已知反例和专门构造的边界对象测试编码与剪枝。反例检查能发现漏项，但若要证明不存在，仍需独立证明候选保全和分类穷尽；若干测试通过不能替代完备性。

三者都不要求每小时换一次路线。反例任务应服务当前选定的收尾机制，而不是增加一条无法结束的并行支线。
