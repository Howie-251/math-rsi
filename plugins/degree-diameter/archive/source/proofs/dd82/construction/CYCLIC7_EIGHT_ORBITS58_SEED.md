# 58 点的 C7 固定层与一个完整失败种子

2026-10-12。实际取得了 HS50 的一个自同构，循环型为 1^1 7^7，
并由它展开一张具有 1^2 7^8 自同构的 58 点、232 边八正则图。
独立全源 BFS 得到直径 3 和 105 个坏对；这不是目标图。
该种子保留整个诱导 HS50，属于已经关闭的扩展族，本次没有优化或搜索这个族。
它提供了下一步可以释放全部旧核心结构的完整 C7 坐标输入。

## 1. 任意 58 点目标的固定层

设 Γ 为 58 点、最大度数八、直径至多二的简单无向图，g 为阶七自同构。
每点度数必须为八，否则其半径二球至多有 1+8·7=57 个点。
对于邻接矩阵 A，令

\[
B=A^2+A-7I-J_{58}.
\]

B 对角为零、非负，行和为七。设固定点集为 F，大小 f，固定诱导图为 H。
由于 g 的循环只有长度一和七，有 f≡2 (mod 7)，所以 F 非空。
每个固定点的八个邻居组成固定点和七轨道的并，故其 H 度数为一或八。
连通性与 g 非平凡保证固定层和非固定层之间有边；某个固定点 u 因而是 H 的叶。

若两个不相邻固定点没有固定共同邻点，则其共同邻点构成非固定七轨道的并。
共同邻点数 μ 满足 1≤μ≤8，故 μ=7，相应 B 项为六。
B 行和七迫使每个固定点至多有一个这种例外伙伴。
其余固定点对在 H 内距离至多二。

设 u 的唯一固定邻居为 a。H 中 u 的半径二球有 1+deg_H(a)≤9 个点，
另至多一个例外点，故 f≤10。因此

\[
f\in\{2,9\}.
\]

当 f=2 时，两固定点 c,v 必相邻。每个分别完整连接一个非固定七轨道 S,T。
若 S=T，则 c,v 有七个共同邻点，故 B_cv=7；对每个 s∈S，边 cs 又有共同邻点 v，
故 B_cs≥1。c 的 B 行和至少十四，矛盾。因此 S≠T。

而且 S,T 必须都是独立集。设 S 的内部度数为 r_S，它是偶数，因为七循环不变
简单图的邻接位移成正负对。对每个 x∈S，c 与 x 的共同邻点恰为 x 在 S 内的邻点：
c 的其余邻点只有 v，而 v 连接的是不同轨道 T。因此 B_cx=r_S。
七个 x 的总贡献为 7r_S≤7，结合 r_S 偶数得到 r_S=0；T 同理。

另可确定 f=9 时 H=K1,8。若没有八度点，九点皆一度违反度数和奇偶性；
若至少两个八度点，则所有其余点固定度至少二，因而也为八，得到 K9 固定连通分量，
违反 Γ 的连通性。所以恰有一个八度中心。

记该中心为 h。它的八个邻点全是固定叶，所以直径二要求剩余四十九个非固定点
各邻接某个固定叶。七个非固定七轨道中的每一个因此至少与一片固定叶完整相连。
每片固定叶已有 h 这一个邻点，其余七个邻点恰为一个非固定轨道。
八片叶分配给七个非空轨道，必有一个轨道分配两片叶，其余六个轨道各分配一片叶。
这两片叶不相邻，且其八个邻点完全相同：h 和共同的七轨道；它们是 false twins。

本引理只限制自同构表示，不排除 58 点目标，也不把 f=2 分支冒充全部阶七作用。

## 2. 实际 HS 自同构与种子展开

唯一运行的 [源程序](../../../computations/dd82/construction/cyclic7_eight_orbits58_seed.py)
读取已有 hs58_edge_k26_structure_run/hs50.edges（50 点、175 边）。
选择 c=0，把它染成独立颜色，把七个邻居分别染成七种颜色；
第二份同图将这些七种颜色沿排序邻居的七循环移位。
NetworkX GraphMatcher 的首次完整同构即满足这些指定像。
它实际已经为阶七，不需要取非平凡幂；没有假设任意局部邻居置换必可延拓。
对该置换逐一核验全部 175 条旧边的像恰为原边集。

其七个非固定轨道依照实际自同构依次排列为

| 轨道 | 原 HS 顶点，按作用顺序 |
| --- | --- |
| 0 | 1,4,5,12,25,37,45 |
| 1 | 2,43,7,13,46,14,48 |
| 2 | 3,42,30,27,49,40,6 |
| 3 | 8,41,20,35,47,44,9 |
| 4 | 10,19,23,36,26,18,33 |
| 5 | 11,16,32,31,29,24,38 |
| 6 | 15,34,22,17,28,39,21 |

新增七轨道 T=(50,51,52,53,54,55,56) 和固定点 v=57。
对七个旧轨道中的每一个，将其第 t 点连接到 T 的第 t 点；
再添加 cv 和 v 到 T 的全部七条边。
总边数为 175+49+1+7=232。每个旧非固定点增加一条边，c 增加 cv，
T 中每点连接七个旧轨道及 v，v 连接 c 和 T，因此所有 58 点均为八度。
所得循环型为 1^2 7^8，并逐一验证全部 232 条边的像保持边集。

导出坐标为：固定点 c,v 编号 0,1；第 a 个七轨道的第 t 点编号 2+7a+t，
其中 a=7 是新增轨道。原标号、双向重标号和实际置换均保存在
[coordinates.json](../../../computations/dd82/construction/cyclic7_eight_orbits58_seed_run/coordinates.json)。

## 3. 可释放旧核心的完整轨道表示

对固定点 0,1 及八个自由七轨道，所有简单无向不变边集合由以下 237 个互不相交边轨道组成：

- 一个固定点之间的单边轨道；
- 十六个固定点—七轨道接口，每个包含七条边；
- 每个七轨道内部位移 1,2,3 的三个轨道，共二十四个；
- 任意不同七轨道之间位移 0,…,6 的七个匹配，共 28·7=196 个。

它们恰分割全部 58·57/2 个无序点对；完整展开表保存在
[palette.json](../../../computations/dd82/construction/cyclic7_eight_orbits58_seed_run/palette.json)。
当前种子选中三十四个边轨道，其中一个含一条边，其余三十三个各含七条边。
[parameters.json](../../../computations/dd82/construction/cyclic7_eight_orbits58_seed_run/parameters.json)
保存八乘八位移集合、内部度数、固定点接口及所有选中轨道编号。
从这些轨道独立重建的边集合与完整种子逐边相等。

由第一节，对任何 f=2 目标可将 S,T 分别重标为轨道 0,7，固定选择 cv、c—S、v—T，
其余固定点接口全部不选。剩余真正可变部分是二百二十个七边轨道中的三十一个，
且须满足八个轨道的剩余度数为 (7,8,8,8,8,8,8,7)。其中 S,T 内部的六个轨道
由第一节必须禁用，所以也可把可选择域写为剩余二百一十四个轨道。
该参数化允许原 HS 核心内部及跨轨道结构全部改变；本次没有搜索这一释放后的域。
这些规范与独立性约束只覆盖 f=2 分支；f=9 的星形固定层和 false twins 不能据此省略。
