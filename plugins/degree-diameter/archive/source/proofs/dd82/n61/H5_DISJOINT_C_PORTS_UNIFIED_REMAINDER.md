# h=5四个不同C端口：统一重复支撑与剩余矩阵障碍

2026-10-19，连续本地纸面推导。沿用 [两份W重复排除](H5_DISJOINT_C_PORTS_TWO_W_REPEATS.md) 的精确范围：所选非邻双缺陷根u、v无三角且该双缺陷在两端孤立，h=5，X、Y各两点、互不相交且全部在C。其他双缺陷不假定孤立。不固定父色、匹配排列、交集或对称性；没有新计算、外审或Lean。本稿没有排除剩余的整个h=5范围。

记P=X∪Y，W为三个不交六点集W_i之并，C=R\W，δ_i=Δ[s_i,R]，τ=Σ_iδ_i，k=τ(W)。各δ_i总量2，总τ为6。写D={r:τ(r)=1}、D_W=D∩W、D_C=D∩C。以下所有矩阵和邻点均来自同一原61点图。

## 1. 端口自身不能承载重复，剩余4/6完整

逐点根传播为

$$\tau(r)+\Delta(U,r)=d_X(r),\qquad
\tau(r)+\Delta(V,r)=d_Y(r). \tag{1}$$

层度与三份闭邻覆盖给

$$\begin{array}{c|cc}
 &d_W&d_C\\\hline
r\in W&2+\tau(r)&5-\tau(r)\\
r\in C&3+\tau(r)&3-\mathbf1_P(r)-\tau(r).
\end{array} \tag{2}$$

普通C点若τ≥2，由(1)须邻四个不同端口，但(2)给C度至多1；W点若τ≥2也须邻四端口，其C度至多3。端口自身的同侧邻点最多一个，先有τ≤1；若端口τ=1，(1)又要求它邻一个同侧端口和一个异侧端口，而其C度仅1。故

$$\boxed{\tau\in\{0,1\}\text{ 在R逐点成立},\qquad \tau(P)=0.} \tag{3}$$

所以D恰有六点。每个c∈D_C的C度为2，且必须恰接一X、一Y；其对U、V的缺陷全为零。

任意U父点x的C父类C_x有六点。UV为五条匹配，完整父行计数给

$$\Delta(x,R)=2-|N(x)\cap P|,\qquad
\Delta(x,W_i)=\delta_i(C_x).$$

第二式直接由\(e(C_x,W_i)=6+\delta_i(C_x)\)减去六个必须覆盖的点对得到。求和并用(3)，得到精确预算

$$\boxed{\Delta(U,C)=\Delta(V,C)=4-\tau(C)=k-2.} \tag{4}$$

因此k≥2。又由(2)，

$$k=2|E(H[W])|-36$$

是偶数，且k≤6。结合已经完成的k=2排除，**当前范围剩余恰为k=4或6**，没有遗漏奇数或k=0。

## 2. 六个重复点之间的真实边只能是匹配

完整S缺陷行是另外两个S单位加δ_i。在(s_i,w)、w∈W处交换AΔ=ΔA，给

$$\boxed{\Delta(W_i,w)=1-\mathbf1_{W_i}(w)+\delta_i(N_H(w)).} \tag{5}$$

对i求和，再将(1)代入w的完整缺陷行和4，得到

$$\boxed{\Delta(C,w)=2+\tau(w)-d_P(w)-d_D(w).} \tag{6}$$

若w∈D_W，(1)要求至少一X、一Y邻点，因此

$$\Delta(C,w)+d_D(w)+d_P(w)=3,\quad
d_D(w)\le1,\quad d_P(w)\in\{2,3\}. \tag{7}$$

接三个端口时，w没有实际重复邻点，且Δ(C,w)=0。若w有一个实际重复邻点，则它恰接一X、一Y，仍有Δ(C,w)=0。

后一种情形中，真实重复边的两端不能共有端口：否则该端口—w原边处于三角形，违反Δ(C,w)=0。因此两端各自的一X一Y端口对恰互补。D_C点的两个C邻点都是非重复端口，所以D_C内部没有边；结合d_D(w)≤1，H[D]起初只能是以D_C为中心的星、D_W之间的匹配及孤点。

事实上星中心也不能有两个叶。设c∈D_C同时邻p、q∈D_W。它们的端口对都与c互补，故p、q共有两个端口及c，真实Δ_pq=2。若p、q属于同一W_i，它们还共有s_i，超过全域三个共同邻点上限。因此p∈W_i、q∈W_j，i≠j。

由(7)，p、q各自唯一的实际重复邻点都是c。将(5)分别用于(p,W_j)、(q,W_i)，得到

$$2\le\Delta(W_j,p)=1+\delta_j(c),\qquad
2\le\Delta(W_i,q)=1+\delta_i(c).$$

这迫δ_i(c)=δ_j(c)=1，与τ(c)=1矛盾。于是

$$\boxed{H[D]\text{ 是匹配加孤点；每条边的端口对互补。}} \tag{8}$$

这是对所有允许父色与真实无向边的统一必要结构，不是先选一种匹配。它也避免把三点路径的叶换根继续拆成新位置分类。它尚不说明六个重复点的其余邻接和缺陷能够完成。

## 3. 精确块预算与k=6的核空间关系

由(2)、(3)、(6)对W求和：四端口到W共12条边，六重复点到W共\(3k+4(6-k)=24-k\)条边，所以

$$\boxed{\Delta(C,W)=2k.} \tag{9}$$

取F=H[C]、K=H[W]的邻接矩阵，B=A[C,W]，E=Δ[C,W]。因为C不邻S，U/V父点也不邻W，完整原图恒等式在该块上为

$$\boxed{(F+I)B+BK=J+E.} \tag{10}$$

不能把E删掉：其总量在k=4、6时分别为8、12。若某整数v满足Fv=−2v+r，令f=B^Tv、s=Σv，则精确转移为

$$\boxed{(K-I)f=s\mathbf1+E^Tv-B^Tr.} \tag{11}$$

因此只有右侧确为零时，才能继承上一稿的整数1特征向量论证。

k=6时D_C为空。每端口的三条W邻边都必须落在D_W：完整S行在端口z处求和给

$$3+\Delta(W,z)=d_D(z)\le d_W(z)=3.$$

故Δ(P,W)=0，每端口三个W邻点全重复；总共12条边迫六个D_W点各恰接一X、一Y。取C上的\(v=\mathbf1_X-\mathbf1_Y\)，便有

$$B^Tv=0,\qquad E^Tv=0,\qquad \sum v=0.$$

由(10)还得到

$$\boxed{B^TFv=0.} \tag{12}$$

这里还有实际不交分割的等价解释。每端口z有三个D_W邻点和两个C邻点；\(\Delta(z,W)=0\)给

$$ (K+I)\mathbf1_{N_W(z)}+B^T\mathbf1_{N_C(z)}=\mathbf1_W.$$

左侧五个非负0/1列分别为三个大小4的D点闭邻域及两个大小3的C点W邻域，故它们两两不交，恰分割18点W。共享端口的D点在H[W]中距离至少3；普通W点若邻两个D点，它们的端口对必互补。这是真实共同实现规则，没有指定两套匹配。对X、Y作符号求差，分割给出的正是(12)，不能因此额外推出下一步不变性。

这给出一个确实的连续核空间关系，而不是宣称整个ker(B^T)已经在F下不变。设t=Fv，因\(F\mathbf1=3\mathbf1-\mathbf1_P\)，有Σt=0；再应用(10)，准确的下一障碍是

$$\boxed{B^TF^2v=E^TFv.} \tag{13}$$

右侧尚未被逐点传播、父预算或(8)证明为零。更精确地，(6)给E在已匹配D_W点处的列和为0，孤立D_W点处为1，普通W点处为\(2-d_D(w)\)；总量仍为12。现有关系尚允许真实缺陷误差经其余C/W点传播，没有迫出一个有限正缺陷分量。也没有理由从(12)推出E^TFv=0、完整核空间不变或一个非零整数1特征向量。k=4同样没有被强迫出的封闭C四圈及零误差接口，不能直接套用上一稿。

## 本轮止点

新增的统一结构是端口零重复、精确父预算、六重复点诱导匹配，以及完整的带误差矩阵关系。**本轮没有关闭k=4或k=6。** 真正未闭的是：同一F、K、B及实际缺陷E，能否同时满足三份闭邻覆盖、所有父点覆盖、(8)和(10)，并保持真实缺陷正支撑连通。k=6核空间入口具体卡在(13)的\(E^TFv\)，不是缺少一个人为指定的配色或匹配排列。这里停止统一延伸，不自动进入颜色交集、端口子型或新求解。

## 4. k=6四分割的手工弱见证与完整缺陷预算

本节是后续有界纸面检查，未改前述范围或结论。每个端口z的三个D邻点闭邻域各有四点，与其两个C邻点的三点W邻集，必须精确划分18点W。共享端口的D点在K中距离至少3；普通W点至多邻两个D，若有两个则其端口对互补。这些集合分割须与(5)同时实现。

确有一个手工规则能同时实现四分割及三份Wi闭邻计数：取六个互不相交的三色三角T_iε，i=1,2,3、ε=0,1，其中颜色i的点为d_iε；再加三边d_i0—d_i1。于是δ_i恰支持d_i0、d_i1。前两对D分别接端口对(X0,Y0)/(X1,Y1)，第三对接(X0,Y1)/(X1,Y0)。每个端口在每对D中选一个，其三个D闭邻域覆盖全部六个D和六个普通点；剩下三个未选三角的六个普通点按颜色i+1/i−1分成两套三色横截，交给该端口的两个不同C邻点。四份分割因此同时准确成立。完整规则与未补边界见 [手工分割诊断](H5_SIX_W_REPEATS_PARTITION_COMPATIBILITY.md)。

但这个弱见证已经不能扩展为原图。取p=d_10、q=d_20，它们共享X0、Y0，故Δ_pq≥1；p所在三角中颜色2的普通邻点与p的边又有一个共同邻点，给第二个W2缺陷单位。于是Δ(W2,p)≥2。p唯一D邻点d_11只承载δ1，故(5)却准确给Δ(W2,p)=1。后续增边不能修复此冲突。因而不能把已排好的四分割称为完整k=6局部对象。

这一检查可写成不依赖端口排列的统一预算。对p∈D∩Wi，令T(p)为与p共享同一X、Y端口对的其他D点，t_W(p)为p所在的W内三角形数。由(5)，
\[
\Delta(W,p)=2+d_D(p),\qquad d_D(p)\in\{0,1\}.
\]
同端口对伙伴不邻p，且各贡献至少1个缺陷；它们也不在Wi，因为每个端口在每个Wi中恰有一个邻点。W内每个三角在p行贡献2。若唯一D邻点也在Wi，其原边已有S父点作共同邻点，故再贡献1，而且这条边不能同时属于W三角。故这些互不重复的贡献必须一起满足
\[
\boxed{
2t_W(p)+|T(p)|
+\mathbf1_{\{N_D(p)\cap W_i\ne\varnothing\}}
\le 2+d_D(p).} \tag{14}
\]
这是同一真实缺陷行的联合预算，不是把几种局部条件分别拼接；它本身尚未排除全部k=6配边。

**本轮有限检查止点：未得满足全部已知条件的k=6共同对象，也未闭合k=6。** 四分割的弱规则被完整S行否决后，不再固定另一个W圈重试，不按端口对或颜色继续细分。剩余问题仍是同一F、K、B能否同时实现这些真实预算、全部父类覆盖及带误差块方程。

## 5. k=6双父类消元：误差由孤立重复点驱动

本节继续同一k=6整体范围，不按匹配边数或父色分类。将UV的五条匹配识别为同一标号，设

$$L=A[U,C],\quad M=A[V,C],\quad
D_U=\Delta[U,C],\quad D_V=\Delta[V,C].$$

真实父边覆盖及AΔ=ΔA给

$$LB=MB=J,$$
$$L(F+I)+M=J+D_U,\qquad M(F+I)+L=J+D_V,$$
$$\boxed{LE=D_UB,\qquad ME=D_VB.} \tag{15}$$

两缺陷矩阵各总量4。U父点x的行和为\(2-|N(x)\cap P|\)，V对称；列和分别为d_X(c)、d_Y(c)。因此D_U、D_V的非零列分别恰在N_F(X)、N_F(Y)。若某父点行和为零，(15)的非负性迫其整个真实C父类的E行全为零。

另一方面，完整S行在C处给

$$E(c,W)=d_D(c)-3\mathbf1_P(c). \tag{16}$$

所以E的非零行恰是普通C中邻接D的点。上述零父行结论把它们限制在两套未饱和父类的共同位置；它不是一个已经能独立完成全部父类的生成规则。

令I_D为H[D]中的孤立点集，q=|I_D|，仍写\(v=\mathbf1_X-\mathbf1_Y\)、\(t=Fv\)。对p∈D，(6)给

$$E(C,p)=1-d_D(p).$$

将(15)左乘全1行，得到更强的逐点式

$$d_X(N_C(p))=d_Y(N_C(p))=1-d_D(p). \tag{17}$$

若p已匹配，它的全部C邻点都避开N_F(P)。因此E非零行中t_c≠0的点只能邻孤立D；它也不可能接两个X端口或两个Y端口，否则其任何D邻点均会与某端口组成被禁止的三角形。故这些行上t_c∈{−1,0,1}。

设e_X=e(F[X])、e_Y=e(F[Y])、e_{XY}=e(F[X,Y])，e_P=e_X+e_Y+e_{XY}。对(17)在D上求和，再扣除每端口恰三个D邻点的贡献，得到准确非负乘积总量

$$\boxed{\begin{aligned}
\mathbf1^TD_UE\mathbf1&=q-3(2e_X+e_{XY}),\\
\mathbf1^TD_VE\mathbf1&=q-3(2e_Y+e_{XY}).
\end{aligned}} \tag{18}$$

于是前节未控制的误差满足

$$\boxed{\|E^TFv\|_1\le 2q-6e_P.} \tag{19}$$

其正、负部分分别至多为(18)第一、第二行右侧。这是由同一真实支撑得到的界，不把q的取值另列成新的研究分支。

### 匹配覆盖全部D时，多一步归零而非无限不变

若q=0，(18)与非负性同时迫端口间没有边，并有完整矩阵等式

$$\boxed{D_UE=D_VE=0.} \tag{20}$$

令R=L−M，父覆盖差给RF=D_U−D_V，所以RFE=0。由\(\mathbf1^TR=v^T\)，得到\(E^TFv=0\)，从而前节(13)加强为\(B^TF^2v=0\)。这一步确实补上了所述情形的第一次误差；仍没有证明完整核空间不变。

下一次转移准确留下

$$\boxed{B^TF^3v=E^TF^2v
=\bigl(D_UFE-D_VFE\bigr)^T\mathbf1.} \tag{21}$$

这里ΣF²v=0由端口间无边及\(F\mathbf1=3\mathbf1-\mathbf1_P\)得到。现有零乘积没有使D_UFE、D_VFE逐项归零，也未证明它们相等。

缺陷连通方向也有同一个有限深度边界。记Q=Δ[C,C]，其完整真实表达为

$$Q=F^2+F+BB^T+L^TL+M^TM-7I-J.$$

由(20)有\(\Delta^2[U,W]=\Delta^2[V,W]=0\)，但下一步精确是

$$\boxed{\Delta^3[U,W]=D_UQE,\qquad
\Delta^3[V,W]=D_VQE.} \tag{22}$$

尚未证明这两个非负矩阵为零。父缺陷目标N_F(P)与E行支持虽然不交，Q仍可能连接两者；例如两个点若处在同一个非对角U/V父格，它们的两个共同父点本来就贡献正缺陷，不能因集合不交而删去该贡献。这里并未声称已构造满足全部条件的这种接口。

**本次止点：** 得到真实零行传播、孤立重复点控制的误差界，以及q=0时一次严格可用的额外归零；没有由它们关闭k=6。继续宣称F核空间不变或缺陷分量隔离，分别还缺(21)与(22)的控制。本轮在这两个具体未闭乘积处停止，不自动细分q、端口边或颜色排列，也不启动新计算。
