# 非相邻双缺陷：五点覆盖与其余Wi的真实交叉边

本稿只处理至少一组Wi为五点的范围。根代理本轮旧源对齐回报：非相邻双缺陷的端点在三角形上的情形已落入旧t1_01直接排除或t1_02/03完整baseline RAW覆盖，不需O15/noO前提。本稿未重审这些旧记录，也不提高RAW证据等级；以下新纸面关系仅解释该旧范围，不作为新求解入口。

## 1. 一组五点类迫三组Wi全部独立且不交

不失一般性，设 $|W_1|=5$，且 $s_1$ 接唯一 $x\in U$，记 $X=N_R(x)$、$|X|=6$，$L=H+I$。源稿已证

$$L\mathbf1_{W_1}=\mathbf1_R-\mathbf1_X,$$

且W₁各点H度7、没有U/V邻点。

三角形 $u,s_1,x$ 已用完u在uv双缺陷之外的两个单位，所以 $\alpha(R)=0$。由 $d_U(r)=1+\alpha_r-k_r\ge0$，R内所有 $k_r\le1$，三组Wi因此两两不交；任一Wi点又满足 $d_U=0$。特别地

$$X\cap(W_1\cup W_2\cup W_3)=\varnothing. \tag{1}$$

对任一六点类Wj，记 $\delta_j(r)=\Delta_{s_jr}$，有
$L\mathbf1_{W_j}=\mathbf1_R+\delta_j$、$\sum_R\delta_j\le2$。利用同一L的对称性，

$$5+\delta_j(W_1)
=\mathbf1_{W_1}^{\mathsf T}L\mathbf1_{W_j}
=\mathbf1_{W_j}^{\mathsf T}L\mathbf1_{W_1}
=6-|W_j\cap X|=6.$$

故 $\delta_j(W_1)=1$。逐点使用两个覆盖式得到

$$\boxed{H[W_1,W_j]\text{有六条边：Wj侧每点度1，W₁侧度为 }(2,1,1,1,1).} \tag{2}$$

唯一二度点就是 $\delta_j$ 在W₁上的真实单位端点，没有另选重复矩阵。

而 $\delta_j(W_j)=2e_H(W_j)$；已有一个单位在不交的W₁，剩余总量至多1，故 $e_H(W_j)=0$。五点类本来就是packing，所以只要出现一组五点类，**三组Wi全部独立且两两不交**。这并不禁止不同组之间形成三角形。

## 2. 六点遗漏集X也有精确近覆盖式

x的邻点恰为u、s₁及X。对任意 $r\in R$ 直接计算实际共同邻点，得到

$$\boxed{L\mathbf1_X=\mathbf1_R-\mathbf1_{W_1}+\Delta[x,R].} \tag{3}$$

X各点因邻接U点x而不邻接S，故其H度为 $6-\beta_r$。对(3)求和，

$$42-\beta(X)=41+\Delta[x,R]\mathbf1,\qquad
\boxed{\Delta[x,R]\mathbf1+\beta(X)=1.} \tag{4}$$

在X上，(3)给 $\Delta[x,X]\mathbf1=2e_H(X)$。它不超过1，因此X独立。这里β位置仍取自原图；没有把它改成可独立选择的误差项。

## 3. 两组五点类的完整交叉接口

若还有五点W₂，其唯一外邻点必在V，记为y，$Y=N_R(y)$。于是u、v各自的三角形耗尽残余行，$\alpha(R)=\beta(R)=0$。第三组W₃为六点，三组大小是5、5、6；记余集

$$C_0=R\setminus(W_1\cup W_2\cup W_3),\qquad |C_0|=30.$$

X、Y都在C₀中。由各自packing式及(2)，可准确读出：

- W₁–W₂为五条完美匹配边；
- W₃的每点各接一个W₁点、一个W₂点；每个五点侧分别有唯一二度点；
- W₃独立且每点H度7，故每点接C₀五次；每个C₀点恰接一个W₃点。

最后一项的逐点结论使用：W₃的缺陷总量恰为2，并已在W₁、W₂各占一个单位，故在C₀没有剩余缺陷。

两个遗漏集还必须恰交一点。由(3)与W₂的packing式互反，

$$5+\Delta_x(W_2)=6-|X\cap Y|.$$

x、y不相邻，其全部共同邻点恰在 $X\cap Y$；原图直径2要求 $|X\cap Y|\ge1$。上式与非负性合起来给

$$\boxed{|X\cap Y|=1,\qquad \Delta_x(W_2)=\Delta_y(W_1)=0.} \tag{5}$$

再以X与W₃互反得 $\Delta_x(W_3)=\delta_3(X)=0$，对Y同理。式(4)在此给x、y各恰一个R缺陷单位，它们都位于C₀中，而不在三组Wi中。
