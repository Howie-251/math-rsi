# h=6不同双W端口：真实父表的共同生成前端

2026-10-19，本地纸面归约；没有生成候选表、统计表数或运行求解。范围为无三角、两端孤立的非邻双缺陷根u、v，h=6，两个不同R端口a、b均在W。使用已证三组六点集独立、不交且两两完美匹配；不假定其他双缺陷孤立，不固定a、b同组或异组，不预选父色和圈长。本稿的父表只是必要前端，**不是一张完整61点图**。

## 1. 固定UV骨架合法；父表的精确边际

记X={a,P}、Y={b,Q}，Q∈U、P∈V为各自唯一UV度2点。a唯一U父点为x，b唯一V父点为y。

先在整个双W范围排除QP为原边。若QP为边，完整父R预算给Δ(Q,R)=Δ(P,R)=0，因此C_Q∩C_P为空（其中一点会与QP成三角）。直接对W计数又有

$$\Delta(Q,W)=\tau(C_Q)-3+A_{Qy},$$

故τ(C_Q)≥2。C_Q的正重复点须邻a；若其中某点τ=2，逐点根传播又迫它邻P，违反交集为空。所以至少两个不同C_Q点邻a。无论a是否邻Q，都与Δ(Q,a)=0矛盾。于是QP非边。

因此可以合法标记

$$U=(Q,l_1,l_2,i_1,i_2),\qquad
V=(P,m_1,m_2,j_1,j_2),$$

使UV邻接矩阵E的六条边恰为

$$Qm_1,Qm_2,\quad l_1P,l_2P,\quad i_1j_1,i_2j_2.$$

这给两个P3和两个K2；只是按实际分量重标，没有要求图存在自同构。暂不删去x=Q、y=P，也不预定端口组别。

C有28点，每点恰有一个U父点和一个V父点。设

$$C_{ij}=\{c\in C:c\sim U_i,V_j\},\quad m_{ij}=|C_{ij}|,\quad
F=\Delta[U,V].$$

U_i、V_j的共同邻点恰为C_{ij}，因此

$$\boxed{F=m-J+E,\qquad m=J-E+F.} \tag{1}$$

完整度数及实际缺陷限额准确等价于下列父表条件：

$$\boxed{\begin{aligned}
F&\in\mathbb Z_{\ge0}^{5\times5},\\
F\mathbf1&=2\mathbf1-e_x,\qquad
F^T\mathbf1=2\mathbf1-e_y,\\
F_{ij}&\le1\quad(E_{ij}=1),\qquad
F_{ij}\le2\quad(E_{ij}=0).
\end{aligned}} \tag{2}$$

所以ΣF=9、Σm=28，且

$$\sum_jm_{ij}=7-\deg_E(U_i)-\mathbf1_{i=x},\qquad
\sum_im_{ij}=7-\deg_E(V_j)-\mathbf1_{j=y}. \tag{3}$$

E边上的格大小为0或1；非E边上的格大小为1、2或3。

## 2. 一个共同参数结构，而不是逐表另起分支

把F视作U、V两侧十个父点上的二部多重图。只有x、y度1，其他八点度2。因此它**恰为一条从x到y的交替奇长路径，加若干顶点不交的偶圈**。所有十个父点恰使用一次；长度2的圈表示一对平行边，依(2)只能位于E非边。反过来，任意这样的路径与圈联合给出(2)的全部边际；再筛选E边重数上限，即得到全部允许F。

可用同一个数据对象记录：

```
port_parent_u: x
port_parent_v: y
defect_path: [U_x, V_*, U_*, ..., V_y]
defect_cycles: [偶长交替顶点环, ...]  # 允许两点双边环
cells[i,j]: [(i,j,1), ..., (i,j,m[i,j])]
```

这不选择一种路径长度、圈型或配色。由(1)产生实际28个C顶点后，定义固定0/1父矩阵L、M：L_{i,c}=1当且仅当c∈C_{ij}，M_{j,c}=1当且仅当c∈C_{ij}。于是每列各有一个1，且LM^T=m。格内编号只是可交换点名，不限制真实边。

还应接入完整父R预算。U内部缺陷恰为l_1l_2一条单位边；V内部恰为m_1m_2。根、S父项及F边际相抵后，

$$\boxed{r_U(i):=\Delta(U_i,R)=2-\mathbf1_{i=Q}-\mathbf1_{i\in\{l_1,l_2\}},} \tag{4}$$

V侧对称为\(r_V(j)=2-\mathbf1_{j=P}-\mathbf1_{j\in\{m_1,m_2\}}\)。两侧总量各7。

若E_{ij}=F_{ij}=1，唯一C_{ij}点与U_i、V_j构成真实三角，在两父点的R行各耗一个单位。因此父表还必须满足

$$\boxed{\sum_{j:E_{ij}=1}F_{ij}\le r_U(i),\qquad
\sum_{i:E_{ij}=1}F_{ij}\le r_V(j).} \tag{5}$$

特别是Q的两条UV边、P的两条UV边分别不能同时有三角。这是预算筛选，不把某条边先指定为有或无三角。

生成表还不能决定C内部边。必要限制包括：每个父格C_{ij}独立（否则一条原边已有两个共同父点）；Q、l_1、l_2的整个C父类独立，V侧P、m_1、m_2同理，因为父类内一条边在对应父R行耗两单位，而这些行的预算仅1。另两个U父类、另两个V父类内部各至多一条边；若有，它耗尽该父点全部R预算。它们也必须由同一C图实现，不能独立选边。

## 3. 父表之后必须共同选择的真实边

给W三个六点组，令Z为3×18的组指示矩阵。根负责的W部分仍是同一张三部二正则图K：三对组间各一份完美匹配。选不同点a、b∈W，任意同组或异组；固定父边矩阵

$$A_U=e_xe_a^T,\qquad A_V=e_ye_b^T.$$

真正待共同构造的量是

$$B=A[C,W]\in\{0,1\}^{28\times18},\qquad
T=A[C,C]=T^T\in\{0,1\}^{28\times28},\quad\operatorname{diag}T=0.$$

令\(D=ZB^T-J_{3,28}\)、\(\tau=D^T\mathbf1\)。精确覆盖、度数及现有根预算要求

$$\boxed{\begin{aligned}
D&\ge0,\qquad 0\le\tau\le2,\\
D\mathbf1&=2\mathbf1-Z(e_a+e_b),\qquad \sum\tau=4,\\
B^T\mathbf1&=5\mathbf1-e_a-e_b,\\
T\mathbf1&=3\mathbf1-\tau.
\end{aligned}} \tag{6}$$

这些式子保留δ_i集中两单位、不同δ_i在一点重合，以及所有合法端口位置。行和关系不会单独证明B、T存在。

四块完整父覆盖必须使用同一B、T、K：

$$\boxed{\begin{aligned}
D_{UC}&=L(T+I)+EM+A_UB^T-J,\\
D_{VC}&=M(T+I)+E^TL+A_VB^T-J,\\
D_{UW}&=LB+EA_V+A_U(K+I)-J,\\
D_{VW}&=MB+E^TA_U+A_V(K+I)-J.
\end{aligned}} \tag{7}$$

它们是实际Δ块，不是自由附加矩阵。全部应非负，每项至多2，原边位置至多1，并满足

$$D_{UC}\mathbf1+D_{UW}\mathbf1=r_U,\qquad
D_{VC}\mathbf1+D_{VW}\mathbf1=r_V. \tag{8}$$

两根传播还可直接读为

$$\tau+D_{UC}^T\mathbf1=B e_a+M^Te_P,\qquad
\tau+D_{VC}^T\mathbf1=B e_b+L^Te_Q. \tag{9}$$

特别地D_{UW}在a列全零、D_{VW}在b列全零；a不能接自己的U父类C_x，b不能接自己的V父类C_y。没有把这些零列扩大成所有父缺陷都零。

## 4. 前端与完整61点验收之间的准确边界

余下三块也是同一边赋值的真实共同邻接，而非独立松弛量：

$$\begin{aligned}
D_{CW}&=(T+I)B+BK+L^TA_U+M^TA_V-J,\\
D_{CC}&=T^2+T+BB^T+L^TL+M^TM-7I-J,\\
D_{WW}&=K^2+K+B^TB+Z^TZ+A_U^TA_U+A_V^TA_V-7I-J.
\end{aligned} \tag{10}$$

对非对角项要求非负、至多2，实际原边项至多1。CC、WW的对角由八正则度数自动为零。其余原图块由固定根、S、E、父表及端口直接确定：例如S–C块为D，S–W块为零，U–S块为\(e_x(Ze_a)^T\)，V–S对称。

因此可以从一份合法路径/圈父表开始，共同构造K、a、b、B、T，再用(6)–(10)及固定块检查完整实际缺陷。若全部实际块满足覆盖，即可还原并直接验证61点八正则直径二图；反过来当前范围中每张真实目标图都会给出这样的数据。**仅有(1)–(5)的一张父表，或只有(6)的度数/覆盖，并不代表其后共同边方程可解。**

本稿完成的是一个不固定配色的真实父点前端及其完整补全接口。没有宣称已有通过补全的对象，没有逐表开启证明分支，也没有据这些必要式启动求解。下一实质工作是让同一B、T同时满足两套父覆盖与所有原图点对；这与独立填好父格容量有明确区别。

## 5. 任意W匹配的完整正规化及共同计算入口

可给W1任意编号，再沿W1–W2、W1–W3的两份真实完美匹配传递编号。因此所有W边都可写成

$$(1,k)(2,k),\qquad (1,k)(3,k),\qquad (2,k)(3,\sigma(k)),\qquad k=1,\ldots,6.$$

这里σ允许任意六元排列。同一编号置换π同时作用三组，将σ变成πσπ⁻¹；故以6的11个整数分拆为圈型代表，完整覆盖所有未标记W骨架。σ的一个m圈对应W中的一个3m圈。这只是重标定理，不要求图存在相应对称性，不是关闭了11个数学分支。

重标必须同时搬运端口a、b、全部父边、C–W边和C内部边。不能再默认a=(1,1)、b=(2,1)，不能独立按父色排序每组W；选择σ代表后只剩与之交换的置换可继续用。C的父格编号可以独立排序。特别是旧完整61编码中R的13位父邻接lex约束不能原封不动保留在这里的W上，否则会删去真实对象。

这允许一份共同生成规则保留所有σ、不同端口位置和父表，再共同选择B、T；无需为11种圈型各启动一轮预算。精确边数由分层给出：根边16，S–W18，UV6，端口父边2，C父边56，W内部18，C–W88，C内部40，合计244，即61×8/2。B的504个位置与T的378个上三角位置仍须由同一实际图实现全部点对覆盖。

与旧1658个自由原边位置相比，固定S–W、正规化W及UV后为1342个待定原边位置；若端口及其父点在生成时已给定，则为1162（C父边280、B504、T378）。这些只是原边变量的位置数，不是新CNF变量或子句统计，也不表示原百万级共同邻点约束会自动消失。本稿未生成正式输入、未运行新求解；旧UNKNOWN不变。

## 6. 三组共同Gram预算：精确列容量及其止点

本节仍保留所有端口位置和父色，纯纸面推导，未新增计算或外审。令

$$p=e_a+e_b,\qquad \epsilon_x=\mathbf1_{x=Q},\quad
\epsilon_y=\mathbf1_{y=P},\quad\epsilon=\epsilon_x+\epsilon_y.$$

三份匹配给 \(KZ^T=J-Z^T\)，同一B给 \(BZ^T=J+D^T\)。将(10)的WW块右乘Zᵀ，使用 \(ZZ^T=6I\) 和
\(A_U^TA_U+A_V^TA_V=\operatorname{diag}p\)，准确得到

$$\boxed{D_{WW}Z^T=(I-\operatorname{diag}p)(J-Z^T)+B^TD^T.} \tag{11}$$

所以对每个w以及全部三组求和分别为

$$\begin{aligned}
\Delta(W_i,w)&=(1-p_w)(1-\mathbf1_{w\in W_i})
                  +\delta_i(N_C(w)),\\
D_{WW}\mathbf1&=2(\mathbf1-p)+B^T\tau.
\end{aligned}$$

端口所在组的真实根/父项已在此相抵，不能再额外扣一次。另一方面，对(7)的两块父W矩阵求列和，直接得到

$$\boxed{\begin{aligned}
D_{UW}^T\mathbf1&=Ke_a+\epsilon_y e_b,\\
D_{VW}^T\mathbf1&=Ke_b+\epsilon_x e_a,\\
t:=\Delta(U\cup V,W)^T\mathbf1&=Kp+\epsilon_xe_a+\epsilon_ye_b.
\end{aligned}} \tag{12}$$

因此父W缺陷总量是 \(4+\epsilon\)，不是14；14是两个完整父R块的总量。由W每点缺陷行和4、根W块为p、S–W块为零，得到同一真实C–W块的逐列容量

$$\boxed{D_{CW}^T\mathbf1
=2\mathbf1+p-Kp-\epsilon_xe_a-\epsilon_ye_b-B^T\tau\ \ge0.} \tag{13}$$

这同时约束三个Wi中的实际邻点，不能把三份覆盖分别实现后忽略它。但求和不会自动消除不正规覆盖。设 \(n_2=|\{c:\tau(c)=2\}|\)，则
\(\sum\tau^2=4+2n_2\)。由(9)、(11)–(13)及完整C行预算可得

$$\begin{aligned}
\sum D_{UC}&=5-\epsilon_y,&\sum D_{VC}&=5-\epsilon_x,\\
\sum D_{WW}&=48+2n_2,&\sum D_{CW}&=18-\epsilon-2n_2,\\
\sum D_{CC}&=80+2\epsilon+2n_2.
\end{aligned} \tag{14}$$

这里方块矩阵的和按有序行列项计算，CW矩形块只算一次。它们恰满足
\(\sum D_{WW}+2\sum D_{CW}+\sum D_{CC}=164\)，就是46个R点总缺陷184减去根、S、U/V边界的 \(2+4+14\)；继续相加只是原行预算重排。尤其 \(0\le n_2\le2\)、\(0\le\epsilon\le2\) 下仍有 \(\sum D_{CW}\ge12\)，没有把不正规覆盖的总代价迫成零。这不证明局部例能够共同补全，只说明上述总量尚未跨过共同实现难点。

式(13)有一个可直接用于共同生成的点级后果。若某w同时邻a、b，则w不是端口，t(w)=2，于是
\(D_{CW}(:,w)=0\) 且 \((B^T\tau)_w=0\)。它在K中的两个邻点恰为a、b，故(10)进一步成为

$$\boxed{(T+I)B_w+B_a+B_b=\mathbf1.} \tag{15}$$

因此 \(N_C(w),N_C(a),N_C(b)\) 三集两两不交，大小分别5、4、4。第一集的五点均τ=0、T度3，且其五个T闭邻域恰分割
\(C\setminus(N_C(a)\cup N_C(b))\) 的20点。这是同一真实B、T必须满足的近packing义务；并不保证这样的w存在，不据此另开端口位置分支，也不算完整排除。

本次整体推导的实际边界是：三组Gram关系给出了准确列容量和饱和后的真实配边要求；现有总预算未迫使每份覆盖都可删重复而正规化。完整K、B、T及真实父类的共同对象仍未构造，亦未被本节统一排除。

一次有限父投影检查也停在这里：结合(7)、(10)消去T后，仍保留 \(D_{UC}B\)、\(D_{UW}K\) 等真实非负项；例如对 \(i\ne x,\ w\notin\{a,b\}\)，只能推出
\(\Delta(C_i,w)\le(D_{UC}B)_{iw}+(D_{UW}K)_{iw}\)，不能无依据把右端清零。L/M投影本身还会丢失点级配边：\(i_1,i_2\) 与 \(P,m_1\) 的四个父格均非空，选对角两点或反对角两点所得非负总量2向量具有完全相同的L/M投影。这不是完整图的相容反例，也不证明投影系统可解；本检查未取得三份覆盖可正规化的结论，仅记录弱投影的准确止点，不作为新排除或新分支。
