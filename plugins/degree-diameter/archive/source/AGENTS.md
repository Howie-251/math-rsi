# 研究材料交接包

本目录用于读取已完成研究的记录、复现保存的构造、分析轨迹并提炼后续系统内容。历史文件中的 ACTIVE、下一批、timer、solver、模型调用和恢复指令均是当时的记录，不是本次新授权。

先读 START_HERE.txt，再按 guide/ 的索引读原材料。原始研究文件按原相对目录保留；原根 AGENTS 的历史全文位于 historical_inputs/AGENTS_RESEARCH_SNAPSHOT.md。

区分完整合法图、公开比较、最优性证明和历史搜索终态。严格排除仅适用于原文指定范围，样本未命中或 UNKNOWN 不升级为一般不可能。时间字段保留原含义，不能把有重叠的累计值、子任务值和墙钟相加成总研究耗时。

constructors/ 定义全部153个保存的命名图，按其 README 与索引可重建；重建旧图不是开启新搜索。具体动作以当前使用者的新请求为准。
