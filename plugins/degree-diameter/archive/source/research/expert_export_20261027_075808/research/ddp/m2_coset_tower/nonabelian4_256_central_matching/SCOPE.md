# 中心完美匹配替换：结构与固定 L4 范围

本任务终态：一次检查全部 22 个指定删除选择。固定已保存 L4 的 D32 电压时，22 个商图都存在三步覆盖缺口，四根缺口和为 9 至 59。因此该固定投影下的这 22 个改动及任意合法中心位都不能达到 D3。未枚举中心位、未生成实际 Q64 图、未运行 BFS。一般变体未被本次排除。

## 1. 完整构造与计度

令 G=Q64，c=(16,0)，c²=e 且 c 位于中心。原四轨道以 64i+g 标号，跨轨道匹配为 (i,g)—(j,gh_e)。原 K4 匹配重数按 01,02,03,12,13,23 为 [3,3,2,2,3,3]，共有 16 条无向基边。

分别从一组对边的两个类各删一条匹配：01/23 有 3×3=9 种，02/13 有 3×3=9 种，03/12 有 2×2=4 种，共 22 种。每个轨道恰失去一条跨轨道邻接。随后每轨道加入 (i,g)—(i,gc)。这是一个无不动点对合给出的完美匹配：每点贡献度 1，每轨道只有 32 条无向边。它应在底图实现为一个反向即自身的单 dart，不能当成贡献度 2 的普通 loop。

删边后跨边共有 14×64=896 条，四个内部匹配共有 4×32=128 条，总计 1024 条，仍为 256 点、度 8。只需保留每对轨道之间实际群电压互异，内部匹配与跨边不会重合。对每个 a∈G，(i,g)→(i,ag) 保持所有边，所以左 G 作用仍有四个正则轨道；四根缺失数之和乘以 32 即全部坏无序点对。

一般新底图有 14 条独立跨边；规范一棵三边生成树后为 11 个自由跨边电压，四个内部 c 均固定。不要机械保留原底图的 13 个有效自由电压。如果删掉原规范树边，需另选剩余生成树并同步规范；本次只读固定投影筛没有进行这种新参数赋值。

## 2. 精确的三步中心覆盖公式

记 H 为删除两条匹配后的跨边子图（每点跨度 7），X 为再加入四个中心匹配的图。对根轨道 i、目标轨道 j，令 R_H^{≤k}(i,j) 是长度至多 k 的跨边路径电压集合。由于 c 中心且 c²=e，路径中的内部 c 可移动到同一位置，两个 c 可以相消。因此精确地有

    R_X^{≤3}(i,j) = R_H^{≤3}(i,j) ∪ c R_H^{≤2}(i,j).

这涵盖内部匹配在任意位置出现的情况。保留真正的基边 ID，只去掉同一条边的立即反向；不同平行边即使投影电压相同也不能合并。

取中心商 D32，固定其跨边电压。每条跨边路径仍给中心仿射形式 f_w(z)=b_w XOR parity(mask_w & z)，其中 b_w 必须用真实 Q64 乘法与逆元计算。对一个商目标 slot：

- 若存在长度至多 2 的跨边路径 w，则 w 与 c·w 同时给出 f_w 和 1+f_w；该 slot 的两个 lift 对每个中心赋值自动覆盖。特别地，四个原中心反点由空路径和一条内部 c 边自动覆盖。
- 若没有长度至多 2 的跨边路径，但有长度 3 的路径，则必须由这些三步路径形式同时取到 0、1。选其中一个形式作基准后，缺一 lift 仍恰是所有差分为零的仿射子空间。
- 若没有长度至多 3 的跨边路径，则两个 lift 恒缺。内部 c 投影为单位元，不能改变这个商距离缺口。

因此 exact score 仍是空 slot 各加 2，加上其余非自动 slot 的坏仿射子空间指示函数。这里自动补齐中心反点是真正的结构变化，但不能宣称其他目标全部改善。

## 3. 一般短词容量：没有在此得到统一排除

设 A 是删除后的四点跨边重数矩阵，行和为 7。命名跨边的非回退路径数长度 0..3 为 I、A、A²−7I、A³−13A。将内部 c 的交换与消去关系全部合并后，抽象字容量矩阵是

    C = (I+A+A²−7I+A³−13A) + (I+A+A²−7I)
      = A³ + 2A² − 11A − 12I.

每根总容量为 302+50=352，低于无关系的 8 度 Moore 数 457。这里是只施加逆消与 c 中心对合关系后的不同抽象字数，因实际 Q64 电压还可能发生额外重合，它是实际覆盖量的上界，不能称为 Q64 实际不同端点数。

删 01/23 或 02/13 得到跨边形状 3/2/2（18 个命名选择）：对角容量 94，重数 3 的异轨道槽 82，重数 2 的槽 88。删 03/12 得到 3/3/1（4 个选择）：对角容量 80，重数 1 的槽 80，重数 3 的槽 96。所有槽都至少 80，超过所需群阶 64，所以这条抽象路径计数没有排除一般变体。CAPACITY.json 逐案保留完整矩阵；程序的命名短路径计数与矩阵公式一致。
