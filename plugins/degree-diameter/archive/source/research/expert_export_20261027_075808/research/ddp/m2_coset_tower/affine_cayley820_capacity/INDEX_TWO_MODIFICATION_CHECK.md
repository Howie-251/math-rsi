# 保存 820 点图的指数二拆分与独立电压范围

2026-10-26。只对 `profile.best.edges` 完成一次全源最终验收：4920 条边与独立群乘法重建逐项相等；820 点简单连通、12 正则、实际直径 4、坏无序对 13,940，根谱 `1,12,132,641,34`。全部 820 根由既有 `verify_graph` 检查一次。总 CPU 0.025830577 秒，其中通用检查器 0.015645 秒；详见 `best.independent_verify.json`、`profile.best.independent_check.json`。下面没有生成第二张图或运行第二张图的 BFS。

原群 `G=F41⋊36 C20`；指数二子群 `H=F41⋊25 C10`，乘法

\[
(x,k)(y,l)=(x+25^k y,k+l).
\]

取 `t=(0,1)∈G`。将旧顶点写成 `h t^ε`，正好得到

\[
(x,j)_{old}\mapsto (\epsilon=j\bmod2,\ x,\ k=\lfloor j/2\rfloor).
\]

保存生成集给出的实际度分配是 **内部 6、跨层 6**：

```
A = [(0,1),(0,9),(36,3),(32,7),(28,5),(22,5)]
B = [(0,1),(0,9),(25,3),(4,7),(24,5),(13,5)]
T = [(34,1),(17,8),(6,1),(3,8),(16,1),(8,8)].
```

内部 A、B 各包含 phase 1 与 3 的两个逆对，以及两个 phase 5 的反射对合。以上是实际保存图的参数，不是此前来源笔记提出但未测试的内部 2/cross 10 分支。

偶指数生成元 s 给 `A=s`、`B=tst⁻¹`，即 `B=τ(A)`、`τ(x,k)=(36x,k)`。奇指数生成元 s 给 `T=st⁻¹`；原 S 的逆闭性等价于该 T 在

\[
\Psi(x,k)=(-36^{-2k-1}x,-k-1)
\]

下闭合。生成元级别的 A/B 逆闭性、`B=τA` 及 `T=ΨT` 已核对并记录在独立 JSON 中。

放开原 Cayley 对称的准确边规则仍是

\[
0h\sim0ha,\quad1h\sim1hb,\quad0h\sim1ht
\quad(a\in A,b\in B,t\in T).
\]

实施时的关键边界：

- A、B 可独立选择，但各自必须逆闭、无单位、恰六个不同元素；若保留当前相位组成，就是每侧两逆对加两不同反射。逆对中的第二元由真实 H 逆元 `(-25^(-k)x,-k)` 给出，不能作为独立变量。
- T 是六个不同 H 元素，**不需要**逆闭，也不应继续强制 `T=ΨT`；每条反向跨边自动使用 `T⁻¹`。若固定当前相位多重集，就是三项 phase 1 和三项 phase 8，各相位内 field 互异。
- 如把 `t0=(34,1)` 跨锚归为 e，必须同时做 `B'=t0Bt0⁻¹`、`T'=Tt0⁻¹`；A 不变。跨相位变为三项 0、三项 7，内部相位不变。只改 T、不共轭 B，会改变保存图而失去原图回归。
- 在解除限制后，左 H 仍分别在两层上传递，但未证明可交换两层。因此实际评价必须从两层根各做一次；若其直径 3 缺失数为 `m0,m1`，坏无序对是 `410(m0+m1)/2`。不能沿用原 Cayley 的单根权重 `820*m0/2`。
- 在固定相位上调整独立 field 是这个具体双轨道子族的优化，不是所有 820 点图、所有双轨道图或所有相位模式的完整判定。当前只有原保存图经过本次完整验收；放宽后的任何新候选均无现成直径保证。
