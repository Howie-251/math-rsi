# 820点双轨道：解除原Cayley生成集合之间的约束

本次是固定相位、固定33个起点的有限构造尝试，目标为820点、12正则、直径3；不穷尽整个双轨道族。原820点Cayley图的唯一独立全源验收已在相邻目录完成，本任务只做一次精确边重标号和两代表根校准。

## 顶点、群和全部边

令 $H=\mathbb F_{41}\rtimes_{25}C_{10}$，乘法为
$(x,k)(y,l)=(x+25^k y,k+l)$，逆元为
$(-25^{-k}x,-k)$。$25$在模41的阶为10，$25^5=-1$。
顶点为 $(s,h)$，$s\in\{0,1\}$、$h\in H$；编码 `s*410+x+41*k`。

两侧各用六元逆闭集合

```
A = {(a1,1), (a1,1)^-1, (a3,3), (a3,3)^-1, (a5,5), (a5prime,5)}
B = {(b1,1), (b1,1)^-1, (b3,3), (b3,3)^-1, (b5,5), (b5prime,5)}
T = {(t1,1),(t2,1),(t3,1),(t4,8),(t5,8),(t6,8)}.
```

同侧边为 $(0,h)\sim(0,ha)$、$(1,h)\sim(1,hb)$；跨侧边为
$(0,h)\sim(1,ht)$。从侧1反向读取电压 $t^{-1}$。
14个field坐标依次为 `a1,a3,a5,a5prime,b1,b3,b5,b5prime,t1,...,t6`。

合法性恰为两侧的两反射field分别不同，以及T的两个三元field组各互异。内部相位1/3的逆对占据1/9和3/7四个不同非零相位，始终不是对合；相位5的元素均为对合。跨侧相位1和8不同，跨边没有自环。因此合法参数产生简单无向12正则图。field为0允许，不另加规范或剔除重复相位槽。

左乘 $h\mapsto gh$ 同时作用于两侧，保持全部边。因此两代表根 `(0,e)`、`(1,e)` 的完整BFS足以精确决定连通性和直径。若两根距大于3或不可达的点数之和为 $m$，全图坏无序点对数恰为 $410m/2=205m$。

## 原Cayley图的精确拆分

原群为 $G=\mathbb F_{41}\rtimes_{36}C_{20}$，$36^2=25$。
原坐标 $(x,j)$ 写为 $(x,2k)(0,1)^s$，其中 $s=j\bmod2$、$k=\lfloor j/2\rfloor$。
因此重标号为 `(x,j) -> (j mod2,x,floor(j/2))`。

偶相位源生成元 $(x,2k)$ 在侧0对应 $(x,k)$，在侧1对应
$\tau(x,k)=(36x,k)$。奇相位源生成元 $(x,2k+1)$ 从侧0给出跨电压 $(x,k)$。
原逆闭性同时强制 $T$ 对
$\Psi(x,k)=(-36^{-1}25^{-k}x,9-k)$ 闭合。

源最佳图的14坐标为

```
[0,36,28,22, 0,25,24,13, 34,6,16,17,3,8]
```

新族保留上述相位，但独立变化A、B、T，解除 $B=\tau(A)$ 和 $\Psi(T)=T$。
这改变了可生成图，不是给原Cayley图换标签。代码先将源边表全部4,920条边重标号，并与该seed展开边集合精确比较；C++评分器再核两根谱均为 `[1,12,132,641,34]`、总缺失68。

## 本次固定运行规则

`std::mt19937_64(2026102624)`；先保留源seed，再一次性生成32个合法随机14向量。每个field按 `rng()%41` 产生，非法向量重抽；没有同构去重、共同缩放或平移锚。

每seed先执行一次单坐标严格下降。每轮完整扫描14个坐标、各40个不同值，非法集合跳过；对每个合法邻点完整执行两根BFS。选择分数严格最小的改善者，并列按坐标和值的遍历次序取首个。整轮无改善即停，每段最多接受30次下降。

之后至多8次双坐标扰动，每次从该seed当前最好局部候选出发，随机选择两个不同坐标并分别改成不同值，非法则重抽。对合法扰动起点完整评分，再按同一规则下降；仅当段末严格改善该seed的最好结果时更新其局部候选。劣化段仍如实计入实际检查量，没有额外起点或续种子。

总上限33个seed、297个下降段、264个合法双坐标扰动；单worker累计120 CPU秒包含准备、编译、校准及搜索。驱动留1秒收尾储备，它不计作实测CPU。超时只保存已执行前缀和当前游标，不重启。命中目标立即保存完整边表并停止；否则仅保存最终最佳一张完整图，供父代理安排唯一独立验收。
