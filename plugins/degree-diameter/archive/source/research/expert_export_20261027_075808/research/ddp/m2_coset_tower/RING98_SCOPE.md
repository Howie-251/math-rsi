# Z98 陪集塔：规范范围与完整五步容量障碍

本报告核对固定 $G=\mathbb Z_{98}\rtimes_3 C_{42}$、$H=\langle(0,7)\rangle$、$K=\langle(0,1)\rangle$ 的 degree7 陪集塔。**这个固定塔中，任意六元、逆闭、无单位元的叶生成集合 $S$ 都不能给出直径至多5。** 原拟340200个规范输入的保全和计数正确，但新的统一叶路由容量证明使该枚举不再必要；没有运行该批候选搜索。

这里关闭的是这个固定群、固定 $H,K$ 的构造族，不是一般4900点最大度7图，也不是其他环或其他塔。

## 1. 群、顶点与所有五步树路线

群乘法和逆元为

\[
(x,i)(y,j)=(x+3^iy\pmod {98},i+j\pmod {42}),\qquad
(x,i)^{-1}=(-3^{-i}x,-i).
\]

$3^{21}=97=-1$、$3^{14}=79\ne1$、$3^6=43\ne1$，且 $3^{42}=1$，故3的阶是42，生成整个单位群 $\mathbb Z_{98}^{\times}$。$|G|=4116$、$|H|=6$、$|K|=42$。

叶顶点是 $g\in G$，block 顶点是 $gH$，head 顶点是 $gK$；树边连接 $g$ 与 $gH$、$gH$ 与 $gK$，叶边为 $g\sim gs$，$s\in S$。因此有4116叶、686 blocks、98 heads，总4900点。六元逆闭非单位 $S$ 给出简单7正则图。左乘 $G$ 保持全部边，在叶上传递，故以下固定叶根 $e$。

将叶之间的树路径压缩为加权步骤：右乘一个非单位 $h\in H$ 的同block跳转成本2；右乘 $k\in K$ 的同group跳转成本至多4。异block时真实树距为4；把全部 $K$ 都允许作成本4只会多计，不会漏路。叶边右乘 $S$ 的成本为1。

任意两叶之间的全图路径都可按相邻叶之间的段分解。没有中间叶的树段位于同一棵group树，约化后长度为2或4。因此，所有长度至多5的叶路径必属于下列四类：

1. 纯叶词，至多5个 $S$ 步；
2. 恰一个 $H$ 跳转，加至多3个 $S$ 步，插入位置任意；
3. 两个 $H$ 跳转，加至多1个 $S$ 步；
4. 一个 $K$ 跳转，加至多1个 $S$ 步，即目标包含于 $K\cup KS\cup SK$。

三次 $H$ 跳转或 $H+K$ 已花至少6步；两个 $K$ 跳转至少8步。相邻树段可约化，允许上述分类重叠不影响上界。这一分类明确包含成本2的block捷径及 $2+1+2$ 路线，没有把全图距离替换为普通Cayley距离。

## 2. Head–head 强制五个非零环轨道

不同head之间的五步路线必须是两步下树、一条叶边、两步上树。因此完整head覆盖等价于

\[
\{0\}\cup\bigcup_{(x,i)\in S}\langle3\rangle x=\mathbb Z_{98}.
\]

非零横坐标在单位缩放作用下恰有五个轨道：

| $\gcd(x,98)$ | 轨道大小 |
|---|---:|
| 1 | 42 |
| 2 | 42 |
| 7 | 6 |
| 14 | 6 |
| 49 | 1 |

取逆保持横坐标的gcd类。故每个二元逆对、每个单独对合，都只能覆盖一个这样的轨道。六元逆闭集合的组成只有六对合、一个逆对加四对合、两个逆对加两对合、三个逆对四种。后两种分别只有4、3个逆组件，不能覆盖五类，已经违反head–head条件。

剩余“一个逆对加四对合”恰有五个逆组件，所以每个非零gcd轨道必须恰占一个组件，不能有零横坐标组件或重复轨道。

## 3. 对合、原340200规范输入与保全

非单位对合满足 $2i=0\pmod {42}$ 和 $(1+3^i)x=0\pmod {98}$。因此它们恰为全部98个 $(x,21)$，再加 $(49,0)$，共99个。

非对合元素的无序逆对数为：

| 横坐标类 | 非对合逆对数 |
|---|---:|
| gcd1 | $42\cdot41/2=861$ |
| gcd2 | 861 |
| gcd7 | $6\cdot41/2=123$ |
| gcd14 | 123 |
| gcd49 | $(42-2)/2=20$ |
| 零横坐标 | 20 |
| 合计 | 2008 |

对任意单位 $\lambda$，$(x,i)\mapsto(\lambda x,i)$ 是保留 $H,K$ 的群自同构，因而保持完整塔图。没有使用通常不保持 $H,K$ 的平移内共轭。

原拟输入的保全方法如下。若唯一逆对位于gcd1轨道，选其任一元素并缩放为 $(1,i)$，$i\ne21$。若逆对不在gcd1轨道，则唯一gcd1组件必是对合；将其缩放为 $(1,21)$。其余组件按真实群逆元取无序逆对，不再错误地对非单位横坐标取乘法逆元。

| 唯一逆对所属类 | 规范后选择数 |
|---|---:|
| gcd1 | $41\cdot42\cdot6\cdot6\cdot2=123984$ |
| gcd2 | $861\cdot6\cdot6\cdot2=61992$ |
| gcd7 | $123\cdot42\cdot6\cdot2=61992$ |
| gcd14 | $123\cdot42\cdot6\cdot2=61992$ |
| gcd49 | $20\cdot42\cdot6\cdot6=30240$ |
| 合计 | **340200** |

gcd49的两个对合选择是 $(49,21)$ 与 $(49,0)$；非对合逆对指数必须排除0和21。gcd1分支指数0的 $(1,0)$ 是合法非对合，不能误删。归一化可能保留同构重复，但不漏合法候选。这些是正确的输入范围计数，**不是实际完成枚举数**。

## 4. 统一叶层容量：一个逆对加四对合全部排除

令唯一逆对为 $a^{\pm1}$，$a$ 的商指数为 $i\in\mathbb Z_{42}$。所有四个对合的指数为0或21，在block指数 $\mathbb Z_7$ 中均为0。$H$ 跳转也保持该指数。

### 4.1 $i\not\equiv0\pmod7$

因为7为素数，可将block指数坐标乘以 $i^{-1}\pmod7$。这是计数坐标重标，不要求它提升为群自同构。六个叶字母在这个坐标中的指数是

\[
+1,-1,0,0,0,0.
\]

固定目标block指数为3的叶层。它包含98个横坐标、每个横坐标6个完整商指数，总计588片叶。按第1节的全部路径分类计算可达端点上界。

**纯叶路径：至多182。** 最短纯叶词可以消去相邻互逆字母。四个零指数字母分别是对合，所以不能立即重复同一个字母。长度0至5、总指数为3模7的非立即回退词数为

\[
0,0,0,1,17,164.
\]

这可直接手计：长度3只有 $aaa$；长度4是三个 $a$ 加一个任选四种对合（$4\cdot4=16$），或四个 $a^{-1}$（1）。长度5中，总整数指数3时是三个 $a$ 加两个对合，计 $\binom52 4^2-4\cdot4=144$；四个 $a$ 加一个 $a^{-1}$ 无法避免立即回退。总整数指数 $-4$ 时是四个 $a^{-1}$ 加一个对合，计 $5\cdot4=20$。故总数 $1+17+164=182$。群关系或不同词撞点只会减少端点数。

**一个 $H$ 跳转：新增至多20。** 剩余至多三个叶字母；要得到指数3，只能是三个 $a$。非单位 $H$ 有5个元素，跳转可插在这三个字母的四个间隙，至多 $4\cdot5=20$ 个端点。

**两个 $H$ 跳转：0。** 最多剩一个叶字母，其指数只能是0或 $\pm1$，不能达到3。

**一个 $K$ 跳转：至多78。** 固定目标block指数后，$K$ 中只有6个可能元素。每个固定 $s\in S$，$ks$ 或 $sk$ 达到该指数时，也分别只有6个可能 $k$。所以 $K\cup KS\cup SK$ 在这一层至多

\[
6+6\cdot6+6\cdot6=78
\]

个端点。这个计数直接在群元素上进行，不假设不同head组之间的边数均匀。

合计得到

\[
\boxed{\#\{\text{五步内的目标指数3叶}\}\le182+20+0+78=280<588.}
\]

故该叶根至少漏掉这一层的308片叶，直径不可能至多5。反向指数 $-3$ 同理，且两层不交，因此还可得到每片叶至少616个超过五步的叶目标；排除结论只需要前一层。

### 4.2 $i\equiv0\pmod7$

此时全部 $S$ 步和全部 $H$ 跳转保持block指数。对任意非零目标指数，前面三种路径贡献都为0，只可能由 $K\cup KS\cup SK$ 到达，容量仍至多78，而目标层大小仍是588。因此同样排除，不必分析具体横坐标。

## 5. 六对合型与ring组间多重边的注意事项

六对合型也全部保持block指数，故直接适用第4.2节：任意非零目标指数五步容量至多78，少于588。这样完整排除所有六对合集合，包括不通过head–head条件的集合。

另一个正确但较弱的跨组论证是：给定一片叶，42个与其head坐标相差单位的组中，至多6个被它直接接触。任选未接触的目标组。对单位组差 $\delta$，单个生成元 $(u,j)$ 的组间边满足 $3^k u=\delta$；单位 $u$ 恰有一个解，非单位 $u$ 没有解。因此这两个组之间总共至多6条叶边。在目标组，与根不同block指数的叶有36片，至少30片不接触根的组。这样的目标不能通过唯一可能的“树4+叶1”路线到达。

**不能把上述“至多6”用于任意非零组差。** 对 $\delta=49$，任意横坐标为49的生成元均满足 $3^k49=49$，会贡献42条组间边。若唯一逆对位于gcd49类，两个元素会贡献84条不同边；六对合型中同时取 $(49,0),(49,21)$ 也会贡献84条。因此42只是单个生成元的上界，不是整套 $S$ 的统一组对上界。第4节的群词容量证明完全避开这个陷阱。

## 6. 结论与实际执行状态

head–head先排除两个逆对加两对合、三个逆对；第4节统一排除一个逆对加四对合；第5节排除六对合。这四种组成覆盖所有六元逆闭非单位集合，故固定4900点塔族已经由纸面证明完整排除。
