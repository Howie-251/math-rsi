# 原文六点基图的 C4×C8 电压提升：一次有限试验

结论：容量筛选通过，但本次固定有限电压搜索没有找到 192 点 exact-NB5 控制图。最佳图仍缺 2752 个有序顶点对的恰好五步无立即反走路径。本轮已结束，不增加起点、邻域或接续群。

原始依据为 Ryosuke Mizuno 的 arXiv:2606.15860，附录 A.5 的六点基图及 C4×C6 电压表；项目保存的原文在 `literature/dd82/arxiv_2606.15860.txt`。此处恢复的十二条具名无向基边及正向电压为：

| 边号 | 正向基边 | 原 C4×C6 电压 |
| --- | --- | --- |
| 0 | 0→2 | (1,0) |
| 1 | 0→3 | (2,4) |
| 2 | 0→4 | (2,0) |
| 3 | 0→4 | (2,5) |
| 4 | 1→2 | (1,2) |
| 5 | 1→3 | (3,5) |
| 6 | 1→5 | (1,1) |

基图允许两组平行具名边。每个基点度数四；非反走是禁止下一步立即反走同一条具名边，允许使用另一条平行边。每个根有 4·3⁴=324 条五步词，共 1944 条。逐词累加原电压，36 个有序基点对均覆盖 C4×C6 的全部 24 状态，恢复了原文的验收条件。

新试验取 H=C4×C8。顶点为 `(u,x,y)`，其中 `u∈{0,…,5}`，`x∈Z/4Z`，`y∈Z/8Z`，编码 `32u+x+4y`；具名正向边 e=(u,v) 给出 `(u,h)∼(v,h+γ_e)`。因此 n=6·32=192，合法电压下简单四正则，边数 12·32=384。若该控制图满足所有有序对（含对角）的 exact-NB5，已有 F3⁵ 通用路由图表将给出 192·3⁵=46656 点、最大度 12、直径至多 5 的图，超过当前保存下界 42342；本轮没有获得所需控制图，没有生成该大图。

取树边 {0,1,2,4,6} 并规范为零电压，剩余自由边顺序 {3,5,7,8,9,10,11}。这保留全部阿贝尔电压赋值的规范代表。为使两组平行匹配不重合，边 3 与 7 的自由电压均非零。七个自由电压的完整合法空间有 31²·32⁵=32245809152 个赋值，本轮没有穷尽它。

容量筛选把同一基点对的五步词映为七个自由电压上的线性函数，并按模 8 系数合并（8 是群的指数）。36 个槽的不同函数数分别为：

每槽均至少 32，故未出现立即容量障碍。不同函数在具体赋值后仍可能碰撞；通过此必要条件不意味着存在覆盖全部状态的赋值。详见 `capacity.json` 与 `base_words.json`。

正式搜索前，把原文第二坐标按原整数值移植到模 8 后作树规范。首图的六个轨道代表分别能经 exact-NB5 到达 [167,164,167,167,166,165] 个顶点，共缺 156 个代表根目标项。独立 Python 的 `(顶点,末条实际边)` 状态 DP 与基图电压词给出的全部六行 192 列矩阵一致；这份首评分被正式搜索复用。平移作用使每个代表缺项对应 32 个有序顶点对，首图总缺 4992；不是普通距离计数。校准保存于 `first_calibration.json`。

正式范围为单 worker、固定种子 20261027192、八个起点（第一个为原文移植图），每起点 25000 次单坐标改变提案。仅改变一个自由边电压为另一个群元素；违反两条非零条件的提案跳过。固定退火温度从 6.35 下降至约 0.35，目标是 36 个槽中缺失状态数之和，达到零即停。CPU 硬限 450 秒，内部在 445 秒停止；实际有限批次先完成，未耗满预算。

本轮共 200000 次提案，198258 个评分（含八个起点），接受 1051 次；八个起点全部完成。各阶段最优缺项 [102,100,98,98,86,86,86,86]，最佳 86 个代表根目标项，即 86·32=2752 个有序顶点对。最佳自由电压编码为 [20,7,22,31,24,15,7]，完整十二边坐标值为：

```
(0,0), (0,0), (0,0), (0,5), (0,0), (3,1),
(0,0), (2,5), (3,7), (0,6), (3,3), (3,1)
```

搜索 CPU 1.871 秒；编译 1.203 秒，Python 准备与输出 0.017 秒，总 CPU 3.094 秒，墙钟 3.101 秒。容量推导另用 0.008 秒。真实游标、计数、计时与赋值存于 `terminal.json`。`best.edges` 保存完整 192 点 384 边图；`best.labels.json` 使用两个定向基图六圈给出 a±、b± 四个出弧标签，已检查每顶点四邻点唯一及逆相容。

root已从保存边表完成唯一全192根普通BFS及独立整数非回退递推：简单四正则、连通，普通直径6、距离大于五的无序点对144个；exact-NB5有序缺项2752，逆一致标号通过。结果见best.independent_check.json，核查程序为root_independent_check.py；不重复BFS。有限试验失败只关闭这一批搜索，不排除整个固定基图 C4×C8 电压族，也不排除其他 192 点控制图。
