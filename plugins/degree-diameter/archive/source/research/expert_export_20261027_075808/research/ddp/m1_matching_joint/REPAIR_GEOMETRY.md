# 六匹配扩张：共同修复的小球条件

结论：可把删边损伤转换成**两条匹配边共同提供端点见证**的约束，比各边
`critical5` 数量之和更直接。单边替换还有明确的小球筛选式，见第3节。
后续已证明本配对扩张的原G端点距离给出精确的新点捷径，见
`../m1_matching_augmentation/DISTANCE_CHECK.md`末节。小球条件可精确判断指定捷径；
仍需另查H中实际损坏的旧对和全部其他点对。
本次只核对保存的candidate02残留小例，没有生成或搜索新匹配。

## 1. 至少两条匹配边；近端点未必来自另一条边

设 `d_G(x,y)=5`，所有最短路均使用拟删除边e。令S为选中匹配的全部端点，
分成接u的A和接v的B。若扩张修复xy，则存在端点p、q满足：同色时
`d_G(x,p)+d_G(y,q)≤3`，异色时该和≤2。两类条件的并集精确判断新点捷径是否足够短；
配对邻接还使异色项被同色项支配，可省略异色项而不改变结果。

两个见证端点必须来自**不同匹配边**：若p=q，三角不等式给距离和≥5；
若它们是同一匹配边两端，则颜色相反且G中相邻，距离和至少为4，不能≤2。
同理，此结论对 `d_G(x,y)≥4` 仍成立。

至少一个见证端点属于 `B_G^1(x)∪B_G^1(y)`，因为两个非负整数的和≤3时不可能都≥2。
但这个近端点**可以是致损边e自己的端点**。不能直接说“其他五条边必须提供一个距离≤1端点”。

沿一条x到y的五步最短路，把e写成 `p→q`，令 `i=d_G(x,p)`，则

```
             到x距离     到y距离
p               i          5−i
q              i+1         4−i       (i=0,1,2,3,4).
```

仅当 `i=2`（e为中央第三条边），e自己的两个端点都不在上述两个半径1球中；
此时确实强迫另一条匹配边的端点落入 `B1(x)∪B1(y)`。
因而“所有其他匹配端点离x、y均至少2，则失败”在中央边情形成立，通常情形不成立。

一个无条件规则的反例：G含路径 `0–1–2–3–4–5`，再在2处接四条互不相交的
二步枝 `2–z_j–w_j`。选择六条匹配边 `01,23,z_jw_j (j=1,…,4)`，令
`A={0,3,z_1,…,z_4}`、`B={1,2,w_1,…,w_4}`。
原距离 `d_G(0,5)=5` 且唯一最短路使用01；其他匹配端点到0、5均≥2，
扩张却有四步路 `0–u–3–4–5`。这里近端点正是e自己的0。
此反例为简单图、原直径5、最大度6；用于否定无条件规则，不冒充2810点源图中的实例。

## 2. 保留e时，由e自身一个端点承担见证

沿上述方向假设 `p∈A,q∈B`。若修复见证使用e的一个端点，另一个见证必须来自其他匹配边，
且其位置满足下列二者之一：

\[
 r\in A\cap\bigl(B_{3-i}(y)\cup B_{i-2}(x)\bigr),\qquad
 r\in B\cap\bigl(B_{2-i}(y)\cup B_{i-1}(x)\bigr).
\]

约定负半径球为空。这是原G距离下“使用e一个端点”的见证条件，直接把第1节四个距离和
代入p、q的距离即可得到。它不是全部修复的必要条件：另外两条匹配边也可能共同完成修复，
完全不用e的两个端点。若e的定向与上述相反，交换A、B。

## 3. 可执行的单边替换条件

从当前六匹配中撤下一个选择f，保留另外五条，端点集记 `A0,B0`，并记
`α_x=d_G(x,A0), β_x=d_G(x,B0)`。对一个当前原G新点捷径式已经失败、
且 `d_G(x,y)≥4` 的残留对，拟加入有向旧边 `(a,b)`（a接u，b接v）。定义

\[
\begin{aligned}
S_A(x,y)={}&B_{3-\alpha_y}(x)\cup B_{3-\alpha_x}(y)
             \cup B_{2-\beta_y}(x)\cup B_{2-\beta_x}(y),\\
S_B(x,y)={}&B_{3-\beta_y}(x)\cup B_{3-\beta_x}(y)
             \cup B_{2-\alpha_y}(x)\cup B_{2-\alpha_x}(y).
\end{aligned}
\]

那么新匹配提供经过u或v的至多五步捷径**当且仅当**

\[
\boxed{a\in S_A(x,y)\quad\lor\quad b\in S_B(x,y).}
\]

证明：剩余五条边是原失败选择的子集，不能自行提供见证；新边的两个端点也不能自行
提供见证（第1节，原距离≥4）。所以必须恰有一个见证端点来自新边、另一个来自保留端点。
逐项写出同色和≤3、异色和≤2，恰得到以上八个球。

这可用于真实提案：针对要共同修复的残留集合R，要求同一条有向旧边满足
`∀(x,y)∈R: a∈S_A(x,y) 或 b∈S_B(x,y)`，同时保留旧边存在、端点互异和匹配合法性。
若只做改善提案，可统计它满足R中多少行；不必要求一次修复所有残留。
这明确体现共同选择、颜色和方向，`critical5` 总量没有表达这些条件。
它保证指定这一对的实际新点捷径，但不处理新删边给其他点对造成的损伤，故不是完整图接受条件。

根代理拟据此生成定向提案时，可先固定一个当前必坏对和撤下的槽位，从上述八个球的一个
非空分量抽取相应颜色端点，再选其关联旧边并按该颜色定向；须过滤与保留五匹配冲突的端点。
这样得到的合法提案保证指定这一对实际有至多五步新点捷径，不保证同时修复全部残留。
若所有分量均空，或球内没有合法可用边，则该单槽替换不能提供这样的捷径。
这**不等于单槽替换不能修复该对**：撤下的旧选择恢复了一条G边，可能直接使新H恢复短路。
只有仍保留至少一条使该对属于D_e的致损边时，才可排除这种H内修复，进而说明单槽替换不足。
双槽改变亦无成功保证。本条修正此前empty-balls的过强解释，没有运行额外实验。

最直接的共同替换目标来自七个 `(0,y)` 例：

```
Y={108,1114,1460,2458,2605,2709,2725}.
```

若保留 `(0,1405)` 并替换其余任意一条匹配边，则对全部这些y，保留端点仍满足
`α0=0,β0=1,αy≥4,βy≥3`。第3节的条件对合法、与保留匹配不交的新边 `(a,b)` 简化为

\[
\boxed{d_G(y,a)\le3\quad\lor\quad d_G(y,b)\le2.}
\]

当 `βy=3` 时，形式上的 `S_B` 另含 `{0}`；但0已被保留匹配占用，不能作为新端点，故删去。
因此同一替换边若要共同修复这七例，必须使
`Y⊆B3(a)∪B2(b)`。这是针对真实残留的明确、有向的小球覆盖目标；本次没有枚举满足它的边，
也没有声称其足以修复candidate02全部350个旧–旧缺孔或14个新–旧缺孔。
