# 首次逐点解除 PSL 轨道限制：四个固定 greedy profile

固定作者12度 witness 的 7959 个 split fiber、既有颜色和 280 个 H(3) 额外 copies，移除其63个普通 padding twins。只准把 merged fiber 改为某一颜色的 split；不删旧 split、不改旧颜色、不改 copies、不优化 twins。

依次执行四个预定优先序：自然序、逆序、随机序种子 2026102701、随机序种子 2026102702。每个序从同一作者状态独立开始。一个候选的两个颜色都合法时，选同色 split 邻数较少者，这也最小化新增度负载；平局固定选 color0。每轮若有新增即重扫，以允许自身 merged 负载改为同色负载后解锁其他候选。

四个 profile 均在第一轮新增零个，已达到各自操作的固定点。共检查 100296 个 merged 候选（25074×4）；所有候选在颜色无关的条件已经被拦截，因此实际进入颜色合法性测试为零。原因只涉及至少一个相邻 merged fiber 的负载已达二，或其 H(3) 邻点已度十二；精确分类及样例在 `blocking_stats.json`。

最终最佳仍为作者核心：`|S|=7959`、copies=280、n=41636。需要的核心目标是 n≥42343、|S|≥8666，本轮没有达到。度分布为 10:5950、11:13720、12:21966，剩余25620个度 slots，但这些 slots 的局部分布没有给出任何合法单点加入步骤。

这份 profile 本身说明固定该初始 S 和 copies 后，单纯改已有 split 的颜色也不能移除这些 merged/H(3) 拦截。随后 root 独立重算相同负载，并完成一次更强的闭包检查：15022 个满载 merged 点构成单个连通分量；252 个 H(3) 已满载的禁 split 点经反向强迫使全部25074个 merged 点均禁止加入。详见 root 保存的 `root_monotone_closure.json` 与 `root_closure_check.py`。因此固定作者 S 且固定280 copies 的任何真 S 超集都不可能，即使允许重染旧、新 split 的颜色。此闭包结果是 root 的独立新增结论，不是四序 greedy 单独证明的。

先删后增或改变 copies 仍在开放范围，但不属于本轮有限任务，未执行；没有追加批量 split 或其他单调变体。

单 worker 实测 CPU 0.225秒，30秒硬限、27秒内部停止均未触及。`best_state.json` 保存完整合法三态和 copies；`best_loads.json` 保存33033项 generic 负载和364项 H(3) 度，并完成一次从最佳状态直接重算的一致检查；`terminal.json` 保存四个 profile 的零新增终态、计数和真实游标。未生成显式大图，未做 BFS，也未计算哈希。本范围已结束，不追加优先序。
