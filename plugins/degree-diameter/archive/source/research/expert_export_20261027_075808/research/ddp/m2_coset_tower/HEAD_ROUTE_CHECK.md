# Head 路由公式：三张已存图逐点集合核对

父代理提出的三个五步 head 路由公式，在已存 650 正控、q41 最佳图、degree-four F25 最佳图上，**三个目标层的全部预测顶点集合均与完整边表 head-root BFS 精确一致，未发现反例**。这是实施和实例核对，不替代任意生成集的普遍证明。

设 degree 为 d，`h=d−1`，`k=dh`，`G=A⋊_r C_k`，`H=<(0,d)>`，`K=C_k`。`W_j` 为 S 字长不超过 j 的元素集合，包含恒等元；`ρ(x,i)=r^(−i)x`，`U=<r^d>`。核对的公式是：

- head 0 到 leaf `(x,i)` 五步可达，当且仅当 `ρ(x,i)∈T_L=ρ(W_3)∪ρ(S)U`。
- head 0 到 block `(x,b)` 五步可达，当且仅当 `x*r^(−b)∈T_B=ρ(W_2)U`。
- head 0 到 head x 五步可达，当且仅当 `x∈T_H={0}∪S_x<r>`。

程序独立从每张完整边表重建邻接，仅从 head 0 做完整 BFS，再对每个目标标签逐点计算公式真假。没有使用搜索器缓存或仅比较数量。JSON 保存每层完整预测可达标签、BFS 可达标签、BFS 缺失标签，以及两个方向的差集；所有六个方向差集在三图均为空。

| 对象 | 实际 head 根 | `|W0|,|W1|,|W2|,|W3|` | `|TL|,|TB|,|TH|` | BFS 缺 leaf/block/head |
|---|---:|---|---|---|
| 原 650 | 625 | 1,5,17,53 | 25,25,25 | 0 / 0 / 0 |
| q41 best | 1025 | 1,5,17,53 | 39,37,41 | 40 / 20 / 0 |

相应实际可达目标数分别是：650 的 500/125/25；q41 的 780/185/41；F25 的 240/76/25。公式与 BFS 对齐的 head 总缺失为 0、60、84。

## 算术和标签绑定

650 使用 **Z25 环**，r=2、d=5、k=20，生成元来自已验证的 `source650_hierarchy/algebraic_reconstruction.json`。leaf=`x+25*i`；block=`500+5*x+b`；head=`625+x`。

q41 使用 F41 的模 41 运算，r=2、d=5、k=20，生成元是 `(1,6),(16,14),(34,7),(26,13)`。leaf=`x+41*i`；block=`820+x+41*b`；head=`1025+x`。其 block 位序与原650不同，程序分别处理。

d4 使用 **F25=F5[u]/(u²−2)** 的系数运算，编码 `a+5*b` 表示 `a+b*u`，r=`1+u` 编码6，d=4、k=12。生成元是 `(1,6),(u,7),(2+4u,5)`。leaf=`12*enc(x)+i`；block=`300+4*enc(x)+b`；head=`400+enc(x)`。所有域乘法、加法、r 幂和 ρ 均使用 F25 运算，没有将它们当成整数模25。

三张图均核对了实际叶恒等元的生成元邻居，防止将参数与另一种标签约定混用。U 的大小分别为4、4、3，作用幂表阶数分别为20、20、12。
