# Cubic200 的单点拆分：固定600项全部直径八

本轮没有得到新下界。作者公开200点三价D7源的600个带标号1+2拆分均失败；它们对应300条旧边各细分一次的两种标号。520项在新根即出现七步不可达点，余80项虽新根覆盖全旧图，仍有旧旧点对超过七步。固定源与固定操作至此停止。

## 来源及查重

原始源来自 [Nishant Bhakar 的数学仓库](https://github.com/f4t4nt/degree-diameter-graphs/tree/main/graphs/deg3/dia7)。[SOURCE.json](SOURCE.json) 保存三份实际下载文件的URL；[source200.edges](source200.edges) 实际读得200点、300边、全三正则。D7继承该源既有公开验证，本轮没有重跑旧源全直径BFS。

作者 [README.author.md](README.author.md) 与 [construction.author.json](construction.author.json) 给出五点底图在阶40群上的电压提升：

~~~
G = C5 ⋊_4 C8 = <x,y | x^5=y^8=1, yxy^-1=x^4>.
~~~

五个40点纤维的标签为40v+i+5j。底图有恒等电压链0—1、0—2、0—3、1—4；1→2电压y；2处半边电压y^4；3/4处环电压xy²、x²y²。前三纤维构成五个边两次细分的Wagner块，后两纤维为连接这些块的四条20圈。没有假设额外对称性来删减本轮600项。

既有账本中的AFY70二重D6及三重D7普通覆盖针对另一固定底图及cover机制。已闭的相邻单点拆分是D3/D4/D5的八个具体源；本轮是同一拆分操作在新source及D7半径的迁移，不计为新的独立方法。

## 事前判断及精确操作

[PREDICTION.json](PREDICTION.json) 在扫描前冻结：预测至少一项保留D≤7。依据是源中块内通路与connector圈通路提供不同连接方向，而拆分所得较低度根的七步容量255尚大于201；这只是允许进一步实际检验，并非覆盖保证。

对每个旧点v及其每个邻点s，令另两邻点为t1,t2，删去vt1、vt2，增加新点200和边200—t1、200—t2、200—v，保留v—s。结果为201点、301边，v度二，其余200点度三。将新点与旧v交换名字后，这恰是把旧边vs细分一次。因此每条旧边出现两种标号，600项的结构范围为全部300个单边细分。

同一操作在当前D6/132点源上无需扫描：任何最大度三且含度二点的D6图最多

~~~
1+2+4+8+16+32+64 = 127
~~~

个点，小于目标133。这里没有取得或重验132点源，也未声称任意133点三价图不存在。D7对应容量255，故容量本身不排除201点。

## 为何本轮改图检查完整

对拆分于v的每项，令A为源图中v的闭半径三球。若两旧端点都在A外，它们到v的距离均至少四，因此任何经过v的源路径长度至少八。继承源D7可知两者存在不经v的至多七步路径；这条路径在改图中全部保留。

所以逐个BFS所有A中旧根及新根，检查至多七步是否覆盖全部201点，即可完整决定该候选D≤7。这是完整根集证书，不是对称性抽样。本轮先检查新根，仅通过后再检查A，遇第一个缺点便拒绝。没有把新根通过当作全图通过。

每个候选又同构于一个旧边细分：旧点之间的源最短路最多增长一步，新细分点到任意旧点最多为旧端点到该点的距离加一。因此继承源D7得到全部候选D≤8。逐项超过七步的见证与此上界合并，证明这600项都恰为D8；无需对每项再跑全源BFS。

## 实际结果与解释

完整扫描600/600项，未试0、UNKNOWN0、导出的新候选0：

| 计数 | 实际值 |
| --- | ---: |
| 新根七步覆盖失败 | 520 |
| 新根通过、旧旧检查失败 | 80 |
| 改图根BFS次数 | 715 |
| 源R3搜索缓存根数 | 200 |
| 旧源全直径复验次数 | 0 |
| native CPU秒 | 0.006137 |
| 编译CPU秒 | 0.861580 |
| 整批CPU秒 | 0.869740 |

源R3缓存是本次候选完整根集的新搜索输入；它不是重新验收旧源D7。所有计数见 [RESULT.json](RESULT.json)、[NATIVE_RESULT.json](NATIVE_RESULT.json)，每项顺序与首个失败点见 [cases.tsv](cases.tsv)，实现为 [probe.cpp](probe.cpp) 与 [run.py](run.py)。

80个新根通过者恰为纤维3或4的connector点，singleton分别位于纤维0或1，即保留connector的块内边、让新三价点接过两条connector圈边。它说明这种分割能让一个新根保持路线互补，仍不足以保护全图旧旧路线。

首个此类反例是ordinal360：v=120、singleton=0。新根200在七步内覆盖全部旧点，但旧0到旧41超过七步。首项ordinal0（v=0、singleton=40）则新根仍漏4点，首缺37。这里的4是一个新根的缺点数，不是全图普通无序坏对数；本轮没有统计全图坏对总数，该字段保持null。

事前正向预测被推翻。已闭范围仅为这个实际200点源的全部单边细分；不排除其他201点图、其他source或改变边连接机制的小gadget。按本批约定，不追加删边、边对、偏移或追逐失败点修补；重新启动须有不同连接机制或新源的全局覆盖理由。
