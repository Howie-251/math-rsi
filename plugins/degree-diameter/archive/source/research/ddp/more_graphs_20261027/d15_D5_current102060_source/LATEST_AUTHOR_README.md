## File formats

**Adjacency lists** (`.txt`, or `.txt.xz` compressed; `xz -dk FILE.txt.xz` writes `FILE.txt`). Line v reads
`v n1 n2 ... nk`: the vertex followed by its neighbours, vertices numbered from 0.

**Lift files** (`.json`) describe a Cayley graph or a voltage lift instead of listing the edges. The group is
G = Z_m ⋊_r Z_n with product (i, j)(p, s) = (i + p·r^j mod m, j + s mod n), and the element (i, j) has id
j·m + i. The graph has h·|G| vertices and the vertex (c, x) has id c·|G| + id(x). Each unit (kind, i, j, val)
contributes darts: kind 0 a loop pair at copy i with voltages val and val⁻¹; kind 1 an involution loop at copy
i; kind 2 an edge from copy i to copy j with voltage val, the reverse dart carrying val⁻¹. The vertex (c, x) is
adjacent to (c′, x·g) for every dart (c → c′, g). Every lift file here has h = 1, so the graph is the Cayley
graph of G on the set of voltages, except deg7_diam5_n2810.json, which has h = 2.

## Verification

    cc -O2 -o bpverify2 bpverify2.c
    cc -O2 -o voltverify voltverify.c
    ./bpverify2 deg13_diam3_n972.txt
    ./voltverify deg12_diam9_n178084211.json

`bpverify2` reads an adjacency list, checks that the graph is simple (no loops, no repeated neighbours, no
vertex number out of range, every edge listed at both ends), then runs a breadth-first search from every
vertex, 64 sources at a time, and prints the order, the edges, the maximum and minimum degree, the number of
defects, the number of unreached pairs and the diameter. A list is correct when it reports 0 defects, 0
unreached pairs, maximum degree Δ and diameter D. For the three largest graphs the work can be split:
`./bpverify2 FILE b0 b1` searches only from vertices 64·b0 to 64·b1 − 1, and the diameter is the largest
value over all the parts.

`voltverify` reads a lift file, checks the group parameters and that the darts give a simple graph, and runs a
breadth-first search from one vertex in each copy — enough, because left multiplication by an element of G is
an automorphism transitive on each copy. It ends with OK when the degree, the diameter and the order all
match the three fields of the file.
