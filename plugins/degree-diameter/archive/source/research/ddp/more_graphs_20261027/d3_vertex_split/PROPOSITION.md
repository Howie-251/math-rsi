# 相邻单点拆分的完整 D3 判定与容量预筛

固定一个简单源图 G、D(G)≤3、最大度≤Δ。取 v，其邻集 N 分成非空无序两部分 S,T；删去 v，以相邻新点 u,w 分别连接 S,T，保留其余旧边。记 H=G−v。

旧点度数不变；两个新点度数为 |S|+1、|T|+1，要求各≤Δ。旧点两端都在N时，同侧经u或w长2，异侧经u–w长3；两端都不在N时，原≤3路不可能经过v（经过需至少4），所以保留。仅有 a∈N、y∉N 的点对需要处理。若H已有≤3路则安全；否则变换后存在≤3路当且仅当有 b∈N∩N_H(y) 与a同侧，此路为a–u–b–y或a–w–b–y。其它新点参与形式在≤3内无法以非N点y结尾。

从新u到旧y的≤3路，要么先入S后在H走≤2步，要么先u–w入T后在H走≤1步。因此精确条件是 d_H(S,y)≤2 或 d_H(T,y)≤1。交换S/T即另一新点条件。新点间相邻。以上条件联合覆盖全部点对；不使用抽样或坏对近似评分。

还有不依赖源边表的容量预筛。令a=min(|S|,|T|)、b=max，a+b=d(v)。从较小一侧新点计0/1/2/3层非回退走步上界分别为

- 1；
- a+1；
- a(Δ−1)+b；
- a(Δ−1)²+b(Δ−1)。

总和为 2+a(Δ²−Δ+1)+bΔ。重复走步只会使真实R3球更小。固定d时，a越大上界越大；d≤Δ时由平衡d=Δ给全局最大值。Δ4..12 的上限依次36/59/113/159/262/339/507/623/872。对应当前基线+1为42/73/121/171/254/586/651/716/811。因此Δ4–7、9–11的这个操作无论源图怎样均不能达到各自目标；这是拆分操作容量界，不是任意新阶图不存在。

仅Δ8、12还需查真实源。Δ8的3+5上界213<254，所以仅4+4可能；Δ12的5+7上界751<811，所以仅6+6可能。低度v更弱，不能绕过。固定源实际均正则，须完整查253×35=8855与810×462=374220项；其它无序非空分割由容量直接拒绝。每候选按上述精确判定，任何通过者展开完整图并由producer全源BFS确认；root另独立最终验收。
