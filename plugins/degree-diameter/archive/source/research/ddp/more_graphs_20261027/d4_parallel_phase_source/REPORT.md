# 官方 Loz1100 平行 phase8 规则的 p61 迁移：有限范围已闭

固定参数范围内没有完整命中，没有生成 1220 点新图。事前预测“至少一项完整覆盖 phase0”得到支持：恰有 6300 项覆盖该层，但全部在其它层失败。新下界仍为 0。

来源是 [Comellas 官方 D4 描述中的 Loz1100 r3 Cayley 实例](https://web.mat.upc.edu/francesc.comellas/delta-d/desc_g/desc_g4.html)。采用右作用乘法
\[
(i,x)(j,y)=(i+j\pmod {20},\;xr^j+y).
\]
原公开源的正向生成元为 \((1,39),(9,8),(8,1),(8,33)\)，模数55、\(r=3\)。共同共轭参数8、缩放43后为 \((1,0),(9,12),(8,33),(8,34)\)。这是已知1100点源的参数解释，本轮没有重新计算它的邻接或直径。保存基线 \(L_{8,4}=1100\)，官方表复核时间继承主线程的 2026-10-27 12:58:40 UTC。

迁移固定在 \(p=61\)、商群 \(C_{20}\)。对全部19个非平凡 \(r^{20}=1\)，取四个逆对的正向代表
\[
A=(1,0),\quad B=(9,B),\quad C=(8,C),\quad D=(8,C+1),\qquad B,C\in\mathbb F_{61}.
\]
这里字母与平移参数同名。\(r\ne1\) 允许共同共轭令 A 的平移为0；两条不同 phase8 逆对允许缩放令 \(D-C=1\)。这给出 \(19\cdot61^2=70699\) 个规范参数项，不声称它们两两非同构。右乘约定下 \(g_D^{-1}g_C=(0,-1)\)，故生成全部平移，phase1 又生成整个商群。每项都对应连通、简单、8正则的1220点 Cayley 图；只有根在四步内到达全部1220端点才是候选命中。

先枚举长度0至4的全部约化词，词数依次为1、8、56、392、2744。对每个实际 r，端点写为 \(aB+bC+c\)，按商层去重。某层不足61个不同形式就不可能覆盖61个端点。这里保留了 \(D=C+1\) 的常数项，并直接按实际 r 计算，未把非本原作用误当作本原20阶作用。构造采用逐次左加字母，遍历的是全部右作用词；全词反序不改变完整球的端点集合。

r=11、50、60 的形式容量先行排除共11163项，而且它们的 phase0 本身也不足61，因此这三种作用的 phase0 幸存数可直接证为0。余16种作用的59536项完整数值枚举：先覆盖 phase0，再按1至19顺序在首个失败层停止。6300个 phase0 幸存者的首个其它失败层分布为：phase1有5952项、phase2有272项、phase3有72项、phase4有4项。没有一项通过全部20层。保存的第一个薄层幸存者是 \(r=3,B=1,C=2,D=3\)，在 phase1 失败。

先运行1000项 profile，之后只运行剩余58536项，未重放 profile。形式容量生成 CPU 0.074759475秒；两次原生程序 CPU 合计0.025145秒；编译不计入且未单独计时。本轮没有全图 BFS、已知源复验、独立新图检查、MIP、外审或 Lean。所有幸存参数与首失败层保存在 [PROFILE1000.json](PROFILE1000.json) 和 [REMAINDER.json](REMAINDER.json)。[enumerate.cpp](enumerate.cpp) 读取已保存的 [coefficients.txt](coefficients.txt)，可复现整个数值枚举；[CAPACITY.json](CAPACITY.json) 保存全部19种作用的20层形式容量。

结论精确关闭 p61、固定正向 phases1/9/8/8、两条 phase8 生成元不同的这一规范平移范围。r=1 的阿贝尔作用由4维半径4 Lee 球上界321小于1220排除，无需参数枚举。不同 phase pattern、不同商群或一般1220点图均未排除。旧 phases1/12/11/16 及双 involution 分支各有独立范围，不混写成整个半直积群不可能。当前结果表明平行逆对确能解除单层缺口，但这批连接不能同时覆盖全部层；按预定范围停止，不继续换素数、相位、seed或求解器。
