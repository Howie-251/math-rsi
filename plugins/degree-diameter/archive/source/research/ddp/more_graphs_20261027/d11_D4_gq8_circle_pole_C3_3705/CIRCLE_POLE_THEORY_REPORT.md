# q8 circle-pole 电压的纸面核对与单 pencil 反例

本文仅核对同一个已冻结的 q8 候选规则；不产生第二个候选，不运行字段网格、球搜索或图 BFS。唯一实际图的生成及距离结果见主 REPORT/RESULT。

## 极点、行列式与射影良定义

记 F=F64，K=F8，Tr(z)=z+z^8，N(z)=z^9。非 spread 的 totally isotropic K-二维线在 spread 参数 P1(F) 上给一个九点 Miquelian circle。若不含 infinity，它唯一写成 N(t+c)=r，其中 c∈F，r∈K*。中心唯一：两个不同中心的圆方程之差是非零 K-仿射线性方程，最多有八个解，不能同时包含这九点。r=0 也不可能给九点。

有限圆的极点 w=(1,c) 不落在圆上，因为 N(c+c)=0≠r。故对线上的任意点 p=(x,tx)，det(p,w)=x(c+t) 非零。对含 infinity 的圆，选 t0 不在圆内，T(x,y)=(y+t0 x,x) 把圆变成有限圆。T 的行列式在特征二为一；其有限圆中心 c 不为零（该圆含零，半径为 N(c)∈K*）。拉回极点为 (c,1+t0 c)，仍不在原圆上，因此所有行列式非零。spread 有限线和 infinity 线分别取 (0,1)、(1,0)，同样无零行列式。

χ(t^k)=k mod3 在 K* 上恒零，因为 K*=<t^9>。所以以 K* 缩放项目点不改变电压。极点以 F* 缩放只给该整条线增加同一个相位，即线端 gauge，不改变完整覆盖问题。更强地，对每条非 spread 线，det(-,w) 是 K-线性同构 K²→F，九个项目点的相位各有三次；这只是单线 flag 均衡，不能推出四步路线均衡。

## S0 到 S∞：精确纸面预测为 [2,3,4]

取 S0={(x,0)}，S∞={(0,y)}。九条四 incidence geodesic 由 x∈F*/K* 参数化，中间点可取 p=(x,0)、r=(0,x^-1)。中间线的 circle 为 C=hK∪{infinity}，h=x^-2。

写 K0=h^7，D=t0^8+K0 t0。经 t'=1/(t+t0) 变换后的圆心为

c=K0/D=1/[h Tr(t0/h)]。

拉回极点的 slope 为

s=t0+c^-1=h^-7 t0^8。

沿 S0-p-L-r-S∞ 的相位中，x 与 x^-1 的因子相消，所得相位正是 χ(s)。八个 hK≠K 的方向均取最小外点 t0=1；特殊方向 hK=K 取 t0=2。于是八个普通方向给相位 2χ(h)，特殊方向给 χ(2^8)=2。九个方向的 χ(h) 原本各三次，特殊方向把一个零相位替换成相位二，因此直向 histogram 为 [2,3,4]，反向为 [2,4,3]。

Root 在收到 q8 数值路线结果前已记录此修订；本核对独立确认同一公式。原 [3,3,3] 预测应保留为被反驳的较强预测，三色仍全的必要 gate 不受影响。候选规则未改变。这个线对的三色也排除了“全部电压只是一个全局 coboundary、所有同端路线必同相位”的解释；它不保证其它相反点对或线对三色齐全。

## 唯一实际图失败后的同 pencil 单匹配规则

这里只读既存 GEOMETRY.json 与 FIRST_FAILURE.json，未重新计算距离。缓存实际给出：

- 起点 P0=(0,2)，位于 S∞。
- 缺点 P73=(1,0)，对应图点 220，即 sheet1。
- 另一个缺点 P137=(3,0)，对应图点 413，即 sheet2。
- K 的显式编码为 {0,1,14,15,22,23,24,25}，所以 3∉K。

若想仅为该起点选同一 spread 线 S∞ 上一个伙伴 q=(0,y)，靠“一条新 point matching + 两 incidence + 一次 line K3”同时获得这两个缺点的全部 sheet 路由，则至少必须有 B(q,P73)=B(q,P137)=0。由于 B=Tr(det)，这两个条件分别是

y∈K*，3y∈K*。

它们同时成立会推出 3=(3y)/y∈K，矛盾。故没有一个这样的 q 能以该统一短路类型同时修复这两个已漏目标，更不能修复全部十九个缺点。每个条件单独选出 S∞ 上一个项目点，但两个所需项目点不同。

这是对这一个“单起点、同 pencil、同一伙伴、指定 matching+incidence+K3 短路”的反例。它没有排除一般联合匹配、其它线依赖电压或其它几何构造；本轮不生成这些变体。
