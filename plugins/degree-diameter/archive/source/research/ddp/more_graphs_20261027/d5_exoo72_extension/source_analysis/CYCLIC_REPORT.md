# 同一Exoo72的六基点循环生成规则：固定C14比较失败

从同一源恢复V={(t,i):t=0..5,i mod12}，编号12t+i。固定较小基点类型指向较大类型，电压取[-5,6]内的balanced整数；反向严格取负。14条cross电压为：

```text
0–3: -3       0–4: -1,3     0–5: -1,2
1–2: -4,0     1–3: 3,6      1–5: 2
2–5: 1,3      3–4: -1,1
```

类型2、4各有内部matching偏移h=m/2。推广到任意偶数m时，cross规则为(t,i)–(s,i+delta)，只把两内部halfturn改为h；n=6m、degree5、边数15m。这是事前冻结的一条整数代表规则，不把模12两个方向的余数同时搬到模14而破坏逆关系。完整参数见 [CYCLIC_RULE.json](CYCLIC_RULE.json)。

容量分三层，不能混写：每个根共有1+5+20+80条≤3约化base词；它们的每槽最小raw数是14，出现在0↔5、1↔3。把14条cross电压视为自由变量、两halfturn视为共享C2符号后，最小形式数仍14，故这个固定base的任意循环电压也不能支持m≥16；自由C14尚未排除。把cross固定成上面的整数后，a+b*h形式的最小数为12，只排这条literal规则的所有偶数m≥14，不排整个自由电压base。全部六根容量表在 [CYCLIC_CAPACITY.json](CYCLIC_CAPACITY.json)。

事前解析预测针对root0自纤维：其闭路偏移为
\[
\{0,\pm1,\pm3,\pm4,\pm5,\pm7,h,h\pm4\}.
\]
在原m12中，h6提供此前缺失的偶偏移2、6、10，恰与其它路线补齐12点；在m14中，h7及h±4全部落回已有奇偏移。预测m14只覆盖10/14，缺2、6、8、12。这个预测在程序的唯一C14比较中逐项得到支持，没有事后改offset。

已生成完整 [C14.edges](C14.edges)：84点、210边、simple5regular。两条0→5电压差3与14互素，基图连通，所以该图连通。利用C14同时平移的6个轨道，只枚举各代表的全部≤3词，六根遗漏状态依次为12、13、11、13、13、12。它们是六个代表的R3缺项，**不是报告成普通无序坏对**。目标D3失败，直径下界4；实际精确D未计算，没有BFS或额外验收。

由Moore(5,3)=106，6m超过72且在界内的偶数m只有14、16；m14的此规则已失败，m16由容量直接止损，无需数值运行。因此原balanced整数规则的全部更大偶数lift已闭。更强的raw14容量也排除这个base的任意电压m≥16，但自由C14仍开放，未启动搜索。
