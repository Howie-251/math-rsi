# 两个120阶群的完整四元逆闭 Cayley 集比较：0命中

S5 的27831项与 SL2(F5) 的1711项全部完成，没有一项能在四步内覆盖全部120个单位根端点。事前预测“至少一个群有命中”被推翻。没有导出候选边表，没有新下界，也没有进行独立120点全图检查。目标为 \((\Delta,D)=(4,4)\)，保存基线104、假设阶数120，日期2026-10-27；\(104<120<161\) 符合Moore容量初筛。

这次是两个具体群的完整有限比较。旧Möbius108是Schreier置换图，旧Q8lift112是14点底图上的固定提升，均不等于这里的群及全部四元逆闭范围；没有重跑它们。

V取群的全部120个元素，候选边为 \(\{g,gs\}\)，其中S为4个互异非单位元组成的逆闭集合。右乘定义边，左乘是图自同构。因此单位根四步覆盖全部120点就保证全图D≤4；不覆盖便足以拒绝该生成集。未预先筛掉非生成集，它们自然在此完整测试中失败。更低度数也无法容纳120点、D4，因为degree3的Moore界仅46；所以检验恰4个生成元不会漏掉这一阶数下的更低度命中。

S5 按字典序列出五元排列，乘法为 \((p q)(i)=p(q(i))\)。25个非单位对合由10个换位与15个双换位组成，其余94个元素分成47个普通逆对。全部四元逆闭集合恰分成三种互不重叠形态：

| 形态 | S5完整项数 | SL2(F5)完整项数 |
|---|---:|---:|
| 4个对合 | \(\binom{25}{4}=12650\) | 0 |
| 2个对合与1个普通逆对 | \(\binom{25}{2}\cdot47=14100\) | 0 |
| 2个普通逆对 | \(\binom{47}{2}=1081\) | \(\binom{59}{2}=1711\) |
| 合计 | 27831 | 1711 |

SL2(F5)直接列出所有模5行列式为1的2×2矩阵，用模5矩阵乘法。非单位对合只有−I，剩余118个非单位非对合元素形成59个普通逆对；四元逆闭集合中的对合数必须为偶数，因此这里只能用两个普通逆对。没有额外同构/共轭删减。

S5的奇偶扩张有两类结构上立即可解释的失败：3906个纯even集合始终留在A5；1635个纯odd集合给二分图，degree4、D4的二分Moore上界80小于120。其余22290个mixed集合亦全部未四步覆盖。上述三类均实际执行了精确端点测试，纸面观察没有替代枚举。

对SL2(F5)，把每个端点同其负矩阵合并，得到60个中心商类。1711项中，四步盖满这60类的项数也为0，因而“商已满、另一sheet仍缺”的项数为0。本次失败已经发生在商的路线覆盖层；不能把它写成已找到一个商全满但中心翻层不足的例子。对一般中心双覆盖，商覆盖仍只是必要条件，但本轮无需把分析推进到该更强前提。

[prepare.py](prepare.py) 完整生成两个120×120乘法表、元素编号和实际逆；数据保存在 [group_tables.txt](group_tables.txt) 与 [group_elements.json](group_elements.json)。[enumerate.cpp](enumerate.cpp) 按三种形态枚举全部集合，每项只做单位根深度4的精确扩张。原始终态见 [ENUMERATION.json](ENUMERATION.json)，群规模与类别计数见 [GROUPS.json](GROUPS.json)。没有保存最好坏对、不做局部修补，也没有额外群。

群表准备 CPU 0.016816636999999995秒；原生完整枚举 CPU 0.011523秒。编译另为user 1.31966秒、system 0.103222秒，不混入3CPU实验预算。事前 [PREDICTION.json](PREDICTION.json) 在群表及端点测试前保存，完整汇总见 [RESULT.json](RESULT.json) 和 [terminal.json](terminal.json)。

结论只关闭S5、SL2(F5)这两个固定群的恰四元逆闭Cayley集；不排除其它120阶群、一般120点图或其它连接机制。按照预定范围停止，不继续换群或根据坏对接续修补。
