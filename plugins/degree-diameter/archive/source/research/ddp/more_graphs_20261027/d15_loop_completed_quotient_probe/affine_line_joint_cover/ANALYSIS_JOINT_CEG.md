For an old target t, let K(t) be the actual free pins whose cached radius-(D-1) balls contain t. The exact line support is

    A(t) = union over p in K(t) of {line L containing p}.

Its clause is the OR of all selected-line variables in A(t). A line satisfies that clause if any one of its three pins covers t; it need not cover the rest of t's fiber. Thus the conjunction of these clauses for all old targets is equivalent to full old-target coverage by the union of the selected lines.

At most five line selectors are permitted. Expanding their literal points and removing duplicates gives a free old-pin set S with |S|<=15. Overlap does not create multiple spokes. All selected pins have actual degree14, so adding one new vertex adjacent to S is degree-legal. The initial target rows, such as zero and both signs of the fixed coordinate basis in every target fiber, form only necessary constraints. For each SAT assignment, expand the lines and evaluate the full original-n cached OR. If it misses t, the clause for t is false under the current line assignment. Adding this clause therefore strictly strengthens the formula and removes that assignment. Adding a first missing point from each missed fiber, and its negative point, is sound: both are genuine old targets. This does not require the chosen line set to be inversion-invariant. If a negative point coincides with an existing row, exact duplicate removal is harmless; at least the originally missed t must be a new violated constraint in a correctly checked SAT model.
