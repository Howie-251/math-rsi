# H9 的全局覆盖规则：42342 点归纳证书与非 star 生成缺口

本轮已从可证 D≤5 的共同 41356 点 partial-fold 核心出发，验证当前 42342 图按原标签的全部 986 次加入都安全，得到该**整图的全局 D≤5 归纳证书**。这是对已知图覆盖机制的新理解，没有产生新图或新下界。另一方面，810 个非 star 附加点的连接集合如何系统生成仍未解释；不能把证成已有邻接序列当成恢复了 pencil 构造公式。

## 继承的几何保证及起点

H(9) 的关联图是二部图，直径为 6；任意 point 到任意 line 因而有长度至多 5 的奇路。给定 point–line **双射** σ，将 point x 到 line σ(y) 的关联路中每条 line L 换成 point σ⁻¹(L)，得到 x 到 y 的至多 5 步图中路，其中相邻关系为 p∈σ(q) 或反向关联。无需 σ 是极性或自同构；双射是关键前提。

作者以 τ、φ=τ² 及每个 φ-pair 的共同颜色得到这样的双射。合并未 split 的 φ-pairs 是图商，距离不会增加；这不是保距断言，允许的 split 集 S/颜色 c 也不必在 PSL₂(8) 轨道上常值。以下两种增点保径操作亦为继承结论。

- **H3 copy blowup：** 将原型替换成非空独立 copy 类，相邻原型之间连接完整二部图。不同原型可提升旧路，同原型 copies 经一个邻点走 2 步，所以 D≤5。
- **Ordinary twins：** 冻结旧图 B，新增 twin(v) 恰连接完整旧开邻域 N_B(v)，所有这次新增 twins 之间独立。到原型 v 可走 2 步；不同原型不相邻时复用旧路，相邻时走 twin(v)–w–v–twin(w)，长 3。因此 D≤max(D(B),3)。H3 copy 类间边与普通 twins 独立规则不能混同。

关系核对证明，旧 41699 图与当前 42342 图同编号诱导前缀 **K=0..41355** 完全相同，共 234318 条边，正是 33397+7959 的 partial fold；其 D≤5 由同 S/c 的几何定理继承。完整旧 41699 图并未被证明嵌入当前图：同编号有 3369 旧边缺失，均在附加标签区，可能涉及重编号。这里可靠的归纳起点是 K，而不是默认保留全部旧图。

## 两种全局覆盖证书

设保留旧图 B 的全部边，D(B)≤5；新点 z_i 的旧邻集为 A_i。写 R_r^B(A) 为距 A 至多 r 的旧点集。忽略新增点之间的边，下列条件足以允许它们**同时**加入：

\[
R_4^B(A_i)=V(B)\quad(\forall i),\qquad d_B(A_i,A_j)\le3\quad(\forall i<j).
\]

前项给旧—新距离≤1+4=5，后项给新—新距离≤1+3+1=5；旧—旧继承。仅有前项不够：每个点分别可以加入，不推出它们同时加入安全。这是充分证书，并非必要条件；新点间还可能经其他新点互助。

两个无需 BFS 的反例说明缺项。旧图为路径 0–1–2–3–4 时，分别在两端各挂一个新叶子：每个 pin 的旧 R4 球都覆盖全部旧图，单独加入均 D=5，同时加入却是 P7，两个新点相距 6。若要求旧直径恰为 5，可取 C10，新点分别连接 {0,1} 与 {5,6}；两组均 R4 覆盖旧图，组间距离为 4，故新—新距离为 6。最终最大度仅 3。

逐点加入的证书则能将所有先前新点一并纳入。令 G_{i-1} 是真正的诱导 earlier-prefix，E_i 是点 i 的全部 earlier-neighbors，则

\[
d_{G_i}(i,v)=1+d_{G_{i-1}}(E_i,v).
\]

所以 D(G_{i-1})≤5 与 R4_{G_{i-1}}(E_i)=V(G_{i-1}) 共同推出 D(G_i)≤5。完整归纳不需要知道各点是 copy、pencil 还是其他类型；但不能借用未来点或最终图中的路径验证某一步。

## 为什么 non-star helpers 比完整邻域复制多了一种能力

在只保留普通 twin spokes、忽略新—新边的子图中，新增 twins **不会缩短任意两个旧点的距离**：每段旧点–twin(v)–旧点都可用原型 v 替换，长度不增加。它复制旧路由，但不为旧核心制造真正更短的通道。

P4 的 helper42177 则产生了真实旧-core shortcut。37638 与 25879 都属于 K，在 42177-prefix 中它们原距离必至少 3：若≤2，则结合 25879–10162–41838，subject 的原 pin37638 已可在旧图 4 步内到41838，与静态缺项矛盾。新 helper 把两者连成 37638–42177–25879，长 2。P5 同理：若旧距离 d(36398,14650)≤2，则再走 14650–9751 就令两 pinsets 距离≤3，与实测距离4矛盾；helper42291 将这段缩为2。它们是改变旧核心路由的非 star 连接，而不是换一个完整邻域原型。

这种能力的必要性还有整类度数上界支持。若一个新点的核心邻集 A_i **包含**某完整核心开邻域 N_K(v)，任选一个这样的原型并计数 t_v。对每个核心点 u，

\[
\sum_{v\in N_K(u)}t_v\le12-d_K(u).
\]

现有 287 行整数覆盖证书将全部 574 个未强迫为零的原型变量分成 196 个单变量预算1、63 个二变量组预算1、28 个九变量组预算3，合计上界 **343**；旧 280 copies+63 twins 达到此数。该上界也覆盖额外 core anchors 和新—新边，因为这些边不会释放上述核心度预算。

所以固定 K、保留其边且最大度12时，所有 star-containing 新点合计≤343；全靠它们至多 41699 点。当前 986 个附加点至少需 643 个 non-star；若要超过 42342，987 个附加点至少需 644 个 non-star。这不是所有 H9 构造的上界，更不限制改变 K/S/c 或删除核心边的情形。

真实包含分类检验的是正确方向 **N_K(v)⊆A_i**。当前恰有 176 个 star 点，全部是相等而无严格超集；810 点对任意原型都不含完整核心 star。因此 core+176 的 41532 点子图已可用普通 twin 的 spanning 子图统一保证 D≤5，实际额外边只会缩距；该顶点集合不是必然数值前缀。810 non-stars 才是完整 star/twin 证书覆盖不到的主体，但不能因此将它们全命名为 pencils。

## 尚未解释的生成规则与下一项宏观对照

P3 已解释**这个实际邻接序列为何全局保径**，还未给出生成 810 个 non-star 附件的几何规则。作者 README 未公开 search methods；metadata 没有 pencil 的几何索引、附加锚点或可复用整批路由证明。若新点确实代表一条 line，并连接线上全部 point 的 fold 像，point→line 奇路可给核心旧点到该新点≤5；但 line→line 只天然给偶路≤6，仍须额外证明各类新点之间≤5，包含 copy/pencil 和 pencil/pencil。这个条件模型尚未被恢复为作者定义。

随后已事前冻结并实际检验宏观预测 **P6**：基底固定为已证 D≤5 的 42177-prefix 加由 P4/P5 两条独立见证选出的 {42177,42291}，共 42179 点；预测余 163 点的基底附件均 R4 覆盖该基底，且所有附件对距离≤3，忽略余点内部边仍可整批加入。两 helper 基底本身安全由既有 P1 行记录及唯一失败对清单继承，不重新 BFS。

**P6 已被反驳。** 复用 156 个原静态 R4 成功行、326 项到两 helper 的半径保证和既有成功 pair 证书后，只需对原 7 个失败点做 7 次多源 R4 检查：42326 通过，其余 6 点仍失败。所有余点附件对距离条件则全部通过；原唯一失败对的附件间路由已由 36398–42291–14650–9751 缩为 3。CPU 0.422154869 秒，无新图、优化或全图逐源 BFS。

因此两个实际 non-star shortcuts 足以解释两个见证，却不是整个 tail 的公共路由层。按冻结约定，停止这个两 helper 层猜测，不加第三 helper、不改 pin、不追逐残余遗漏；也不将其外推为其他结构层不可能。P3 对整图的顺序证书完全不受影响。见 [冻结预测](P6_PREDICTION.md) 与 [唯一实际结果](../tail165_mechanism/P6_RESULT.json)。

下一步应区分“已有全局直径证书”与“可生成大批 non-stars 的规则”：恢复 810 点中的几何索引、附件及锚点公式，并证明所有新类之间的覆盖，而不是从局部成功点继续累加 helper。任何希望超过基线的固定核心方案，都须真的给出至少 644 个 non-star 点及其度预算和整体路由；普通 star 复制已由整类上界止损。本项不再提出新的 helper 队列或启动额外数据试验。
