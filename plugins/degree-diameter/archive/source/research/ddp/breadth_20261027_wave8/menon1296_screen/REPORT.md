# Menon1296：方向类保留族的短路障碍

结论：设计和局部配额成立，但只要所有 incidence 置换保留四个 AG(2,3) 方向类，所得图一定有直径至少 5，不能产生目标 (8,4) 下界。这个障碍独立于三色差约束是否可行；因此没有启动该 CSP、没有生成 1296 点图或跑 BFS。一般的任意 36 阶 incidence 置换仍未被排除。

## 设计、配额与局部距离

按二进制位 x0,…,x3，D={x:x0*x1+x2*x3=1}={3,7,11,12,13,14}。16 个 F2^4 平移块各有六点，每点属于六块，每对不同点恰在两块。有限检查还确认任意两不同块交于两点。

每个 point p 有九个 A 点和 K9 的 36 个边标签 C 点；每块有 36 个 B 点，分为 12 个三角形。A–C 按 K9 端点，C–B 按每个 incidence 的任意双射，B 内保留上述三角形。因此：

| 类型 | 点数 | 度数来源 |
|---|---:|---|
| A | 16×9=144 | K9 中的八条 incident edges |
| C | 16×36=576 | 两个 A 端点、六个 incident blocks |
| B | 16×36=576 | 块中六个 point、两个三角形邻点 |

总计 1296 点、1152+3456+576=5184 边，简单 8 正则。这些计数对任意 incidence 双射成立。

每个 point 内的 A–C 子图为 K9 的细分，故 A–C 距离至多 3、C–C 距离至多 4。任意 incidence 双射也总产生连通图：任意两个 point 共块；该块每个 B state 都分别连接这两个 point 内的某个 C 点，而每个 point 内 A/C 已连通。每个 B 点也连接六个这样的 point。

## AG(2,3) 分组与三色条件

K9 的顶点取 F3^2。四个方向取 (1,0)、(0,1)、(1,1)、(1,2)，每方向有三条平行三点线。各线按该方向标号 0,1,2；对 g=0,1,2，在每条线选取遗漏 g 的一条边，即得一个三边 matching。四方向、三个 g 共 12 组，恰分割全部 36 条 K9 边。每组覆盖六个 A indices；同方向的任意两个不同组覆盖全部九个。

若 incidence 置换采用 `(c,g,line) -> (c,g+a_pL, line permutation)`，则跨 point u,v 的目标 C 标签在两共同块 L,M 给出的两个 preimage groups，其方向 c 相同，组号差分别为 a_vL-a_uL 和 a_vM-a_uM。因此使这两组覆盖全部九个 A indices 的条件正是

`a_vL-a_uL-a_vM+a_uM != 0 (mod 3)`。

共有 96 个 incidence 变量、120 个上述非零约束；point/block gauge 去掉 31 个变量后余 65 个自由量。本次没有求一般三色约束的可行性，因为下述更直接的路径障碍已经排除整个方向类保留族。

另外，六参数平移不变子族 `a_(p,L_t)=f(p+t)` 必不满足该条件：任意 d≠e∈D 对应的两个共同块给出互为相反数的差，因此要求 f(d)≠f(e)。D 的 15 个无序对恰给出全部 15 个非零 F2^4 差，故六个 D 元素需要六种不同颜色，F3 不够。该小结论同样不等于一般 96 变量不可行。

## 独立于三色的方向类障碍

假设每个 incidence 双射都保留四个方向类 c。允许任意组号偏移和任意组内 S3；事实上，即使放宽到每个方向类内任意 S9 双射，以下论证仍成立。

所有 B–C 边及 B 三角形边均保持 c。唯一能改变方向类的层转移是 C–A–C。考虑起点 B 在块 L、方向类 c，终点 C 在 point v、另一方向类 d。若 v 不在 L，则不存在长度至多四的 walk：

* 不经过 A 的 walk 保持方向类，不能从 c 到 d。
* 经过 A、由 B 起步并在 C 结束、长度至多四的全部层 words 只有 `B-C-A-C` 和 `B-B-C-A-C`。后者的开头 B–B 留在同一块；两种 word 的终点 C 都仍属于 L 中的某个 point。

这份层 word 列表由 `screen.py` 完整枚举，允许反走，因而也覆盖全部最短路径的可能性。

一个显式符号见证是 L=D（平移 0）、起点 B 的类 c=(1,0)、g=0、line=0；终点为 point v=0 内、K9 边 {(0,0),(0,1)} 的 C 点，方向类 d=(0,1)。由于 0 不在 D 且 c≠d，该点对距离至少五。

对每个 B 点，块外有十个 point，各有另外三类、每类九个 C 标签。因此整个族至少有 `576×10×27=155520` 个距离大于四的无序 B–C 点对（两个方向共 311040 个有序对）。这不是单次初态失败，而是方向类保留模板的统一阻断。

## 范围与文件

该结论不排除任意 S36 incidence 置换：如果不同 incidence 可以混合四个方向类，方向不变量就不再存在。没有自动继续该更大空间。

`design_and_groups.json` 保存 16 块、全部 120 对共块及 12 组显式 K9 边。`RESULT.json` 保存计数和障碍见证；`screen.py` 是本次有限检查代码，实际 CPU 0.002358 秒。不含大图、CSP 搜索或哈希。
