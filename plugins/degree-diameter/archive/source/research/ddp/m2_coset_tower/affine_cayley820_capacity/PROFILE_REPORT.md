# 820阶仿射群：固定分层样本与16条坐标下降终态

**本次授权的有限尝试已完整结束，无直径3命中；没有排除整个820阶群。** 第一阶段对全部2,139个符号容量存活模式各取16个合法field赋值，实际检查34,224个图，最小根三步缺失47。第二阶段只优化由这些实际分数选出的前16个候选，检查6,258个合法邻点，将最好根缺失降到34；16条轨迹都在规定单坐标邻域中停止。

前序完整容量范围见 [REPORT.md](REPORT.md)，其约1.32万亿的普通规范输入上限没有被当作本次已搜索量。本报告是另获授权的有限构造尝试，不是完整field穷举或全族排除。

## 第一阶段的固定采样规则

固定群为 $G=\mathbb F_{41}\rtimes_{36}C_{20}$，顶点编码 $x+41j$。输入为 [symbolic_survivors.json](symbolic_survivors.json) 的全部2,139个模式，按原文件顺序遍历。

每个模式保留“逆对槽在前、对合槽在后”的全部field坐标。沿前序保全规范，固定已保存 `anchor_slot` 的field坐标为0；**不再实施共同缩放**，所以剩余坐标各完整取模41值。这是一个固定平移规范下的坐标空间，不声称是均匀图抽样或无同构重复。

采用 `std::mt19937_64`，固定种子 **2026102622**，每个非锚槽按实现的 `rng()%41` 规则赋值。若全部field为0，则落入20点补群，跳过；若真实逆元展开后的十二个元素不互异或含单位元，则跳过；若与本模式已接受的field向量相同，也跳过。每模式收满16个不同合法非零field向量便停止抽取，不根据图分数延长该模式的抽样。

实际共36,624次抽取，2,400次因真实生成集合非法被拒绝；全零与重复field向量拒绝数均0。全部2,139模式各恰有16项，得到34,224次完整单根 BFS。每次用实际群乘法表读取全部右 Cayley 邻居，并遍历到结束，未因发现三步缺失而早退评分。左正则作用传递，故根0的完整距离谱精确决定每个图的直径。

每个实际field向量和分数保存在 [profile.samples.jsonl](profile.samples.jsonl)。第一阶段最小根缺失为47；其模式为原ID2469、样本11。该阶段记录 CPU 为0.943772秒。

## 第二阶段的固定16条下降轨迹

## 唯一保存的最终图

只为两个阶段合计40,482次实际 BFS 中的最终最好图写出完整边表，没有保存34,224张样本图。最好结果来自排名13的起点，原模式ID2334、初始样本11，两个下降步骤后根缺失34：

```
action root = 36
component phases = [2,3,3,3,6,10,10]
fields = [0,34,6,16,36,28,22]
S = [82,738,157,714,129,700,139,705,282,606,438,432]  # x+41*j
```

这是五个非对合逆对加两个对合。图有820点、4920边、12正则、连通、直径4；根距离谱 `[1,12,132,641,34]`，相对目标D3坏无序点对为 $820\cdot34/2=13940$。**34只是在本次固定有限尝试中观察到的最小值，不是整个模式或群的全局最小值。**

完整边表和参数见 [profile.best.edges](profile.best.edges)、[profile.best.json](profile.best.json)。唯一独立验收已经完成：独立按群坐标重建的4,920条边与保存边表逐项相等；通用检查器完整遍历820个根，确认简单、连通、12正则、直径4、坏无序点对13,940，根谱与保存谱相同。独立验收记录 CPU 为0.025830577秒（重建/根0/算术0.010185577秒，通用全根检查0.015645秒），见 [best.independent_verify.json](best.independent_verify.json) 和 [profile.best.independent_check.json](profile.best.independent_check.json)。没有重复检查其他图。
