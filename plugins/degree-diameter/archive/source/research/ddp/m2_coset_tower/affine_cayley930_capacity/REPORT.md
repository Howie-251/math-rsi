## 完整相位范围

3¹⁵=−1、3¹⁰=25、3⁶=16 mod31，因此 3 的阶为 30。群运算为 (x,j)(y,k)=(x+3ʲy,j+k)，逆元为 (−3⁻ʲx,−j)。非单位对合全部为 (x,15)，共31个。非对合逆对用 phase0..14 表示：phase0 有15个实际平移逆对，phase1..14各31个。重复 phase 保留不同 field 槽位。

给定度 d、逆对数 p，对合数为 d−2p。非降 p 相位多重集有 C(p+14,p) 个。本度数范围内每相位的可用真实元素数不构成额外计数上限。d11 总 C(20,5)=15504，d12 总 C(21,6)=54264。没有对 quotient 相位使用额外 unit 规约，也没有预先去掉零平移。

设 a_j 为有向字母的 phase 重数。自由约简的长度≤3形式词的相位计数精确为

    a*a*a + a*a + (2−2d)a + (1−d)δ0。

这里长度2扣除 d 个逆消，长度3容斥扣除 (2d−1)a。重复相位仍按字母重数计数。每相位必须至少有31条形式词，故这是必要筛。每个 p≤3 分支均在这一层完整拒绝，没有为它们构造巨大符号词表。

符号层按每组件独立 field 变量，逆字母系数 −3⁻ʲ，实际乘法递推 c+3ʲd。同相位完整系数向量相同的词对任何赋值均相同；不同形式不足31即可排除。系数按每坐标5位精确存储，最多12坐标共60位，不损失模31信息。两个新纯符号输入与既有 Python symbolic_affine_words.py 的全部30个系数集合逐点相等；卷积结果也与直接词枚举相等，见 calibration.check.json。没有图/BFS 校准。

## 完整终态与规范大小
