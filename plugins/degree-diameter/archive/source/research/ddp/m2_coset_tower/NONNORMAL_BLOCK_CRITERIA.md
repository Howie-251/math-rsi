# 非正规 AGL 块子群：精确的两个 BB 覆盖集合

## 目标与范围

把既有完整公式 `H W3 H ∪ K W1 H ∪ H W1 K` 化成可计算的两个集合。它仍然只是块头—块头（BB）覆盖，不替代叶子和组头条件。本稿为精确推导，不使用概率近似；独立数学核查与实际图校准另记。

设 B 为 q 元有限域，K=AGL(1,B)，元素 (t,a) 表示 z↦t+az，a≠0。H={(0,a)} 是0的稳定子，阶q−1，非正规。A 是有限加法群，K通过自同构作用于A；写 T_t、L_a 分别为平移和乘法元素在A上的作用。因此

    (t,a)·v = T_t L_a v,
    L_a T_t = T_(at) L_a.

令G=A⋊K。塔的叶、块、组头分别为g、gH、gK；S为逆闭非单位叶生成集合，Wj包含所有长度至多j的S词及单位元。这里q是K的底域阶，不能与|A|混用；度数为q，阶为|A|(q²+1)。

## 陪集坐标

右乘H只改变K元素的乘法分量a，不改平移分量t。因此g=(v,t,a)对应块坐标(v,t)，对应组头v。一个K元素(c,h)左作用于块坐标为

    (v,t) ↦ (T_c L_h v, c+ht).

特别地H作用为(v,t)↦(L_h v, ht)。这说明目标块的第二坐标只有0和非零两个H轨道，但横坐标v必须同时变换，不能忽略它。

## 两个集合的定义

对词w=(v_w,t_w,a_w)，定义

    R0 = H·{v_w : w∈W3, t_w=0},
    R1 = {L_(t_w^−1) v_w : w∈W3, t_w≠0},
    P  = H·{v_s : s∈W1},
    Q  = H·{T_(−t_s) v_s : s∈W1}.

H·X表示用全部L_h作用的并集；W1含单位元，所以P、Q均含0。R1的定义没有额外H闭包。

结论为

    M0 = R0 ∪ P ∪ Q,
    M1 = R1 ∪ P ∪ T_1 Q.

从根块H出发五步可达的目标块，第二坐标为0时横坐标恰是M0；第二坐标为b≠0时横坐标恰是L_b M1。因此

    missing_BB = (|A|−|M0|) + (q−1)(|A|−|M1|).

完整BB覆盖等价于M0=M1=A。对当前两个入口，(|A|,q)分别为(64,7)和(128,8)。

## 三种路径逐项推导

1. `H W3 H`：右H不改目标块，左h∈H把(v_w,t_w)变为(L_hv_w,ht_w)。若目标b=0，只有t_w=0可贡献，得到R0。若b≠0，每个t_w≠0唯一选h=b/t_w，得到L_bR1。

2. `K W1 H`：固定s=(v,t,a)，左K元素(c,h)要使目标第二坐标为b，必须c=b−ht。其横坐标为

       T_(b−ht)L_hv = T_b L_h T_(−t)v.

   对s∈W1及h∈B*取并，恰得T_bQ。特别b=0时为Q。b≠0时，因Q在H下不变且T_b=L_b T_1 L_(b^−1)，有T_bQ=L_b T_1Q。

3. `H W1 K`：左H作用于s的横坐标给L_hv_s；右K可把目标第二坐标改成任意b而不改横坐标。每个b恰得到P。P在H下不变，所以也等于L_bP。

把三项合并即得M0和L_bM1。每项来自已证明的完整五步路径分类，故既不遗漏目标端组头路线，也不加入不存在的路线。

## 实现与证据边界

可预计算H轨道、T_t和L_a的作用表，逐个产生W3并累积R0/R1；无需假设H正规，也无需展开全部q个块坐标掩码。以64或128位集合实现时，最终计数只用两个集合。

使用该式作搜索必要条件前，应在一次实际展开图上逐点比较所有|A|q个BB目标；这是新非正规作用的校准，不应复用旧正规H公式的检查结论。完整图的最终验收仍由独立全源BFS或已证明的三层传递性承担。

固定H、K的规范变换也须同时保持两者；任意K共轭通常移动H，不能沿用此前正规H族的规约。
