# AGL(1,17) 的相位容量与共同仿射规范核对

状态：所述数学规范保全；本检查没有生成候选图、运行搜索或 BFS。目标范围是固定群 `G=F17 ⋊_3 C16` 上所有八元、非单位、互异、逆闭的 Cayley 生成集，直径目标 3。结论不外推任意 272 点图或其他群。

实际已读 `quotient_capacity.py`、`QUOTIENT_CAPACITY.json`、`search_projective.cpp`、`run_projective.py` 及实现代理给出的规范方案。以下把已证明的数学步骤与计算表的已报计数分开记录。

## 1. 单元素分类与 495 个相位多重集

乘法为 `(x,j)(y,k)=(x+3^j*y,j+k)`，逆元为 `(-3^-j*x,-j)`。3 的阶为 16，3^8=-1。除单位元以外，全部对合恰为 `(x,8)`，x 可取全部 F17。相位 0 的非零平移不是对合。

设生成集含 p 个非对合逆对和 i 个对合，则 `2p+i=8`，p=0,...,4。每个非对合逆对可以选择相位代表 j∈{0,...,7}：j=1,...,7 决定唯一方向，j=0 保留有向 x 和 -x 两种表示。相位 8 不属于非对合逆对。

所以 p 个逆对的相位是八类上的无序多重集，计数 `C(p+7,p)`；求和为 `1+8+36+120+330=495`。**多重集允许重复相位**，每个出现仍对应独立的 field 坐标槽位；不能按相位去重。对合槽位也各自保留独立坐标。本计数不承诺生成集表示唯一。

## 2. 相位容量只给必要条件

给实际八个字母各自标号。逆对的两个字母互为逆标号，每个对合自己的标号为逆标号。长度 0..3 且无立即逆消的形式词数为 1、8、56、392，共 457。

每个距离≤3 的实际群元素至少有一个这样的词表示，因为立即逆消可删除且不增长长度。若投影相位 j 的形式词数少于 17，则不可能覆盖该相位中的全部 17 个 field 元素。因此每相位容量≥17 是安全的必要过滤。不同词可表示同一群元素，只会使该上界更松，不会使筛除失去保全。

真实 `quotient_capacity.py` 使用 `i^1` 为每个非对合逆对的两个标号配逆；其余标号各自自逆，未合并相同相位的槽位。空词计入相位 0；所有 495 个相位多重集都由 `combinations_with_replacement(range(8),p)` 生成。代码与上述必要条件一致。

现成计算表记录：3 逆对+2 对合保留 42 个相位模式；4 逆对保留 116 个；其余组成均被必要条件拒绝。此处只读该结果，没有重复运行相位枚举，也没有把容量通过当作 D3 成立。

## 3. 平移锚点与首非零 scalar 规范

对 λ∈F17*、t∈F17，映射

`F_(λ,t)(x,j)=(λ*x+(1−3^j)*t,j)`

是群自同构：乘积的平移项使用 `(1−3^j)+3^j(1−3^k)=1−3^(j+k)`。它同时作用于全部生成元，保持逆元、互异性、非单位及 Cayley 图距离。

固定一个相位模式，按固定槽位顺序选首个 j_a≠0 的槽位，设其 field 坐标为 x_a。先取 λ=1、`t=−x_a/(1−3^j_a)`，把该坐标置 0。分母非零，因为 3 的阶为 16。容量存活模式必有非零相位；全相位 0 的模式不可能覆盖 C16。

其余 m−1 个槽位组成向量 z，其中 m=p+i。若 z=0，则全部生成元均落入标准补群 `{(0,j)}`，只能生成至多 16 点，不可能覆盖 272 点，故可丢弃。对 z≠0，再共同缩放使固定槽位顺序中的首个非零坐标为 1。这个步骤不改变锚点 0，且每条非零 scalar 轨道都能如此规范。

因此每个模式可完整遍历 `P^(m−2)(F17)`：依次选择首非零位置 h，令此前坐标为 0、该坐标为 1、此后坐标任取 F17。必须遍历所有 h，不能只把紧接锚点的某一个坐标强制定为 1。

3pair+2inv 的 m=5，每模式 `1+17+17²+17³=5220`；4pair 的 m=4，每模式 `1+17+17²=307`。现存活模式共最多 `42*5220+116*307=254852` 个规范标记输入。这里允许不同槽位标记、逆对方向或额外群同构造成重复，不能机械再除以阶乘或 2。

## 4. 实际生成集过滤的保全边界

- 相位 0 的逆对代表 x=0 会给出单位元，必须在真实元素展开后拒绝。
- 相位 0 两槽位取 x 与 -x 代表同一逆对；两者同时出现时实际元素不足八个，按 `8distinct` 拒绝是正确的。不要在 projective 规范前额外限制有向 x 的正负代表。
- 相同非零相位的不同逆对可以有不同 x，必须保留；相位 8 的不同 x 也是合法不同对合。
- 用真实逆元把每个逆对展开成两元素；每个对合展开一个元素；最终检查恰有八个互异非单位元素且逆闭。共同仿射自同构是双射，所以这些合法性过滤不可能丢掉原本合法的生成集。

这些规范只利用共同仿射变换；未额外假设商相位乘以任意单位是本群自同构，也未施加额外生成元排序或移除重复相位。
