# BB 公式的现有对象反例：遗漏经过目标 head 的路线

本次只读检查已存图，从 `block(0,0)` 做完整 BFS，并对每个目标 block 的原标签逐点核对归一化集合。先检查原650，无反例；随后在 q41 最佳图找到反例并立即停止。按授权没有继续检查 d6 或 first-head-zero 图，也没有生成或搜索新候选。

记 `R1=ρ(W1)={0}∪ρ(S)`，`U=<r^d>`，目标 block 为 `(x,b)`，比较坐标为 `r^(−b)x`。被检查的原式和修正式分别为：

`Tbad(b)=U R1 ∪ U ρ({w∈W3 : quotient(w) mod d=b})`；

`Tgood(b)=Tbad(b) ∪ r^(−b) U S_x`。

## 实际反例

在 `q41_search/search.best.edges` 中，根为 block **820**=`(x=0,b=0)`，目标为 block **914**=`(x=12,b=2)`。归一化目标是 `12*2^(−2) mod41=3`。

完整图距离恰为五，一条实际最短路径是：

`820 → 205 → 750 → 955 → 1037 → 914`。

其类型和坐标依次为：

`block(0,0) → leaf(0,5) → leaf(12,18) → block(12,3) → head(12) → block(12,2)`。

路径先从根 block 到一片叶，再走一条叶边，最后经**目标所在组的 head 1037** 到目标 block。归一化值3不在 `Tbad(2)` 中，但在补项 `2^(−2) U S_x` 中，因而在 `Tgood(2)` 中。这是目标 head 路线被遗漏的具体五步反例，不是数量比较推测。

## 逐点集合结论

原650的原式和修正式均与从根block500出发的可达 block 集合吻合，未提供反例。

q41 最佳图的 `Tbad` 预测181个可达block，实际BFS可达197个，故有 **16 个假阴性**、零假阳性；加入补项后的 `Tgood` 也预测197个，并与全部 205 个目标 block 的实际五步可达性**逐点精确相同**，两个方向差集均为空。完整预测标签、BFS 标签、逐 b 的归一化集合和16个实际漏点保存于 `BLOCK_ROUTE_CHECK.json`。
