## 精确局部模型与边界

自由 generic f 使用二元变量 x_f0、x_f1，s_f=x_f0+x_f1≤1；自由 H3 点 h 使用整数 z_h∈{0,1,2}。域外这些变量按当前状态代入常数。对 Q 度数 d_f、generic 的可能 H3 邻点 h(f)，最大度十二的三条条件编码为：

```
Σ_{g∈NQ(f)} s_g + z_h(f) − d_f s_f ≤ 2
Σ_{g∈NQ(f)} x_g0 + z_h(f) + d_f x_f0 ≤ 2+d_f
Σ_{g∈NQ(f)} x_g1 + z_h(f) + d_f x_f1 ≤ 2+d_f.
```

这分别在 f merged、split-color0、split-color1 时激活正确负载；其他状态下的 d_f 是足够的松弛量，不改变合法状态范围。H3 条件为：

```
Σ_{f∈HQ(h)} s_f + Σ_{h'∈NH3(h)} z_h' ≤ 5+[h absolute].
```

模型包括自由球内点、所有球外 Q 邻点、自由 z_h 相邻的球外 generic，以及所有受 s/z 影响的 H3 点。因而球外满载点的预算并未被忽略。四区实际受影响 generic 数分别为7383/7221/7605/7626，H3数4/5/140/130。

目标最大化自由域内 Σs+Σz；域外贡献固定，等价于最大化全局 |S|+Σz。加上不低于当前目标值的下界，并在调用 solver 前逐行检查原合法状态对应的整数向量满足所有约束，四次均通过。SciPy 没有 warmstart；若没有返回 incumbent，规定记 UNKNOWN 并原样保留当前状态，本轮没有出现这种情况。
