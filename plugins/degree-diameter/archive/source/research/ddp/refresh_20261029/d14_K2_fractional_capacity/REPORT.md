# D14 K2：完整对称分数松弛可行

本批得到一个已对全部 **94186 个旧目标**验收的精确有理可行向量，总量
**24.136823828 < 26**。因此，这个分数容量松弛不能阻断固定源上的 K2 扩张。
**整数两侧端口集合 A、B 仍为 UNKNOWN；本批没有新图。**

## 固定对象与松弛

输入仅为 `../d14_K2_exact_signature_compression/` 的既有完整 R3/R4 支持与
`PORT_GROUPS.json`，未读原图或计算新球。3589 个精确覆盖等价组中，3480 组容量
为 1，109 组容量为 2。这里容量是两个 helper 合计可使用的端口次数，不是两侧
必须选择不同组。

记 `a_tg = 1[t∈R4_g] + 1[t∈R3_g]`，其值为 0、1 或 2。本批唯一 LP 为

```
min Σ_g x_g
0 ≤ x_g ≤ c_g
Σ_g a_tg x_g ≥ 2       对全部 94186 个目标 t。
```

必要性来自两侧覆盖条件。若 α、β 是 helper A、B 的组选择变量，必须有

```
Σ_g (1_R4_g(t) α_g + 1_R3_g(t) β_g) ≥ 1,
Σ_g (1_R3_g(t) α_g + 1_R4_g(t) β_g) ≥ 1,
Σα ≤ 13, Σβ ≤ 13, α_g + β_g ≤ c_g。
```

相加并令 `x=α+β` 即得本批必要松弛与 `Σx≤26`。反过来，对本批分数可行解取
`α=β=x/2`，因为 `c_g≤2`，每侧组变量也至多 1；每侧总量为 **12.068411914**，
两条完整分数覆盖条件都成立。这是通常双侧线性覆盖松弛的实际可行解，尚未满足
0/1 选择，不能转换成整数端口或图的存在声明。

单线程 SciPy 1.15.3 / HiGHS 原位求解三轮稀行 LP；每轮后用保存的两个支持位集
检查全部 94186 行。没有建立完整稠密矩阵。

| 2 | 512 | 8.071660307 | 0.342372941 | 0.602794049 |

三轮原始解都不是全目标可行解。原 `RESULT.json`、`TERMINAL.json` 和 `HANDLE.json`
保留三轮上限停止的历史状态，未改写。求解合计 4.547585209 CPU 秒，准备、编译、
求解与检查合计 5.425692188 CPU 秒；HiGHS 在 Python 进程内运行。启动命令为
`python research/ddp/refresh_20261029/d14_K2_fractional_capacity/run_once.py`。
运行期间曾输出 driver PID，但最终 HANDLE 覆盖时未保留；现存终态不补造该 PID。

根代理根据第三轮的实际全目标最小覆盖，作了一次统一正比例放大，再按固定分母
`D=10^9` 向上取整；没有第四次 LP。确切向量见 `EXACT_GLOBAL_WITNESS.json`，
整数全验结果见 `RESCALING_RESULT.json`：

- 3589 个组的全部分子与精确整数容量已保存；391 个分子为正。
- 总分子 `24136823828 < 26D`。
- 最大组分子 `289268360`，全部组满足 `0≤X_g≤c_gD`。
- 全部 94186 行以 int64 累计 `(R3+R4)` 系数；最小值为 `2000000030≥2D`，
  在旧目标标签 **39334** 取得。
- 该一次缩放及整数验收用时 0.210710738 CPU 秒，本批累计 **5.636402926 CPU 秒**。

所以可行性不依赖浮点求解器残差。24.136823828 是实际可行上界，**不是所求 LP
最优值的断言**。`RESCALING_DECISION.md` 记录缩放依据；逐轮实际解及目标列表在
`round_01/02/03*.json`。

## 结论与停止范围

完整分数松弛已有精确可行证据，故不可能再用该同一 LP 的合法 dual 得到大于 26
的下界。若整数 K2 确实不可行，其阻断理由必须使用这个分数松弛未表达的约束；
本批没有证明存在这样的阻断。整数 K2 的存在性仍未解决，也不自动授权继续旧
SAT、随机取整或端口优化。

本批 3 次 LP，0 次 SAT、0 次 BFS、0 次源图读取、0 张生成图；没有追加轮次、
改变端口池或延长旧计时。数值工作已停止，无待验收项。
