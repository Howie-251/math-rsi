# 单一删平面诱导实例：事前预测与范围

本次唯一输入为已验 F5 3750 点、20 正则、直径 3 的字面边表
`../f5_full_d20_D3/graph_d20_D3_n3750.edges`，标签为
`125*a+x0+5*x1+25*x2`。

唯一规则：在每个控制器 fiber 删除 `x0+x1+x2=0 (mod 5)` 的 25 点，
保留其余 100 点。预测诱导图恰有 3000 点、24000 边、各度数 16；
四个噪声方向与该平面均横截，每一原端口的五个邻居恰删一个。

本次具体反预测为：该规则不能保持直径 3。固定保留目标旧标签 626
（控制器 5，fiber code 1），选 fiber 18 中已删顶点 z，使 z 到 626
在原图有一条两步路，再选 fiber 0 中保留的 x 邻接 z。
控制器 0 到 5 的唯一三步路为 `0–18–29–5`，端口为 `[0,2,1]`；
已有满秩证据使提升路径也唯一，删除 z 应令该保留点对失去全部三步路。

严格执行范围：源边表只读取一次；构造这一张完整诱导图及旧标签映射；
查找上述字面路径；只从选定 x 做一次诱导图 BFS，保存目标距离、各控制
fiber 的半径 3 遗漏。不得进行全部 3000 根验证、其它平面/规则/优化、
SAT、原图直径复验或其它图生成。一次实现与执行目标不超过 5 CPU 秒。

若预测失败，不修改规则重试。若反例成立，只排这一张规则图，
不排一般诱导子图机制。另有纸面预言：fiber 5 的每个保留 y 至少有
20 个 fiber 0 保留点在诱导图距离大于 3，因此该跨 fiber 无序坏对
至少 2000；这不是全图实测坏对数，本次单根 BFS 不验证全部 2000 对。

随后只提交完整保留变量、条件度数、保存唯一测地路蕴含的必要 CNF
准备方案与规模估计，不启动求解器。旧纯删边证明保留全部 3750 点，
不覆盖本次删顶点规则或一般保留变量范围。
