# 3750点完整F5图：每条边均为直径三必要边

## 结论

固定`f5_full_d20_D3/PARAMETERS.json`定义的3750点、37500边、20正则图，**任意删除一条或更多现有边、同时保留全部顶点，都会使直径不再至多三**。因此从这张图纯删边到19度或18度的路线直接关闭，无须扫描整图的单边删除、完美匹配或二因子删除。

这里“必要”指存在一对图顶点，其唯一长度不超过三的路径使用指定边；不是仅指删边后旧证明不再适用。结论不涉及重接、加入原来没有的新边、删顶点或一般3750点19度图。

## 事前预测与实际有限检查

事前范围保存在`PREDICTION_AND_SCOPE.md`。预测的充分条件是：每条定向控制弧都作为某个控制距离恰三、唯一三步控制路径的首弧，并且该三步词的三个噪声列满秩。

本次只从保存的30点四正则controller枚举1080条非回退三步词，处理全部900个控制有序对。NB3词数分布为0:120、1:498、2:264、3:18。其中258个有序对的控制距离恰三且三步词唯一。

这258条唯一路线的首弧覆盖全部120条定向控制弧，每条首弧对应的证据数分布为1:24、2:60、3:30、4:6，无缺弧。程序另直接用保存的四个矩阵和四个方向计算36类非回退三步词的噪声列行列式，全部非零。控制器及秩检查耗时0.002462428 CPU秒；0次源图BFS、0张删边图。

`CONTROLLER_CERTIFICATE.json`给出全部120条弧的具体唯一控制路径，以及36个字面噪声矩阵的列和行列式。该有限证据支持下面的自含推导，不把历史推导稿的“尚未生成”状态误作新图状态。

## 为何这证明每条具体提升边不可删

记反向port为inv(p)，对应噪声方向v_p=ℓ_inv(p)。在实际规则中，一步为

    (a,x) → (C[a][p], T_p x + λ v_p),   λ∈F5。

取任意具体定向边e，其参数为(a,x,p,λ)。从120弧证书选首弧(a,p)对应的唯一控制三步路径，其port序列为(p,q,r)，控制终点为d。令第一步仍是e，再取后两步噪声为0，得到真实图上的路径

    (a,x) → (b,y) → (c,T_q y) → (d,T_r T_q y),
    y=T_p x+λv_p。

因为d的控制距离恰为三，不存在长度0、1、2的投影路线，所有长度不超过三的图路径必须投影到这条唯一三步控制路径。对于固定控制词，三个噪声参数到末坐标的映射为

    T_r T_q T_p x
      + μ0 T_r T_q v_p
      + μ1 T_r v_q
      + μ2 v_r。

证书给出三列[T_r T_q v_p, T_r v_q, v_r]的非零行列式，所以该映射是F5³上的双射。既然(λ,0,0)产生了上述目标，便是唯一噪声三元组。因此上面是这对具体图顶点之间唯一长度≤3的路径，且必经e。

移去e就破坏该点对的三步可达性。任意非空删边集合包含某条e，进一步删除其余边不会创造新路径，故任意非空纯删边都不可能保持D≤3。

固定第一步噪声λ、让后两噪声任取F5²，还给每个定向具体边至少25个不同目标坐标，全部具有唯一长度三路径。结论覆盖75000条定向边，亦即全部37500条无向边，而未逐边运行BFS。

## 一个可直接检验的具体见证

边(0,2250)的见证控制路径为0–18–29–5，ports[0,2,1]，控制距离恰三且该三步路径唯一。

真实顶点路径为

    0 → 2250 → 3625 → 625。

四个纤维坐标均为0，三个噪声也均为0；满秩保证不存在其他噪声组合。删边(0,2250)后，0到625不再有长度≤3路径。该例不依赖重跑3750点源图BFS。

## 六平面并集的冗余实际在哪里

另直接读取`f5_complementary_triples/MATRICES_AND_PENCILS.json`中的六平面，四个port均得到：每平面25点，公共线5点，并集125点；120个线外点各仅属于一个平面，公共线5点各属于六个平面。数据在`PENCIL_REDUNDANCY.json`。

所以相邻控制纤维的覆盖确有公共线重合，且线上的点原本一步就可达。但这些局部重复不能推出某条边可删：控制距离三的唯一投影路径给出了另一类远端点对，已经把每条具体边锁定。

同样，每条控制边上的完整二部关系可分成25个K5,5；移去其中一条边后，它本身的两端仍可经K5,5中的三步绕行。这个局部绕行也不能修复上述远端见证，因为那会超过总三步预算。
