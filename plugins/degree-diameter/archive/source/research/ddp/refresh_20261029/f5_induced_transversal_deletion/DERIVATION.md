# F5字面3750源：逐纤维四方向transversal删点不能保D3

这是静态推导，不生成图、不枚举删除集、不运行BFS或solver。固定源为`f5_full_d20_D3/PARAMETERS.json`定义并已验收的3750点20正则图。旧保全部3750点的纯删边结论不包含本次删顶点问题；d15的6912点matroid诱导图也不是本源。

## 1. 所排范围与度数

每个controller纤维a取D_a⊂F5³，要求对四个固定方向ell0,…,ell3的每条平行仿射线，D_a恰含一个点。每个方向有25条这样的线，故|D_a|=25，保留100点/纤维、共3000点。

源中port p的五个邻点，在目标纤维恰构成方向ell_inv(p)的一条五点线。删除目标D_a使这条线恰少一个邻点。因此每个保留顶点四个port各剩4邻点，诱导图确为16正则、条件性边数24000。删除集可以非线性、逐纤维不同；不要求它们是平面或使用同一公式。

下面证明这整个删除域必不能D≤3，而不只是某个平面样本失败。

## 2. 唯一controller路线及字面端口

参数表中：

    C[0]  = [18,20,2,9]
    C[18] = [2,0,29,4]
    C[29] = [14,5,15,18]
    C[5]  = [29,15,12,3]。

0与5不相邻，邻集无交，所以没有长度≤2路线。0的其它邻点行是C[20]=[0,28,24,27]、C[2]=[1,18,11,0]、C[9]=[22,19,0,14]；它们都不连C[5]中的任何点，只有18—29给出中间边。因此唯一三步controller walk为

    0 --p0--> 18 --p2--> 29 --p1--> 5。

旧`controller_structure.json`的NB3_counts[0][5]=1也与这个字面检查一致。本次未重算controller NB3表。

这条路线的中央秩列为[T2 ell1,ell3,ell1]，其det=2 mod5；也属于已有全36turn满秩证书。因此对每对端点x∈fiber0、y∈fiber5，恰有一组系数、恰有一条源图长度3路径。controller无≤2路，故这也是源图唯一的≤3路径。

## 3. 反向两步平面与首边逆像线

以z∈fiber18、v∈fiber29记两中间点。正向边式为

    z = T0 x + alpha ell1；
    v = T2 z + beta ell3；
    y = T1 v + gamma ell0。

固定任一保留的y∈fiber5。由反向ports0、3可得全部可能的z为仿射平面

    P_y = T3 T0 y + span(T3 ell1, ell2)。

字面T3 ell1=(1,3,4)，与ell2=(0,0,1)独立，所以P_y确为25点平面，并分成五条方向ell2的平行线。D18在每条线上恰删一点，因此|D18∩P_y|=5。

对其中每个已删z，首边全部逆像是

    L_z = T1 z + span(ell0)，

因为T1 ell1=ell0。D0在该五点线恰删一点，所以L_z中有4个保留x。

对这样的x、y，源图唯一的≤3路径经过已删除的z。诱导子图不会新增路径，因此x、y在诱导图内不能三步可达。任取一个保留y即得反例，足以排整个transversal域。

## 4. 无须枚举的精确跨纤维反例数量

平面方向span((1,3,4),ell2)与span(ell1)交仅{0}。因此P_y中不同z不能落在同一ell1平行线；相应L_z两两不同且不相交。

先记A为唯一短路径的fiber18中间点已删事件。五个已删z各有4个不同保留x，所以固定保留y时|A|=20。

再记B为fiber29中间点已删事件。最后一边逆像是五点线

    T0 y + span(ell1)，

它与D29恰交一个点w。这个w在fiber0的两步逆像为

    T1 T3 w + span(ell0, T1 ell2)。

T1 ell2=(0,3,1)，与ell0独立；该25点平面分成5条ell0平行线，各被D0删一点，故|B|=20。

对A交B，w已固定，前一边在fiber18的逆像为T3 w+span(ell2)，与D18恰交一个点z；再向前的L_z有4个保留x。因此|A交B|=4。

所有端点x、y均已保留，源的≤3路径又唯一，所以失败恰等于至少一个中间点被删，即A并B。每个保留y恰有20+20−4=36个保留坏搭档x。fiber5有100个保留y，因此fiber0与fiber5之间恰有3600个无序不同端点对不能三步可达（反向合计7200个有序项）。这是所有transversal模式共同的精确局部计数，不是生成图的测量值；全图其它纤维可再增加失败，所以全图坏无序对至少3600。

## 5. 对一般诱导搜索的准确启发

该排除不包含任意>1920点的maxdegree16诱导子图。一般删除模式可以有不均匀纤维大小、整条线被删或某方向不止一点损失，均不满足本次transversal前提。

真正可迁移的是唯一旧distance3路径的保留闭包。若源图x、y旧距离为3且唯一短路径为x-p-q-y，令k_v表示保留，则诱导D3必须满足

    (k_x and k_y) => (k_p and k_q)，

即两条closure clauses：¬k_x∨¬k_y∨k_p、¬k_x∨¬k_y∨k_q。不能把它误用于“distance2唯一最短路”：那时其它三步路线仍可能补偿。

对本条controller路线还有直接几何版本：若保留y且删除z∈P_y，则必须删除整条L_z，否则仍有保留坏端点。均匀地每条L_z只删一点正好与此闭包冲突。

maxdegree16另要求每个保留v在其20个旧邻点中至少删4个；若希望超过1920点，还需Σk_v≥1921。闭包与度数约束必须共同处理；本次没有建立或求解这样的模型，也没有证明一般诱导子图不存在。
