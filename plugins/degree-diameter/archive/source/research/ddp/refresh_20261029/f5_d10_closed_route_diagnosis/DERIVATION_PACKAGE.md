# 闭路线并集与三角holonomy的全源覆盖条件

## Target

解释原两批3750点10度候选为何局部补路成立却不能实现完整D4，并判断允许各控制边独立选系数是否值得搜索。目标是准确的同纤维全源覆盖判据及一个会改变下一生成规则的结论。

## Status

COHERENT AS STATED。精确判据与五环有限证据支持固定控制器/矩阵、逐控制边固定系数集域的整体排除。证明详见PROOF_PACKAGE.md；实际Gemini3.8Flash/high审阅SUCCESS、SOUND AS STATED，见reviews/ddp/f5_d10_oddcycle_20261029.DISPOSITION.md。审阅为静态核对，未冒作第二次数值运行或Lean定理。

## Invariant Object

对根控制器a及每个源坐标x，所有长度至多4返回a的控制字终点位移并集。要求的是对每个x都等于F5³；固定x=0的覆盖数只是该对象的一片，不能替代全源量词。

## Assumptions

- 固定原30控制器与F5四矩阵；每条三角边选任意三元系数集、外部边选任意二元系数集，反向负集。
- 允许不同控制边各自选集，不允许随纤维坐标改变。
- 只分析保存的五环0–20–28–22–9及各根的完整短闭字，不借用未证明的控制器端口自同构。

## Notation

B是0/2/4步回退位移并集，与源坐标无关；H是正向三角闭字的矩阵乘积，Z是该字三噪声的27点像；h=(H−I)x；反向字的位移是−H⁻¹(h+Z)。G(Z)是两方向三角位移并集对全部实际h的交。U是所有1000种局部三角系数选择的G之并，仅作放松。

## Derivation Strategy

先按全部真实闭字分离不随源坐标变的回退位移与随源漂移的三角噪声；然后严格按全源量词取交，最后将必要的局部差集形状条件沿同一实际五环联立。

## Derivation Map

1. identity：逐边代入确定每个短字的线性部分与噪声列。
2. finite identity：五个根均有1/0/4/2/28个长度0至4的闭字；四步全部回退。
3. identity：偶数回退只依赖差集，三元集差集满F5，二元集只有两种形状。
4. identity：全源同纤维覆盖当且仅当B∪G(Z)=F5³。
5. proposition：rank(H−I)≥2时，两个三角方向对任一位移最多服务2·3^r个源像值，少于5^r，因此G为空。
6. relaxation：G(Z)⊆U，故B∪U=F5³是必要条件。
7. finite certificate + proposition：五个根的必要条件各迫两外部边形状不同，与奇五环矛盾。

## Main Derivation

全源条件可以写成：对所有h∈im(H−I)，B∪(h+Z)∪[−H⁻¹(h+Z)]=F5³。因为B不随h变，等价于B∪G(Z)=F5³。把不同源的三角可达集合取并会把量词方向弄反，本批始终取交。

根0的H−I秩实为1，推翻最初可能满秩的解释；不能据54<125直接排它。根20、28、22实际秩2，其G为空可由27点笛卡尔积与仿射子空间交的计数证明，不依赖三角参数逐项试败。根0和9的所有G之并各有40点，仍须允许它们补回退遗漏。

根0共有16个外部差集形状可通过完整三角补充的必要检验：8个回退本身覆盖125点，另8个回退只覆盖123点且可由合适三角参数修补。这直接反驳“回退必须单独全覆”的过强命题。正确条件保留两路互补。

最终五根放松通过形状数为16/16/4/4/6，但每项均要求根的两条外部边的差集形状分别为1和2。位置依赖的选择因此不能任意分开实现：沿同一五环联立后产生奇环矛盾。结论排的是整套固定矩阵、固定边系数操作，不是全体10度图。

## Remarks and Interpretation

- 此前不知道的具体问题已回答：不仅旧均匀系数失败，逐控制边改变系数仍不能跨过同一外部五环的共同约束。
- 三角路线的覆盖对某个源确实有用，但其中心漂移使它无法为所有源共同补同一个缺口。rank≥2时这种差别由计数完全确定。
- 下一生成规则应改变holonomy或控制器路线，而非增加同矩阵系数样本。当前受控候选是将三角闭字矩阵乘积设I，使三角噪声不再随源坐标漂移；这是实质改变矩阵规则，尚未得到新完整图。
- 同一3750点20度图的纯删边路线已由另目录的每边唯一三步见证关闭；750点平移商的更高普通覆盖亦由路线容量≤5关闭。这些结论针对不同操作，不能互相扩大范围。
