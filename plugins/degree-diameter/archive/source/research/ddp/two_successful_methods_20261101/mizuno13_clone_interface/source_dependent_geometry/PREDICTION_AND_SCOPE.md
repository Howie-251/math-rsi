# source-dependent仿射满27块的g容量问题：事前预测与模型域

只沿已保存的十三度88452源，研究315个无self/P且M仿射、F=A_matching_port的常规source。固定W=<e0,e1>，每个满27仿射横截块写作H_R+c，其中H_R是R:F3^3→W的图，R有6个F3变量，共729个线性斜率；c只改变相位，不改变输出超平面方向或K=I的M分离条件。本次完整729域是为判定gmax的有限代数域，不是随机寻找更好H或全图packing。

对每port令ell=A^-1b∈W，取W上的非零线性L满足L(ell)=0。H_R+ell的源法向为f_R(w,t)=L(w−Rt)。选择一个与目标b独立的W方向e，令A^-1e=(w,t)；该输出超平面包含目标W当且仅当L(Rt)=L(w)，这是一条6变量线性方程。M分离因F=A等价于f_R(A^-1d)非零，是一条线性不等式，与相位无关。

先查全部入射到同target的四个普通噪声方向是否为W中四个不同射影方向，并查M目标位移d是否在W内；不据局部例子套用。按四条g方程与一条M非零条件的规范distinct几何类型评估729个R，只保留本地M合法者，记录g=max可含W输出数。

具体待检验猜想是局部M合法是否强迫g≤2；若只支持≤3或更松，必须如实保留，不把所需容量结论当条件。给每source的真实gmax，使用必要计数：每个不含W输出必须独占目标，所以4T≤1092−2B，B≥sum_selected(4−gmax)。等价加权必要界sum_selected(12−2gmax)≤1092；异常49 source只可乐观各加一块，不冒已验局部可行。

准备和计算合计单worker≤30CPU，0solver/BFS/完整图/相位梯子。成本先测至多三个distinct类型；若不清楚则停在代表，不自动放大。即使上界超过213也仅说明这条门没挡住，不能称有可行构造。
