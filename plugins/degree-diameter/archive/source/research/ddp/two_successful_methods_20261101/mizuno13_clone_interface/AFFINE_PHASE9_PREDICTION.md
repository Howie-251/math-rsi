# u0已成功27块的九个仿射相位：事前预测

只使用已经通过的H={(-z,0,a,b,z)}，不换H、不扫其它fiber。W=<e0,e1>给九个不同相位H+c，c=(c0,c1,0,0,0)。由于K=I且f(d')=1，ordinary/M在f商中的层差始终为1，预测九个相位都局部负载≤1。

由H∩W=0，ordinary port零点被占当且仅当c属于该port输入方向直线。c=0属于四条线，非零c恰属于一条。因此非零相位只占一个ordinary目标零点。M零点对应输入−d'=2e4；它在H+2e0中，预测仅相位c=2e0含M零点。排除这个可选的零点预算特殊相位后，八个相位仍可用，其中七个非零相位只占一个旧零点；排除不是因为该相位局部不合法。

实际只展开9×27个中心的普通＋M＋P旧邻域及每port的目标仿射超平面方程，检查无交叠、351点并集和zero占用。0图/BFS/全controller模型。其它source块在同target的81点超平面必须平行并错相，否则至少交27点；总体积或zero必要门不能替代这一相容条件。
