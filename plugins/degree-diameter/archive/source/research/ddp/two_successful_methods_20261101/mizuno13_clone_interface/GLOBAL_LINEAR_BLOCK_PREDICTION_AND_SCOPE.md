# 原点线性27块的全局必要门：事前范围与零点反预测

下一拟议域是在无self/P且M仿射的源fiber中，依同一不变泛函方法各选一个过原点的三维线性H，选择至少213个满27块。拟议体积必要门3*ordinary_count+x_mate<=9只数目标fiber总量，不能忽略固定旧顶点容量。

在启动任何336局部批处理或HiGHS前，先检查零噪声边：普通关系y=A x+t b在x=t=0时必到目标fiber零点。对非self源，这些边真实存在且四个目标互异。每个入选H含0，所以每块占用四个旧零点；cap14只允许各零点负载1。因此预期更强必要门是每目标ordinary_count<=1，总块数<=91，直接不可能达到213。

这个门只排每个块都含自身fiber原点的域，不排非零仿射横截面。若数据支持即停止原点controller模型，不运行注定无意义的可行性求解。仍保留u0局部27块成功结果。
