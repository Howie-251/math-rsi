# 平移型 F3³ 仿射线提升：可执行评价器

## Target

给定简单四正则控制图C（拟用31–33点），选择每条无向边的项目方向，输出
度12、阶 `27|C|` 的完整候选，并精确判断直径≤3。31–33点对应837/864/891，
均超过本轮 `(12,3)` 的810快照，但没有合格候选之前不能声称新下界。

## Status

**COHERENT AS STATED；已实现评价器，等待合格控制图。** 没有在 `A³` 存在零元的
控制图上启动纤维搜索。准备阶段使用K5小控制图作实现回归，135点结果不是研究发现。

## Invariant Object

对每个控制起终点 `(s,t)`，全部长度≤3路线的方向张成空间之并。

## Assumptions

- C简单、无向、四正则，且其邻接矩阵 `A³` 逐项严格正。
- 每条无向控制边e选择 `v_e∈F3³\{0}`，倍数相同者视为一个项目方向，共13种。
- 提升边为 `(u,x)~(v,x+λv_e)`，`λ∈F3`。因此本特殊族固定 `M=I,u=0`。
- 同一边的正反向使用同一项目方向，保证无向一致性。
- 此族不声称包含公开810图；恢复的810图表使用非平凡线性矩阵。

## Notation

纤维编码为 `x0+3*x1+9*x2`。方向通过第一个非零坐标归一化为1，得到13个代表。
对控制路线 `P=e1...el`，令 `S(P)=span(v_e1,...,v_el)`；空路空间为 `{0}`。

## Derivation Strategy and Map

1. 沿边逐步代入，路线终点恰为 `x+Σ λ_i v_ei`。
2. 对固定控制路线，所有终点恰为 `x+S(P)`。
3. 对所有路线取并得到完整距离球；通过平移对称性只需每个控制起点的纤维0。
4. 将27个向量编码为27位掩码，以位或求并，精确计数缺失向量。
5. 搜索输出由独立程序展开成完整边表，重读后全源BFS确认。

## Main Derivation

### 精确覆盖条件

对每个 `s,t` 必须且只需

    ⋃_{P:s→t, |P|≤3} S(P) = F3³.

这不是只要求每一条三步路线满秩，也不是只统计满秩路线数量。
两步路线、立即反向路线、闭三角形和不同平面的共同覆盖均在评价中真实计入。

所有全局平移 `(u,x)↦(u,x+a)` 都是图自同构，因为它保持差向量。
因此每个控制根纤维0的BFS覆盖正确代表该控制顶点的27个根；全图不满足D3的
有序点对数等于27倍这些代表根的不满足点对数。

### 度数和简单性

每个控制邻点提供三个不同目标纤维向量，不同控制邻点互不重叠，故度数恰为12。
控制无自环保证提升无自环，边按无向集合保存；总边数为 `6*(27|C|)`。

### 局部条件的准确范围

如果控制顶点s只属于一个三角形，则该三角形的三方向必须线性独立。否则三角形
返回像至多一个9点平面，s的其余两条控制边往返各至多增加两点，总并至多13，
不能覆盖27。若s属于多个三角形，此论证不能要求每个三角形都独立；不同平面
可以联合覆盖，程序不强加这项限制。

对相邻控制点u,v，背返三步路线给出含 `v_uv` 的平面。这样的平面对应商空间
`F3³/<v_uv>` 的四个项目方向。若控制图无四圈，则u,v至多有一个共同邻点，
其两步路线最多增加一个平面；少于四个背返平面不能覆盖27。若允许多个共同
邻点或其他三步路线，必须重新计算实际并集；程序仍直接计算全部路线。

## Implementation and Verification

- `translation_search.cpp`：独立检查控制图简单四正则、A³全正；预计算13方向的一、二、
  三方向张成掩码；逐路线位或评价全缺点数。单边方向替换与有界模拟退火只影响搜索，
  不影响最终精确验收。预算到达或缺点为0即停，保存完整方向配置。
- `expand_verify.py`：不使用搜索掩码，逐坐标生成全部边，保存 `.expanded.edges`，
  从该文件重新建立邻接，全源BFS，并核对代表根分数及其27倍关系。
- K5两份零搜索时长回归均得到135点、度12、直径3，独立全源BFS与搜索评价一致。
  它们只是低成本实现检验，不改善810下界。

## Boundaries and Non-Claims

方向搜索没有扩大到任意邻接矩阵；本族是所有可逆仿射图表的严格特殊情形。
控制图A³全正只是必要条件；此平移族失败不能关闭非平凡M的一般仿射族。
未见合格31–33点控制对象之前只保留就绪程序，不假称计算已在后台运行。

## Open Risks

尚待取得控制图，随后需要检查项目方向是否能共同满足全部路线空间覆盖。
每个局部满秩结论均不能代替完整评价。有效候选仍须核对当前公开纪录及后续正式审阅/Lean。
