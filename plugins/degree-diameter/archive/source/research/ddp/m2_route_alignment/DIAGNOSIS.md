# Head–block 失败定位：有商路径，缺端口同位

只读分析了原公开 650 图、40 条 matching 边扩张的 676 图，以及 cyclic-pairing 的 676 图。没有生成、改动、优化或试验新图。主诊断单核 CPU 0.309 秒，远低于 30 秒上限；补充比较仅汇总已存计数。

**明确结论：在这三张固定 block 骨架的 head–block 条件中，没有“block 商中不存在两步以内路径”的端口无关缺口。** cyclic 的全部 588 个坏对，以及 matching 扩张的全部六个坏对，都已有若干潜在 block 路线，但两条叶边落在中间 block 的不同叶端口。这个逐对结论不证明所有端口对齐要求可同时满足，也不排除其他点对类型或全局容量的阻碍。

## 精确计数的对象

设 head 属于 group g，目标 block 为 b，且 b 不在 g 中。令 `L_g` 为 g 的二十个 leaves，`L_b` 为 b 的四个 leaves，E 为普通叶图。使用已证明的精确条件：

`d(head_g,b) ≤ 5 ⇔ d_E(L_g,L_b) ≤ 2`。

直接叶边数记为 D。对每个潜在中间 block k，令 I 是在 k 这一端、另一端属于 `L_g` 的关联集合，J 是在 k 这一端、另一端属于 `L_b` 的关联集合。则：

- 潜在关联对路线数 `Q = Σ_k |I_k| |J_k|`，只看 block 关联，不要求端口对齐。
- 真实叶两跳数 `T = Σ_k Σ_port |I_k(port)| |J_k(port)|`，要求两条关联在 k 落到同一个 leaf。
- 因此真实条件为 `D > 0` 或 `T > 0`，不能把 `Q > 0` 当作充分条件。

另独立统计了潜在中间 blocks 数量，以及不计平行边的 block 两步 walk 数。对本次所有坏对，这两种计数都恰等于 Q。程序从完整边表重建关联，再从每个 head 做完整 BFS；上述精确条件与全部 9,500 个跨 group head–block 对的 BFS 判定逐项一致。另 385 个本 group head–block 对均由树边直接相邻。

## 与正控的实际对齐比较

为排除已经有直接叶边的简单情形，下表只比较 D=0 的 head–block 对：

| 图 | D=0 对数 | Q 最小/中位/最大 | T 最小/中位/最大 | T=0 对数 |
|---|---:|---|---|---:|
| 原 650 | 1,000 | 10 / 10.5 / 11 | 2 / 3 / 4 | 0 |
| matching 扩张 676 | 1,173 | 3 / 10 / 16 | 0 / 2 / 5 | 6 |
| cyclic 676 | 1,170 | 4 / 10 / 16 | 0 / 0 / 10 | 588 |

原 650 的 T 实际只取 2 或 4，各 500 对；表中中位数 3 是这两类之间的统计中位数。它的 1,000 对有 10,500 条潜在关联对路线，恰有 3,000 条对齐叶两跳，并且每对至少两条。

cyclic 的 1,170 对共有 11,386 条潜在关联对路线，实际两跳总数 2,285；其中 588 对为零，而少数对有多达十条。这说明商路线总量与实际覆盖分布是不同问题：当前 rank-mod4 端口分配有很多未对齐路线和覆盖重复。这里没有证明存在能消除全部零项的共同端口分配。

## 可以直接进入后续模型的同位约束

把 block k 的每条关联 e 分配到端口 `p_k(e)∈{0,1,2,3}`，每个端口容纳四条关联。对一个 D=0 的 head–block 对，其潜在关联对列表为 R，则精确覆盖约束是：

`OR_{(k,e,f)∈R} [p_k(e)=p_k(f)]`。

每个现有坏对的全部候选同位关联已经导出，包括完整边表中的零基 edge id、中间 block 原顶点标签、两条关联当前叶顶点和端口。例子：

- cyclic 的 head 0 到 block 28 当前距离六。一个潜在中间 block 是 57：边 id 77 为 `(19,74)`，边 id 145 为 `(36,75)`。它们在 block 57 分别落在 leaf 74/75，即端口 0/1；把这两条关联放到同一个中间叶端口即可实现这一条两跳路线。该坏对共有八个这样的替代路线要求。
- matching 扩张的 head 650 到 block 509 当前距离六。经 block 520 的一个选项是边 id 24 `(4,660)` 与边 id 645 `(129,351)`；中间叶为 4/129，端口 0/1。该坏对共有六个替代路线要求。

上述是关联重分配的条件，不是在当前固定边表中宣称已有路径。不同坏对可共享、竞争同一关联；修复还必须满足每端口四条的容量，并保留当前已覆盖的其他 head–block 条件。更不能仅修复 HB 就断言 HL/BB/BL/LL 或整图直径五成立。

- `summary.json`：三图真实终态、范围、成本和分类。
- `baseline650.summary.json`、`expanded676.summary.json`、`cyclic676.summary.json`：路线分布及示例。
- `*.pairs.tsv`：所有跨 group HB 对的 D、Q、T、实际距离和分类。
- `*.bad_pair_alignment_constraints.json`：全部现有坏对的替代同位约束，含关联边的完整标签映射。
- `without_direct_edge_comparison.json`：D=0 子集的完整直方图和路线总数。
- `diagnose.py`：完整只读计算；`compare_saved_counts.py`：只汇总已存计数，不再遍历图。

本阶段没有启动端口求解、图优化或新候选。
