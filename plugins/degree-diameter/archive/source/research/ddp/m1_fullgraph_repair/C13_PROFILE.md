# C13 电压修复：唯一 120 秒轮次结果

2026-10-26，M1 机制内的实际生成改变。结论：**没有获得直径 4 的 702 顶点图**。原候选仍为本轮最好对象：七正则、直径 5、1,404 个坏无序点对。没有继续第二个 seed 或延长预算。

## 生成范围与基线

保留原图的 54 顶点简单七正则商图，189 条无向基边各拥有独立 \(\mathbb F_{13}\) 电压，反向取负。展开为 702 顶点，边为

\[
(u,x)\sim(v,x+z_{uv}).
\]

基图无自环或平行边，故任意电压赋值均生成简单七正则图。该生成范围放开了原 \(C_{27}\) 的关系，同时保留 \(C_{13}\) 平移自同构；它不是任意邻接矩阵搜索。

优化器从每个基顶点的纤维零点做精确四步 BFS，共 54 个根。若未覆盖顶点总数为 (s)，则完整图坏无序点对数为 (13s/2)。目标是 (s=0)，没有以局部改善替代完整图验收。

`prepare.py` 从原 702 图诊断数据提取基边电压，并重新展开比较全部边；边集完全相等。C++ 优化器保存的基线也与原图边集相等。独立验证器检查全部 702 个根，原始距离直方图逐项复现：

\[
(702,4914,29484,160758,294138,2808),
\]

分别对应距离 0 至 5。这是已知未合法候选的实现回归，不是新下界。

在原电压状态，对全部 189 条基边的另外 12 个电压值作精确评估，计 2,268 个合法邻居。

| 原代表缺损 (s) | 216 |
| 改善的邻居 | 0 |
| 相同目标值的邻居 | 0 |
| 代表缺损增量最小值 | +38 |
| 增量中位数 | +70 |
| 增量最大值 | +108 |

所以原图在**独立修改一个基边电压**的完整邻域中是严格局部最小值。此计算不排除两个或更多电压的联合改动。

该测量约 0.80 秒。使用实测分位设置初始温度

\[
T_0=56/\log5\approx34.7948,
\]

令 +56 的初始接受概率为 20%；120 秒内按时间平滑降至 \(0.02T_0=0.695896\)。温度单位为 54 个代表根的未覆盖总数，不能和原全图 switch 的坏无序点对温度混用。

## 单次试验的实际提案

保存了每对基顶点全部长度至多四的不同电压线性式。当前缺失值 (y) 的一个路径形式为 \(L=\sum c_ez_e\)，选取 (c_e\ne0) 后令

\[
z_e\leftarrow z_e+(y-L)c_e^{-1}\pmod{13}.
\]

这保证所选路径补上一个当前缺失值，但仍以完整目标决定接受，允许其对其他纤维造成损失。

- 约 70% 提案采用上述单电压定向改动。
- 约 20% 再尝试第二个缺失值的定向改动，并禁止修改第一条路径涉及的边，保留第一条路径保证；若无法找到合适第二条，则保留单改动。
- 约 10% 随机改动一个电压；定向提案偶尔无法构成时也回退到单电压改动。

实际提案始终保持固定基图和简单七正则展开，没有引入任意自由边、通用 SAT 或额外轨迹。

## 解释与边界

改变了真实生成自由度，但该预算内的定向一／二电压改动没有越过原目标值。完整单电压邻域结果解释了为何不能指望从原图直接贪心下降；升温确实使过程离开原图，而非原先全图 switch 的零接受状态，但没有得到更好的完整对象。

这不是 189 电压族的穷尽排除，也未证明多电压联合修复不可能。没有数学或实验依据时，不用另一个 seed 或更长预算重复同一轮次。后续若继续该固定基图，需要能控制新缺损的共同电压条件或更明确的联合改动机制；也可转向同一 M1 内有新结构依据的其他商图。
