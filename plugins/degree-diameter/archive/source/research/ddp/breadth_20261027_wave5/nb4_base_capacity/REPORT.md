# 两个6基点结构的NB4容量：均被8词短见证排除

目标为4正则exact-NB4控制器78点（6基点×C13）。若有该控制器，结合root另行保存的F3^4 universal chart才可条件性地产生degree12、D≤4、6318点图。本次没有生成控制器或搜索电压，两个固定base均在容量必要条件处失败。

## 表示与完整计算

A严格使用`wave3/controller_lift192/base_words.json`原12条具名边，不合并平行边；树edge ids为[0, 1, 2, 4, 6]，7个自由edge ids为[3, 5, 7, 8, 9, 10, 11]。B为简单octahedron K2,2,2，部为{0,1}、{2,3}、{4,5}，按端点字典序给12条边命名；树为[0, 1, 2, 3, 4]，自由边为[5, 6, 7, 8, 9, 10, 11]。两棵树均按既定具名边顺序作Kruskal选取，树电压规范化为0。

每个base的每个根都完整枚举108条恰4步非回退词；仅禁止立即反走同一具名edge，平行的其他edge仍允许。对36个有序基点对，保存7整数系数形式及逐坐标模13形式。系数均在[-4,4]，故模13约化在这些形式上是单射；本次两个容量矩阵整数值和mod13值相同。没有把普通≤4步可达性当成exact-NB4。

## 短见证与范围

A的slot(0,0)只有8条具名NB4词，产生8个不同形式。以自由变量x0至x6表示，它们为±2x0、±x1、±(x5−x3)、±(x6−x4)。无论给7个变量赋何种C13值，都至多到达8个fiber元素，不能覆盖13个。其容量最小值8的全部slot为[[0, 0], [1, 1], [2, 3], [3, 2], [4, 4], [5, 5]]。

B的slot(0,1)（同一个部中的两个opposite基点）同样只有8条具名NB4词、8个整数和mod13形式。全部紧slot为[[0, 1], [1, 0], [2, 3], [3, 2], [4, 5], [5, 4]]。8个形式和8条具名词的明确列表保存在`RESULT.json`的obstruction字段。

因此两个base都不能产生要求的78点C13控制器，应立即止，不开7参数搜索。更强地，两处短见证连具名词数本身都只有8，所以同一固定base的任何uniform fiber大小≥9都无法exact-NB4覆盖；这一句只使用投影词数，不依赖交换群线性化，也没有扩接其他group搜索。结论不排除其他base或一般78点quartic控制器。

两者所有对角slot都不含恒等零形式。A对角形式数为8、8、16、16、8、8；B各为20。对角没有自动保证，但两个base已被更直接的容量不足关闭，无需继续研究参数满足条件。
