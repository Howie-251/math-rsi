# F2³四逆标签通用三步chart：完整无解与Fano障碍

结论：**全部197568个规范输入均未给出36词通用rank3 chart；还有一个不依赖枚举的Fano商空间短矛盾。** 全空间最佳为28/36词满秩。root对保存的最佳候选完成唯一一次36词有限校准，逐词秩与逆关系完全一致。没有控制图搜索、图BFS或新下界；本参数变体在此收束，不更换域、维数或步长。

这是route-chart机制的一个参数变体。其结论适用于下面精确的线性单词通用要求，不外推其他多route覆盖、edge-local矩阵或一般degree8/D3图。

## 覆盖公式和唯一规范化

四标签逆映射为[1,0,3,2]。一步为 `x↦A_t x+λv_t`，x∈F2³、λ∈F2；反边必须使用

    A_(t⁻¹)=A_t⁻¹，v_(t⁻¹)=A_t⁻¹v_t。

特征二使一般逆公式中的负号消失。对三步字a b c，直接展开得

    x₃=A_c A_b A_a x₀
       +λ₁ A_c A_b v_a+λ₂ A_c v_b+λ₃ v_c。

故可控三列为 `[A_c A_b v_a, A_c v_b, v_c]`。秩三恰好保证沿这一个controller词从任意fiber初点能到达全部八个fiber目标。若全部36个约化长度三字均秩三，配合quartic exact-NB3控制器C，将给8|C|点、degree8、D≤3；超过保存253需|C|至少32。本轮所需chart不存在，未进入控制图构造。

AAA和BBB满秩分别强迫v_A、v_B非零。GL3(F2)在非零向量上传递，同一次换基可令v_A=(1,0,0)，同时共轭A、B并变换所有v；秩和逆关系保持。因此只固定v_A的第一标准向量，不限制矩阵轨道。枚举所有168个A、168个B及七个非零v_B，完整输入数为168²×7=197568。

## 不依赖枚举的统一纸面障碍

记四标签向量为v_t。对合法词a b c，左乘可控矩阵以A_c⁻¹，秩等于

    rank[A_b v_a，v_b，v_(c⁻¹)]。

首先，四个v_t必须非零且两两不同。非零由重复三字词强迫。若v_d=v_b且d≠b，取c=d⁻¹、任取a≠b⁻¹，词a b c合法，但后两列相同，秩至多二，矛盾。

现将这四个不同非零向量视为Fano平面的四点。必存在一个标签b，使另外三个向量在V/⟨v_b⟩中分别占据全部三个非零方向：

- 若四点不含三点线，任取b；另外两点投影相同将意味着它们与b三点共线，故三投影互异。
- 若含三点线，取线外的第四点为b。该三点线对应二维子空间，它与⟨v_b⟩相交为零，所以其三个非零向量在商空间中互异且非零。

固定这样的b，任取a≠b⁻¹。若A_bv_a在该商空间投影为零，第一、二列已相关，任取d≠b。若其投影非零，从另外三个向量中选d≠b，使v_d投影与之相同。两种情况都使

    rank[A_b v_a，v_b，v_d]≤2。

取c=d⁻¹。第一处约化条件由a≠b⁻¹保证，第二处由d≠b保证，因此得到一个合法三字词a b c却秩至多二，矛盾。这个论证排除了所述全部36词通用chart；它没有额外证明计算所得“最多28词”的精确上界，后者仍是完整有限枚举结论。
