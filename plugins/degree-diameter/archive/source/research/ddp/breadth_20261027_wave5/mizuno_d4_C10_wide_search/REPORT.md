## 原始构造与两套充分条件

实际读取作者原始 [degree12-diameter4](https://github.com/rmizuno42/ddp/tree/main/results/degree12-diameter4) 目录的 [proof_ja.md](https://github.com/rmizuno42/ddp/blob/main/results/degree12-diameter4/certificate/proof_ja.md)、构造JSON、route/pencil证书、搜索provenance和verifier。原件保存在相邻只读的 `../mizuno_d4_source/`。

root新发现的F3⁴ quotient chart在108个约化四字上均满秩；本代理一次检查108字及逆条件通过（0.0036CPU秒），没有重跑旧324字。它给出“quartic exact-NB4控制器n≥73 ⇒ 81n≥5913、degree12、D≤4”的充分入口，但本轮没有这样的控制器。该chart的balanced≤4词只覆盖33/81 fiber坐标，长度二词的往返插入族各只覆盖45/81，因此不能直接替换到作者girth5的72点控制器。

作者5832图采用另一张F3⁴ chart：100/108个约化四字满秩，例外为 `AABD ACDD BBAC BDCC CABB CCDB DBAA DDCA`。作者72点控制器确实不是exact-NB4：共有720个有序缺项，每个根缺九或十一项，全部72对角均缺。其真正可复用的宽证书是：

```
每个控制器有序对可由 identity、十二个reduced2词之一、
或一百个rank-good reduced4词之一到达。
```

十二个reduced2词各有十一条长度≤4、自由约简至同词的walk，四个rank3超平面含共同rank2核并覆盖81点；所有这些walk的矩阵积相同，故任意起点的affine中心相同。33个balanced≤4词全部在任意逆一致控制器根返回，矩阵积I；其十八个rank2平面并覆盖81点。这些性质完全local，不依赖原C9电压或girth。已在 `repair_comparison.json` 核对原chart的全部十二族与balanced覆盖；这与quotient chart是两套不同条件，不能混用。

## 八点base与电压规范

原controller是八点无环四正则multibase的C9覆盖。其16条具名基边完整保存在 `construction.json`；边号按原文件顺序0..15。内部2factor由两组双边0–2、1–3及方圈4–6–5–7–4构成，其余八边构成0–4–2–7–1–5–3–6–0的C8。

本次保留原base和原label（inverse=[3,2,1,0]），改为C10电压。选树边 `{0,2,3,4,6,7,9}` 规范为零，剩余自由边依次：

```
1,5,8,10,11,12,13,14,15.
```

边1、5为平行边的电压差，必须非零；其他七项任意。树规范是逐基点平移fiber编号，不改变labels或宽route证书，覆盖全部9²·10⁷=810000000个合法规范赋值。本轮仅有限采样，不穷尽该父族。

候选控制器顶点为 `(g,i), g∈{0,…,7}, i∈Z10`；基边 `(g,h,δ,t)` 连 `(g,i)` 与 `(h,i+δ)`。若宽证书达到零缺项，最终图为 `(g,i,x), x∈F3⁴`，边为 `(g,i,x)~(h,i+δ,A_t x+λb_t)`、λ∈F3，阶6480、度12、38880边、D≤4。

宽证书的64个基点对槽有10–19个不同C10电压函数，必要容量筛通过。原C9全部64槽覆盖九状态的小校准已复用。把原16项整数电压直接解释为mod10再作该树规范，首自由赋值为 `[1,1,1,1,1,5,6,7,5]`，已有首评分44个代表缺项、440个有序缺项，本次C++首评分与44相等。

## 必须分开的止损范围

1. **原base的exact-NB4大覆盖：** 基点0..3各仅十条闭NB4基walk；若覆盖self，至少一对反向walk同返self，故最多九个不同fiber目标。任何≥10-sheet普通覆盖都不能exact-NB4。这个结论没有排除作者宽D4证书。
2. **强制20个C4的六自由C10模板：** 用factor forest加连接边作树规范，边1、5置5、K22圈电压为零，六条C8电压自由；该规范完整覆盖此固定因子模板。虽然self和sheet对顶可由I/R2处理，宽证书仍在0→4等槽仅有九个函数，不能覆盖十状态。因此未运行百万枚举。见 `C4_wide_C10_capacity.json`。
3. **本次未强制C4的九自由父族：** 上述容量为10–19，尚无全族排除；本profile仅失败后按指令停止，不把六自由障碍或有限搜索外推到父族。

source侦察中另一4-base×C19的76点C4模板也因18<19的符号容量立即止损，未运行图生成或搜索，未接续该线。
