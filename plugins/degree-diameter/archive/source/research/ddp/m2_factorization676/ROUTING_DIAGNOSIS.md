# K26 一因子 3/4 骨架：对角配块的统一障碍与保度错位

**结论：同 index 对角配块不能作为 D5 搜索入口。** 不论如何把每个 block 的 16 个关联分配到四个叶端口，完整图至少有 **92,300 个距离超过五的无序点对**。其中跨不同 index 的叶–叶坏对数恰为 **73,060**，跨不同 index 的 blockhead–blockhead 坏对数恰为 **520**；另有至少 **18,720** 个跨 index 的 blockhead–leaf 坏对。这是指定对角骨架的统一结论，不是某个端口种子的表现。

父代理随后授权的唯一循环错位配块保持所有度数，并具有不能由每组局部重编号消去的闭路错位。因此它确实改变了上述结构障碍；这不保证五步路由。下文将纸面结论与已经保存的两个唯一实例分开。

## 1. 一因子与每个 block 的 16 个关联

组集合为 $\mathbb Z_{25}\cup\{\infty\}$，其中实现标签 $\infty=25$。颜色 $t$ 的一因子是

\[
M_t=\{\{\infty,t\}\}\ \cup\
\{\{t+k,t-k\}:1\le k\le12\},
\]

有限标签运算模 25。每色有 13 个不相交组对，覆盖全部 26 组。有限不同组 $g,h$ 的唯一颜色为 $t=(g+h)/2\bmod25$，而 $\{\infty,g\}$ 的颜色为 $g$；2 在模25下可逆。因此 25 个颜色恰分解 $K_{26}$ 的全部 325 条边。

令 $c=t\bmod5$。有序 selected list 为

\[
I_t=(c,c+1,c+2)
\]

（下标模5），在 bonus 颜色 $0\le t\le4$ 时再加 $c+3$。记 $q_t=|I_t|=3$ 或4。五个 bonus 一因子共有 $5\cdot13=65$ 个四边组对，其余260个为三边组对。叶边总数

\[
260\cdot3+65\cdot4=1040.
\]

固定任一组 $g$ 和 block index $i$。由于每组每色恰出现一次，基础三位置包含 $i$ 恰在 $c=i,i-1,i-2$ 三个余数类中，每类有五个颜色，贡献15。bonus第四位置还在唯一颜色 $t=i-3\bmod5\in\{0,\ldots,4\}$ 中贡献1。因此每个 block 恰有 **16** 个叶边关联。

把这16个关联按任意规则均分为四份，每份交给一个叶端口，就使每叶外度4。rank modulo4 是其中一个确定性均分规则。加上树边后，每个完整图顶点恰为5度；总点数676、边数1690。组对之间每端的 selected blocks 各使用一次，故无重复叶边或自环。此度数证明不依赖同 index 配对，适用于后文的任何逐组对双射。

## 2. 对角规则保留全局 index，组内换名不能解除

原规则把 $(g,i)$ 与 $(h,i)$ 配对。普通叶图的每条边保持 index $i$，因而它分为五个互不相连的 104 点部分

\[
E_i=\{(g,i,p):g\in\mathbb Z_{25}\cup\{\infty\},\ 0\le p<4\}.
\]

每个部分是4正则，但依端口安排还可能再分裂；不能无条件声称恰好只有五个叶分量。

在 block 商层面，每个固定 index 的26个 blocks 构成16正则简单图 $Q_i$。它一定连通：一个分量至少含17个顶点，不可能在26点中出现两个分量。因此对角 block 商恰有五个26点分量。叶层连通性不能由此推出。

若对每个组统一施加一个 block 置换 $\pi_g$，原先的五个类只会变为由 $\pi_g(i)$ 描述的五个隐藏类。这是完整图的局部重新命名，不能消除守恒量，不能修复下述距离障碍。

完整图仍然连通，因为组内树连接全部五个 index，而组商为 $K_{26}$。但一片叶从 index $i$ 切换到另一个 index，必须经过同组两个不同 blocks，树代价至少4。**连通不等于能在五步预算内切换 index 并到达另一组。**

## 3. 跨 index 叶对：精确 73,060 个必坏对

沿用 ../m2_hierarchical676/DISTANCE_RULES.md 的精确叶加权图：叶边权1，同 block 跳转权2，同组异 block 跳转权4。

取不同组 $g,h$，叶 $x$ 的 index 为 $i$，叶 $y$ 的 index 为 $j\ne i$。权1叶边与权2同 block 跳转均不能改变 index。任何连接 $x,y$ 的路线必须包含至少一次权4跳转，同时必须至少用一条叶边改变组。总长度要至多5，只能是这两种次序：

\[
\text{叶边1}+\text{组内树路4},
\qquad
\text{组内树路4}+\text{叶边1}.
\]

因此有精确等价式

\[
d_F(x,y)\le5
\iff
x\text{ 有叶邻居位于组 }h
\quad\text{或}\quad
y\text{ 有叶邻居位于组 }g.
\tag{1}
\]

它同时证明了充分性：两个直接接触条件各自给出一条实际至多五步路线。

固定组对颜色 $t$、重数 $q=q_t$。每个 selected block 只有一片叶直接接触对面组，未选 block 则没有。令

\[
a_i=4-\mathbf1_{\{i\in I_t\}},
\]

即组 $g$ 的 index $i$ 中不接触组 $h$ 的叶数；组 $h$ 的对应数相同。由式 (1)，跨不同 index 的坏叶对数恰为

\[
\sum_{i\ne j}a_i a_j
=\left(\sum_i a_i\right)^2-\sum_i a_i^2.
\]

- 三边组对：$a=(3,3,3,4,4)$ 的某个排列，计 $17^2-(3\cdot9+2\cdot16)=230$ 对。
- 四边组对：$a=(3,3,3,3,4)$ 的某个排列，计 $16^2-(4\cdot9+16)=204$ 对。

所以整个图的这部分坏对数固定为

\[
260\cdot230+65\cdot204=\boxed{73060}.
\]

这里每个组对只计一次；两组不同 index 的每对叶恰有一种方向“第一组的 index、第二组的 index”，没有把无序点对加倍。端口选择只改变究竟哪些叶是接触端点，不改变这个总数。同 index 叶对仍可能额外失败。

## 4. 两项额外、互不重叠的统一障碍

### 4.1 跨 index blockhead 对恰有520个必坏

对 $i\ne j$，原精确 block–block 判据中的普通叶图跨 index 路线不可能存在。于是

\[
d_F(B_{g,i},B_{h,j})\le5
\iff i\in I_t\ \text{或}\ j\in I_t.
\]

如果 $i$ 被选，走本 block 叶、直接组间边，再走对面组内至目标 blockhead 的至多三步树路即可；$j$ 被选时对称。两者均未选则所有精确分支均失败。

三边组对有两个未选 index，产生两个不同 index 的 block 对；四边组对只有一个未选 index，不产生这种失败。因此这类坏对精确为

\[
260\cdot2=\boxed{520}.
\]

同 index block 对可能另外失败。

### 4.2 跨 index blockhead–leaf 至少18,720对必坏

固定源组 $g$、目标叶 index $j$，取源组另一个 index $i\ne j$ 的 blockhead。目标叶 $y$ 位于异组且 index为$j$。

blockhead 经本 block 叶出发，若要转到 index $j$ 并改变组，叶间至少需要树跳4加叶边1，连同起始一步已超过5。唯一可能的五步分支，是先在源组树内用3步到达 index $j$ 的某片叶，再走至多两条普通叶边。因此

\[
d_F(B_{g,i},y)\le5
\iff d_{E_j}(L_{g,j},y)\le2.
\tag{2}
\]

$E_j$ 共有104片叶。源 block 的四片叶共向16个不同对面组各发一条边，故恰有16个不同的一步叶邻居。每个邻居除返回源 block 的边外，至多还有三条边。因此

\[
|B^2_{E_j}(L_{g,j})|\le4+16+16\cdot3=68.
\]

至少有 $104-68=36$ 片叶未在半径2内；这36片都在异组，因为源组同 index 的四片叶全在初始集合内。对源组其余四个 blockheads，它们全部由式 (2) 强制为坏对。

对26个组和5个目标 index 求和，得到

\[
26\cdot5\cdot4\cdot36=\boxed{18720}.
\]

每个被计点对由其 blockhead 所在组/索引和目标叶索引唯一确定，没有重复。实际半径2邻域若发生碰撞，坏对会更多。

三类点对的顶点类型不同，故下界可以相加：

\[
\boxed{\#\{\,\{x,y\}:d_F(x,y)>5\,\}\ge
73060+520+18720=92300.}
\]

因此对角骨架已经被纸面排除，改端口排序、均衡或随机种子都不能达到D5。本结论不排除非对角 block 匹配。

## 5. 与已授权循环错位规则对齐的保度替代

对每个组对按标签定向 $g<h$，仍使用同一个有序 selected list

\[
I_t=(b_0,\ldots,b_{q-1}).
\]

将原来的对角配对改为

\[
(g,b_k)\longleftrightarrow(h,b_{k+1\bmod q}).
\tag{3}
\]

反向自然使用逆双射。每端的 selected blocks 都恰被使用一次，因此每个 block 的关联数仍为16；沿用每个 block 的 rank modulo4 端口分配，每叶仍恰有4条叶边。所有组对重数保持3/4，组商保持 $K_{26}$，完整图仍简单且5正则。该论证也适用于每个组对任取一个双射，但本报告只对齐已明确授权的式 (3)，不提出额外方案队列。

### 不能通过每组局部重编号恢复对角的明确见证

取闭合组路线

\[
0\longrightarrow5\longrightarrow\infty\longrightarrow0.
\]

三个组对颜色分别是15、5、0；前两者的 selected list 是 $(0,1,2)$，最后一个 bonus list 是 $(0,1,2,3)$。按式 (3)：

\[
(0,0)\longrightarrow(5,1)\longrightarrow(\infty,2)
\longrightarrow(0,1).
\]

最后一步是 $0<\infty$ 双射的反向。路线返回原组0，却把 block0变成block1。这是一个明确的闭路错位（holonomy）。

若存在每组置换 $\pi_g$ 能把所有边重新变为同 index 对角连接，则任何闭合组路线都应保持重新编号后的 index。然而上式的两端会变成 $\pi_0(0)$ 和 $\pi_0(1)$，仍然不同，矛盾。因此循环错位不是原对角骨架的局部重命名，原来五个全局 index 类的解释不能保留。

**这个 block 层面的三边路线不等于三步叶路线。** 两个中间 block 的入、出边可能占用不同叶端口，各需另走两步树路；也不因此保证任一目标叶的五步覆盖。闭路错位只证明真实改变了守恒结构，不能代替完整距离判据。
